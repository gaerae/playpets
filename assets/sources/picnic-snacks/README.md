# Shared picnic snack prop

`original.png` is the accepted image-generation source for `src/art/props/picnic-snacks.png`. The image replaces the single-cookie care marker with a shared meal on a blanket. It is separate from the collectible picnic gift.

The runtime keeps the full transparent artwork and scales it with the yard. Friends gather behind and beside it; it remains a temporary care action rather than a saved decoration. `generation.json` retains the prompt and generation method.
