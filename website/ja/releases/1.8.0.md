# 1.8.0

<ReleaseMeta />

育った実のなる木が季節に実を落とし、クリックすると友だちが拾います。冬には友だちが紅梅の香りをかぎに行きます。

<Downloads version="1.8.0" />

## 変更点

- 栗・柿・ナラは秋、イチジクと紅梅は夏、ユズは冬に実を落とします。
- 落ちた実をクリックすると友だちが拾いに行き、その日最初の実には特別なひと言を言います。
- 落ちた実はしばらくその場に残ります。別の場所へ行って戻っても同じです。
- 冬には友だちがときどき咲いた紅梅の下に立ち、花の香りをかぎます。
- 紅梅をよりふっくらと描き直し、枝ごとに紅い花が咲きます。
- デスクトップの友だちが、じっとしている間に使う CPU が減りました。

木の育て方は[庭と遊び](../guide/play.md)にあります。
