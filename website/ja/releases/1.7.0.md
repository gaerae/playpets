# 1.7.0

<ReleaseMeta />

コーディングエージェントを手伝う友だちに、ガラス屋根のガーデン工房ができました。外の場所は落ち着いた一つのトーンの新しい絵になり、石造りの中庭は自然の庭になりました。

<Downloads version="1.7.0" />

## 変更点

- くつろぎのリビングの代わりに、ガラス屋根のガーデン工房ができました。
- 工房で働く友だちは鉢植えの台に座り、承認を待つときはベルのそばに立ちます。
- エージェントがいなくても、工房の友だちは本を読み、お茶を飲み、休んでから散歩します。
- 友だちがエージェントの状態を見せます。その場にいて、聞きに来て、戻ります。
- エージェントの状態の点は、名札の中の名前の横にあります。
- 外の場所の絵が新しくなり、芝生はどの季節も同じ落ち着いた緑です。
- 石造りの中庭は自然の庭になりました。池と大きなオークのある広い野原です。
- 友だちも花も木も贈り物も、絵の地面ならドアの前までどこへでも行けます。
- 季節に合う場面を選ぶと、日付に関係なくお祭りが来ます。
- 飾りがツリーの枝に付き、地面の贈り物にやわらかい影が落ちます。
- 夜は贈り物や植物が夜の青に染まり、ランタンが地面を照らします。
- ホタルは少なく、やわらかく、ほのかな光として見えます。
- 友だちは虫取り網と釣りざおを体の前で持ちます。
- 釣りのうきが波紋を立てて水に浮かびます。
- 中秋の満月の夜は、月がまんまるです。
- ドラッグ中の花や木はポインターのすぐ下にあり、持っている間は揺れません。
- にぎやかな庭でも、植えた木をなめらかにドラッグできます。
