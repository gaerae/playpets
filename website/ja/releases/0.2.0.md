# 0.2.0

<ReleaseMeta />

4人の仲間、繰り返し使える制作キット、自由に調整できる庭。ダウンロード欄には、GitHubで公開されたインストールファイルが表示されます。

<Downloads version="0.2.0" />

## 変更点

- Daisy、Clover、PipにカワウソのMisoが加わります。それぞれに春・秋の基本衣装、夏服、冬服があります。
- キャラクターと背景のキットには、参照シート、制作依頼文、スキルが含まれます。選んだツールで制作・検証・パッケージ化し、完成ファイルをアプリに取り込みます。
- ミニモードを、サイズを自由に変えられる枠なしの庭に統合します。最前面表示や全画面表示を切り替え、元のサイズと位置に戻せます。
- 小さなウィンドウでも共通メニューから仲間、招待、設定、場所・雰囲気を開けます。庭を右クリックするか、Cmd/Ctrl+Shift+Pを押します。
- 新しい庭は晴れた春の昼から始まります。案内と操作を整理し、保存済みの仲間や背景設定は保持します。
