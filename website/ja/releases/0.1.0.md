<Shot name="yard-evening" version="0.1.0" caption="夕方の庭で休む3匹。時刻と天気は自動でも手動でも選べます。" />

初めての公開版です。庭で友だちを世話し、デスクトップへ出し、使っているClaude CodeやCodexのサブスクリプションで話せます。コーディングエージェントの作業にも反応します。

### 追加したこと

- 庭でなでたり、おやつを置いたりできます。時刻、天気、季節の風景の中を歩きます。太陽と月は時計に従い、月の満ち欠け、花、紅葉、雨上がりの虹が変わります。名前を探すかくれんぼ、おさんぽ行列、おにごっこで遊べます。名札のクリックで会話を開きます。なでるとハート、おやつと作業完了ではきらめきが出ます。動きを減らす設定ではこれらを止めます。
- 丘、木、雲をアニメーションの背景のように描きます。丸い木は太陽側から照らし、谷の小さな湖は空を映します。
- 湖をクリックすると釣り、沈んだ浮きをクリックすると魚を釣れます。蝶、トンボ、蛍をクリックすると捕まえます。季節、時刻、天気で変わる魚19種と虫16種（各1種はイベント限定）を図鑑に記録します。右上の時計に日時を表示します。
- 桜祭り、蛍の夜、中秋の月、冬の灯り、新年のイベントが庭を変え、期間限定のプレゼントが届きます。
- 風、湖、昼の鳥、暖かい夜の虫、友だちの小さな音があります。既定は控えめで、時計横のスピーカー、設定、⌘/Ctrl + Shift + Sで切れます。
- 一緒の時間と行動でなかよし度が上がります。名札のハートで示し、帰宅の挨拶や自主的な釣りなどが増えます。
- 散歩で見つけた種を植えると、時計に従って季節の2種類のどちらかの花になります。1日1回のプレゼントはベンチ、ランタン、たき火、ブランコ、風鈴など14種類で、好きな場所へ動かせます。
- 初期ペットとしてTabby、Smoky、Mochiを同梱しました。招待タブのPlayPetsの仲間から、初回起動ですぐ招待できます。
- 初回の空の庭に候補を出し、1クリックで招待できます。案内カードが次の手順を示し、完了にチェックを付けます。Claude CodeやCodex CLIがあれば、キーなしで全員へAIを接続できます。
- 設定のスイッチでログイン時に起動できます。デスクトップモードがオンなら友だちだけを表示します。
- ミニモードは庭だけの小窓を最前面に置きます。初回は画面の隅、以後は前回の場所に開き、ポインターを重ねると世話のボタンが出ます。
- デスクトップの友だちはすべてのモニターで歩き、ドラッグでき、目でポインターを追います。重ねると名前のボタンが出て会話を開けます。macOSでは全画面のアプリの上にも出ます。
- 友だちごとにClaude Code、Codex、Ollama、OpenAI互換サーバーを接続できます。性格を設定や会話で変え、複数の友だちと話せます。
- 友だちタブはメッセンジャーのように、名前、状態、関係、なかよし度を上にまとめます。「⋯」で設定、AI接続、会話の消去、送り出しを選べます。最初の質問候補と発言ごとの顔も表示します。
- 関係は友だち、恋人、頼れる先輩、いたずら好きな弟・妹から選び、呼び名も決められます。口調が変わり、友だち同士も互いの関係を知っています。AIなしの言葉にも関係ごとの声があります。
- 庭のおしゃべりボタンでAI付きの友だちが時刻や天気について話します。自動設定なら20分ごとに話します。
- Claude Code、Gemini CLI、Cursorのフック、Codexの通知、MCPで作業に反応し、最近の仕事を話せます。各エージェントを友だちへ割り当て、名札とチップに表示します。頭の点で作業、確認待ち、完了、問題を示します。アプリ本体で受けるためNode.jsは不要です。
- コミュニティページ、GitHubフォルダー、手元のフォルダーから取り込めます。`playpets://import?url=<pet page address>`は確認後に取り込み、招待タブを開きます。出典ごとのグループと種類（すべて、人、動物、その他）で絞れます。
- フォルダーの移動や取り外しでも友だちは失われず、なかよし度を保って待ちます。人数を知らせ、ファイルが戻ると復帰します。
- 한국어、English、日本語、简体中文に対応します。最初はシステム言語に従い、設定で変えるとデスクトップにも反映します。
- 更新は上部のボタンと設定の点で知らせ、変更点、あとで、インストールして再起動を選べます。進捗も表示します。設定は一般、庭、連携、アプリ情報に分かれます。トレイは表示モードをチェックで示し、確認待ちに印を付けます。トレイとmacOSメニューに設定、更新、情報があります。⌘/Ctrl + ,で設定、+1/+2でタブ、+Shift+M/+Shift+Dで表示を切り替えます。
- macOSのdmgには庭の絵とApplicationsへの案内、Windowsのインストーラーにはペットの絵、Linuxのソフトウェアセンターには説明と画面を用意しました。
- 配布形式はmacOS dmg（Apple Silicon/Intel）、WindowsインストーラーとポータブルZIP（x64/arm64）、Linux debとAppImage（x64/arm64）です。試用MSIXだけはローカルビルドです。

### セキュリティ

- ペットの取得は貼り付けたサイト、そのサブドメイン、掲載コミュニティのホストに限り、別サイトを指すページには従いません。名前解決時にプライベートアドレスを拒否します。
- ペットの紹介は命令ではなく説明とラベルを付けてAIへ渡します。会話で保存した性格も同じラベルを保ちます。

### 既知の制限

- 未署名のためGatekeeperやSmartScreenが初回起動を遮断する場合があります。[インストール](../guide/install.md)の説明を確認してください。
- Windows 11 ARMの仮想マシンでx64インストーラーの導入と起動を確認していますが、実機での検証はまだ十分ではありません。
