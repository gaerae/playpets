# 1.3.0

<ReleaseMeta />

Grokが庭にやってきました。Grok Buildの作業中は友だちがそばで見守り、友だちどうしがGrokで会話することもできます。

<Downloads version="1.3.0" />

## 変更点

- Grok Buildが考える、ツールを使う、返事を待つ、終えるたびに友だちが反応します。
- xAI APIキーを入れると、友だちがGrokで会話します。キーはOSの安全な保管場所に保存されます。
- Grokの作業が、Claude CodeやCursorの友だちに混ざって表示されなくなりました。
- <Only os="macOS" /> Appleの署名と公証を受け、すぐに開けます。
- 「種まき」のタイルが狭くても、種の数がはみ出さなくなりました。

## そのほか

- Microsoft Store、winget、macOSのHomebrewからもインストールできます。[インストール](../guide/install.md)をご覧ください。
- ユーザーガイドを書き直し、ボタン名をアプリに合わせました。
- アプリが使うライブラリのセキュリティ更新を含みます。

Grok Buildの設定は[コーディングエージェント連携](../guide/agents.md)をご覧ください。
