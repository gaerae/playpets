# 1.3.0

<ReleaseMeta />

PlayPets 1.3.0ではGrokに対応しました。Grok Buildの作業の様子を友だちが知らせ、友だちどうしがGrokで会話することもできます。macOSアプリは署名と公証を受け、Microsoft Store、winget、Homebrewからもインストールできます。

<Downloads version="1.3.0" />

## 変更点

- Claude Code、Codex、Gemini CLI、CursorにGrok Buildが加わりました。設定 → 開発ツール連携で設定をコピーして`~/.grok/hooks/`に保存すると、Grokが考える、ツールを使う、返事を待つ、終えるといった様子を友だちが知らせます。
- GrokはClaude CodeとCursorのフックも実行します。Grokの作業が、Claude CodeやCursorを担当する友だちに表示されることはなくなりました。
- 友だちがGrokで会話できます。AIを接続するときに**Grok API**を選び、xAI APIキーを入力します。キーはOSの安全な保管場所に保存されます。
- macOSアプリはAppleのDeveloper IDで署名され、Appleの公証を受けているため、「このまま開く」の手順なしで開けます。
- Microsoftが署名したMicrosoft Storeのアプリ、または`winget install --id 9NSKXQ6R187M --source msstore`でインストールできます。macOSでは`brew install gaerae/tap/playpets`でHomebrewからインストールできます。
- 「種まき」のタイルが狭くても、種の数がはみ出さなくなりました。
- ユーザーガイドを4言語すべてで書き直し、ボタン名をアプリに合わせました。
- Linuxのキーリング、アップデートの確認、AI接続に使うRustライブラリのセキュリティ更新を含みます。

詳しくは[コーディングエージェント連携](../guide/agents.md)と[インストール](../guide/install.md)をご覧ください。
