# 1.3.0

<ReleaseMeta />

Grokが庭にやってきました。Grok Buildの作業中は友だちがそばで見守り、友だちどうしがGrokで会話することもできます。

<Downloads version="1.3.0" />

## 変更点

- Grok Buildが考えたり、ツールを使ったり、返事を待ったり、作業を終えたりすると、友だちが反応します。
- xAI APIキーを入力すると、友だちがGrokで会話できます。キーはOSの安全な保管場所に保存されます。
- Grok BuildはClaude CodeとCursorのフックも実行しますが、作業は専用の友だちだけに表示されます。
- <Only os="macOS" /> アプリがAppleの公証を受け、すぐに開けるようになりました。
- 「種を植える」のタイルが狭くても、種の数がはみ出さなくなりました。

## そのほか

- Microsoft Store、winget、macOSのHomebrewからもインストールできます。[インストール](../guide/install.md)をご覧ください。
- ユーザーガイドを書き直し、ボタン名をアプリに合わせました。
- アプリが使うライブラリのセキュリティ更新を含みます。

Grok Buildの設定は[コーディングエージェント連携](../guide/agents.md)、Grokでの会話は[友だちと話す](../guide/chat.md)をご覧ください。
