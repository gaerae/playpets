# 1.0.0

<ReleaseMeta />

PlayPets 1.0.0は小さな窓に風景と友だちを残し、選んだときだけ少し遊べるように整えました。

<Downloads version="1.0.0" />

## 変更点

- 小さな窓では友だちから短い遊びの選択欄を開きます。大きな窓では場所と雰囲気・遊ぶ・メニューを分けました。
- 友だちに穴掘りを頼んで8種類の小さな発見を集め、桜・カエデ・松を植えられます。木はアプリを閉じても育ちます。図鑑ガイドで確率を確認でき、毎日のノルマはありません。
- 家具を友だちに合う大きさにし、メニューの余白と区切りを整えました。
- 更新の進捗は今の庭で確認でき、ダウンロード中は折りたためます。インストールと再起動は自分で選びます。
- 背景制作キットで穴掘りや植樹に使える土を指定できます。
- アプリは1.0.0、MSIXは必須の4桁表記で1.0.0.0です。MSIXはパッケージ管理、GitHub版は署名付きアップデーターで更新します。

Microsoft Storeの審査・公開はGitHubリリースとは別です。このページはStoreでの公開完了を意味しません。
