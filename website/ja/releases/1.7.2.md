# 1.7.2

<ReleaseMeta />

新しい木8種と花8種が庭で育ちます。デスクトップへ出すとすぐ現れ、おしゃべりや保存の最中も庭はなめらかです。

<Downloads version="1.7.2" />

## 変更点

- 新しい木8種と花8種を育てられます。図鑑は185枠になりました。
- いくつかの木の季節の絵を描き直し、育った松はアカマツの姿になりました。
- デスクトップへ出すとすぐに現れます。初めて出すときも、全部戻した直後も同じです。
- 庭が早く開きます。
- 友だちのおしゃべり、コーディングエージェントの知らせ、ポインターの動きの間も庭がなめらかです。
- 長い会話は最新の言葉から開き、上へスクロールすると前の言葉が続いて出ます。
- Windows のノートパソコンをバッテリーで使っていても、友だちがなめらかに歩きます。
- 解像度の違う画面へウィンドウを移しても、背景と天気がくっきりしたままです。
- なでる、景色を選ぶ、ものを動かす、トレイのスイッチが保存を待たなくなりました。
- 友だちが多くても、10分ごとに庭が一瞬止まらなくなりました。
- 背景を読み込んでいても、アプリが早く開き、メモリも少なく済みます。
- 小さなウィンドウでも、パネル、会話、吹き出し、名札がどの言語でも欠けずに収まります。
- 友だちが木や花、贈り物の後ろに立つと手前のものが薄くなり、友だちが見えなくなりません。
- パソコンと一緒に起動してトレイにあるとき、庭が画面に一瞬出なくなりました。
- アプリを初めて開くと、ウィンドウが画面の真ん中に出ます。
- デスクトップの友だちが使う CPU が減りました。画面が複数ある Windows では特にです。

友だちや贈り物を出す方法は[デスクトップモード](../guide/desktop.md)にあります。
