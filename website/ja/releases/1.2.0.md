# 1.2.0

<ReleaseMeta />

PlayPets 1.2.0では、パネルをそれぞれ一画面にまとめ、遊びの道具を持ったまま続けて使えるようにし、月が実際の空に合わせて満ち欠けします。

<Downloads version="1.2.0" />

## 変更点

- 「場所と雰囲気」「遊ぶ」「友だちと設定」は、タブや戻るボタンのない一画面のまとまりになりました。「遊ぶ」は見つける、庭、みんなで遊ぶに分かれ、遊んでいるゲームはそのタイルをもう一度押すと終わります。
- 穴掘りと木を植える道具は持ったまま続けて使えます。場所を選ぶたびに手の空いた次の友だちが向かい、Escでしまうまで1、2、3で穴掘り、木、種を切り替えられます。空いた地面を右クリックすると「ここを掘る」、友だちを右クリックすると話す、遊ぶ、掘ってもらうが出ます。
- 設定 →「友だちとAI」で「ときどき自分で穴を掘って遊びます」をオンにすると、手の空いた友だちがときどき自分で穴を掘ります。
- 友だちの名札を押すと会話が開きます。花や木を抜いたり贈り物を片付けたりするとすぐに消え、下の通知から数秒間元に戻せます。元に戻せないことだけを先に確認します。
- 設定 →「友だちとAI」ですべてのAI接続を管理でき、編集はその場で開きます。大きな窓では設定の一覧が横に残り、小さな窓ではまとまりを一つずつ開きます。「PlayPets について」はリンクをまとめて表示し、データフォルダーも開けます。「アプリのアップデート」からは使っているバージョンの変更点を見られます。
- 遊びの案内、発見のカード、通知など、庭からのお知らせはすべて下のバーのすぐ上の一か所に表示され、重なったカードは消し合わずに順番を待ちます。
- 小さな窓では、ポインターを窓に重ねたときだけ隅のメニューボタンが表示され、デスクトップには庭だけが残ります。
- 夜は星が丘の向こうの空にだけ出て、月は実際の形で満ち欠けします。中秋の名月のイベントは9月8日から始まり、十五夜のように、期間中最初の満月のころに大きな黄金色の月が昇ります。
- ダークモードでも名札と吹き出しが絵の庭の上で読みやすくなり、日本語、中国語、韓国語の文が単語の途中で改行されなくなりました。

詳しくは[庭と遊び](../guide/play.md)と[設定](../guide/settings.md)をご覧ください。
