# 1.1.0

PlayPets 1.1.0は開発中です。以下のダウンロードはGitHubリリースの公開後に利用できます。

<Downloads version="1.1.0" />

## 準備中の変更

- Daisy、Clover、Pip、Misoが、季節の服に合わせた穴掘り、植え付け、釣り、発見の専用モーションを見せます。読み込んだペットは元のアニメーションシートを使い続けます。
- 季節の花、水辺の生きもの、昆虫、贈りもの、木、小さな発見を集め、100種類の図鑑を完成させます。ガイドは正確な確率ではなく、役立つ生息条件を案内します。
- 穴掘りで苗木を見つけ、ポケットに集めます。植えるときに手持ちの苗木を1本使います。桜、カエデ、松、オーク、シラカバ、ヤナギの6種類があり、植えた木はアプリを閉じても育ちます。
- 17種類の小さな発見を集められます。種は穴掘りで手に入り、花の種と木の苗木を同じ探索で見つけられます。
- 起動20秒後、その後は6時間ごとに静かに更新を確認し、失敗した場合も静かに再試行します。新しいバージョンを表示するだけで、設定を開いたりインストールを始めたりしません。
- 設定の「PlayPets について」で確認結果、変更内容、ダウンロードの進捗、エラー、再試行をまとめて確認できます。**インストールして再起動**を選ぶと開始します。ダウンロード中に設定を閉じても続行し、開き直しても重複して開始しません。
- Microsoft Storeパッケージは、引き続き独立したパッケージ管理で更新します。
- 小さいウィンドウでも大きいウィンドウでも庭を隠しすぎないよう、風景、遊び、管理の操作を簡潔にまとめました。

詳しくは[発見ガイド](../guide/play.md#discovery-guide)と[更新手順](../guide/install.md#updates)をご覧ください。Microsoft Storeの審査、公開はGitHubでの公開とは別です。
