# 設定

- **友だちと設定 → 設定**には次のまとまりがあります。
  - **言語と起動**
  - **友だちとAI**
  - **開発ツール連携**（[別の説明](./agents.md)があります）
  - **アプリのアップデート**
  - **PlayPets について**
- 新しいバージョンがあると、メニューの**設定**に点が付きます。
- 季節、音、音量は**場所と雰囲気 → 雰囲気**で調整します。

| | 大きな窓 | 小さな窓 |
|---|---|---|
| 表示 | システム設定のように一覧が左に残り、選んだまとまりが隣に開きます。もう一度開くと、最後に見ていたまとまりが出ます | 一覧から始まり、まとまりを一つずつ開きます |
| 戻る操作 | 友だちと設定へ戻ります | まとまりからは設定の一覧へ、一覧からは友だちと設定へ戻ります |

- トレイとmacOSのメニューバーの**PlayPets について**、**アップデートを確認…**、更新の案内は、そのまとまりを直接開きます。
  - 小さな窓では、このときも戻る操作で一覧へ戻ります。
- 閉じると風景へ戻ります。

## 言語 <Since v="0.1.0" />

- 한국어、English、日本語、简体中文から選べます。
- 最初はシステムの言語に従います。
- 変更すると、庭とデスクトップのウィンドウを新しい言語で読み込み直します。トレイメニューとウィンドウのタイトルも変わります。
- 選んだ言語は`state.json`の`language`に保存します。
- 友だちの独り言と挨拶は、選んだ言語になります。
- AIも基本的にその言語で答えます。新しいメッセージで別の言語を指定できます。
- 言語を変えると、生成中の返答は中止されます。以前の会話は翻訳されず、そのまま残ります。
- コーディングエージェントと端末には英語を使います。
- 環境変数`PLAYPETS_LANG=ko|en|ja|zh-hans`を付けて起動すると、保存された言語より優先します（テスト用）。

## ログインしたらPlayPetsも起動する <Since v="0.1.0" />

- オンにすると、コンピューターにログインするたびにPlayPetsが起動します。既定はオフです。
- デスクトップモードがオンなら、ログイン時に庭の窓は開きません。友だちがデスクトップに出て、窓はトレイで待ちます。
- この選択はシステムが保管します（macOSのログイン項目、WindowsのRun一覧、Linuxの自動起動項目）。どちらでオフにしてもオフになります。

## 友だちとAI <Since v="1.2.0" />

- **友だちとAI**には、すべてのAI接続が、使っている友だちの数と一緒に並びます。
- **編集**か、新しい接続を追加する**AIを接続する**を押すと、このまとまりの中に接続のフォームが開きます（設定の上に画面を重ねません）。
- **Esc**でフォームを閉じます。
  - 入力した内容がある場合は閉じず、「変更があります。保存するか、変更を破棄する場合は「キャンセル」を押してください。」と表示します。
- ここで接続を編集しても、友だちがその接続に移ることはありません。
- 接続がなくても、友だちは遊んだり反応したりします。
- 接続の作り方は[友だちと話す](./chat.md#connect)にあります。

## ときどき友だち同士で話します <Since v="0.1.0" />

- **友だちとAI**のこのスイッチをオンにすると、AIを接続した友だちが20分ごとに短くおしゃべりします。
- 既定はオフです。使いたいときにオンにしてください。
- この呼び出しは、サブスクリプションの利用枠か接続先の料金を使います。ローカルのOllamaモデルにはホスト型推論の料金はかかりません。
- 窓が隠れているときや誰かが返答している間は、その回を見送ります。

## ときどき自分で穴を掘って遊びます <Since v="1.2.0" />

- **友だちとAI**のこのスイッチをオンにすると、庭が表示されている間、手の空いた友だちが数分ごとに、自分で選んだ場所を1か所掘ります。
- 既定はオフです。AI接続は不要です。
- 掘らないとき：
  - ゲーム中や、道具を手にしている間
  - くつろぎのリビングのように、土のない場所
- 見つけたものは、ほかの穴掘りと同じように残ります。

## PlayPets について <Since v="0.1.0" />

- **PlayPets について**には、バージョンと3つのまとまりがあります。
  - **ヘルプ**：使い方、問題を報告、**データフォルダーを開く**（友だち、設定、バックアップの保存場所。[データフォルダー](#data-folder)を参照）
  - **プロジェクト**：サイト、リリースノート、GitHub
  - **プライバシーとライセンス**
- リンクはブラウザーで開きます。
- 更新は**アプリのアップデート**で行います。

## アプリのアップデート <Since v="0.1.0" /> {#updates}

- Microsoft Store版の更新はStoreが管理します。**Microsoft Store → ライブラリ**で確認してください。
- 以下のGitHubインストーラーによる更新は、MSIX以外のインストールに適用されます。テスト用MSIXもパッケージ管理による更新を使います。
- 保存と外部通信は[プライバシーポリシー](../privacy.md)をご覧ください。
- この行には現在のバージョンが表示されます。
- **アップデートを確認**を押すと、GitHubリリースの`latest.json`を読みます。最新なら**最新バージョンです**と表示します。
- 起動20秒後に静かに確認し、6時間ごとに再確認します。手動でも確認できます。
- インストールは選んだときだけ行います。そのことは項目の下にも書かれています。
- **このバージョンの変更点**は、使っているバージョンのリリースページを開きます。
- 更新の案内から**友だちと設定 → 設定 → アプリのアップデート**を開きます。
- **変更点を見る**は、ブラウザーでリリースページを開きます。
- 次はすべてアプリのアップデート内で行います。別の更新ウィンドウは開きません。
  - **インストールして再起動**
  - ダウンロードの進捗、検証、インストール
  - 失敗時の再試行
- サイズが不明な場合は、割合なしで進捗を表示します。
- 再起動後も友だちと設定は残ります。インストールしたバージョンを短く通知します。

## PlayPets を終了 <Since v="0.1.0" />

| 操作 | 結果 |
|---|---|
| **友だちと設定**の**ウィンドウを閉じる** | 庭をトレイに隠します。デスクトップの友だちやエージェント連携は動き続けます |
| その隣の**PlayPets を終了** | 確認なしにすぐ終了します。トレイの**PlayPets を終了**やmacOSの<kbd>⌘</kbd> <kbd>Q</kbd>と同じです |

- 会話は保存されません。
- 背景の右クリックには終了操作が直接出ません。先に**友だちと設定**を開きます。

## メニューとショートカット <Since v="0.1.0" />

**トレイメニュー**（メニューバーやタスクバーの猫）

- 項目：**庭を開く**、友だちがいるときの**友だち**、**友だちを招待…**、**常に手前に表示**、**デスクトップに表示**、デスクトップ表示中の**デスクトップでおさんぽ**、**庭の音**、**設定…**、**アップデートを確認…**、**PlayPets について**、**PlayPets を終了**
- 友だちがいなくても**常に手前に表示**は使えます。
- デスクトップの切り替えは、友だちが来ると表示されます。
- 音がオンならチェックが付きます。
- 更新があれば**v… にアップデート…**と表示されます。
- Windowsでは左クリックで庭、右クリックでメニューを開きます。
- エージェントの確認待ちは青、問題は赤の印で伝え、ツールチップに友だちの名前が出ます。

**macOSのメニューバー**

- **PlayPets**：**PlayPets について**、**アップデートを確認…**、**設定…**、非表示、**PlayPets を終了**
- **編集**：テキスト欄でのカット、コピー、ペースト
- **表示**：**友だちと設定**、**友だち**、**友だちを招待…**、チェックで切り替える**常に手前に表示**と**デスクトップに表示**（デスクトップの切り替えは、友だちが来るまで灰色で使えません）、チェックで切り替える**庭の音**
- **ウインドウ**

**ショートカット**（macOSは<kbd>⌘</kbd>、WindowsとLinuxは<kbd>Ctrl</kbd>）

| キー | 操作 |
|---|---|
| <kbd>⌘</kbd> <kbd>1</kbd> | **友だちと会話**を開く |
| <kbd>⌘</kbd> <kbd>2</kbd> | **友だちを招待**を開く |
| <kbd>⌘</kbd> <kbd>,</kbd> | 設定を開く |
| <kbd>⌘</kbd> <kbd>Shift</kbd> <kbd>P</kbd> | 友だちと設定を開く |
| <kbd>⌘</kbd> <kbd>Shift</kbd> <kbd>M</kbd> | 常に手前に表示のオン、オフ |
| <kbd>⌘</kbd> <kbd>Shift</kbd> <kbd>D</kbd> | デスクトップに表示のオン、オフ |
| <kbd>⌘</kbd> <kbd>Shift</kbd> <kbd>S</kbd> | 庭の音のオン、オフ |
| <kbd>⌘</kbd> <kbd>Q</kbd> | PlayPets を終了（macOS） |

## データフォルダー <Since v="0.1.0" /> {#data-folder}

| OS | 場所 |
|---|---|
| macOS | `~/Library/Application Support/app.playpets/` |
| Windows | `%APPDATA%\app.playpets\` |
| Linux | `~/.local/share/app.playpets/` |

| ファイル | 内容 |
|---|---|
| `state.json` | 友だち（名前、性格と出典、関係、あなたの呼び方、大きさ、位置、選んだAI接続）、AI接続の一覧（キーは除く）、言語、デスクトップモードと散歩、各エージェントの担当の友だち、自動おしゃべり、自動の穴掘り、庭の音とその音量、ウィンドウの位置と大きさ、常に手前に表示の設定、花と飾り（`garden`）、図鑑（`album`）、なかよし度（`bonds`）、自分で選んだペットフォルダー、ファイルの形式番号（`schema`）。新しいバージョンが書いたファイルは別にコピーしてから、このバージョンが理解できる部分だけを読みます |
| `bridge.json` | エージェント連携のポートとトークン。起動のたびに書き直します |
| `pets/` | URLから取り込んだペットフォルダー |
| `builtin/` | 付属の4種類の仲間。起動のたびに展開して確認します。それぞれ独立した基本画像を持っています |

**起動時に友だちを読み込めなかったとき**
- 下のバーのすぐ上に、折りたたまれた**起動時のお知らせ**カードが出ます。庭の表示領域は狭くなりません。
- カードを開いて詳細を確認してください。
- ペットファイルが見つからない場合：元のペットフォルダーとファイルを確認し、必要なら復元してから、PlayPetsを終了して開き直してください。
- 友だちが上限の12人に達している場合：空きを作ってから開き直してください。
- お知らせが出ても、保存された友だちの記録は削除されません。
- カードを閉じると今回の起動中は非表示になり、新しいお知らせが届くと再び表示されます。

## 環境変数

| 変数 | 内容 |
|---|---|
| `PLAYPETS_DATA` | データフォルダーを別の場所へ移します。端末コマンド（`playpets say`など）も同じ値を読みます |
| `CODEX_HOME` | Codexのホームフォルダー。**友だちを招待**のCodexペットフォルダーが`$CODEX_HOME/pets`になります |
| `PLAYPETS_LANG` | 言語を固定します（`ko`、`en`、`ja`、`zh-hans`） |
| `PLAYPETS_PET` | 端末コマンドの既定の友だち。`--pet`オプションと同じです |
| `PLAYPETS_BRIDGE` | 端末コマンドが読む`bridge.json`のパス。`--bridge`オプションと同じです |

- 変数はアプリを起動する環境で設定してください。端末からアプリを起動するか、OSの環境変数の設定を使います。

## 保存するもの、しないもの <Since v="0.1.0" />

**保存するもの**

- 友だちそれぞれの名前、性格、関係、あなたの呼び方、大きさ、庭での位置
- 友だちそれぞれのなかよし度
- 花、庭の飾り、図鑑
- AI接続それぞれの種類、サーバーのアドレス、モデル名
- 言語、デスクトップモードと散歩、ウィンドウの位置と大きさ、常に手前に表示の設定、選んだ時間帯、天気、季節
- 取り込んだペットファイルとその出典

**別の方法で保存するもの**

- APIキーは`state.json`に入れません。
  - このコンピューターの安全な保管場所（macOSのキーチェーン、Windowsの資格情報マネージャー、LinuxのSecret Service）にだけ保管します。
  - 接続を削除すると、キーも削除します。

**保存しないもの**

- 友だちとの会話。メモリーの中にだけあり、アプリを終了すると消えます。
- コーディングエージェントの最近の活動の記憶。アプリを終了すると消えます。
- ゲーム中の位置。ゲームが終わると、友だちは元の場所へ戻ります。

アンインストール後にすべての痕跡を消すには、データフォルダーと、安全な保管場所にあるPlayPetsの項目も削除してください。
