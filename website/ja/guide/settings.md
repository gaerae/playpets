# 設定

**友だちと設定 → 設定**を開くと、**言語と起動**、**友だちとAI**、**開発ツール連携**、**アプリのアップデート**、**PlayPets について**の5つのまとまりがあります。**開発ツール連携**は[別のページ](./agents.md)で説明しています。

季節や音、音量は**場所と雰囲気 → 雰囲気**で調整します。新しいバージョンが出ると、メニューの**設定**に点が付きます。

| | 大きな窓 | 小さな窓 |
|---|---|---|
| 表示 | システム設定のように一覧が左に残り、選んだまとまりが隣に開きます。もう一度開くと、最後に見ていたまとまりが出ます | 一覧から始まり、まとまりを一つずつ開きます |
| 戻る操作 | 友だちと設定へ戻ります | まとまりからは設定の一覧へ、一覧からは友だちと設定へ戻ります |

- トレイとmacOSのメニューバーの**PlayPets について**、**アップデートを確認…**、更新の案内は、そのまとまりを直接開きます。小さな窓では、このときも戻る操作で一覧へ戻ります。
- 閉じると風景へ戻ります。

## 言語 <Since v="0.1.0" />

한국어、English、日本語、简体中文から選べます。最初はシステムの言語に合わせます。

言語を変えると、庭とデスクトップのウィンドウが新しい言語で読み込み直され、トレイメニューとウィンドウのタイトルも切り替わります。作成中だった返答は中止されます。それまでの会話は翻訳せず、そのまま残ります。

友だちのあいさつや独り言は、選んだ言語になります。AIも基本はその言語で答えますが、別の言語で聞きたいときは新しいメッセージでそう頼んでください。コーディングエージェントと端末には英語で話します。

- 選んだ言語は`state.json`の`language`に保存します。
- テスト用：環境変数`PLAYPETS_LANG=ko|en|ja|zh-hans`を付けて起動すると、その回だけ保存された言語より優先します。保存された言語は変わりません。

## ログインしたらPlayPetsも起動する <Since v="0.1.0" />

オンにすると、コンピューターにログインするたびにPlayPetsも起動します。最初はオフです。

デスクトップモードがオンのときは、ログインしても庭の窓は開きません。友だちだけがデスクトップに出てきて、窓はトレイで待っています。

この選択はシステム側が覚えています。macOSではログイン項目、Windowsではスタートアップ アプリ、Linuxでは自動起動項目です。どちらでオフにしてもオフになります。

Microsoft Store版では、Windows側でオフにしたPlayPetsをアプリから再びオンにはできません。Windowsの **設定 → アプリ → スタートアップ** でオンにしてください。

## 友だちとAI <Since v="1.2.0" />

ここにはすべてのAI接続が、それぞれを使っている友だちの数と一緒に並びます。接続がまだなくても、友だちは遊んだり反応したりします。

**編集**か、新しい接続を追加する**AIを接続する**を押すと、別の画面は重ならず、このまとまりの中に接続のフォームが開きます。ここで接続を編集しても、友だちがその接続に移ることはありません。

- **Esc**でフォームを閉じます。入力した内容がある場合は閉じずに「変更があります。保存するか、変更を破棄する場合は「キャンセル」を押してください。」と表示します。
- 接続の作り方は[友だちと話す](./chat.md#connect)にあります。

## ときどき友だち同士で話します <Since v="0.1.0" />

**友だちとAI**にあるスイッチで、最初はオフです。オンにすると、AIを接続した友だちが20分ごとに短くおしゃべりします。窓が隠れているときや、誰かが返答している間は、その回を見送ります。

おしゃべりのたびに、サブスクリプションの利用枠か接続先の料金を使います。ローカルのOllamaモデルなら、ホスト型推論の料金はかかりません。使いたいときだけオンにしてください。

## ときどき自分で穴を掘って遊びます <Since v="1.2.0" />

これも**友だちとAI**にあるスイッチです。最初はオフで、AI接続はいりません。オンにすると、庭が表示されている間、手の空いた友だちが数分ごとに自分で選んだ場所を1か所掘ります。見つけたものは、ほかの穴掘りと同じように残ります。

次のときは自分では掘りません。
- ゲーム中
- 道具を手にしている間
- くつろぎのリビングのように、土のない場所

## PlayPets について <Since v="0.1.0" />

バージョンと、3つのまとまりが表示されます。リンクはブラウザーで開きます。アップデートは**アプリのアップデート**のほうで扱います。

- **ヘルプ**：使い方、問題を報告、**データフォルダーを開く**（友だち、設定、バックアップの保存場所。[データフォルダー](#data-folder)を参照）
- **プロジェクト**：サイト、リリースノート、GitHub
- **プライバシーとライセンス**：プライバシーポリシー、ライセンス

## アプリのアップデート <Since v="0.1.0" /> {#updates}

Microsoft Storeから入れた場合、更新はStoreが管理します。**Microsoft Store → ライブラリ**で確認してください。テスト用MSIXも、パッケージ管理による更新を使います。以下のGitHubインストーラーによる更新は、MSIX以外でインストールした場合の説明です。

何を保存し、どこと通信するかは[プライバシーポリシー](../privacy.md)にまとめています。

- この行には現在のバージョンが表示されます。
- **アップデートを確認**を押すと、GitHubリリースの`latest.json`を読みます。最新なら**最新バージョンです**と表示します。
- 起動20秒後に静かに確認し、6時間ごとに再確認します。手動でも確認できます。
- インストールは選んだときだけ行います。そのことは項目の下にも書かれています。
- **このバージョンの変更点**は、使っているバージョンのリリースページを開きます。
- 更新の案内から**友だちと設定 → 設定 → アプリのアップデート**を開きます。
- **変更点を見る**は、ブラウザーでリリースページを開きます。
- 次はすべてアプリのアップデート内で行います。別の更新ウィンドウは開きません。
  - **インストールして再起動**
  - ダウンロードの進捗、検証、インストール
  - 失敗時の再試行
- サイズが不明な場合は、割合なしで進捗を表示します。

再起動しても友だちと設定はそのまま残り、インストールしたバージョンを短く知らせます。

## PlayPets を終了 <Since v="0.1.0" />

| 操作 | 結果 |
|---|---|
| **友だちと設定**の**ウィンドウを閉じる** | 庭をトレイに隠します。デスクトップの友だちやエージェント連携は動き続けます |
| その隣の**PlayPets を終了** | 確認なしにすぐ終了します。トレイの**PlayPets を終了**やmacOSの<kbd>⌘</kbd> <kbd>Q</kbd>と同じです |

終了すると、会話は保存されません。背景を右クリックしても終了の操作は直接出てこないので、先に**友だちと設定**を開いてください。

## メニューとショートカット <Since v="0.1.0" />

庭の上のほうにポインターを動かすと、ウィンドウサイズのリセット、最小化、閉じるのボタンが出ます。**ウィンドウサイズをリセット**は背景の右クリックメニューにもあります。モニターを外してウィンドウが収まらなくなったときは、残った画面の中へ自動で戻ります。

**トレイメニュー**（メニューバーやタスクバーの猫）

- 項目：**庭を開く**、友だちがいるときの**友だち**、**友だちを招待…**、**ウィンドウサイズをリセット**、**常に手前に表示**、**デスクトップに表示**、デスクトップ表示中の**デスクトップでおさんぽ**、**庭の音**、**設定…**、**アップデートを確認…**、**PlayPets について**、**PlayPets を終了**
- 友だちがいなくても**常に手前に表示**は使えます。
- デスクトップの切り替えは、友だちが来ると表示されます。
- 音がオンならチェックが付きます。
- 更新があれば**v… にアップデート…**と表示されます。
- Windowsでは左クリックで庭、右クリックでメニューを開きます。
- エージェントの確認待ちは青、問題は赤の印で伝え、ツールチップに友だちの名前が出ます。

**macOSのメニューバー**

- **PlayPets**：**PlayPets について**、**アップデートを確認…**、**設定…**、非表示、**PlayPets を終了**
- **編集**：テキスト欄でのカット、コピー、ペースト
- **表示**：**友だちと設定**、**友だち**、**友だちを招待…**、チェックで切り替える**常に手前に表示**と**デスクトップに表示**（デスクトップの切り替えは、友だちが来るまで灰色で使えません）、チェックで切り替える**庭の音**
- **ウインドウ**：**ウィンドウサイズをリセット**、しまう、閉じる

**ショートカット**（macOSは<kbd>⌘</kbd>、WindowsとLinuxは<kbd>Ctrl</kbd>）

| キー | 操作 |
|---|---|
| <kbd>⌘</kbd> <kbd>1</kbd> | **友だちと会話**を開く |
| <kbd>⌘</kbd> <kbd>2</kbd> | **友だちを招待**を開く |
| <kbd>⌘</kbd> <kbd>,</kbd> | 設定を開く |
| <kbd>⌘</kbd> <kbd>Shift</kbd> <kbd>P</kbd> | 友だちと設定を開く |
| <kbd>⌘</kbd> <kbd>Shift</kbd> <kbd>M</kbd> | 常に手前に表示のオン、オフ |
| <kbd>⌘</kbd> <kbd>Shift</kbd> <kbd>D</kbd> | デスクトップに表示のオン、オフ |
| <kbd>⌘</kbd> <kbd>Shift</kbd> <kbd>S</kbd> | 庭の音のオン、オフ |
| <kbd>⌘</kbd> <kbd>0</kbd> | ウィンドウサイズをリセット |
| <kbd>⌘</kbd> <kbd>Q</kbd> | PlayPets を終了（macOS） |

## データフォルダー <Since v="0.1.0" /> {#data-folder}

| OS | 場所 |
|---|---|
| macOS | `~/Library/Application Support/app.playpets/` |
| Windows | `%APPDATA%\app.playpets\`。Microsoft Store（wingetで入れた場合も）：パッケージ専用のフォルダー内 |
| Linux | `~/.local/share/app.playpets/` |

| ファイル | 内容 |
|---|---|
| `state.json` | 友だち（名前、性格と出典、関係、あなたの呼び方、大きさ、位置、選んだAI接続）、AI接続の一覧（キーは除く）、言語、デスクトップモードと散歩、各エージェントの担当の友だち、自動おしゃべり、自動の穴掘り、庭の音とその音量、ウィンドウの位置と大きさ、常に手前に表示の設定、庭で選んだ場所、季節、時間帯、天気（`scene`）、花と飾り（`garden`）、図鑑（`album`）、なかよし度（`bonds`）、自分で選んだペットフォルダー、ファイルの形式番号（`schema`）。新しいバージョンが書いたファイルは別にコピーしてから、このバージョンが理解できる部分だけを読みます |
| `bridge.json` | エージェント連携のポートとトークン。起動のたびに書き直します |
| `pets/` | URLやZIPから取り込んだペットフォルダー |
| `backgrounds/` | 取り込んだ背景。背景ごとに1ファイルです |
| `builtin/` | 付属の4種類の仲間。起動のたびに展開して確認します。それぞれ独立した基本画像を持っています |

**起動時に友だちを読み込めなかったとき**

下のバーのすぐ上に、折りたたまれた**起動時のお知らせ**カードが出ます。庭の表示領域は狭くなりません。カードを開いて詳細を確認してください。

ペットファイルが見つからない場合：
1. 元のペットフォルダーとファイルを確認します。
2. 必要なら復元します。
3. PlayPetsを終了して、開き直します。

友だちが上限の12人に達している場合は、空きを作ってから開き直してください。

お知らせが出ても、保存された友だちの記録は消えません。カードを閉じると今回の起動中は表示されなくなり、新しいお知らせが届くとまた出てきます。

## 環境変数

| 変数 | 内容 |
|---|---|
| `PLAYPETS_DATA` | データフォルダーを別の場所へ移します。端末コマンド（`playpets say`など）も同じ値を読みます |
| `CODEX_HOME` | Codexのホームフォルダー。**友だちを招待**のCodexペットフォルダーが`$CODEX_HOME/pets`になります |
| `PLAYPETS_LANG` | 言語を固定します（`ko`、`en`、`ja`、`zh-hans`） |
| `PLAYPETS_PET` | 端末コマンドの既定の友だち。`--pet`オプションと同じです |
| `PLAYPETS_BRIDGE` | 端末コマンドが読む`bridge.json`のパス。`--bridge`オプションと同じです |

- 変数は、アプリを起動する環境で設定してください。端末からアプリを起動するか、OSの環境変数の設定を使います。

## 保存するもの、しないもの <Since v="0.1.0" />

**保存するもの**

- 友だちそれぞれの名前、性格、関係、あなたの呼び方、大きさ、庭での位置
- 友だちそれぞれのなかよし度
- 花、庭の飾り、図鑑
- AI接続それぞれの種類、サーバーのアドレス、モデル名
- 言語、デスクトップモードと散歩、ウィンドウの位置と大きさ、常に手前に表示の設定、選んだ時間帯、天気、季節
- 取り込んだペットファイルとその出典

**別の方法で保存するもの**

- APIキーは`state.json`に入れません。
  - このコンピューターの安全な保管場所（macOSのキーチェーン、Windowsの資格情報マネージャー、LinuxのSecret Service）にだけ保管します。
  - 接続を削除すると、キーも削除します。

**保存しないもの**

- 友だちとの会話。メモリーの中にだけあり、アプリを終了すると消えます。
- コーディングエージェントの最近の活動の記憶。アプリを終了すると消えます。
- ゲーム中の位置。ゲームが終わると、友だちは元の場所へ戻ります。

アンインストールしたあと跡をすべて消したいときは、データフォルダーに加えて、安全な保管場所にあるPlayPetsの項目も削除してください。
