# 設定

**メニュー → 設定**、<kbd>⌘</kbd>/<kbd>Ctrl</kbd> <kbd>,</kbd>、またはトレイの「設定…」で開きます。設定は庭の上に開き、外側をクリックするか<kbd>Esc</kbd>で閉じます。「一般」（言語・ログイン時の起動）、「庭」（季節・自動おしゃべり・音）、「コーディングエージェント連携」、「PlayPets について」（ロゴ・バージョン・更新・プロジェクトへのリンク）の4つに分かれています。[コーディングエージェント連携](./agents.md)は別のページで説明します。

タイトルと目次は固定され、選んだ項目だけがスクロールします。別のグループを選ぶと内容が切り替わり、設定を開き直すと最後に見ていたグループを表示します。アプリの終了は「PlayPets について」にあります。

## 季節

「設定 → 庭 → 季節」で自動、春、夏、秋、冬を選びます。自動はローカルの暦に従います。選んだ季節は保存され、通常モードとミニモードの風景と、友だちの季節の服装を変えます。デスクトップの友だちも同じ季節に従い、反映には最大1分かかることがあります。春と秋は普段の重ね着を使います。お祭りは実際の日付に開かれます。

## 言語 <Since v="0.1.0" />

한국어、English、日本語、简体中文から選べます。最初はシステムの言語に従い、変更すると庭とデスクトップのウィンドウを新しい言語で読み込み直します。トレイメニューとウィンドウのタイトルも変わります。選んだ言語は`state.json`の`language`に保存します。

友だちの独り言と挨拶は選んだ言語になります。AIも基本的にその言語で答えますが、新しいメッセージで別の言語を指定できます。言語を変えると生成中の返答は中止され、以前の会話は翻訳されずそのまま残ります。コーディングエージェントと端末には英語を使います。

環境変数`PLAYPETS_LANG=ko|en|ja|zh-hans`を付けて起動すると、保存された言語より優先します。テスト用です。

## ログインしたらPlayPetsも起動する <Since v="0.1.0" />

オンにすると、コンピューターにログインするたびにPlayPetsが起動します。既定はオフです。デスクトップモードがオンなら、ログイン時に庭の窓は開きません。友だちがデスクトップに出てきて、窓はトレイで待ちます。この選択はシステムが保管するので（macOSのログイン項目、WindowsのRun一覧、Linuxの自動起動項目）、どちらでオフにしてもオフになります。

## ときどき友だち同士で話します <Since v="0.1.0" />

「庭」にあるこのスイッチをオンにすると、AIを接続した友だちが20分ごとに短くおしゃべりします。既定はオフです。この呼び出しはサブスクリプションの利用枠か、接続先の料金を使います。ローカルのOllamaモデルにはホスト型推論の料金はかかりません。使いたいときにオンにしてください。窓が隠れているときや誰かが返答している間は、その回を見送ります。

## 庭の音 <Since v="0.1.0" />

庭には庭の音があります。そよ風、湖の小さな波、葉を揺らす風、昼の鳥（朝がいちばん多いです）、夏と秋の夜の虫、雨の日の雨音です。友だちも小さな音を立てます。なでるとやわらかい音、魚がかかるとぽちゃん、釣り上げるとばしゃん、プレゼントや新しいなかよし度の段階には短いメロディーが鳴ります。音は時間帯、天気、季節で変わります。

- 最初から小さな音量でオンになっていて、窓の中を初めてクリックした後に鳴り始めます。
- 庭が見えている間だけ鳴ります。窓が隠れているときや最小化されているとき、デスクトップにだけ友だちが出ているときは静かです。ミニモードでは鳴り続けます。
- オン・オフは、**メニュー**のスピーカー、トレイの「庭の音」、このスイッチ、macOSのメニューバーの「表示」→「庭の音」、または<kbd>⌘</kbd>/<kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>S</kbd>で切り替えます。スイッチの下の「音量」スライダーで大きさを決めます。

## PlayPets について <Since v="0.1.0" />

設定タブの最後のグループにはバージョンと「アプリのアップデート」があり、このサイトのページとGitHubのプロジェクトを開けます。「ウェブサイト」、「使い方」、「リリースノート」、「GitHub」、「問題を報告」（新しいイシュー）、「ライセンス」（MIT）があり、ブラウザーで開きます。

### アプリのアップデート <Since v="0.1.0" /> {#updates}

この行には現在のバージョンが表示されます。「アップデートを確認」を押すとGitHubリリースの`latest.json`を読み、最新なら「最新バージョンです」と表示します。

新しいバージョンがあると、この確認でも、アプリの起動20秒後の静かな確認でも、メニューからの確認でも、次のようになります。

- 庭の下部にある操作バーのいちばん左、場所選択の前に新バージョンのボタンが表示され続けます。**メニュー**内の「設定」にも点が付きます。
- ボタンを押すとアップデートの窓が開きます。「変更点を見る」はこのサイトのそのバージョンのページを開き、「あとで」は次の起動までアップデートのボタンをしまいます（行と点は残ります）。「インストールして再起動」を押すと、ダウンロードの進捗、署名の確認、インストールを順に表示してからアプリが再起動します。ダウンロードサイズが不明な場合は割合のない進捗バーが動きます。失敗した場合は同じ窓で理由を確認して再試行できます。友だちと設定はそのままです。再起動後、インストールしたバージョンを短い通知で知らせます。
- 「PlayPets について」の行にも「変更点を見る」があり、インストール前に同じアップデートの窓が開きます。

確認できなかった場合はネットワークを確認してください。また、WindowsのポータブルZIPは自動アップデートの対象外です。詳しくは[インストール](./install.md#updates)を参照してください。

## アプリを完全に終了 <Since v="0.1.0" />

庭の窓の閉じるボタンは窓を隠すだけで、アプリはトレイに残ります。デスクトップの友だちとエージェント連携は動き続けます。

本当に終了するには、**メニュー → 設定 → PlayPets について**の「アプリを完全に終了」を押します。「PlayPetsを終了しますか？」という確認が出ます。会話は保存されず、デスクトップの友だちも一緒にいなくなります。トレイメニューの「終了」も同じです。

## メニューとショートカット <Since v="0.1.0" />

- **トレイメニュー**（メニューバーやタスクバーの猫）：「庭を開く」、友だちがいるときの「友だち」、「友だちを招待…」、「小さく表示」、「デスクトップに表示」、デスクトップ表示中の「デスクトップを歩き回る」、「庭の音」、「設定…」、「アップデートを確認…」、「PlayPets について」、「終了」があります。友だちがいない間は表示の切り替え項目が省かれますが、招待と音は使えます。音がオンならチェックが付きます。更新があれば「v… にアップデート…」と表示されます。Windowsでは左クリックで庭、右クリックでメニューを開きます。エージェントの確認待ちは青、問題は赤の印で伝え、ツールチップに友だちの名前が出ます。
- **macOSのメニューバー**：「PlayPets」→「PlayPets について」、「アップデートを確認…」、「設定…」、非表示、「PlayPets を終了」。テキスト欄でカット・コピー・ペーストを使う「編集」。「表示」→「友だち」、「友だちを招待…」、チェックで切り替える「小さく表示」と「デスクトップに表示」（友だちが来るまでは灰色で使えません）、チェックで切り替える「庭の音」。そして「ウインドウ」です。
- **ショートカット**（macOSは<kbd>⌘</kbd>、WindowsとLinuxは<kbd>Ctrl</kbd>）：

| キー | 操作 |
|---|---|
| <kbd>⌘</kbd> <kbd>1</kbd> | 「友だち」タブを開く |
| <kbd>⌘</kbd> <kbd>2</kbd> | 「招待」タブを開く |
| <kbd>⌘</kbd> <kbd>,</kbd> | 設定を開く |
| <kbd>⌘</kbd> <kbd>Shift</kbd> <kbd>M</kbd> | ミニモードのオン・オフ |
| <kbd>⌘</kbd> <kbd>Shift</kbd> <kbd>D</kbd> | デスクトップに表示のオン・オフ |
| <kbd>⌘</kbd> <kbd>Shift</kbd> <kbd>S</kbd> | 庭の音のオン・オフ |
| <kbd>⌘</kbd> <kbd>Q</kbd> | 終了（macOS） |

## データフォルダー <Since v="0.1.0" /> {#data-folder}

| OS | 場所 |
|---|---|
| macOS | `~/Library/Application Support/app.playpets/` |
| Windows | `%APPDATA%\app.playpets\` |
| Linux | `~/.local/share/app.playpets/` |

| ファイル | 内容 |
|---|---|
| `state.json` | 友だち（名前、性格と出典、関係、あなたの呼び方、大きさ、位置、選んだAI接続）、AI接続の一覧（キーは除く）、言語、デスクトップモードと散歩、各エージェントの担当の友だち、自動おしゃべり、庭の音とその音量、ミニ窓の位置と大きさ（`miniRect`）、花と飾り（`garden`）、図鑑（`album`）、なかよし度（`bonds`）、自分で選んだペットフォルダー、ファイルの形式番号（`schema`）。新しいバージョンが書いたファイルは別にコピーしてから、このバージョンが理解できる部分だけを読みます |
| `bridge.json` | エージェント連携のポートとトークン。アプリを起動するたびに書き直します |
| `pets/` | URLから取り込んだペットフォルダー |
| `builtin/` | 付属の3種類の仲間。起動するたびに展開して確認します。それぞれ独立した基本画像を持っています |

## 環境変数

| 変数 | 内容 |
|---|---|
| `PLAYPETS_DATA` | データフォルダーを別の場所へ移します。端末コマンド（`playpets say`など）も同じ値を読みます |
| `CODEX_HOME` | Codexのホームフォルダー。招待タブのCodexペットフォルダーが`$CODEX_HOME/pets`になります |
| `PLAYPETS_LANG` | 言語を固定します（`ko`、`en`、`ja`、`zh-hans`） |
| `PLAYPETS_PET` | 端末コマンドの既定の友だち。`--pet`オプションと同じです |
| `PLAYPETS_BRIDGE` | 端末コマンドが読む`bridge.json`のパス。`--bridge`オプションと同じです |

変数はアプリを起動する環境で設定してください。端末からアプリを起動するか、OSの環境変数の設定を使います。

## 保存するもの・しないもの <Since v="0.1.0" />

**保存するもの**

- 友だちそれぞれの名前、性格、関係、あなたの呼び方、大きさ、庭での位置
- 友だちそれぞれのなかよし度
- 花、庭の飾り、図鑑
- AI接続それぞれの種類、サーバーのアドレス、モデル名
- 言語、デスクトップモードと散歩、ミニモードとミニ窓の位置と大きさ、選んだ時間帯、天気、季節
- 取り込んだペットファイルとその出典

**別の方法で保存するもの**

- APIキーは`state.json`に入れません。このコンピューターの安全な保管場所（macOSのキーチェーン、Windowsの資格情報マネージャー、LinuxのSecret Service）にだけ保管し、接続を削除するとキーも削除します。

**保存しないもの**

- 友だちとの会話。メモリーの中にだけあり、アプリを終了すると消えます。
- コーディングエージェントの最近の活動の記憶。アプリを終了すると消えます。
- ゲーム中の位置。ゲームが終わると、友だちは元の場所へ戻ります。

アプリをアンインストールした後にすべての痕跡を消したい場合は、データフォルダーと、安全な保管場所にあるPlayPetsの項目も削除してください。
