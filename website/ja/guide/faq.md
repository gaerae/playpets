# よくある質問

## PlayPetsはどんなアプリですか？

- PlayPetsは、手もとのCodexペットを12人まで一緒に遊ばせられる、無料でオープンソースのデスクトップマスコットアプリです。macOS、Windows、Linuxで使えます。
- ペットたちは小さな庭で一緒に過ごし、デスクトップにも出てこられます。ChatGPTのデスクトップアプリに出てくるのは、選んだペット1体です（[OpenAIのガイド](https://learn.chatgpt.com/docs/pets)、2026年10月時点）。
- つないだAIを通してあなたとも友だち同士でも話し、Claude Code、Codex、Gemini CLI、Cursorが働いているときに反応します。

## Codexのペットも使えますか？

- 「Codexのペット」は、ChatGPTとCodex向けに作られたカスタムペットの呼び名です。OpenAIはこの機能を「Pets」と呼んでいます。
- はい。PlayPetsはCodexのペットファイルをそのまま読み込みます。`pet.json`とスプライトシートが入ったフォルダーひとつがペット1体です。すべての動きを使い、シートに視線の向きがあれば16方向の視線も使います。
- Codexのペットフォルダー（`~/.codex/pets`）にいるペットは、取り込まなくても**友だちを招待**に表示されます。コミュニティサイト、GitHubのフォルダー、パソコンのフォルダーから[さらに迎えられます](./import.md)。
- Codexは必要ありません。ChatGPTのデスクトップアプリを使っているなら、そちらのペットもそのままで大丈夫です。PlayPetsは同じペットファイルを読み込みます。

## お金はかかりますか？

- アプリはMITライセンスの無料オープンソースです。
- ログイン済みのClaude CodeやCodex CLIで話すと、プランの利用枠を使います。別のAPI請求はありません。上限や追加クレジットの料金は適用されます。
- ローカルOllamaモデルにはホスト型推論の料金はありません。
- APIキー、互換サーバー、Ollamaクラウドは接続先の料金に従います。
- [AI接続](./chat.md#connections)を参照してください。

## インターネットなしでも使えますか？

- 使えるもの：招待、遊び、デスクトップ表示、時刻や天気。自動天気も実際の天気を取得しません。
- 通信が必要なもの：コミュニティのペットの取り込み、更新、オンラインAI。
- ダウンロード済みのローカルOllamaならオフラインで会話でき、内容もPC内に留まります。クラウドモデルには通信が必要です。

## コードやプロンプトをペットへ送りますか？

- [フック](./agents.md)は利用者のプロンプトとツール入力を省き、`127.0.0.1`とトークンでローカルに通信します。
- ただし、短い完了報告や通知に、省略した答えなどの作業内容が含まれることがあります。それを、選んだAIとの会話で使う場合があります。
- 端末やMCPから送る内容を確認してください。PC内に留めたい場合はローカルモデルを使ってください。

## うまくいかないとき {#troubleshooting}

| 起きること | 理由 | すること |
|---|---|---|
| macOSでPlayPetsが開けない | 1.2.0以前は未署名です | 1.3.0以降を入れます。古い版は[このまま開く](./install.md#macos)を見てください |
| WindowsのインストーラーにSmartScreenが警告する | GitHubのインストーラーはまだコード署名されていません | Microsoftが署名する[Microsoft Storeかwinget](./install.md#microsoft-store)で入れます。または出典を確かめて**詳細情報 → 実行**を選びます（[GitHubのインストーラー](./install.md#installer-from-github)） |
| LinuxでAppImageが起動しない | FUSE 2がありません | `libfuse2`（Ubuntu 24.04は`libfuse2t64`）を入れるか、`--appimage-extract-and-run`で起動します（[Linux](./install.md#linux)） |
| 窓を閉じたら庭が消えた | 閉じると隠れるだけです | トレイアイコンから**庭を開く**を選びます。GNOMEはAppIndicator拡張がないとトレイアイコンを隠しますが、アプリをもう一度起動しても庭が戻ります |
| 友だちが「遊ぶ準備ができました！」と言うだけで返事をしない | その友だちにAIがありません | [AIを接続します](./chat.md#connect) |
| Claude CodeやCodex CLIのカードに**インストール済み**が出ない | アプリがコマンドを見つけられません | 端末で`claude`や`codex`が動くか確かめます。Windowsでnpmで入れた場合は`%APPDATA%\npm`にある必要があります |
| 接続を保存すると安全な保存領域にアクセスできないと出る | キーの保存先がロックされているか、ありません（LinuxではSecret Serviceがないとき） | アクセスを許可するか、LinuxではGNOME KeyringかKWalletを使います。Ollamaとサインイン済みのCLIはキーがいりません |
| コーディングエージェントが動いても友だちが反応しない | 設定を貼っていない、エージェントを起動し直していない、またはアプリを移動しました | 設定をもう一度コピーして貼り付け、エージェントを起動し直します（[コーディングエージェント](./agents.md)）。Codex CLIの友だちは作業完了だけを表示し、作業中は表示しません |
| 別の友だちに知らせが届く | **担当の友だち**を選んでいないので、最初の友だちが受け取ります | **設定 → 開発ツール連携**で担当の友だちを選び、設定をもう一度コピーして貼り付けます |
| ペットのアドレスを取り込めない | 対応していないサイトか、ファイルが別のサイトにあります | ペットをダウンロードして、フォルダーかZIPで取り込みます（[ペットを取り込む](./import.md)） |
| 動作が遅い、電池を使う | 友だちが動いている間は頻繁に描きます | 庭の窓を閉じます。隠れた庭は描かれません。友だちを減らすか、**デスクトップでおさんぽ**をオフにしてみてください |

ほかに困ったことがあれば、使っているシステムとPlayPetsのバージョンを書いて[Issue](https://github.com/gaerae/playpets/issues)で知らせてください。Windows版は実機での検証がまだ十分ではありません。

## 自分でペットを作れますか？

- はい。`pet.json`とスプライトシートが入ったフォルダーひとつが、ひとつのペットです。
- 形式はCodexのペットと同じです。
- 作ったフォルダーは、**ペットを取り込む**の**このパソコンのフォルダから取り込む**ですぐに招待できます。
- 詳しいルールは[ペットを取り込む](./import.md#make-your-own)と、開発者向け文書（英語）の[Pet file format](/dev/standards/pet-files)にあります。

## モニターが複数ある場合は？

- [デスクトップモード](./desktop.md)では、友だちはどのモニターにもいられます。
- 別のモニターへドラッグすると、そこに留まります。
- モニターごとに表示倍率が違っても使えます。

## データはどこですか？

| OS | 場所 |
|---|---|
| macOS | `~/Library/Application Support/app.playpets/` |
| Windows | `%APPDATA%\app.playpets\`。Microsoft Store（wingetで入れた場合も）：パッケージ専用のフォルダー内 |
| Linux | `~/.local/share/app.playpets/` |

- 友だちと設定は`state.json`、取り込んだペットは`pets/`、取り込んだ背景は`backgrounds/`、付属のペットは`builtin/`にあります。
- APIキーはここにはなく、OSの安全な保管場所にあります。
- PlayPetsは会話履歴をファイルに保存せず、アプリを開いている間だけ保持します。
- 接続先での保存は、そのサービスの方針に従います。
- [設定](./settings.md#data-folder)を参照してください。
