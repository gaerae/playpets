# 最初の友だちを招待する

1. アプリを初めて開くと、空の庭に**だれと遊びますか？**と出て、動く4人の仲間から選べます。
2. 1人をクリックすると、その子が庭に入ってきて手を振ります。

ほかのペットも見たいときは、**ほかのペットを見る**を押してください。このコンピューターにあるペットがすべて並んだ**友だちを招待**が開きます。

## 付属の友だち <Since v="0.1.0" />

初回起動時の**友だちを招待**には、まず**PlayPetsの基本ペット**が並びます。探検家のDaisy、庭づくりが好きな子猫のClover、元気な子犬のPip、穏やかなカワウソのMisoの4人です。アプリのメインマスコットはCloverで、カードにはどの言語でもこの名前が表示されます。

4人ともCodexのペット形式なので、ほかのペットと同じように招待したり、デスクトップへ出したり、AIをつけたりできます。ファイルはデータフォルダーの`builtin/`にあります。

以前の基本ペットは、保存された名前、設定、なかよし度をそのまま引き継ぎます。AriaはDaisy、NoahはPip、元の猫はCloverの姿になります。自分で取り込んだペットは変わりません。会話は起動している間だけ保持され、再起動すると復元されません。

4人は選んだ季節に合わせて、庭でもデスクトップモードでも自動で着替えます。自動にしているときは、ローカルのカレンダーに従います。夏は軽い夏服、冬は暖かい冬服を着て、春と秋は同じ普段着の重ね着です。顔、持ち物、動きはそのままなので、服が替わってもすぐ見分けられます。

## 友だちの物語 <span id="companion-stories"></span>

仲間を紹介する小さな物語です。会話で実際に使う性格は友だちの設定で変えられ、AIを接続したときに使われます。

白い花びらに黄色い花芯の小さな花が、4人に共通する目印です。

### Daisy, 曲がり角の小さな発見

デイジーは、みんなが通り過ぎてしまう小道が気になってしかたありません。咲いたばかりの花や、クジラに似た雲がひとつあれば、その日は心に残る一日になります。先に着くことより、一緒に見つけることが好きな探検家です。

### Clover, 今日も少し育ったよ

クローバーは庭を見守るやさしい子猫で、PlayPetsのメインマスコットです。新しい葉っぱにだれよりも早く気づき、日当たりのいい場所は友だちに譲ります。小さな変化を、時間をかけて待つのが得意です。

### Pip, もう一人、一緒にどうぞ

ピップは、初めて会う友だちにいつも真っ先に手を振ります。インディゴのデニムジャケットにアイボリーのショートパンツで散歩や遊びを盛り上げながら、置いていかれた子がいないか振り返るのも忘れません。みんなで過ごせる午後が大好きです。

### Miso, 池のほとりの一ページ

ミソは、本とひと休みの時間を大切にする穏やかなカワウソです。薄紫のニットベストを着て、水面の波紋を眺めながら考えがまとまるのを待ちます。おしゃべりしなくても、隣に座っているだけでうれしい日もありますよね。

## 次にすること <Since v="0.1.0" />

最初の友だちが来ると、隅に小さな**次にすること**カードが出て、残っていることを教えてくれます。

- 友だちにAIを接続する（**つなぐ**）
- コーディングエージェントの知らせを伝える友だちを選ぶ（**選ぶ**）

このコンピューターにClaude CodeかCodex CLIがあれば、最初のボタンは**すぐつなぐ**になります。キーなしで、友だち全員に一度で接続します（[友だちと話す](./chat.md#connect)）。

終わった項目にはチェックが付き、全部終わるとカードは消えます。先に隠したいときは**表示しない**を押してください。

庭に友だちがいない間は、遊びの道具が隠れます。それでも**友だちと設定 → 友だちを招待**は使えます。

## 友だちを招待 <Since v="0.1.0" />

<Shot name="invite" caption="「友だちを招待」では、ペットの保存場所ごとにカードが並びます。" />

**友だちを招待**では、ペットファイルがある場所ごとに、カードが4つのグループに分かれます。ペットがいないグループは表示されません。

| グループ | ペットの出どころ |
|---|---|
| **PlayPetsの基本ペット** | アプリに付属する4種類のペット。データフォルダーの`builtin/`に展開されます |
| **Codexのペットフォルダ** | `~/.codex/pets`にあるCodexのペット。自動で表示されます |
| **URLやZIPから取り込んだペット** | **ペットを取り込む**で、コミュニティのページやZIPファイルから手に入れたペット。データフォルダーの`pets/`にコピーされます |
| **このパソコンから選んだペット** | 自分で選んだフォルダーのペット。コピーせず、そのフォルダーをそのまま読みます |

- 最初の3グループには**フォルダを開く**ボタンがあり、エクスプローラーやFinderでそのフォルダーを開けます。
- このパソコンから選んだペットは、各カードにフォルダー名が出ます。
- カードが1枚もないときは、[ペットを取り込む](./import.md)から始めてください。

棚の上の**種類**チップ（**すべて**、**人**、**動物**、**その他**）は、ペットファイルの`kind`で絞り込みます。人の姿のペットだけにできるので、恋人や先輩にする友だちを選ぶときに便利です。

**ペットを検索**に名前や作者を入れると、同じ棚をさらに絞り込めます。種類と組み合わせて使え、**すべて表示**を押すと検索と種類の両方が解除されます。

## 招待する <Since v="0.1.0" />

1. カード（右側の`+`）をクリックします。すでに庭にいる友だちのカードには**もう1人招待**と表示されます。
2. 友だちが庭に現れて手を振り、パネルはその友だちの画面に切り替わります。
3. 同じペットをもう一度クリックすると**もう1人招待**になります。2人目からは、見分けられるよう名前の後ろに番号が付きます。

庭には12人まで招待できます。

## 友だちの設定 <Since v="0.1.0" />

友だちの画面で、名前の横の**⋯**メニューから**友だち設定**（鉛筆）を選ぶと開きます。名前の横の関係チップからも開けます。

| 項目 | 内容 |
|---|---|
| **名前** | 庭の名札と会話に表示。24文字まで |
| **性格** | 会話で友だちはこの性格で答えます。最初はペットファイルの紹介文。書き換えて保存するとその内容に変わり、**ペットファイルの紹介文を入れる**で元に戻せます。400文字まで。AIを接続していない間はまだ使われません |
| **関係** | 友だち、恋人、頼れる先輩、いたずら好きな弟、妹。話し方や、あなたの一日の尋ね方が変わります |
| **呼んでほしい名前** | 友だちはあなたをこの名前で呼びます。24文字まで。関係と呼び名は[友だちと話す](./chat.md#relationship)で説明しています |
| **大きさ** | とても小さい、小さい、ふつう、大きい、とても大きいの5段階。スライダーを動かすと庭がすぐ変わります |

ウィンドウの下部には友だちIDが出ます。[コーディングエージェント連携](./agents.md)で特定の友だちを指定するときに使います。

庭から送り出すときは、**⋯**メニューの**お別れする**か、友だち設定の**お別れする**をクリックします。その前に赤い確認が出ます。ペットは**友だちを招待**に残るので、いつでもまた招待できます。ただ、この友だちとの会話と、深まったなかよし度は消えてしまいます。

## 庭でできること <Since v="0.1.0" />

友だちをクリックするとなでられ、ドラッグすると移動できます。最初に招待した友だちが、話しかけ方を教えてくれます。

| 操作 | 方法 |
|---|---|
| なでる | 友だちを1回クリック。跳ねてハートを出します |
| 移動 | 友だちをドラッグして置きます。庭での位置は保存されます |
| 話す | 友だちの名札をクリック。ポインターを重ねると吹き出しのマークと「Cloverに話しかける」のような案内が出ます。その友だちで友だちの画面が開き、会話はウィンドウの大きさに合わせて同じ窓の中で開きます。友だちをダブルクリックしても同じです。右クリックで、話しかける、遊ぶ、穴掘りを頼むから選べる短いメニューが開きます |
| おやつを置く | **遊ぶ → 庭**の**おやつ**をクリックし、庭の場所を選びます（キーボードでは、もう一度押すと選んでいる友だちのそばに置きます）。シートにお弁当、果物、おやつが並び、友だちが周りに集まります。全員が来ない場合は15秒後、全員が食べた場合は最後の友だちが食べてから6秒後に片付きます |

友だちの下には名札があります。友だちを選ぶと名札が選択中の見た目に変わり、コーディングエージェントが作業している間は名札の横に状態が出ます。

放っておくと、友だちは庭をゆっくり歩き回りながら独り言を言います。雨の日は「傘ある？」のようなことを言い、夜になると眠そうにします。時刻と天気については[庭と遊び](./play.md)で説明しています。
