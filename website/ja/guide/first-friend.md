# 最初の友だちを招待する

アプリを初めて開くと、空の庭に「だれと遊びますか？」と表示され、動く4人の仲間の候補が出ます。1人をクリックすると庭に入ってきて手を振ります。「ほかのペットを見る」を押すと「招待」タブが開き、このコンピューターにあるペットがすべて表示されます。

## 付属の友だち <Since v="0.1.0" />

初回起動時、招待タブには「PlayPetsの基本ペット」があります。探検家のDaisy、庭づくりが好きな子猫のClover、元気な子犬のPip、穏やかなカワウソのMisoが並びます。Cloverはアプリのメインマスコットです。カードにはどの言語でもこの名前が表示されます。どれもCodexのペット形式なので、ほかのペットとまったく同じように招待し、デスクトップへ出し、AIをつけられます。ファイルはデータフォルダーの`builtin/`にあります。


基本の友だちはDaisy、Clover、Pip、Misoです。以前の基本ペットは保存された名前、設定、なかよし度を保ち、AriaはDaisy、NoahはPip、元の猫はCloverの姿になります。取り込んだペットは変わりません。会話は起動中だけ保持され、再起動後には復元されません。

Daisy、Clover、Pip、Misoは、選んだ季節に合わせて、庭でもデスクトップモードでも軽い夏服と暖かい冬服に自動で着替えます（自動ならローカルのカレンダーに従います）。春と秋は普段の重ね着を共有します。顔、持ち物、動きは見分けがつくままです。

## 友だちの物語 <span id="companion-stories"></span>

仲間を紹介する小さな物語です。会話に使う性格は友だちの設定で変更でき、AIを接続したときに使われます。白い花びらと黄色い花芯の小さな花が、4人に共通する目印です。

### Daisy, 曲がり角の小さな発見

デイジーは、みんなが通り過ぎる小道に興味津々。咲いたばかりの花やクジラに似た雲があれば、心に残る一日になります。先に着くことより、一緒に見つけることが好きな探検家です。

### Clover, 今日も少し育ったよ

クローバーは庭を見守るやさしい子猫で、PlayPetsのメインマスコット。新しい葉にいち早く気づき、日当たりのいい場所を友だちに譲ります。小さな変化を、時間をかけて待つのが得意です。

### Pip, もう一人、一緒にどうぞ

ピップは初めて会う友だちに、真っ先に手を振ります。インディゴのデニムジャケットとアイボリーのショートパンツで散歩や遊びを盛り上げながら、誰も置いていかれていないか振り返ります。みんなで過ごせる午後が大好きです。

### Miso, 池のほとりの一ページ

ミソは本とひと休みの時間を大切にする、穏やかなカワウソ。薄紫のニットベストを着て、水面の波紋を眺めながら考えをまとめます。お話ししなくても、隣に座っているだけでうれしい日もあります。


## 次にすること <Since v="0.1.0" />

最初の友だちが来ると、隅に小さな「次にすること」カードが出て、残っていることを表示します。友だちにAIを接続する（「つなぐ」）と、コーディングエージェントの知らせを伝える友だちを選ぶ（「選ぶ」）です。このコンピューターにClaude CodeやCodex CLIがあれば、最初のボタンは「すぐつなぐ」になり、キーなしで全員の友だちに接続します（[友だちと話す](./chat.md#connect)を参照）。終えた項目にはチェックが付き、すべて終わるとカードは消えます。「表示しない」で先に隠すこともできます。庭に友だちがいない間は遊びの道具が隠れます。**友だちと設定 → 友だちを招待**は使えます。

## 招待タブ <Since v="0.1.0" />

<Shot name="invite" caption="ペットの保存場所ごとにカードが並ぶ招待タブです。" />

招待タブは、ペットファイルの場所によってカードを4つのグループに分けます。ペットがないグループは表示されません。

| グループ | ペットの出どころ |
|---|---|
| PlayPetsの基本ペット | アプリに付属する4種類のペット。データフォルダーの`builtin/`に展開されます |
| Codexのペットフォルダ | `~/.codex/pets`にあるCodexのペット。自動で表示されます |
| URLから取り込んだペット | 「ペットを取り込む」で手に入れたコミュニティのペット。データフォルダーの`pets/`に保存されます |
| このパソコンから選んだペット | 自分で選んだフォルダーにあるペット。コピーせず、そのフォルダーをそのまま読みます |

最初の3グループには「フォルダを開く」ボタンがあり、エクスプローラーやFinderでそのフォルダーを開けます。このコンピューターから選んだペットは、各カードにフォルダー名が表示されます。カードが1枚もなければ、[ペットを取り込む](./import.md)から始めてください。

棚の上の「種類」チップ（すべて、人、動物、その他）で、人の姿のペットだけに絞れます。恋人や先輩を選ぶときに便利です。ペットファイルの`kind`に従います。

種類の絞り込みは「ペットを検索」と一緒に働きます。名前や作者を入力すると、同じ棚をさらに絞り込めます。「すべて表示」で検索と種類の両方を解除します。

## 招待する <Since v="0.1.0" />

1. カード（右側の`+`）をクリックします。すでに庭にいる友だちのカードには「もう1人招待」と表示されます。
2. 友だちが庭に現れて手を振ります。パネルは「友だち」タブに切り替わります。
3. 同じペットをもう一度クリックすると「もう1人招待」になります。2人目からは、見分けられるように名前の後ろに番号が付きます。

庭には12人まで招待できます。

## 友だちの設定 <Since v="0.1.0" />

友だちタブで、友だちの名前の横にある「⋯」メニューを開き、「友だち設定」（鉛筆）を選ぶと、名前、性格、関係、呼んでほしい名前、大きさを変えられます。名前の横の関係チップからも開けます。

- **名前**：庭の名札と会話に表示されます。24文字までです。
- **性格**：会話するとき、友だちはこの性格で答えます。最初はペットファイルの紹介文が性格として使われます。書き換えたり書き足したりして保存すると、その内容に変わります。「ペットファイルの紹介文を入れる」をクリックすると元の紹介文を戻せます。400文字までです。AIを接続していない間は、性格はまだ使われません。
- **関係**：友だち、恋人、頼れる先輩、いたずら好きな弟、妹。友だちの話し方や、あなたの一日の尋ね方が変わります。
- **呼んでほしい名前**：友だちはあなたをこの名前で呼びます。24文字までです。関係と呼び名については[友だちと話す](./chat.md#relationship)で説明しています。
- **大きさ**：とても小さい、小さい、ふつう、大きい、とても大きいの5段階です。スライダーを動かすと庭がすぐに変わります。

ウィンドウの下部には友だちIDが表示されます。[コーディングエージェント連携](./agents.md)で特定の友だちを指定するときに使います。

友だちを庭から送り出すには、「⋯」メニューの「お別れする」を選ぶか、友だち設定の「庭からお別れする」をクリックします。お別れの前に赤い確認が出ます。ペットは招待タブに残るので、いつでもまた招待できます。この友だちとの会話と、深まったなかよし度は消えます。

## 庭でできること <Since v="0.1.0" />

友だちをクリックすると、なでられます。ドラッグすると移動できます。最初に招待した友だちが話しかけ方を教えてくれます。友だちとできることは次のとおりです。

| 操作 | 方法 |
|---|---|
| なでる | 友だちを1回クリックします。跳ねてハートを出します |
| 移動 | 友だちをドラッグして置きます。庭での位置は保存されます |
| 話す | 友だちの名札をクリックします。ポインターを重ねると吹き出しのマークと「Cloverに話しかける」のような案内が出ます。その友だちの友だちタブが開きます。会話はウィンドウの大きさに合わせて同じ窓の中で開きます。友だちをダブルクリックしても同じです。右クリックすると、話しかける、遊ぶ、穴掘りを頼むから選べる短いメニューが開きます |
| おやつを置く | **遊ぶ → 庭**の「おやつ」をクリックし、庭の場所を選びます（キーボードでは、もう一度押すと選んでいる友だちのそばに置きます）。シートにお弁当、果物、おやつが並び、友だちが周りに集まります。全員が来ない場合は15秒後、全員が食べた場合は最後の友だちが食べてから6秒後に片付きます |

友だちの下には**名札**があります。友だちを選ぶと名札が選択中の見た目に変わり、コーディングエージェントが作業している間は名札の横に状態が表示されます。

放っておくと、友だちは庭をゆっくり歩き回り、独り言を言います。雨の日は「傘ある？」のようなことを言い、夜になると眠そうにします。時刻と天気については[庭と遊び](./play.md)で説明しています。
