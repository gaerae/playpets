# 最初の友だちを招待する

ペットを選ぶと、友だちになって庭に来ます。なでたり、動かしたり、話しかけたり、おやつを置いたりできます。

1. アプリを初めて開くと、空の庭に**だれと遊びますか？**と出て、動く4人の仲間から選べます。
2. 1人をクリックすると、その子が庭に入ってきて手を振ります。

**ほかのペットを見る**を押すと、このコンピューターにあるペットがすべて並んだ**友だちを招待**が開きます。

::: tip 早見表
| したいこと | やり方 | 詳しく |
|---|---|---|
| 友だちをもっと招待する | **友だちと設定 → 友だちを招待**でカードの`+` | [招待する](#inviting-a-friend) |
| なでる | 友だちを1回クリック | [庭でできること](#things-to-do-in-the-yard) |
| 話しかける | 友だちの名札をクリック | [友だちと話す](./chat.md) |
| おやつを置く | **遊ぶ → 庭 → おやつ**を押して場所を選ぶ | [庭でできること](#things-to-do-in-the-yard) |
| 名前、性格、大きさを変える | 名前の横の**⋯** → **友だち設定** | [友だちの設定](#friend-settings) |
| ペットをもっと迎える | 「友だちを招待」の**ペットを取り込む** | [ペットを取り込む](./import.md) |
:::

## 付属の友だち <Since v="0.1.0" />

初回起動時の**友だちを招待**には、まず**PlayPetsの基本ペット**が並びます。

| 友だち | どんな子 |
|---|---|
| Daisy | 探検家 |
| Clover | 庭づくりが好きな子猫。アプリのメインマスコットです |
| Pip | 元気な子犬 |
| Miso | 穏やかなカワウソ |

- カードにはどの言語でもこの名前が表示されます。
- 4人ともCodexのペット形式なので、ほかのペットと同じように招待したり、デスクトップへ出したり、AIをつけたりできます。ファイルはデータフォルダーの`builtin/`にあります。
- 1人ずつ保存することもできます。[ホームページ](../index.md#companions)の友だち紹介から、季節の服まで入った`playpets-<名前>.zip`を保存できます。PlayPetsでは[ZIPファイル](./import.md#zip-file)として取り込み、Codexのペットフォルダー（`~/.codex/pets`、Windowsは`%USERPROFILE%\.codex\pets`）に展開するとChatGPTやCodexでもいっしょです。
- 選んだ季節に合わせて、庭でもデスクトップモードでも着替えます。自動のときはローカルのカレンダーに従います。夏は軽い夏服、冬は暖かい冬服、春と秋は同じ普段着の重ね着です。顔、持ち物、動きはそのままなので、服が替わってもすぐ見分けられます。

以前のバージョンの基本ペットは、保存されたID、名前、設定、なかよし度をそのまま引き継ぎ、見た目だけがこの仲間に変わります。

| 以前の友だち | 今の姿 |
|---|---|
| Aria | Daisy |
| Noah | Pip |
| 元の猫 | Clover |

自分で取り込んだペットは変わりません。会話は起動している間だけ保持され、再起動すると復元されません。

## 友だちの物語 <span id="companion-stories"></span>

仲間を紹介する小さな物語です。会話で実際に使う性格は友だちの設定で変えられ、AIを接続したときに使われます。

白い花びらに黄色い花芯の小さな花が、4人に共通する目印です。

### Daisy, 曲がり角の小さな発見

デイジーは、みんなが通り過ぎてしまう小道が気になってしかたありません。咲いたばかりの花や、クジラに似た雲がひとつあれば、その日は心に残る一日になります。先に着くことより、一緒に見つけることが好きな探検家です。

### Clover, 今日も少し育ったよ

クローバーは庭を見守るやさしい子猫で、PlayPetsのメインマスコットです。新しい葉っぱにだれよりも早く気づき、日当たりのいい場所は友だちに譲ります。小さな変化を、時間をかけて待つのが得意です。

### Pip, もう一人、一緒にどうぞ

ピップは、初めて会う友だちにいつも真っ先に手を振ります。インディゴのデニムジャケットにアイボリーのショートパンツで散歩や遊びを盛り上げながら、置いていかれた子がいないか振り返るのも忘れません。みんなで過ごせる午後が大好きです。

### Miso, 池のほとりの一ページ

ミソは、本とひと休みの時間を大切にする穏やかなカワウソです。薄紫のニットベストを着て、水面の波紋を眺めながら考えがまとまるのを待ちます。おしゃべりしなくても、隣に座っているだけでうれしい日もありますよね。

## 次にすること <Since v="0.1.0" />

最初の友だちが来ると、隅に小さな**次にすること**カードが出て、残っていることを教えてくれます。

| すること | ボタン |
|---|---|
| 友だちにAIを接続する | **つなぐ**。このコンピューターにClaude CodeかCodex CLIがあれば**すぐつなぐ**になり、キーなしで友だち全員に一度で接続します（[友だちと話す](./chat.md#connect)） |
| コーディングエージェントの知らせを伝える友だちを選ぶ | **選ぶ** |

- 終わった項目にはチェックが付き、全部終わるとカードは消えます。先に隠したいときは**表示しない**を押します。
- 庭に友だちがいない間は、遊びの道具が隠れます。それでも**友だちと設定 → 友だちを招待**は使えます。

## 友だちを招待 <Since v="0.1.0" />

<Shot name="invite" caption="「友だちを招待」では、ペットの保存場所ごとにカードが並びます。" />

**友だちを招待**では、ペットファイルがある場所ごとに、カードが4つのグループに分かれます。ペットがいないグループは表示されません。

| グループ | ペットの出どころ | **フォルダを開く** |
|---|---|---|
| **PlayPetsの基本ペット** | アプリに付属する4種類のペット。データフォルダーの`builtin/`に展開されます | あり |
| **Codexのペットフォルダ** | `~/.codex/pets`にあるCodexのペット。自動で表示されます | あり |
| **URLやZIPから取り込んだペット** | **ペットを取り込む**で、コミュニティのページやZIPファイルから手に入れたペット。データフォルダーの`pets/`にコピーされます | あり |
| **このパソコンから選んだペット** | 自分で選んだフォルダーのペット。コピーせず、そのフォルダーをそのまま読みます | なし。各カードにフォルダー名が出ます |

- **フォルダを開く**で、エクスプローラーやFinderでそのフォルダーを開けます。
- 棚の上の**種類**チップ（**すべて**、**人**、**動物**、**その他**）は、ペットファイルの`kind`で絞り込みます。人の姿のペットだけにできるので、恋人や先輩にする友だちを選ぶときに便利です。
- **ペットを検索**に名前や作者を入れると、同じ棚をさらに絞り込めます。種類と組み合わせて使え、**すべて表示**で両方が解除されます。
- カードが1枚もないときは、[ペットを取り込む](./import.md)から始めてください。

## 招待する <Since v="0.1.0" /> {#inviting-a-friend}

1. カード（右側の`+`）をクリックします。すでに庭にいる友だちのカードには**もう1人招待**と表示されます。
2. 友だちが庭に現れて手を振り、パネルはその友だちの画面に切り替わります。
3. 同じペットをもう一度クリックすると**もう1人招待**になります。2人目からは、見分けられるよう名前の後ろに番号が付きます。

庭には12人まで招待できます。

## 友だちの設定 <Since v="0.1.0" /> {#friend-settings}

友だちの画面で、名前の横の**⋯**メニューから**友だち設定**（鉛筆）を選ぶと開きます。名前の横の関係チップからも開けます。

| 項目 | 内容 |
|---|---|
| **名前** | 庭の名札と会話に表示。24文字まで |
| **性格** | 会話で友だちはこの性格で答えます。400文字まで。最初はペットファイルの紹介文で、書き換えて保存するとその内容に変わり、**ペットファイルの紹介文を入れる**で元に戻せます。AIを接続していない間はまだ使われません |
| **関係** | 友だち、恋人、頼れる先輩、いたずら好きな弟、妹。話し方や、あなたの一日の尋ね方が変わります（[友だちと話す](./chat.md#relationship)） |
| **呼んでほしい名前** | 友だちはあなたをこの名前で呼びます。24文字まで |
| **大きさ** | とても小さい、小さい、ふつう、大きい、とても大きいの5段階。スライダーを動かすと庭がすぐ変わります |

- ウィンドウの下部の友だちIDは、[コーディングエージェント連携](./agents.md)で特定の友だちを指定するときに使います。
- **⋯**メニューか友だち設定の**お別れする**を押すと、赤い確認のあとで庭から送り出します。ペットは**友だちを招待**に残るので、いつでもまた招待できます。ただ、この友だちとの会話と、深まったなかよし度は消えてしまいます。

## 庭でできること <Since v="0.1.0" /> {#things-to-do-in-the-yard}

| 操作 | 方法 |
|---|---|
| なでる | 友だちを1回クリック。跳ねてハートを出します |
| 移動 | 友だちをドラッグして置きます。庭での位置は保存されます |
| 話す | 友だちの名札をクリック。ポインターを重ねると吹き出しのマークと「Cloverに話しかける」のような案内が出ます。その友だちで友だちの画面が開き、会話はウィンドウの大きさに合わせて同じ窓の中で開きます。最初に招待した友だちが、話しかけ方を教えてくれます |
| 友だちのメニュー | 右クリックで、話しかける、遊ぶ、穴掘りを頼むから選べる短いメニューが開きます |
| おやつを置く | **遊ぶ → 庭 → おやつ**をクリックし、庭の場所を選びます。キーボードでは、もう一度押すと選んでいる友だちのそばに置きます。シートにお弁当、果物、おやつが並び、友だちが周りに集まります。全員が来ない場合は15秒後、全員が食べた場合は最後の友だちが食べてから6秒後に片付きます |

- 友だちの下には名札があります。友だちを選ぶと名札が選択中の見た目に変わり、コーディングエージェントが作業している間は名札の中、名前の横に状態の点が出ます。
- 放っておくと、友だちは庭をゆっくり歩き回りながら独り言を言います。雨の日は「傘ある？」のようなことを言い、夜になると眠そうにします。時刻と天気は[庭と遊び](./play.md#weather)で説明しています。
