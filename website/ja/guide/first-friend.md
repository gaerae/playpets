# 最初の友だちを招待する

1. アプリを初めて開くと、空の庭に**だれと遊びますか？**と、動く4人の仲間の候補が出ます。
2. 1人をクリックすると、庭に入ってきて手を振ります。

- **ほかのペットを見る**を押すと**友だちを招待**が開き、このコンピューターのペットがすべて表示されます。

## 付属の友だち <Since v="0.1.0" />

- 初回起動時、**友だちを招待**には**PlayPetsの基本ペット**があります。

| 名前 | どんな子 |
|---|---|
| Daisy | 探検家 |
| Clover | 庭づくりが好きな子猫。アプリのメインマスコット |
| Pip | 元気な子犬 |
| Miso | 穏やかなカワウソ |

- カードにはどの言語でもこの名前が表示されます。
- どれもCodexのペット形式です。ほかのペットと同じように招待し、デスクトップへ出し、AIをつけられます。
- ファイルはデータフォルダーの`builtin/`にあります。
- 以前の基本ペットは、保存された名前、設定、なかよし度を保ちます。
  - AriaはDaisy、NoahはPip、元の猫はCloverの姿になります。
  - 取り込んだペットは変わりません。
- 会話は起動中だけ保持され、再起動後には復元されません。
- 選んだ季節に合わせて、庭でもデスクトップモードでも自動で着替えます（自動ならローカルのカレンダーに従います）。
  - 夏は軽い夏服、冬は暖かい冬服。
  - 春と秋は普段の重ね着を共有します。
  - 顔、持ち物、動きは見分けがつくままです。

## 友だちの物語 <span id="companion-stories"></span>

- 仲間を紹介する小さな物語です。
- 会話に使う性格は友だちの設定で変えられ、AIを接続したときに使われます。
- 白い花びらと黄色い花芯の小さな花が、4人に共通する目印です。

### Daisy, 曲がり角の小さな発見

- デイジーは、みんなが通り過ぎる小道に興味津々。
- 咲いたばかりの花やクジラに似た雲があれば、心に残る一日になります。
- 先に着くことより、一緒に見つけることが好きな探検家です。

### Clover, 今日も少し育ったよ

- クローバーは庭を見守るやさしい子猫で、PlayPetsのメインマスコット。
- 新しい葉にいち早く気づき、日当たりのいい場所を友だちに譲ります。
- 小さな変化を、時間をかけて待つのが得意です。

### Pip, もう一人、一緒にどうぞ

- ピップは初めて会う友だちに、真っ先に手を振ります。
- インディゴのデニムジャケットとアイボリーのショートパンツで、散歩や遊びを盛り上げます。
- 誰も置いていかれていないか、振り返ります。みんなで過ごせる午後が大好きです。

### Miso, 池のほとりの一ページ

- ミソは本とひと休みの時間を大切にする、穏やかなカワウソ。
- 薄紫のニットベストを着て、水面の波紋を眺めながら考えをまとめます。
- お話ししなくても、隣に座っているだけでうれしい日もあります。


## 次にすること <Since v="0.1.0" />

- 最初の友だちが来ると、隅に小さな**次にすること**カードが出て、残っていることを表示します。

| 項目 | ボタン |
|---|---|
| 友だちにAIを接続する | **つなぐ** |
| コーディングエージェントの知らせを伝える友だちを選ぶ | **選ぶ** |

- このコンピューターにClaude CodeやCodex CLIがあれば、最初のボタンは**すぐつなぐ**になります。キーなしで全員の友だちに接続します（[友だちと話す](./chat.md#connect)）。
- 終えた項目にはチェックが付き、すべて終わるとカードは消えます。
- **表示しない**で先に隠せます。
- 庭に友だちがいない間は、遊びの道具が隠れます。**友だちと設定 → 友だちを招待**は使えます。

## 友だちを招待 <Since v="0.1.0" />

<Shot name="invite" caption="「友だちを招待」では、ペットの保存場所ごとにカードが並びます。" />

- **友だちを招待**は、ペットファイルの場所でカードを4つのグループに分けます。
- ペットがないグループは表示されません。

| グループ | ペットの出どころ |
|---|---|
| **PlayPetsの基本ペット** | アプリに付属する4種類のペット。データフォルダーの`builtin/`に展開されます |
| **Codexのペットフォルダ** | `~/.codex/pets`にあるCodexのペット。自動で表示されます |
| **URLから取り込んだペット** | **ペットを取り込む**で手に入れたコミュニティのペット。データフォルダーの`pets/`に保存されます |
| **このパソコンから選んだペット** | 自分で選んだフォルダーのペット。コピーせず、そのフォルダーをそのまま読みます |

- 最初の3グループには**フォルダを開く**ボタンがあります。エクスプローラーやFinderでそのフォルダーを開けます。
- このコンピューターから選んだペットは、各カードにフォルダー名が出ます。
- カードが1枚もなければ、[ペットを取り込む](./import.md)から始めてください。
- 棚の上の**種類**チップ（**すべて**、**人**、**動物**、**その他**）で、人の姿のペットだけに絞れます。
  - 恋人や先輩を選ぶときに便利です。
  - ペットファイルの`kind`に従います。
- 種類の絞り込みは**ペットを検索**と一緒に働きます。名前や作者を入力すると、同じ棚をさらに絞り込めます。
- **すべて表示**で検索と種類の両方を解除します。

## 招待する <Since v="0.1.0" />

1. カード（右側の`+`）をクリックします。すでに庭にいる友だちのカードには**もう1人招待**と表示されます。
2. 友だちが庭に現れて手を振ります。パネルは友だちの画面に切り替わります。
3. 同じペットをもう一度クリックすると**もう1人招待**になります。2人目からは、見分けられるよう名前の後ろに番号が付きます。

- 庭には12人まで招待できます。

## 友だちの設定 <Since v="0.1.0" />

- 開き方：友だちの画面で、名前の横の**⋯**メニュー → **友だち設定**（鉛筆）。名前の横の関係チップからも開けます。

| 項目 | 内容 |
|---|---|
| **名前** | 庭の名札と会話に表示。24文字まで |
| **性格** | 会話で友だちはこの性格で答えます。最初はペットファイルの紹介文。書き換えて保存するとその内容に変わり、**ペットファイルの紹介文を入れる**で元に戻せます。400文字まで。AIを接続していない間はまだ使われません |
| **関係** | 友だち、恋人、頼れる先輩、いたずら好きな弟、妹。話し方や、あなたの一日の尋ね方が変わります |
| **呼んでほしい名前** | 友だちはあなたをこの名前で呼びます。24文字まで。関係と呼び名は[友だちと話す](./chat.md#relationship)で説明しています |
| **大きさ** | とても小さい、小さい、ふつう、大きい、とても大きいの5段階。スライダーを動かすと庭がすぐ変わります |

- ウィンドウの下部に友だちIDが出ます。[コーディングエージェント連携](./agents.md)で特定の友だちを指定するときに使います。
- 庭から送り出すには、**⋯**メニューの**お別れする**か、友だち設定の**お別れする**をクリックします。
  - お別れの前に赤い確認が出ます。
  - ペットは**友だちを招待**に残るので、いつでもまた招待できます。
  - この友だちとの会話と、深まったなかよし度は消えます。

## 庭でできること <Since v="0.1.0" />

- 友だちをクリックするとなでられ、ドラッグすると移動できます。
- 最初に招待した友だちが、話しかけ方を教えてくれます。

| 操作 | 方法 |
|---|---|
| なでる | 友だちを1回クリック。跳ねてハートを出します |
| 移動 | 友だちをドラッグして置きます。庭での位置は保存されます |
| 話す | 友だちの名札をクリック。ポインターを重ねると吹き出しのマークと「Cloverに話しかける」のような案内が出ます。その友だちで友だちの画面が開き、会話はウィンドウの大きさに合わせて同じ窓の中で開きます。友だちをダブルクリックしても同じです。右クリックで、話しかける、遊ぶ、穴掘りを頼むから選べる短いメニューが開きます |
| おやつを置く | **遊ぶ → 庭**の**おやつ**をクリックし、庭の場所を選びます（キーボードでは、もう一度押すと選んでいる友だちのそばに置きます）。シートにお弁当、果物、おやつが並び、友だちが周りに集まります。全員が来ない場合は15秒後、全員が食べた場合は最後の友だちが食べてから6秒後に片付きます |

- 友だちの下には**名札**があります。
  - 友だちを選ぶと、名札が選択中の見た目に変わります。
  - コーディングエージェントが作業している間は、名札の横に状態が出ます。
- 放っておくと、友だちは庭をゆっくり歩き回り、独り言を言います。
  - 雨の日は「傘ある？」のようなことを言います。
  - 夜になると眠そうにします。
- 時刻と天気は[庭と遊び](./play.md)で説明しています。
