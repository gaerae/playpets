# コーディングエージェント連携

Claude Code、Codex CLI、Gemini CLI、Cursor、Grok Buildなどのコーディングエージェントが作業していると、友だちもそれに合わせて反応します。設定をひとつコピーして貼り付けるだけで、Node.jsは要りません。

## エージェントごとの友だち <Since v="0.1.0" />

1. **設定 → 開発ツール連携**で、そのツールの行の**担当の友だち**を選びます。
2. もう一度**設定をコピー**を押して貼り付けます。

コピーした設定には友だちの指定（`--pet`）が入るので、Claude CodeはCloverへ、CodexはPipへ、と報告先を分けられます。誰も選ばなければ、最初の友だちに届きます。選んだ友だちとお別れしたときも、最初の友だちに戻ります。

友だちごとに別のエージェントを任せれば、庭がそのまま「誰が何をしているか」の状況板になります。

## 複数のエージェントを同時に

- 友だちはそれぞれ自分のエージェントだけを表示します。状態の点、名札、デスクトップの吹き出しは友だちごとに別々です。
- 友だちに「何してたの？」と聞くと、自分のエージェントが最近したことだけを教えてくれます。

| エージェント | 友だち | 見えるもの |
|---|---|---|
| Claude Code | Clover | ファイルを編集している間は**作業中** |
| Codex CLI | Pip | 返答が終わると**作業完了** |
| Gemini CLI | Daisy | 承認を待つと**確認待ち** |
| Cursor | Miso | コマンドを実行している間は**作業中** |

### 同じエージェントを2つのセッションで

1. **設定 → 開発ツール連携**で、そのツールの**担当の友だち**を選ばずに設定をコピーして貼り付けます。
2. セッションごとに担当の友だちを決めて起動します。

```bash
PLAYPETS_PET=Clover claude
PLAYPETS_PET=Pip claude
```

- PowerShellでは`$env:PLAYPETS_PET="Clover"; claude`のように書きます。
- `PLAYPETS_PET`には、`--pet`と同じく友だちの名前かIDを入れます。
- **担当の友だち**を選ぶと設定にその友だちが書き込まれ（`--pet`）、`PLAYPETS_PET`より優先されます。
- 端末から起動するClaude Code、Codex CLI、Gemini CLI、Grok Buildで使えます。CursorはCursorアプリがフックを実行するため、知らせる先は1人です。

## 庭に表示されるもの <Since v="0.1.0" />

エージェントを担当している友だちは、名札にエージェントの名前が付きます（Clover, Claude Code）。友だちの画面でも、名前の下のチップに出ます。友だちの頭のそばにある小さな点はエージェントの状態で、ポインターを重ねると名前が出ます。

| 点 | 状態 | 消えるとき |
|---|---|---|
| 点滅するオレンジ | 作業中 | エージェントが次に報告するまで続きます |
| 青 | 確認待ち | エージェントが次に報告するまで続きます |
| 緑 | 完了 | 30分で消えます |
| 赤 | 問題 | 30分で消えます |

友だちの画面の表示も、エージェントの状態を表しています。会話の答えはログに出ます。

## 起きること <Since v="0.1.0" />

エージェントの作業が進むと、その段階が友だちの状態になります。状態は友だちの画面の名前の隣と庭の名札に出て、デスクトップでは友だちの上に吹き出しで浮かびます。

| エージェントがしていること | 友だちの状態 |
|---|---|
| 考え中、ツールを使用中（例：「Bash を使用中」） | **作業中** |
| 承認や返答を待っている | **確認待ち** |
| タスクを終えた | **作業完了** |
| エラーが起きた | **問題が起きました** |
| セッションが終わった | **休憩中** |

友だちは最近の活動を8件まで覚えています。[会話](./chat.md)で「何をしていたの？」と聞くと教えてくれます。

## 設定をコピーして貼り付ける <Since v="0.1.0" />

<Shot name="settings-agents" caption="設定 → 開発ツール連携のコーディングエージェント連携。ツールごとに「設定をコピー」ボタンがあります。" />

1. **友だちと設定 → 設定 → 開発ツール連携**を開きます。
2. 使っているツールの隣の**設定をコピー**を押します。どのファイルに貼り付けるかは案内に出ます。
3. そのファイルを開いて貼り付け、保存します。エージェントを再起動すれば、すぐにつながります。

| ツール | 貼り付け先 | しくみ |
|---|---|---|
| Claude Code（おすすめ） | `~/.claude/settings.json` | フックで各段階を報告します |
| Codex CLI | `~/.codex/config.toml`の先頭 | タスクが終わったときに報告します |
| Gemini CLI | `~/.gemini/settings.json` | フックで各段階を報告します |
| Cursor | `~/.cursor/hooks.json` | 編集、コマンド、完了を報告します。見るだけのフックしか使いません |
| Grok Build | `~/.grok/hooks/playpets.json`（新しいファイルとして保存） | フックでステップごとに報告します |
| ほかのMCPツール | そのツールのMCP設定 | AIが`set_pet_state`、`say`、`react`、`list_pets`ツールで状態と吹き出しを直接送ります |

- コピーした設定には、PlayPetsの実行ファイルのパスが入っています。
- この実行ファイル自体がフックコマンドなので、ほかにインストールするものはありません。
- アプリを別の場所へ移したら、設定をコピーし直して貼り付けてください。
- ファイルにすでに`hooks`や`mcpServers`の項目があるときは、コピーした設定をその項目の中にまとめてください。
- Grok BuildはClaude CodeとCursorのフックも実行します。それでもGrok Buildの作業はGrok Buildの友だちにだけ表示されます。

## 端末から <Since v="0.1.0" />

同じ実行ファイルを端末から呼び出せば、友だちに話しかけられます。下の`playpets`はアプリの実行ファイルのことで、macOSでは`/Applications/PlayPets.app/Contents/MacOS/playpets`です。

```
playpets hook claude|gemini|cursor|grok   # フック（標準入力にJSON、終了コードは常に0。GeminiとCursorには{}を出力）
playpets hook codex <json>      # Codex notify
playpets mcp                    # 標準入出力のMCPサーバー
playpets status <状態> [メッセージ]   [--pet 名前|ID] [--bridge ファイル]
playpets say <言葉>
playpets react <動作>
playpets pets
playpets run -- <コマンド>
```

よく使う例：

| コマンド | すること |
|---|---|
| `playpets pets` | 友だちと今の状態を一覧にします |
| `playpets say "Tests passed"` | 状態を変えずに吹き出しを出します |
| `playpets status working "Building"` | 状態を変えます。`idle`、`working`、`waiting`、`done`、`error`のどれか |
| `playpets react wave` | 1回反応します。`wave`、`jump`、`pet`のどれか |
| `playpets run -- npm test` | 実行中は**作業中**、終わると**作業完了**か**問題が起きました**になります |

- 特定の友だちに送るときは`--pet 名前`か`--pet 友だちID`を付けます。付けなければ最初の友だちに届きます。
- 友だちIDは**友だち設定**の窓のいちばん下にあります。

## セキュリティ <Since v="0.1.0" />

- フックはこのコンピューターの中だけで動きます。
  - アプリは`127.0.0.1`のランダムなポートを開き、リクエストごとにランダムなトークンを確認します。
  - ポートとトークンはデータフォルダーの`bridge.json`にあり、起動のたびに変わります。
- [コーディングエージェント連携](./agents.md)は、利用者のプロンプトとツールへの入力を含めません。
  - ローカルのブリッジは`127.0.0.1`とトークン認証を使います。
  - 短い完了報告や通知には、途中で切ったエージェントの答えなど、作業の詳細が入ることがあります。それが、選んだAI接続先との友だちの会話に含まれる場合があります。
  - 端末やMCPのメッセージで送る内容は確認してください。
  - そうした詳細をこのコンピューターの中に留めたいときは、ダウンロードしたローカルモデルを使ってください。
- フックがエージェントの作業を止めることはありません。3秒以内に静かに終わり、アプリを閉じていてもエージェントは動き続けます。
- 会話に使うAI接続とは別のものです。フックを設定しただけでは、友だちと会話はできません。
- 詳しい設計は開発者向け文書（英語）の[Coding agent integration](/dev/agent-integration)にあります。

## Windowsでの注意

- ローカルでビルドした試用のMSIXパッケージでは、実行ファイルが`WindowsApps`の下にあるため、パスで呼び出せません。その場合、コピーした設定は実行エイリアス`%LOCALAPPDATA%\Microsoft\WindowsApps\playpets.exe`を指します。
- npmでインストールした`claude`と`codex`は、`%APPDATA%\npm`にあればアプリが見つけます。別の場所にインストールした場合は、自動検出がうまくいかないことがあります。
