# ペットを取り込む

アプリに付属する基本ペットと、Codexのペットフォルダー（`~/.codex/pets`）にあるペットは、何もしなくても**友だちを招待**に出てきます。それ以外のペットは取り込んで使います。

::: tip 早見表
| どこから | やり方 | 保存先 |
|---|---|---|
| ギャラリーの「PlayPetsで開く」リンク | クリックして承認 | データフォルダーの`pets/` |
| ペットページやGitHubのペットフォルダーのURL | **ペットを取り込む → ペットページのURL → 取り込む** | データフォルダーの`pets/` |
| 手元のフォルダー | **このパソコンのフォルダから取り込む** | その場所のまま。コピーしません |
| 手元のZIPファイル | **このパソコンのZIPファイルから取り込む** | データフォルダーの`pets/` |
:::

## リンクから一度で取り込む <Since v="0.1.0" />

1. ペットのギャラリーで「PlayPetsで開く」リンクをクリックします。リンクは`playpets://import?url=<ペットページのURL>`の形です。
2. PlayPetsがインストールされていれば「このペットを取り込みますか？」と確認され、リンクの送信元のサイトも表示されます。
3. 承認するとそのペットを取り込み、**友だちを招待**が開きます。

ギャラリーを運営しているなら、ペットページにこのリンクを置いてください。

```text
playpets://import?url=https%3A%2F%2Fpetdex.dev%2Fpets%2Fboba
```

## ペットを取り込む画面 <Since v="0.1.0" />

**友だちを招待**の上部にある**ペットを取り込む**をクリックすると開きます。方法は3つです。

| 方法 | やり方 |
|---|---|
| URL | コミュニティサイトのペットページ、またはGitHubのペットフォルダーのURLを**ペットページのURL**に貼り付け、**取り込む**をクリック |
| フォルダー | **このパソコンのフォルダから取り込む**をクリックし、ペットのフォルダーを選ぶ |
| ZIPファイル | **このパソコンのZIPファイルから取り込む**をクリックし、制作キットのZIPなどペットのZIPを選ぶ |

- 取り込みが終わると、そのペットはすぐに友だちとして庭に招待され、「新しいペットを取り込んで庭に招待しました。」と通知が出ます。
- URLから取り込むとき、ファイルはhttpsでだけ、貼り付けたURLのサイト（とそのサブドメイン）からだけ取得します。
- 別のサイトのファイルを指しているページには従いません。
- URLが間違っていたり、サイトが応答しなかったりすると、画面に理由が出ます。
- 取り込みの途中は画面を閉じられません。

## 対応サイト <Since v="0.1.0" />

1. **ほかのペットを探す**を開きます。URLの欄と取り込みの操作を見つけやすいように、最初は折りたたまれています。開くと、サイトの一覧と取り込みの案内がコンパクトに並びます。
2. サイトをクリックすると、ブラウザーで開きます。
3. ペットページのURLをコピーして、上の欄に貼り付けます。

| サイト | サイトのアドレス |
|---|---|
| OpenPets Registry | openpets.sh |
| Petdex | petdex.dev |
| Awesome Codex Pet | codexpet.top |
| Codex Pets | codex-pets.net |

- 上のサイトには専用の取り込み処理があります。
- チップのない場所も使えます。GitHubにあるペットフォルダー（`pet.json`を含むフォルダー）のURLや、codex-pet-shareで作られたサイトのペットページのURLも取り込めます。
- 「**(見るだけ)**」と付いた掲載先には、専用の取り込み処理がありません。ブラウザーで開くことはでき、互換性のある一般的なペットページなら、URLを貼り付けると取り込めることもあります。新しいサイトを掲載しただけでは、取り込みには対応しません。

これらはコミュニティへのリンクで、掲載は提携を意味しません。ここのペットは PlayPets ではなく、ほかの人が作って公開したものです。問題のあるペットは、取り込んだ元のサイトで報告してください。

## 手元のフォルダー <Since v="0.1.0" />

**このパソコンのフォルダから取り込む**で選んだフォルダーはアプリの保存先にコピーされず、アプリはその場所から直接読み込みます。そのため、**友だちを招待**の**このパソコンから選んだペット**に、フォルダー名と一緒に表示されます。

- フォルダーで選んだペットはコピーが作られないので、そのフォルダーは保管しておく場所に置き、使っている間は移動したり削除したりしないでください。
- 制作キットから受け取ったZIPは解凍しなくても、下の[ZIPファイル](#zip-file)のように取り込めます。

::: warning フォルダーを移動すると友だちは待ちます
友だちは、ペットフォルダーのパスで自分のペットを見分けています。選んだフォルダーを移動したり削除したりすると（そのフォルダーがあるドライブを外したときも同じです）、次にアプリを開いたとき、そのペットの友だちは庭に来られません。

ただし、友だちが消えるわけではありません。なかよし度を保ったまま待っていて、何人待っているかは通知で知らせます。フォルダーを同じ場所に戻せば、友だちは戻ってきます。
:::

## ZIPファイル <Since v="1.4.0" /> {#zip-file}

**このパソコンのZIPファイルから取り込む**で選んだZIPはアプリの中にコピーされます。取り込んだあとはZIPを移動しても削除しても大丈夫です。**友だちを招待**の**URLやZIPから取り込んだペット**に表示されます。

- 制作キットのZIPやホームページで保存した友だちの`playpets-<名前>.zip`でも、ペットフォルダーを自分で圧縮したZIPでも取り込めます。
- `pet.json`はZIPのいちばん上か、中にある1つのフォルダーに置きます。
- 同じZIPをもう一度取り込んでも、ペットは1つのままです。内容が変わったZIPは、元のペットの横に新しいペットとして入ります。

## 保存場所 <Since v="0.1.0" />

URLやZIPから取り込んだペットは、[データフォルダー](./install.md#data-folder)の`pets/`に1つのフォルダーとして保存されます。

| **友だちを招待**のグループ | フォルダーの開き方 |
|---|---|
| **URLやZIPから取り込んだペット** | **フォルダを開く**ボタンですぐに開けます |
| **PlayPetsの基本ペット**、**Codexのペットフォルダ** | 同じ**フォルダを開く**ボタンがあります |
| **このパソコンから選んだペット** | ボタンはなく、各カードにフォルダー名が出ます |

取り込んだペットの`pet.json`には、どこから来たかが記録されます。**友だちを招待**のカードには「Petdex, 作者, CC BY-NC 4.0」のように、サイト、作者、ライセンスが1行で出ます。コミュニティのペットは作者の作品なので、使う前にライセンスを確認してください。

## ペットを削除する <Since v="1.4.0" /> {#remove-a-pet}

自分で取り込んだペットには、**友だちを招待**のカードの横にゴミ箱ボタンがあります。PlayPetsの基本ペットとCodexのペットフォルダのペットにはありません。

| ペット | 削除すると |
|---|---|
| URLやZIPから取り込んだペット | `pets/`の中のそのフォルダーが削除されます。また使うときは取り込み直してください |
| このパソコンから選んだペット | 一覧から外れるだけで、フォルダーはその場所に残ります |

- そのペットから迎えた友だちが庭にいる間は削除できません。先にお別れしてください。
- 庭がいっぱいで、あとで戻ってくる友だちがそのペットを使っているときも削除できません。その友だちの名前が表示されます。

## 自分で作る {#make-your-own}

ペットは、`pet.json`とスプライトシート1枚（PNGまたはWebP）を入れた1つのフォルダーです。形式はCodexのペットと同じなので、Codex用に作ったペットはそのまま使えます。自分のAIツールで作るなら[キャラクター制作室](./creator-kit.md)を使います。

```json
{
  "id": "white",
  "displayName": "White",
  "kind": "animal",
  "description": "A puppy.",
  "spriteVersionNumber": 2,
  "spritesheetPath": "spritesheet.webp"
}
```

| 項目 | 内容 |
|---|---|
| シートの幅 | 1536px |
| 1セル | 192×208px、1行8セル |
| v1 | 9行（1872px）。順に休憩、右へ歩く、左へ歩く、手を振る、跳ぶ、エラー、待機、作業、完了 |
| v2 | 11行（2288px）。16方向の視線の2行が加わり、デスクトップでペットがマウスを目で追います |

- `description`は、新しい友だちの最初の性格になります。
- 各行のアニメーションと検証のルールは、開発者向けドキュメントの[ペットファイルの形式（英語）](/dev/standards/pet-files)にあります。
- 作ったフォルダーは、**このパソコンのフォルダから取り込む**ですぐに招待できます。
