# ペットを取り込む

- ペットはキャラクターのファイルです。
- 次のペットは、何もしなくても**友だちを招待**に表示されます。
  - アプリに付属する基本ペット
  - Codexのペットフォルダー（`~/.codex/pets`）のペット
- それ以外のペットは取り込みます。

## リンクから一度で取り込む <Since v="0.1.0" />

1. ペットのギャラリーの「PlayPetsで開く」リンクをクリックします。リンクは`playpets://import?url=<ペットページのURL>`の形です。
2. PlayPetsがインストールされていれば、**このペットを取り込みますか？**と尋ね、リンクの送信元のサイトを表示します。
3. 承認するとそのペットを取り込み、**友だちを招待**を開きます。

- ギャラリーを運営しているなら、ペットページにこのリンクを置いてください。

```text
playpets://import?url=https%3A%2F%2Fpetdex.dev%2Fpets%2Fboba
```

## ペットを取り込む画面 <Since v="0.1.0" />

- **友だちを招待**の上部の**ペットを取り込む**をクリックすると開きます。方法は2つです。

| 方法 | やり方 |
|---|---|
| URL | コミュニティサイトのペットページ、またはGitHubのペットフォルダーのURLを**ペットページのURL**に貼り付け、**取り込む**をクリック |
| フォルダー | **このパソコンのフォルダから取り込む**をクリックし、ペットのフォルダーを選ぶ |

- URLの場合、ファイルはhttpsでだけ、貼り付けたURLのサイト（とそのサブドメイン）からだけ取得します。別のサイトのファイルを指すページには従いません。
- 取り込みが終わると、そのペットはすぐに友だちとして庭に招待されます。「新しいペットを取り込んで庭に招待しました。」と通知されます。

## 対応サイト <Since v="0.1.0" />

- **ほかのペットを探す**は、ペットのURLと取り込みの操作を見つけやすいよう、最初は折りたたまれています。
- 開くと、サイトの一覧と取り込みの案内がコンパクトに出ます。
- サイトをクリックするとブラウザーで開きます。ペットページのURLをコピーして、上の欄に貼り付けてください。
- これらはコミュニティへのリンクで、掲載は提携を意味しません。

| サイト | サイトのアドレス |
|---|---|
| OpenPets Registry | openpets.sh |
| Petdex | petdex.dev |
| Codex PokéPets | github.com/dnnyngyen/codex-pokepets |
| Awesome Codex Pet | codexpet.top |
| Codex Pets | codex-pets.net |

- チップのない場所も使えます。
  - GitHubにあるペットフォルダー（`pet.json`を含むフォルダー）のURL
  - codex-pet-shareで作られたサイトのペットページのURL
- 上のサイトには専用の取り込み処理があります。
- **(見るだけ)**と付いた掲載先には、専用の取り込み処理がありません。
  - ブラウザーで開くことはできます。
  - 互換性のある一般的なペットページなら、貼り付けると取り込めることもあります。
- 新しいサイトを掲載しただけで、取り込みに対応するわけではありません。
- URLが間違っていたり、サイトが応答しなかったりすると、画面に理由が出ます。
- 取り込みの途中は画面を閉じられません。

## 手元のフォルダー <Since v="0.1.0" />

- **このパソコンのフォルダから取り込む**で選んだフォルダーはコピーされず、アプリはその場所から読みます。
- そのため**友だちを招待**の**このパソコンから選んだペット**に、フォルダー名と一緒に表示されます。
- 制作キットから受け取ったZIPは、保管する場所に解凍してからフォルダーを選びます。
- アプリの保存先にはコピーされません。使用中は選んだフォルダーを移動、削除しないでください。

::: warning フォルダーを移動すると友だちは待ちます
- 友だちは、ペットフォルダーのパスで自分のペットを見分けます。
- 選んだフォルダーを移動、削除する（またはそのフォルダーがあるドライブを外す）と、次にアプリを開いたとき、そのペットの友だちは庭に来られません。
- 友だちは消えず、なかよし度を保ったまま待ちます。何人待っているかは通知で知らせます。
- フォルダーを同じ場所に戻すと、友だちは戻ってきます。
:::

## 保存場所 <Since v="0.1.0" />

- URLから取り込んだペットは、[データフォルダー](./install.md#data-folder)の`pets/`に1つのフォルダーとして保存されます。

| **友だちを招待**のグループ | フォルダーの開き方 |
|---|---|
| **URLから取り込んだペット** | **フォルダを開く**ボタンですぐに開けます |
| **PlayPetsの基本ペット**、**Codexのペットフォルダ** | 同じ**フォルダを開く**ボタンがあります |
| **このパソコンから選んだペット** | ボタンはなく、各カードにフォルダー名が出ます |

- 取り込んだペットの`pet.json`には、どこから来たかが記録されます。
- **友だちを招待**のカードには、「Petdex, 作者, CC BY-NC 4.0」のようにサイト、作者、ライセンスが1行で出ます。
- コミュニティのペットは作者の作品です。使う前にライセンスを確認してください。
- 使わなくなったペットを消すには、`pets/`の中のそのフォルダーを削除します。
  - そのペットから作った友だちは、上の説明のとおり、次回の起動から庭の外で待ちます。
  - 友だちも消したいなら、先にお別れしてください。

## 自分で作る {#make-your-own}

- ペットは、`pet.json`とスプライトシート1枚（PNGまたはWebP）を入れた1つのフォルダーです。
- 形式はCodexのペットと同じです。Codex用に作ったペットはそのまま使えます。

```json
{
  "id": "white",
  "displayName": "White",
  "kind": "animal",
  "description": "A puppy.",
  "spriteVersionNumber": 2,
  "spritesheetPath": "spritesheet.webp"
}
```

| 項目 | 内容 |
|---|---|
| シートの幅 | 1536px |
| 1セル | 192×208px、1行8セル |
| 行数 | v1は9行（1872px）、v2は11行（2288px） |
| v1の9行 | 順に休憩、右へ歩く、左へ歩く、手を振る、跳ぶ、エラー、待機、作業、完了 |
| v2で加わる行 | 16方向の視線の2行。デスクトップでペットがマウスを目で追います |

- `description`は、新しい友だちの最初の性格になります。
- 各行のアニメーションと検証のルールは、開発者向けドキュメントの[ペットファイルの形式（英語）](/dev/standards/pet-files)にあります。
- 作ったフォルダーは、**このパソコンのフォルダから取り込む**ですぐに招待できます。
