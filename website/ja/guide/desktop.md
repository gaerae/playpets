# デスクトップモード

- 庭の窓から友だちをデスクトップへ出して、そこで暮らしてもらえます。
- ほかのアプリで作業している間も見えたままです。

<Shot name="desktop" caption="デスクトップモード。友だちがほかのウィンドウの上で暮らし、コーディングエージェントの状態を吹き出しで伝えます。" />

## オン、オフ <Since v="0.1.0" />

1. **友だちと設定 → ウィンドウとデスクトップ**で**デスクトップに表示**をオンにします。
2. 歩き回らせるなら、すぐ下の**デスクトップでおさんぽ**もオンにします（デスクトップ表示がオンのとき使えます）。

- どちらのスイッチも現在の状態が分かり、切り替えてもメニューは開いたままです。
- **デスクトップに表示**をオフにすると、友だちが庭へ戻ります。
- 友だちがいないときはデスクトップ表示を使えません。
- トレイアイコンのメニューにも同じ項目があり、庭の窓を開かずに切り替えられます。

## デスクトップでできること <Since v="0.1.0" />

| 操作 | 方法 |
|---|---|
| なでる | 友だちを1回左クリックします |
| 移動 | 友だちをドラッグして置きます。別のモニターへも移動できます |
| 話す | ポインターを重ねると、下に名前と会話マークが出ます。名前をクリックすると、庭の窓がその友だちの会話を開いた状態で開きます。右クリックでも同じです |
| 視線 | 休んでいる友だちの顔にポインターを重ねると、目で追います。16方向の視線画像があるv2ペットだけが対応します |

- ダブルクリックでは何も起こりません。移動中にうっかり窓が開くことはありません。
- デスクトップモードを初めてオンにすると、話し方の案内が出ます。
- 名前はポインターを重ねるまで隠れているので、友だちがデスクトップになじみます。
- [コーディングエージェント](./agents.md)の状態や友だちの言葉は、頭上の吹き出しに出ます。長い文章は3行の後に「…」で省略します。

## どのモニターにも <Since v="0.1.0" />

- モニターが複数あれば、友だちはどのモニターにもいられます。
- 別のモニターへドラッグすると、そこに留まります。
- モニターごとに表示倍率が違っても、ポインターの位置はそのモニターの倍率で扱います。

## デスクトップでおさんぽ <Since v="0.1.0" />

- **デスクトップでおさんぽ**をオンにすると、友だちがデスクトップをゆっくり歩き回ります。
  - 進む方向を向き、ときどき立ち止まって休みます。
  - ドラッグしている間は歩きません。
- オフにすると、置いた場所に留まります。

## ほかのアプリの全画面の上でも <Since v="0.1.0" />

| OS | 表示 |
|---|---|
| macOS | ほかのアプリが全画面でも最前面に表示。デスクトップの窓を特別なパネルにして、全画面のスペースにも出します |
| Windows、Linux | 通常のウィンドウの上に表示 |
| Linux（Wayland） | 最前面に留まる方法もポインターの位置を知る方法もないため、ほかのウィンドウの後ろになることがあり、ポインターを目で追いません |
| Linux（X11） | どちらも使えます |

## 窓を閉じた後も <Since v="0.1.0" />

- すべてのOSで、タイトルバーやウィンドウボタンを出さずに庭だけを見せます。
  - 移動：上端の細い透明な部分をドラッグします。
  - サイズ変更：端や角をドラッグします。300 × 210まで小さくできます。
- **友だちと設定 → ウィンドウを閉じる**やOSの閉じるショートカットで窓を隠しても、デスクトップの友だちとエージェント連携は動き続けます。
- macOSでは、窓を閉じるとDockアイコンも消えます。
  - クリックしても反応しないアイコンをDockに残さないためです。
  - 庭を開き直すとDockアイコンも戻ります。
- WindowsとLinuxでは、タスクバーから消えてトレイにだけ残ります。

## 開き直す

- メニューバー（macOS）やタスクバー（Windows、Linux）のトレイアイコンをクリックし、**庭を開く**を選びます。
- デスクトップで友だちの名前をクリックしても（または友だちを右クリックしても）、庭の窓が開きます。

## 完全に終了する

- 次のどれかで、確認なしにすぐ終了します。
  - **友だちと設定 → PlayPets を終了**
  - トレイメニューの**PlayPets を終了**
  - macOSの<kbd>⌘</kbd> <kbd>Q</kbd>
- 小さな窓では、右下のボタンか背景の右クリックから**友だちと設定**を開きます。
- 会話は保存されず、デスクトップの友だちも一緒にいなくなります。
- 友だちの名前、性格、大きさと、デスクトップモードがオンだったかは覚えています。次に開くと前のままです。
