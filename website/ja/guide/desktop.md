# デスクトップモード

庭の窓から友だちを出すと、デスクトップで暮らしてもらえます。ほかのアプリで作業している間も、友だちはずっと見えています。

<Shot name="desktop" caption="デスクトップモード。友だちがほかのウィンドウの上で暮らし、コーディングエージェントの状態を吹き出しで伝えます。" />

## オン、オフ <Since v="0.1.0" />

1. **友だちと設定 → ウィンドウとデスクトップ**で**デスクトップに表示**をオンにします。
2. 歩き回らせたいときは、すぐ下の**デスクトップでおさんぽ**もオンにします。デスクトップ表示がオンのときだけ使えます。

どちらのスイッチも今の状態がひと目で分かり、切り替えてもメニューは開いたままです。**デスクトップに表示**をオフにすると、友だちは庭へ戻ります。

- 友だちがいないときは、デスクトップ表示を使えません。
- トレイアイコンのメニューにも同じ項目があり、庭の窓を開かずに切り替えられます。

## デスクトップでできること <Since v="0.1.0" />

| 操作 | 方法 |
|---|---|
| なでる | 友だちを1回左クリックします |
| 移動 | 友だちをドラッグして置きます。別のモニターへも移動できます |
| 話す | ポインターを重ねると、下に名前と会話マークが出ます。名前をクリックすると、庭の窓がその友だちの会話を開いた状態で開きます。右クリックでも同じです |
| 視線 | 休んでいる友だちの顔にポインターを重ねると、目がポインターを追います。16方向の視線画像があるv2ペットだけが対応します |

ダブルクリックでは何も起こらないので、移動中にうっかり窓が開くことはありません。デスクトップモードを初めてオンにすると、話し方の案内が出ます。

名前はポインターを重ねるまで隠れているので、友だちがデスクトップになじみます。[コーディングエージェント](./agents.md)の状態や友だちの言葉は、頭の上の吹き出しに出ます。長い文は3行の後に「…」で省略されます。

## どのモニターにも <Since v="0.1.0" />

モニターが複数あれば、友だちはどのモニターにもいられます。別のモニターへドラッグすると、そこに留まります。モニターごとに表示倍率が違っても、ポインターの位置はそれぞれのモニターの倍率で扱います。

## デスクトップでおさんぽ <Since v="0.1.0" />

**デスクトップでおさんぽ**をオンにすると、友だちがデスクトップをゆっくり歩き回ります。進む方向を向き、ときどき立ち止まって休みますが、ドラッグしている間は歩きません。オフにすると、置いた場所に留まります。

## ほかのアプリの全画面の上でも <Since v="0.1.0" />

| OS | 表示 |
|---|---|
| macOS | ほかのアプリが全画面でも最前面に表示。デスクトップの窓を特別なパネルにして、全画面のスペースにも出します |
| Windows、Linux | 通常のウィンドウの上に表示 |
| Linux（Wayland） | 保証されません。Waylandには最前面に留まる方法もポインターの位置を知る方法もないため、ほかのウィンドウの後ろになることがあり、ポインターを目で追いません |
| Linux（X11） | 通常のウィンドウの上に表示し、ポインターも目で追います |

## 窓を閉じた後も <Since v="0.1.0" />

- すべてのOSで、タイトルバーやウィンドウボタンを出さずに庭だけを見せます。
  - 移動：上端の細い透明な部分をドラッグします。
  - サイズ変更：端や角をドラッグします。300 × 210まで小さくできます。

**友だちと設定 → ウィンドウを閉じる**やOSの閉じるショートカットを使っても、窓が隠れるだけです。デスクトップの友だちとエージェント連携は動き続けます。

macOSでは、窓を閉じるとDockアイコンも消えます。クリックしても反応しないアイコンをDockに残さないためで、庭を開き直せばDockアイコンも戻ります。WindowsとLinuxでは、タスクバーから消えてトレイにだけ残ります。

## 開き直す

メニューバー（macOS）やタスクバー（Windows、Linux）のトレイアイコンをクリックし、**庭を開く**を選びます。デスクトップで友だちの名前をクリックしても（または友だちを右クリックしても）、庭の窓が開きます。

## 完全に終了する

- 次のどれかで、確認なしにすぐ終了します。
  - **友だちと設定 → PlayPets を終了**
  - トレイメニューの**PlayPets を終了**
  - macOSの<kbd>⌘</kbd> <kbd>Q</kbd>
- 小さな窓では、右下のボタンか背景の右クリックから**友だちと設定**を開きます。

終了すると会話は保存されず、デスクトップの友だちも一緒にいなくなります。友だちの名前、性格、大きさと、デスクトップモードがオンだったかは覚えているので、次に開くと前のままです。
