# デスクトップモード

庭の窓から友だちを出すと、作業中のアプリの上で、デスクトップに暮らしてもらえます。

::: tip 早見表
| したいこと | すること | 詳しく |
|---|---|---|
| ひとりだけ出す | 庭で右クリック → **デスクトップに表示** | [オン、オフ](#turning-it-on-and-off) |
| みんなを出す | **友だちと設定 → ウィンドウとデスクトップ → デスクトップに表示** | [オン、オフ](#turning-it-on-and-off) |
| 歩き回らせる | すぐ下の**デスクトップでおさんぽ** | [デスクトップでおさんぽ](#stroll-on-desktop) |
| プレゼント、花、木で机を飾る | 庭で右クリック → **デスクトップに表示** | [プレゼント](#gifts-on-the-desktop)、[花と木](#flowers-and-trees-on-the-desktop) |
| 友だちと話す | ポインターを重ねて名前をクリック | [できること](#things-to-do-on-the-desktop) |
| 庭へ戻す | 右クリック → **デスクトップから外す** | [できること](#things-to-do-on-the-desktop) |
| 窓だけ隠して友だちは残す | **友だちと設定 → ウィンドウを閉じる** | [閉じる、開き直す、終了](#close-reopen-and-quit) |
:::

## オン、オフ <Since v="0.1.0" /> {#turning-it-on-and-off}

ひとりだけ：庭でその友だちを右クリックして**デスクトップに表示**を選びます。出ているあいだはチェックが付き、もう一度選ぶと戻ってきます。友だちは一人ずつ出られて、庭にもそのまま残ります。

みんなを一度に：

1. **友だちと設定 → ウィンドウとデスクトップ**を開きます。
2. **デスクトップに表示**をオンにします。
3. 歩き回らせたいときは、すぐ下の**デスクトップでおさんぽ**もオンにします。デスクトップに何か出ているときだけ使えます。

- どちらのスイッチも今の状態がひと目で分かり、切り替えてもメニューは開いたままです。
- **デスクトップに表示**をオフにすると、友だち、プレゼント、花、木がみんな庭へ戻ります。
- 友だちがいないときは、デスクトップ表示を使えません。
- トレイアイコンのメニューにも同じ項目があり、庭の窓を開かずに切り替えられます。

## デスクトップでできること <Since v="0.1.0" /> {#things-to-do-on-the-desktop}

| 操作 | 方法 |
|---|---|
| なでる | 友だちを1回左クリックします |
| 移動 | 友だちをドラッグして置きます。別のモニターへも移動できます |
| 話す | ポインターを重ねると、下に名前と会話マークが出ます。名前をクリックすると、庭がその友だちの会話を開いた状態で開きます |
| メニュー | 友だちを右クリックすると、**話しかける**と**デスクトップから外す**が出ます。プレゼント、花、木には**デスクトップから外す**があります |
| 視線 | 休んでいる友だちの顔にポインターを重ねると、目が追います。16方向の視線画像があるv2ペットだけが対応します |

- ダブルクリックでは何も起こらないので、移動中にうっかり窓が開くことはありません。
- 初めて何かを出したときに、話し方と庭へ戻す方法の案内が出ます。
- 名前はポインターを重ねるまで隠れているので、友だちがデスクトップになじみます。
- [コーディングエージェント](./agents.md)の状態や友だちの言葉は、頭の上の吹き出しに出ます。長い文は3行の後に「…」で省略されます。

## デスクトップのプレゼント <Since v="1.5.0" /> {#gifts-on-the-desktop}

ベンチや植木鉢などのプレゼントを庭で右クリックして、**デスクトップに表示**を選びます。庭にもそのまま残ります。

- ドラッグで動かせます。別のモニターへも移せて、置いた場所にとどまります。
- デスクトップでおさんぽしている友だちが、ときどきプレゼントのそばへ歩いていって、ひとこと話します。
- 庭でプレゼントを片づけると、デスクトップからも外れます。一度届いたプレゼントは図鑑からまた出せます（[プレゼント](./play.md#gifts)）。
- 雪だるまとクリスマスのプレゼントは、庭に出ているあいだだけデスクトップにも出ます（[季節のイベント](./play.md#seasonal-events)）。雪だるまはマフラーと帽子と鼻を、ツリーは飾りをつけたまま出ます。
- [クリスマスの夜](./play.md#christmas-night)には、デスクトップのツリーも庭のツリーといっしょに育ちます。

## デスクトップの花と木 <Since v="1.6.1" /> {#flowers-and-trees-on-the-desktop}

植えた花や木を庭で右クリックして**デスクトップに表示**を選びます。庭にもそのまま残ります。

- デスクトップでも庭と同じように育ちます。芽を出しておけば、机の上で花が咲きます。
- 育った木は、庭が見せている季節の姿になります。
- ほかの場所の木も、庭がどの場所を見せていてもデスクトップに残ります。
- プレゼントと同じくドラッグで動かせます。デスクトップでおさんぽしている友だちが、ときどきそばへ歩いていきます。
- 庭で抜いたり片づけたりすると、デスクトップからも外れます。

## デスクトップでおさんぽ <Since v="0.1.0" /> {#stroll-on-desktop}

- **デスクトップでおさんぽ**をオンにすると、友だちがデスクトップをゆっくり歩き回ります。進む方向を向き、ときどき立ち止まって休みます。
- ドラッグしている間は歩きません。
- オフにすると、置いた場所に留まります。

## どのモニターにも <Since v="0.1.0" />

- モニターが複数あれば、友だちはどのモニターにもいられます。ドラッグして置くと、そこに留まります。
- モニターごとに表示倍率が違っても、ポインターの位置はそれぞれのモニターの倍率で扱います。

## ほかのアプリの全画面の上でも <Since v="0.1.0" />

| OS | 友だちが浮かぶ場所 |
|---|---|
| macOS | ほかのアプリが全画面でも最前面。デスクトップの窓を特別なパネルにして、全画面のスペースにも出します |
| Windows、Linux | 通常のウィンドウの上 |
| Linux（Wayland） | 保証されません。Waylandには最前面に留まる方法もポインターの位置を知る方法もないため、ほかのウィンドウの後ろになることがあり、ポインターを目で追いません。友だちのクリックやドラッグもまだ確認できていません |
| Linux（X11） | 通常のウィンドウの上。ポインターも目で追います |

## 閉じる、開き直す、終了する <Since v="0.1.0" /> {#close-reopen-and-quit}

| したいこと | 方法 | どうなるか |
|---|---|---|
| 窓を隠す | **友だちと設定 → ウィンドウを閉じる**、またはOSの閉じるショートカット | 庭はトレイに隠れ、デスクトップの友だちとエージェント連携は動き続けます。macOSでは反応しないアイコンを残さないようDockアイコンも消え、庭を開き直すと戻ります。WindowsとLinuxではタスクバーから消えます |
| 開き直す | メニューバー（macOS）やタスクバー（Windows、Linux）のトレイアイコン → **庭を開く**。デスクトップで友だちの名前をクリックしても、メニューの**話しかける**でも開きます | 庭の窓が開きます |
| 終了する | **友だちと設定 → PlayPets を終了**、トレイメニューの**PlayPets を終了**、macOSの<kbd>⌘</kbd> <kbd>Q</kbd> | 確認なしにすぐ終了します。会話は保存されず、デスクトップの友だちも一緒にいなくなります |

- どのOSでも、タイトルバーやウィンドウボタンはありません。上端の細い透明な部分をドラッグして移動し、端や角をドラッグして300 × 210までサイズを変えます。
- 小さな窓では、右下のボタンか背景の右クリックから**友だちと設定**を開きます。
- 終了しても、友だちの名前、性格、大きさと、どの友だち、プレゼント、花、木がデスクトップに出ていたかは覚えています。
