# 庭と遊び

庭は時間帯、天気、季節に合わせて変わり、日を追って育っていきます。友だちは穴掘りで花の種や苗木を見つけたりプレゼントを持ってきたりし、あなたは釣りや虫取りで図鑑を埋められます。友だちはあなたと少しずつ仲良くなり、季節のイベントがやってきては過ぎ、庭には庭の音があり、友だちと3つの遊びを楽しめます。

風景がウィンドウを満たします。下の入口は**場所と雰囲気**、**遊ぶ**、**友だちと設定**の3つです。どれも1ページのパネルで、中はいくつかのまとまりに分かれています。中にタブや戻るボタンはありません。庭のパネルは一つずつ開きます。自動の時間帯は時計を表示せずにパソコンの時刻に従います。

**遊ぶ**には選んでいる友だちに合わせて「Cloverと遊ぶ」のような題が付き、3つのまとまりに分かれています。**見つける**には**穴掘り**、**釣り**、**図鑑**、**庭**には**種を植える**（持っている種の数も表示されます）、**木を植える**、**おやつ**、**みんなで遊ぶ**には3つの遊びと**おしゃべり**があります。おしゃべりにはAIにつながった友だちが2人必要ですが、ほかの遊びはAIなしで使えます。

初めて開く庭は、晴れた春の昼から始まります。季節、時間帯、天気を自動で変えたいときは、それぞれのおまかせを選んでください。保存した設定は、次回もそのままです。

**場所と雰囲気 → 雰囲気**の**庭の音**と**音量**で、音のオン、オフと音量を調整します。最初の操作後、庭が見えている間だけ鳴ります。雨、鳥、水などの環境音は場所、天気、季節、時間帯に従います。自動おしゃべりは別の**友だちと設定 → 設定 → 友だちとAI**にあります。

## 時間帯と天気 <Since v="0.1.0" />

季節と天気は別々に反映されます。夏に雪を選ぶと夏の景色と服装のまま雪が降り、冬に晴れを選んでも冬景色は残ります。室内の窓や取り込んだ背景も同じです。自動で選ばれる雪は、これまでどおり冬だけです。

<Shot name="yard-spring" caption="晴れた春の昼の庭です。時間おまかせを選ぶと、時計に合わせて変わります。" />

右下の**場所と雰囲気**を開くと、背景をサムネイルで選べます。標準の背景と読み込んだ背景が同じ一覧に並びます。パネルは1ページで、**場所**のまとまりでは背景を、**雰囲気**のまとまりでは季節、時間帯、天気を選びます。変更はすぐに反映されます。**背景を読み込む**と**背景制作室**は「場所」の見出しの横にあります。読み込んだ背景を選んだときだけ、そこに削除ボタンが表示されます。

| 項目 | 選択肢 |
|---|---|
| 場所 | 丘の庭、石造りの中庭、湖畔の家、くつろぎのリビング |
| 時間帯 | 時間おまかせ、朝、昼、夕方、夜 |
| 天気 | 天気おまかせ、晴れ、雨、雪 |

3つの屋外の場所には、それぞれ異なる家、四季の風景、釣りの立ち位置があります。**くつろぎのリビング**では同じ落ち着いた雰囲気を室内でも楽しめます。朝、昼、夕方、夜で照明が変わり、窓の外は春の花、秋の紅葉、冬の雪に変わります。雨や雪はガラスの外だけに表示されます。どの場所でも友だちをなでたり、会話したり、花を育てたり、3つの遊びをしたりできます。釣り、虫捕り、屋外の季節演出は3つの庭で楽しめます。場所は時間帯や天気とは別に保存されます。

<Shot name="studio-night" caption="夜のくつろぎのリビング。窓の外には静かな村、室内には暖かな明かりが見えます。" />

- **時間おまかせ**はコンピューターの時計に従います。空と地面の色が朝、昼、夕方、夜と変わり、太陽は空を左から右へ横切り、夜には月がその夜の満ち欠けを見せます。
- **天気おまかせ**は20分に1回、新しい天気を選びます。たいていは晴れで、ときどき雨になり、雪は冬だけです。インターネットから実際の天気を取得することはありません。
- 屋外の場所は、囲まれた中庭から開けた丘や湖畔まで構図が異なります。色は光に合わせて変わり、背景は風景かウィンドウの大きさが変わったときだけ描き直されます。
- 季節を**おまかせ**にすると、屋外の場所は日付に合わせて変わります。春は花と舞う花びら、夏は深い緑、秋は赤や金色の葉、冬は雪景色です。**場所と雰囲気 → 雰囲気**で季節を選ぶこともできます。コンピューターのタイムゾーンが南半球なら、自動の季節は逆になります。
- 昼に雨が上がると、数分間、丘の上に虹がかかります。晴れた日はときどき鳥の群れが空を横切り、秋まではチョウが舞い、春と夏の夜にはホタルが光ります。
- 自分で値を選ぶと、その時間帯と天気に固定されます。選んだ内容は保存されるので、次にアプリを開いたときも同じです。

天気が変わると、1〜2人の友だちが「雨だ！」や「雪だるま作る？」のようにひと言話します。放っておくと、時間帯に合った独り言も言います。

## おしゃべり <Since v="0.1.0" />

**遊ぶ → みんなで遊ぶ**の「おしゃべり」を押すと、AIをつけた友だち（3人まで）が、時間帯と天気について短く話し合います。セリフは庭の吹き出しとして順番に表示されます。AIをつけた友だちが2人未満のときはボタンがオフの見た目になり、押したりポインターを重ねたりすると理由が表示されます。あなたも加わるなら、[友だちタブのグループ会話](./chat.md)を使ってください。

ときどき自分たちで話させたいときは、**友だちと設定 → 設定 → 友だちとAI**の「ときどき友だち同士で話します」をオンにします。20分に1回おしゃべりし、ウィンドウが隠れている間や誰かが返事をしている間は休みます。

## 花を育てる <Since v="0.1.0" />

花の種と苗木は同じ土掘りで見つけます。**土を掘る**を選び、友だちを空いた地面へ送り、見つけたものを植えます。散歩だけでは種や苗木は現れません。

1. **遊ぶ → 庭**の「種を植える」をクリックします（横の数字は持っている種の数です）。
2. 原っぱの場所をクリックします。続けていくつも植えられます。**Esc**を押すか、もう一度ボタンを押すと終わります。

キーボードでは、「種を植える」をEnterかSpaceで選び、もう一度押すと選んでいる友だちのそばに植えます。おやつと同じ操作です。道具を手にしている間は、1、2、3のキーで**穴掘り**、**木を植える**、**種を植える**に持ち替えます。入力欄で文字を打っている間は切り替わりません。

くつろぎのリビングでは、むき出しの土の代わりに小さな鉢に花が植わります。場所を変えても成長や図鑑は引き継がれます。

種は時計に合わせて育ち、アプリを閉じている間も育ちます。10分で芽、40分で葉、2時間でつぼみ、4時間で花になります。植えた季節に合わせて、それぞれ4種類の花が咲きます。春はチューリップ、スイセン、クロッカス、ムスカリ、夏はひまわり、アジサイ、ラベンダー、カンパニュラ、秋はコスモス、キク、ダリア、アスター、冬は椿、スノードロップ、ヘレボルス、シクラメンです。植物にポインターを重ねると、種類と咲くまでの時間が表示されます。

- 植物をクリックすると、いちばん近い友だちが歩いてきて水をやります。
- 友だちは自分から花を見に行くこともあります。
- 植物を右クリックする（または選んで**Delete**を押す）と抜けます。種は戻りません。
- 種は20個、植物は24本まで持てます。花壇は`state.json`の`garden`に保存されます。
- ある種類の花が初めて咲くと「図鑑」（花）に載り、届いたプレゼントもすべて載ります（プレゼント）。

### プレゼント

贈り物は現地の日付で庭全体に一日最大一つです。友だちごとに一つではなく、全員で回数を共有します。待ち時間は20〜40分、最初の贈り物は5分です。決まった配達時刻は保存され、アプリを閉じた時間も数えます。開き続ける必要はなく、閉じている間に時刻が来た場合は戻った後に友だちが届けられます。友だちは跳ねて知らせ、横に置きます。最初のプレゼントは、ベンチ、ランタン、巣箱、小さな池、郵便受け、レジャーシート、かざぐるま、たき火、ブランコ、植木鉢、切り株の椅子、テント、道しるべ、風鈴の順に届きます。そのあとは、庭にまだないものを持ってきます。たき火はランタンと同じように夕方から光り、友だちはブランコや切り株に座り、風鈴は友だちが訪ねると鳴ります。

- 飾りをドラッグすると、原っぱのどこへでも動かせます（選んで矢印キーでも動かせます）。
- クリックすると、いちばん近い友だちが歩いてきます。友だちは自分からも飾りを訪ね、ベンチに座ったり、シートに集まったり、池をのぞき込んだりします。
- ランタンは夕方から灯り、池は空を映し、昼は巣箱に鳥がとまります。
- 飾りを右クリックする（または選んで**Delete**を押す）と片付けられます。別の日にまた友だちが持ってくることもあります。
- 飾りは12個までで、いっぱいになると配達が止まります。片付けても図鑑の記録は残り、残りの贈り物を置く場所ができます。贈り物はイベントの開催日に届く4種類を含めて18種類です。

## 釣りと虫取り <Since v="0.1.0" />

- **釣り**：水面を押すと近くの手の空いた友だちが手動の釣りを始めます。浮きが沈んで**!**が出たらクリックします。早すぎても遅すぎても逃げられます。**遊ぶ → 釣り**では選んだ友だちが最後まで進め、どちらもその背景の釣り場を使います。

釣り竿では淡水エビ、ザリガニ、タニシも見つかります。魚と一緒に**水中の生きもの**の図鑑へ記録されます。

- **虫**：晴れた屋外で、朝と昼には蝶やトンボ、春と夏の夕方と夜にはホタルをクリックします。雨や雪のときには現れません。近くの友だちが捕まえます。
- 親密度3から、庭が見えている間、手の空いた友だちは12〜25分ごとに自分から釣りを試みます。ゲーム、別の釣り、配置ツールの使用中は休み、毎回釣れるとは限りません。
- 何が釣れて何が飛ぶかは、季節、時間帯、天気で変わります。ナマズやウナギは暗くなってから出てきて（雨の日はもっと多く）、ワカサギは冬だけ、黄金ゴイはとても珍しい魚です。魚の大きさは毎回違います。
- 捕まえたものはカードで表示され、新しいものならそう知らせます。魚、虫、咲いた花、贈り物、小さな発見のように図鑑に残るもののカードには**図鑑で見る**があり、押すとその巻を開いた図鑑が開きます。新しいものが届くと、図鑑を開くまで**遊ぶ → 見つける**の**図鑑**と下の入口の**遊ぶ**に小さな点が付きます。
- **遊ぶ → 見つける**の「図鑑」には花、水中の生きもの、虫、プレゼント、木、小さな発見の6冊があり、すべての種類を表示します。捕まえたものは数と最大の魚の大きさを、まだのものはシルエットと、いつどこで探せばよいかを表示します。`state.json`の`album`に保存されます。

図鑑は、いつどこで探せるかと、珍しい発見を再び探せる時刻を案内します。正確な確率は表示しません。

## 季節のイベント <Since v="0.1.0" />

1年に何度か、庭がしばらく変わります。風景のラベルの横にイベント名が表示され、その年に初めて見たときは始まったことを知らせるカードが出て、友だちもその話をします。

| イベント | 期間 | もたらすもの |
|---|---|---|
| 桜まつり | 4月1日〜20日 | あちこちに花びらが舞い、チョウが増えます。友だちが桜の飾りを持ってきます |
| ホタルの夜 | 7月20日〜8月20日 | 夜のホタルがぐっと増え、捕まえられる金色のホタルも出ます。友だちがスイカを持ってきます |
| 中秋の名月 | 9月25日〜10月15日 | 毎晩大きな満月が出て、夜の湖に月光ゴイが現れます。友だちがカボチャを持ってきます |
| 冬のイルミネーション | 12月10日〜31日 | 木々に小さなライトが飾られ、夕方から光ります。友だちが雪だるまを持ってきます |
| お正月 | 1月1日〜7日 | 友だちが新年のあいさつをします |

- イベントのプレゼントは、イベント中に初めてプレゼントが届くときに届き、そのときだけです。図鑑にはそれぞれがいつ届くかが表示されます。
- 南半球では、コンピューターのタイムゾーンに合わせて季節のイベントが6か月後になります（お正月は1月のままです）。

## なかよし度 <Since v="0.1.0" />

友だちはそれぞれ、庭で過ごす時間と一緒にすることを通して、あなたと仲良くなっていきます。名札のハートでどれくらい仲良しかがわかり、友だちタブには今の段階、次の段階までの距離、次の段階でできるようになることが表示されます。段階はどれくらい親しいかを表すもので、お互いがどういう間柄かではありません。そのため、恋人やきょうだいでも友だちと同じように読めます（間柄は[関係](./chat.md#relationship)で決まります）。

| 段階 | できるようになること |
|---|---|
| はじめまして | |
| うちとけた仲 | アプリを開いたときや、しばらくして戻ってきたときに迎えてくれます |
| なかよし | ときどき自分から釣りに行きます |
| 特別な仲 | |
| かけがえのない仲 | 名札に花が付き、ときどきあなただけにひと言話します |

- 一緒の時間は、庭が見えている10分ごとに数えます。なでる、おやつ、会話、水やり、捕まえること、プレゼントも1日分まで数えるので、数分クリックし続けても急には進みません。なかよし度は日を重ねて育ちます。
- 離れていても何かが減ることはありません。なかよし度は`state.json`の`bonds`に保存されます。

## 少し掘って、木を植える

下の入口から**遊ぶ**を開くか、友だちを右クリックして「Cloverと遊ぶ」のようにその友だちと遊ぶ項目を選びます。同じメニューの「Cloverに穴掘りを頼む」を選ぶと穴掘りの道具をすぐに手に取り、その友だちが先に掘りに行きます。**穴掘り**から空いた地面を選ぶと、友だちが歩いて掘ります。AI接続は不要です。水面、家具、木の根は避けてください。**Esc**で取り消せます。到着する前に別の行動をさせた場合、発見はありません。

穴掘りの道具は、しまうまで手に残ります。地面を選ぶたびに手の空いた友だちが掘りに行き、掘ったばかりの友だちが少し休む間はほかの友だちが行きます。下のドックの位置に出る帯から**木を植える**や**種を植える**へ一度で切り替えられ、帯の閉じるボタンか**Esc**で道具をしまいます。道具を手にしていても、湖や生きものが隠れることはありません。水や、飛んだり這ったりしている生きものを押すと道具をしまい、その1回で釣りや虫とりをします。空いた地面を右クリックして**ここを掘る**を選ぶと、**遊ぶ**を開かずにその場所を掘ります。

Daisy、Clover、Pip、Misoは四季を通じて、穴掘り、植える動作、竿を振る動作、魚を待つ姿、釣り上げる動作、発見したときの反応を専用の動きで見せます。Daisy、Pip、Misoは春と秋に同じ普段着を着て、夏服と冬服に着替えます。Cloverは春から秋まで青緑のオーバーオールと麦わら帽子を使い、冬はコート、マフラー、ニット帽に着替えます。取り込んだペットも、元の動きで同じ遊びに参加します。

土を掘ると花の種、苗木、17種類の小さな発見が出ることも、何も出ないこともあります。発見は**図鑑 → 小さな発見**に記録されます。珍しい発見の後は全員と全場所で次の珍しい発見まで24時間待ちます。重複があり、完了時期は保証されません。同じ場所は24時間追加の報酬がなく、友だちごとに8秒の間隔が必要です。種は20個、苗木は樹種ごとに20個までで、満杯でも別の報酬には変わりません。

まず穴掘りで苗木を見つけましょう。**木を植える**で桜、カエデ、松、オーク、白樺、柳の所持数を確認し、持っている樹種と空いた地面を選びます。植えると同じ樹種の苗木を1個使います。2時間で若木、12時間で成木になり、アプリを閉じた時間も含みます。成木は**図鑑 → 木**に一度記録されます。1か所6本、全体24本まで。木は植えた場所に残り、ドラッグで移動、右クリックと確認で片づけられます。図鑑の記録は残りますが苗木は戻りません。室内では穴掘りや植樹をしません。読み込む背景では土の利用可否を明示できます。

## 遊び <Since v="0.1.0" />

3つの遊びは**遊ぶ → みんなで遊ぶ**にあります。遊べるのは一度にひとつだけです。遊んでいる間、その遊びのボタンは遊びの名前付きの「〜をやめる」（「かくれんぼをやめる」など）になり、クリックするとすぐに遊びが終わります。遊びの間はずっと、ほかの遊びと「おやつ」「種を植える」「木を植える」は使えません。遊びが終わると、友だちは元いた場所へ歩いて戻ります。

### かくれんぼ

<Shot name="play-hide-and-seek" caption="かくれんぼ。上のバナーに探す友だちの名前が出ます。" />

1. 「かくれんぼ」をクリックすると、友だちが隠れ場所へ散らばります。15秒以内に隠れ場所に着かなかった友だちは、その場で隠れます。
2. 庭の上のバナーに「クリックして探す」と、探す友だちの名前が表示されます。その下には、まだ隠れているほかの友だちの名前が出ます。
3. 名前を呼ばれた友だちを見つけてクリックします。正解なら「見つかっちゃった！」と飛び出し、バナーは次の友だちに進みます。
4. 違う友だちをクリックすると「残念、その友だちではありません。もう一度探してみてください」と通知が出るだけで、その友だちは隠れたままです。探す名前は変わりません。
5. 全員を見つけると「全員見つけました！」で遊びが終わります。

### おさんぽ行列

「おさんぽ行列」をクリックすると、選択中の友だちが先頭に立ち、ほかの友だちがその後ろに並びます。列がそろうと、みんなで庭を1周します。1周すると先頭の友だちが「一周おわり！」と言い、遊びが終わります。

### おにごっこ

「おにごっこ」には友だちが2人以上必要です。

1. 選択中の友だちがおにになります。「おにだぞ〜！」と言い、名札に「（おに）」が付きます。
2. おにの友だちはいちばん近い友だちを追いかけ、ほかの友だちはおにから逃げます。
3. おにの友だちが画面上でほかの友だちと重なると、その友だちは捕まります。捕まった友だちが次のおにになり、捕まえた友だちは少しの間安全です。
4. 決まった時間がたつと「おにごっこが終わりました。みんなよく走りました！」で遊びが終わります。

## 作業のそばに置くウィンドウ

端や角をドラッグすると、300 × 210まで自由にサイズを変えられます。同じウィンドウで、大きさに合わせて友だち、会話、招待、設定、背景や遊びの道具を使えます。上端の細い透明な部分をドラッグすると移動でき、最後の位置と大きさを覚えています。

幅640ピクセル以下、または高さ480ピクセル以下では下のバーが隠れます。代わりに右下の丸いボタンが、空いた背景を右クリックしたときと同じ短いメニューを開きます。**場所と雰囲気**、**遊ぶ**、**友だちと設定**、**常に手前に表示**の4項目です。**Cmd/Ctrl + Shift + P**は友だちと設定を開きます。小さな窓では各パネルの項目がタイルで並び、名前は2行になることがあります。まとまりの見出しは画面上では隠れます。長いパネルは窓の中でスクロールします。場所と雰囲気や遊ぶを閉じると、そのまま風景に戻ります。友だちタブと招待タブの戻る操作は友だちと設定へ、**×**は庭へ戻ります。設定では、戻る操作でまとまりから設定の一覧へ、一覧から友だちと設定へ戻ります。招待の読み込みボタンは上部に表示します。

友だちの名札を押すと、その友だちとの会話が開きます。名札にポインターを重ねると「Cloverに話しかける」のように表示されます。友だちを右クリックすると「Cloverに話しかける」「Cloverと遊ぶ」「Cloverに穴掘りを頼む」の短いメニューが開きます。遊ぶを選ぶとその友だちの遊ぶパネルが開き、穴掘りを頼むを選ぶとその友だちが先に行くように穴掘りの道具を手に取ります。閉じる、Esc、外側のクリックで風景に戻ります。小さな窓専用の遊び欄はありません。

空いている背景を右クリックすると、ポインターのそばに短い操作メニューが開きます（小さな窓では右下のボタンからも開けます）。窓の中に収まり、必要ならスクロールできます。**Esc**または外側のクリックで閉じます。友だち、花、飾りは、それぞれの右クリック操作を維持します。

**友だちと設定 → ウィンドウとデスクトップ → 全画面表示**で画面いっぱいに広げられます。全画面では同じ項目が**前のサイズに戻す**に変わり、**Esc**でも戻れます。Escは開いているパネルやメニューを先に閉じます。前のサイズ、位置、固定設定を引き継ぎます。

<Shot name="mini" caption="作業のそばに置いた小さな庭のウィンドウ。" />

**友だちと設定 → ウィンドウとデスクトップ → 常に手前に表示**、または右クリックメニューの同じ項目で切り替えます。サイズとは独立し、設定を記憶します。トレイとmacOSの表示メニューにもあります。**Cmd/Ctrl + Shift + M**ならサイズを変えずに切り替えられます。

Linuxでは、最前面表示の対応状況がデスクトップやウィンドウマネージャーによって異なります。一部のWayland環境では適用できないため、切り替わらない場合はデスクトップ側のウィンドウ設定を確認してください。

<Shot name="mini-chat" caption="小さな庭のウィンドウの中で、作業のそばで会話できます。" />

**友だちと設定 → ウィンドウを閉じる**は庭をトレイへ隠し、デスクトップの友だちとエージェント連携を続けます。その隣の**PlayPets を終了**は、トレイの終了やmacOSの<kbd>⌘</kbd> <kbd>Q</kbd>と同じく、確認せずにすぐ終了します。会話は保存しません。短い右クリックメニューや右下のボタンからは、友だちと設定を選んで移動します。

小さな窓の更新案内は点の付いた32ピクセルのダウンロードアイコンです。アクセシブルな名前でバージョンを示し、押すとアプリのアップデートを直接開きます。大きな窓ではバージョン付きボタンを表示します。

友だちの設定、読み込み、AI接続のダイアログは見出しと操作ボタンを固定し、入力部分だけをスクロールします。図鑑と確認ダイアログは、それぞれの本文をスクロールします。

## 友だちをもっと見たいなら

デスクトップ全体を庭として使うなら、[デスクトップモード](./desktop.md)をオンにしてください。庭のウィンドウの大きさに関係なく一緒に使えます。

## ゆっくり集めるためのヒント

図鑑には水中の生きもの、虫、花、贈り物、木、小さな発見を合わせて100種類あります。池の生きもの、テントウムシ、コオロギを探してみましょう。土の中ではビー玉、木のクジラ、フェルトのキノコ、どんぐりのティーカップ、眠るキツネの置物が見つかります。友だちが届けるウサギのじょうろやハリネズミの植木鉢を置く場所も用意してみましょう。

全100種類は一日や一週間で集める目標ではありません。通常の贈り物16種類は異なる日付に届き、イベント限定4種類は暦に分かれたお祭りを待ちます。始めた時期によって、全イベントの贈り物には数か月かかる場合があります。季節を変えてもお祭りは始まりません。花は植えて4時間、木は12時間で育ち、アプリを閉じた時間も含みます。完成日は保証されません。

- **魚:** 雨の日はナマズとウナギを見つけやすくなります。出会える季節と時間を選び、ガイドでどんな魚が釣れるか調べてみましょう。
- **虫:** 晴れた屋外で探します。蝶とトンボは朝と昼、ホタルは春と夏の夕方と夜に現れます。お祭りは暦に従うため、季節を変えるだけでは始まりません。
- **穴掘り:** 季節、天気、屋外の場所で出やすい苗木や発見が変わります。条件が合うと見つけやすくなりますが、合わないものも出ます。雰囲気で季節と天気を別々に選び、珍しい組み合わせも試せます。追加した屋外背景でも季節と天気は反映されます。同じ場所は24時間結果を保ち、外れ続きでも次の発見が出やすくなることはありません。
- **場所を空ける:** 贈り物を片付けても図鑑の記録は残り、次の贈り物を置く場所ができます。種や苗木の袋がいっぱいでも、選ばれた報酬を別のものには変えません。

ガイドでは選んだ条件で出会えるものを確認できます。水や障害物があるため、実際に掘れる区画は背景全体の格子より少なくなります。
