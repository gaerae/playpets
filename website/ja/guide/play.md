# 庭と遊び

庭は時間帯、天気、季節に合わせて変わり、日を追って育っていきます。友だちは花の種を見つけたりプレゼントを持ってきたりし、あなたは釣りや虫取りで図鑑を埋められます。友だちはあなたと少しずつ仲良くなり、季節のイベントがやってきては過ぎ、庭には庭の音があり、友だちと3つの遊びを楽しめます。

## 時間帯と天気 <Since v="0.1.0" />

<Shot name="yard-evening" caption="金色に染まる夕方の庭です。時間帯は自動で時計に従います。" />

庭の左上のラベルは、「夕焼けの庭」のように今の風景を表します。クリックすると、時間帯と天気を選ぶ小さなメニューが開きます。

| 項目 | 選択肢 |
|---|---|
| 場所 | 森の遊び場、窓辺のアトリエ |
| 時間帯 | 時間おまかせ、朝、昼、夕方、夜 |
| 天気 | 天気おまかせ、晴れ、雨、雪 |

アイボリーの石の床、細い金属の窓枠、柔らかな椅子が、都会の仕事場のような落ち着いた雰囲気を作ります。「窓辺のアトリエ」からは、高い階から街、川、橋を見渡せます。朝の光、昼、夕焼け、明かりの灯る夜景にはそれぞれの風景があり、夜も部屋は暖かいままです。晴れ、雨、雪を選べますが、天気はガラスの外にだけ見えます。ここでも友だちをなでたり、会話したり、3つの遊びをしたりできます。釣り、野生の虫、季節の空の演出は「森の遊び場」のものです。場所は、時間帯と天気の選択とは別に保存されます。

<Shot name="studio-night" caption="夜の窓辺のアトリエ。ガラスの外は青い景色、床には暖かい光が届きます。" />

- **時間おまかせ**はコンピューターの時計に従います。空と地面の色が朝、昼、夕方、夜と変わり、太陽は空を左から右へ横切り、夜には月がその夜の満ち欠けを見せます。
- **天気おまかせ**は20分に1回、新しい天気を選びます。たいていは晴れで、ときどき雨になり、雪は冬だけです。インターネットから実際の天気を取得することはありません。
- 絵で描かれた森は、遠くの山、湖、重なり合う木々、開けた広場を重ねたものです。色は光に合わせて変わり、背景は風景かウィンドウの大きさが変わったときだけ描き直されます。
- 森の遊び場は日付で**季節**に従います。春は花と舞い散る花びら、夏は深い緑、秋は赤と金の葉、冬は雪の広場です。（コンピューターのタイムゾーンで）南半球なら季節は逆になります。
- 昼に雨が上がると、数分間、丘の上に虹がかかります。晴れた日はときどき鳥の群れが空を横切り、秋まではチョウが舞い、春と夏の夜にはホタルが光ります。
- 自分で値を選ぶと、その時間帯と天気に固定されます。選んだ内容は保存されるので、次にアプリを開いたときも同じです。

天気が変わると、1〜2人の友だちが「雨だ！」や「雪だるま作る？」のようにひと言話します。放っておくと、時間帯に合った独り言も言います。

## おしゃべり <Since v="0.1.0" />

ツールバーの「おしゃべり」を押すと、AIをつけた友だち（3人まで）が、時間帯と天気について短く話し合います。セリフは庭の吹き出しとして順番に表示されます。AIをつけた友だちが2人未満のときはボタンがオフの見た目になり、押したりポインターを重ねたりすると理由が表示されます。あなたも加わるなら、[友だちタブのグループ会話](./chat.md)を使ってください。

ときどき自分たちで話させたいときは、設定タブの「ときどき友だち同士で話します」をオンにします。20分に1回おしゃべりし、ウィンドウが隠れている間や誰かが返事をしている間は休みます。

## 花を育てる <Since v="0.1.0" />

散歩中の友だちは、ときどき種を見つけます（庭が開いている間、8〜20分ごと。最初の1つは数分以内です）。友だちは跳ねて知らせ、足元に光る種を置きます。クリックすると拾えます。放っておくと1分半後に友だちがしまってくれるので、見ていなくても取りこぼしはありません。

1. ツールバーの「種を植える」をクリックします（横の数字は持っている種の数です）。
2. 原っぱの場所をクリックします。続けていくつも植えられます。**Esc**を押すか、もう一度ボタンを押すと終わります。

種は時計に合わせて育ち、アプリを閉じている間も育ちます。10分で芽、40分で葉、2時間でつぼみ、4時間で花になります。何が咲くかは植えた季節で決まり、季節ごとに2種類あります。春はチューリップかスイセン、夏はひまわりかアジサイ、秋はコスモスかキク、冬は椿かスノードロップです。植物にポインターを重ねると、種類と咲くまでの時間が表示されます。

- 植物をクリックすると、いちばん近い友だちが歩いてきて水をやります。
- 友だちは自分から花を見に行くこともあります。
- 植物を右クリックする（または選んで**Delete**を押す）と抜けます。種は戻りません。
- 種は20個、植物は24本まで持てます。花壇は`state.json`の`garden`に保存されます。
- ある種類の花が初めて咲くと「図鑑」（花）に載り、届いたプレゼントもすべて載ります（プレゼント）。

### プレゼント

1日に1回、その日に庭をしばらく開いていると（20〜40分。いちばん最初のプレゼントは5分後）、友だちが庭へのプレゼントを持ってきます。友だちは跳ねて知らせ、横に置きます。最初のプレゼントは、ベンチ、ランタン、巣箱、小さな池、郵便受け、レジャーシート、かざぐるま、たき火、ブランコ、植木鉢、切り株の椅子、テント、道しるべ、風鈴の順に届きます。そのあとは、庭にまだないものを持ってきます。たき火はランタンと同じように夕方から光り、友だちはブランコや切り株に座り、風鈴は友だちが訪ねると鳴ります。

- 飾りをドラッグすると、原っぱのどこへでも動かせます（選んで矢印キーでも動かせます）。
- クリックすると、いちばん近い友だちが歩いてきます。友だちは自分からも飾りを訪ね、ベンチに座ったり、シートに集まったり、池をのぞき込んだりします。
- ランタンは夕方から灯り、池は空を映し、昼は巣箱に鳥がとまります。
- 飾りを右クリックする（または選んで**Delete**を押す）と片付けられます。別の日にまた友だちが持ってくることもあります。
- 庭に置ける飾りは12個までで、いっぱいの間はプレゼントが届きません。ひとつ片付けると、残りのものが届く場所ができます。

## 釣りと虫取り <Since v="0.1.0" />

- **釣り**：湖をクリックすると、手の空いているいちばん近い友だちが岸へ歩いていき、釣り糸を投げます。見えている水面のクリックだけが有効です。浮きが沈む（**!**が出る）のを待ってからクリックします。早すぎると食いつかず、遅すぎると魚に逃げられます。
- **虫**：昼のチョウやトンボ、春か夏の夜のホタルをクリックすると、いちばん近い友だちが跳びついて捕まえます。
- 何が釣れて何が飛ぶかは、季節、時間帯、天気で変わります。ナマズやウナギは暗くなってから出てきて（雨の日はもっと多く）、ワカサギは冬だけ、黄金ゴイはとても珍しい魚です。魚の大きさは毎回違います。
- 捕まえたものはカードで表示され、新しいものならそう知らせます。
- ツールの「図鑑」には花、魚、虫、プレゼントの4冊があり、すべての種類を表示します。捕まえたものは数と最大の魚の大きさを、まだのものはシルエットと、いつどこで探せばよいかを表示します。`state.json`の`album`に保存されます。

## 季節のイベント <Since v="0.1.0" />

1年に何度か、庭がしばらく変わります。風景のラベルの横にイベント名が表示され、その年に初めて見たときは始まったことを知らせるカードが出て、友だちもその話をします。

| イベント | 期間 | もたらすもの |
|---|---|---|
| 桜まつり | 4月1日〜20日 | あちこちに花びらが舞い、チョウが増えます。友だちが桜の苗木を持ってきます |
| ホタルの夜 | 7月20日〜8月20日 | 夜のホタルがぐっと増え、捕まえられる金色のホタルも出ます。友だちがスイカを持ってきます |
| 中秋の名月 | 9月25日〜10月15日 | 毎晩大きな満月が出て、夜の湖に月光ゴイが現れます。友だちがカボチャを持ってきます |
| 冬のイルミネーション | 12月10日〜31日 | 大きな木に小さなライトが飾られ、夕方から光ります。友だちが雪だるまを持ってきます |
| お正月 | 1月1日〜7日 | 友だちが新年のあいさつをします |

- イベントのプレゼントは、イベント中に初めてプレゼントが届くときに届き、そのときだけです。図鑑にはそれぞれがいつ届くかが表示されます。
- 南半球では、コンピューターのタイムゾーンに合わせて季節のイベントが6か月後になります（お正月は1月のままです）。

## なかよし度 <Since v="0.1.0" />

友だちはそれぞれ、庭で過ごす時間と一緒にすることを通して、あなたと仲良くなっていきます。名札のハートでどれくらい仲良しかがわかり、友だちタブには今の段階、次の段階までの距離、次の段階でできるようになることが表示されます。段階はどれくらい親しいかを表すもので、お互いがどういう間柄かではありません。そのため、恋人やきょうだいでも友だちと同じように読めます（間柄は[関係](./chat.md#relationship)で決まります）。

| 段階 | できるようになること |
|---|---|
| はじめまして | |
| うちとけた仲 | アプリを開いたときや、しばらくして戻ってきたときに迎えてくれます |
| なかよし | ときどき自分から釣りに行きます |
| 特別な仲 | 種をよく見つけるようになります |
| かけがえのない仲 | 名札に花が付き、ときどきあなただけにひと言話します |

- 一緒の時間は、庭が見えている10分ごとに数えます。なでる、おやつ、会話、水やり、捕まえること、プレゼントも1日分まで数えるので、数分クリックし続けても急には進みません。なかよし度は日を重ねて育ちます。
- 離れていても何かが減ることはありません。なかよし度は`state.json`の`bonds`に保存されます。

## 遊び <Since v="0.1.0" />

ツールは庭の下に浮かんでいます。そこの「遊び」を押すと、3つの遊びの小さなメニューが開きます。遊べるのは一度にひとつだけです。遊んでいる間、同じボタンは遊びの名前付きの「〜をやめる」（「かくれんぼをやめる」など）になり、クリックするとすぐに遊びが終わります。遊びの間はずっと「おやつを置く」は使えません。遊びが終わると、友だちは元いた場所へ歩いて戻ります。

### かくれんぼ

<Shot name="play-hide-and-seek" caption="かくれんぼ。上のバナーに探す友だちの名前が出ます。" />

1. 「かくれんぼ」をクリックすると、友だちが隠れ場所へ散らばります。15秒以内に隠れ場所に着かなかった友だちは、その場で隠れます。
2. 庭の上のバナーに「クリックして探す」と、探す友だちの名前が表示されます。その下には、まだ隠れているほかの友だちの名前が出ます。
3. 名前を呼ばれた友だちを見つけてクリックします。正解なら「見つかっちゃった！」と飛び出し、バナーは次の友だちに進みます。
4. 違う友だちをクリックすると「残念、その友だちではありません。もう一度探してみてください」と通知が出るだけで、その友だちは隠れたままです。探す名前は変わりません。
5. 全員を見つけると「全員見つけました！」で遊びが終わります。

### おさんぽ行列

「おさんぽ行列」をクリックすると、選択中の友だちが先頭に立ち、ほかの友だちがその後ろに並びます。列がそろうと、みんなで庭を1周します。1周すると先頭の友だちが「一周おわり！」と言い、遊びが終わります。

### おにごっこ

「おにごっこ」には友だちが2人以上必要です。

1. 選択中の友だちがおにになります。「おにだぞ〜！」と言い、名札に「（おに）」が付きます。
2. おにの友だちはいちばん近い友だちを追いかけ、ほかの友だちはおにから逃げます。
3. おにの友だちが画面上でほかの友だちと重なると、その友だちは捕まります。捕まった友だちが次のおにになり、捕まえた友だちは少しの間安全です。
4. 決まった時間がたつと「おにごっこが終わりました。みんなよく走りました！」で遊びが終わります。

## ミニモード <Since v="0.1.0" />

<Shot name="mini" caption="ミニモード。庭だけの小さなウィンドウが、ほかのウィンドウの上に浮かびます。" />

庭の右上にある表示の操作の中から「庭だけ小さく表示」ボタン（小さなウィンドウ）をクリックすると、パネルとツールバーが消え、庭だけの小さなウィンドウになります。

- 小さなウィンドウは常にほかのウィンドウの上に浮かびます。初回は画面の右下に開き、その後は最後に置いた場所に、最後に変えた大きさで開きます。
- 庭にポインターを重ねると、下に「おやつを置く」と「おしゃべり」が小さなボタンとして現れます。
- 名札は隠れます。友だちにポインターを重ねると、その友だちの名札が少しの間表示されます。
- 友だちのいない空いた場所をドラッグするとウィンドウが動きます。友だちをドラッグすると友だちが動きます。
- なでるのはこれまでどおりです。友だちの名札をクリックすると、小さなウィンドウの中にコンパクトな会話が開きます。閉じるボタンかEscapeで閉じると庭に戻ります。「招待」と「設定」は、これまでどおり大きなウィンドウで開きます。
- 友だちは散歩の合間に長めに休み、自分から跳ねる代わりに静かにあいさつします。
- 遊びの途中でミニモードにすると、その遊びは終わります。

元に戻すには、小さなウィンドウの隅にある「元の大きさに戻す」ボタンをクリックします。ウィンドウは元の場所に戻ります。ミニモードは保存されるので、小さいまま終了すると次回も小さく開きます。
