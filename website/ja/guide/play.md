# 庭と遊び

- 庭は時間帯、天気、季節に合わせて変わり、日を追って育ちます。
- 友だちは穴掘りで花の種や苗木を見つけ、プレゼントを持ってきます。
- あなたは釣りや虫取りで図鑑を埋められます。
- 友だちはあなたと少しずつ仲良くなります。季節のイベントが来ては過ぎ、庭には庭の音があります。
- 友だちと3つの遊びを楽しめます。

**画面のつくり**
- 風景がウィンドウを満たします。
- 下の入口は**場所と雰囲気**、**遊ぶ**、**友だちと設定**の3つです。
  - どれも1ページのパネルで、中はいくつかのまとまりに分かれます。タブや戻るボタンはありません。
  - 庭のパネルは一つずつ開きます。
- 自動の時間帯は、時計を表示せずにパソコンの時刻に従います。

**遊ぶ**（選んでいる友だちに合わせて「Cloverと遊ぶ」のような題が付きます）

| まとまり | 中身 |
|---|---|
| **見つける** | **穴掘り**、**釣り**、**図鑑** |
| **庭** | **種を植える**（持っている種の数も表示）、**木を植える**、**おやつ** |
| **みんなで遊ぶ** | 3つの遊びと**おしゃべり** |

- **おしゃべり**にはAIにつながった友だちが2人必要です。ほかの遊びはAIなしで使えます。

**最初の庭と音**
- 初めて開く庭は、晴れた春の昼から始まります。
- 季節、時間帯、天気を自動で変えたいときは、それぞれ**自動**を選んでください。
- 保存した設定は、次回もそのままです。
- 音のオン、オフと音量は、**場所と雰囲気 → 雰囲気**の**庭の音**と**音量**で調整します。
  - 最初の操作後、庭が見えている間だけ鳴ります。
  - 雨、鳥、水などの環境音は、場所、天気、季節、時間帯に従います。
- 自動おしゃべりは別の場所、**友だちと設定 → 設定 → 友だちとAI**にあります。

## 時間帯と天気 <Since v="0.1.0" />

- 季節と天気は別々に反映されます。
  - 夏に雪を選ぶと、夏の景色と服装のまま雪が降ります。
  - 冬に晴れを選んでも、冬景色は残ります。
  - 室内の窓や取り込んだ背景も同じです。
- 自動で選ばれる雪は、これまでどおり冬だけです。

<Shot name="yard-spring" caption="晴れた春の昼の庭です。時間帯を自動にすると、時計に合わせて変わります。" />

1. 右下の**場所と雰囲気**を開きます。
2. **場所**のまとまりで背景をサムネイルから選びます。標準の背景と読み込んだ背景が同じ一覧に並びます。
3. **雰囲気**のまとまりで季節、時間帯、天気を選びます。変更はすぐに反映されます。

- **背景を読み込む**と**背景制作室**は、**場所**の見出しの横にあります。
- 読み込んだ背景を選んだときだけ、そこに削除ボタンが出ます。

| 項目 | 選択肢 |
|---|---|
| 場所 | 丘の庭、石造りの中庭、湖畔の家、くつろぎのリビング |
| 時間帯 | 自動、朝、昼、夕方、夜 |
| 天気 | 自動、晴れ、雨、雪 |

- 3つの屋外の場所には、それぞれ異なる家、四季の風景、釣りの立ち位置があります。
- **くつろぎのリビング**では、同じ落ち着いた雰囲気を室内で楽しめます。
  - 朝、昼、夕方、夜で照明が変わります。
  - 窓の外は春の花、秋の紅葉、冬の雪に変わります。
  - 雨や雪はガラスの外だけに出ます。
- どの場所でも、なでる、会話、花を育てる、3つの遊びができます。
- 釣り、虫捕り、屋外の季節演出は3つの庭で楽しめます。
- 場所は時間帯や天気とは別に保存されます。

<Shot name="studio-night" caption="夜のくつろぎのリビング。窓の外には静かな村、室内には暖かな明かりが見えます。" />

- 時間帯の**自動**はコンピューターの時計に従います。
  - 空と地面の色が朝、昼、夕方、夜と変わります。
  - 太陽は空を左から右へ横切り、夜には月がその夜の満ち欠けを見せます。
- 天気の**自動**は20分に1回、新しい天気を選びます。
  - たいていは晴れ、ときどき雨。雪は冬だけです。
  - インターネットから実際の天気を取得することはありません。
- 屋外の場所は、囲まれた中庭から開けた丘や湖畔まで構図が異なります。
- 色は光に合わせて変わります。背景は、風景かウィンドウの大きさが変わったときだけ描き直されます。
- 季節を**自動**にすると、屋外の場所は日付に合わせて変わります。
  - 春は花と舞う花びら、夏は深い緑、秋は赤や金色の葉、冬は雪景色。
  - **場所と雰囲気 → 雰囲気**で季節を選ぶこともできます。
  - コンピューターのタイムゾーンが南半球なら、自動の季節は逆になります。
- 昼に雨が上がると、数分間、丘の上に虹がかかります。
- 晴れた日はときどき鳥の群れが空を横切ります。秋まではチョウが舞い、春と夏の夜にはホタルが光ります。
- 自分で値を選ぶと、その時間帯と天気に固定されます。選んだ内容は保存され、次に開いたときも同じです。
- 天気が変わると、1〜2人の友だちが「雨だ！」や「雪だるま作る？」のようにひと言話します。
- 放っておくと、時間帯に合った独り言も言います。

## おしゃべり <Since v="0.1.0" />

- **遊ぶ → みんなで遊ぶ**の**おしゃべり**を押すと、AIをつけた友だち（3人まで）が時間帯と天気について短く話し合います。
- セリフは庭の吹き出しとして順番に出ます。
- AIをつけた友だちが2人未満のときは、ボタンがオフの見た目になります。押したりポインターを重ねたりすると理由が出ます。
- あなたも加わるなら、[友だちの画面のグループ会話](./chat.md)を使ってください。
- ときどき自分たちで話させるには、**友だちと設定 → 設定 → 友だちとAI**の**ときどき友だち同士で話します**をオンにします。
  - 20分に1回おしゃべりします。
  - ウィンドウが隠れている間や、誰かが返事をしている間は休みます。

## 花を育てる <Since v="0.1.0" />

- 花の種と苗木は、同じ土掘りで見つけます。**穴掘り**を選び、友だちを空いた地面へ送り、見つけたものを植えます。
- 散歩だけでは種や苗木は現れません。

1. **遊ぶ → 庭**の**種を植える**をクリックします（横の数字は持っている種の数です）。
2. 原っぱの場所をクリックします。続けていくつも植えられます。
3. **Esc**を押すか、もう一度ボタンを押すと終わります。

- キーボード：**種を植える**をEnterかSpaceで選び、もう一度押すと選んでいる友だちのそばに植えます。おやつと同じ操作です。
- 道具を手にしている間は、1、2、3のキーで**穴掘り**、**木を植える**、**種を植える**に持ち替えます。入力欄で文字を打っている間は切り替わりません。
- くつろぎのリビングでは、むき出しの土の代わりに小さな鉢に花が植わります。場所を変えても成長や図鑑は引き継がれます。
- 種は時計に合わせて育ち、アプリを閉じている間も育ちます。

| 経過 | 段階 |
|---|---|
| 10分 | 芽 |
| 40分 | 葉 |
| 2時間 | つぼみ |
| 4時間 | 花 |

- 植えた季節に合わせて、それぞれ4種類の花が咲きます。

| 季節 | 花 |
|---|---|
| 春 | チューリップ、スイセン、クロッカス、ムスカリ |
| 夏 | ひまわり、アジサイ、ラベンダー、カンパニュラ |
| 秋 | コスモス、キク、ダリア、アスター |
| 冬 | 椿、スノードロップ、ヘレボルス、シクラメン |

- 植物にポインターを重ねると、種類と咲くまでの時間が出ます。
- 植物をクリックすると、いちばん近い友だちが歩いてきて水をやります。
- 友だちは自分から花を見に行くこともあります。
- 植物を右クリックする（または選んで**Delete**か**Backspace**）と、確認なしですぐに抜けます。
  - 下のお知らせに**元に戻す**が6秒ほど出ます。押すと元の場所に戻ります。その後で完全に消えます。
  - それまでにアプリを閉じた場合は残ります。
  - 種は戻りません。
- 種は20個、植物は24本まで持てます。花壇は`state.json`の`garden`に保存されます。
- ある種類の花が初めて咲くと**図鑑**（花）に載ります。届いたプレゼントもすべて載ります（プレゼント）。

### プレゼント

- 贈り物は現地の日付で庭全体に一日最大一つです。友だちごとではなく、全員で回数を共有します。
- 待ち時間は20〜40分、最初の贈り物は5分です。
- 決まった配達時刻は保存され、アプリを閉じた時間も数えます。
  - 開き続ける必要はありません。閉じている間に時刻が来たら、戻った後に友だちが届けます。
- 友だちは跳ねて知らせ、横に置きます。
- 最初のプレゼントは次の順に届きます：ベンチ、ランタン、巣箱、小さな池、郵便受け、レジャーシート、かざぐるま、たき火、ブランコ、植木鉢、切り株の椅子、テント、道しるべ、風鈴。
- そのあとは、庭にまだないものを持ってきます。
- たき火はランタンと同じように夕方から光ります。友だちはブランコや切り株に座り、風鈴は友だちが訪ねると鳴ります。
- 飾りをドラッグすると、原っぱのどこへでも動かせます（選んで矢印キーでも動かせます）。
- クリックすると、いちばん近い友だちが歩いてきます。
- 友だちは自分からも飾りを訪ね、ベンチに座ったり、シートに集まったり、池をのぞき込んだりします。
- ランタンは夕方から灯り、池は空を映し、昼は巣箱に鳥がとまります。
- 飾りを右クリックする（または選んで**Delete**か**Backspace**）と、すぐに片づけられます。
  - 6秒ほどは、お知らせの**元に戻す**で戻せます。それまでにアプリを閉じた場合は残ります。
  - 別の日にまた友だちが持ってくることもあります。
- 飾りは12個までです。いっぱいになると配達が止まります。
  - 片付けても図鑑の記録は残り、残りの贈り物を置く場所ができます。
- 贈り物は、イベントの開催日に届く4種類を含めて18種類です。

## 釣りと虫取り <Since v="0.1.0" />

**釣り**
1. 水面を押すと、近くの手の空いた友だちが手動の釣りを始めます。
2. 浮きが沈んで**!**が出たらクリックします。早すぎても遅すぎても逃げられます。

- **遊ぶ → 釣り**では、選んだ友だちが最後まで進めます。どちらもその背景の釣り場を使います。
- 釣り竿では淡水エビ、ザリガニ、タニシも見つかります。魚と一緒に**水中の生きもの**の図鑑へ記録されます。

**虫**
- 晴れた屋外でクリックします。近くの友だちが捕まえます。
  - 朝と昼：蝶やトンボ
  - 春と夏の夕方と夜：ホタル
- 雨や雪のときには現れません。

**自分から釣る友だち**
- 親密度3から、庭が見えている間、手の空いた友だちは12〜25分ごとに自分から釣りを試みます。
- ゲーム、別の釣り、配置ツールの使用中は休みます。毎回釣れるとは限りません。

**何が見つかるか**
- 何が釣れて何が飛ぶかは、季節、時間帯、天気で変わります。
  - ナマズやウナギは暗くなってから出ます（雨の日はもっと多く）。
  - ワカサギは冬だけ、黄金ゴイはとても珍しい魚です。
  - 魚の大きさは毎回違います。
- 捕まえたものはカードで出ます。新しいものならそう知らせます。
- 図鑑に残るもの（魚、虫、咲いた花、贈り物、小さな発見）のカードには**図鑑で見る**があります。押すとその巻を開いた図鑑が開きます。
- 新しいものが届くと、図鑑を開くまで、**遊ぶ → 見つける**の**図鑑**と下の入口の**遊ぶ**に小さな点が付きます。

**図鑑**
- **遊ぶ → 見つける**の**図鑑**には6冊あり、すべての種類を表示します：花、水中の生きもの、虫、プレゼント、木、小さな発見。
- 捕まえたものは、数と最大の魚の大きさを表示します。
- まだのものは、シルエットと、いつどこで探せばよいかを表示します。
- `state.json`の`album`に保存されます。
- 図鑑は、いつどこで探せるかと、珍しい発見を再び探せる時刻を案内します。正確な確率は表示しません。

## 季節のイベント <Since v="0.1.0" />

- 1年に何度か、庭がしばらく変わります。
- 風景のラベルの横にイベント名が出ます。
- その年に初めて見たときは、始まったことを知らせるカードが出て、友だちもその話をします。

| イベント | 期間 | もたらすもの |
|---|---|---|
| 桜まつり | 4月1日〜20日 | あちこちに花びらが舞い、チョウが増えます。友だちが桜の飾りを持ってきます |
| ホタルの夜 | 7月20日〜8月20日 | 夜のホタルがぐっと増え、捕まえられる金色のホタルも出ます。友だちがスイカを持ってきます |
| 中秋の名月 | 9月8日〜10月15日 | 中秋の名月のように、期間中最初の満月の前後2日の夜は大きな黄金色の満月が昇ります。ほかの夜はその日の月の形のままです。夜の湖に月光ゴイが現れます。友だちがカボチャを持ってきます |
| 冬のイルミネーション | 12月10日〜31日 | 木々に小さなライトが飾られ、夕方から光ります。友だちが雪だるまを持ってきます |
| お正月 | 1月1日〜7日 | 友だちが新年のあいさつをします |

- イベントのプレゼントは、イベント中に初めてプレゼントが届くときに届きます。そのときだけです。
- 図鑑には、それぞれがいつ届くかが出ます。
- 南半球では、コンピューターのタイムゾーンに合わせて季節のイベントが6か月後になります（お正月は1月のままです）。

## なかよし度 <Since v="0.1.0" />

- 友だちはそれぞれ、庭で過ごす時間と一緒にすることを通して、あなたと仲良くなります。
- 名札のハートで、どれくらい仲良しかがわかります。
- 友だちの画面には、今の段階、次の段階までの距離、次の段階でできるようになることが出ます。
- 段階はどれくらい親しいかを表すもので、お互いの間柄ではありません。
  - そのため、恋人やきょうだいでも友だちと同じように読めます。
  - 間柄は[関係](./chat.md#relationship)で決まります。

| 段階 | できるようになること |
|---|---|
| はじめまして | |
| うちとけた仲 | アプリを開いたときや、しばらくして戻ってきたときに迎えてくれます |
| なかよし | ときどき自分から釣りに行きます |
| 特別な仲 | |
| かけがえのない仲 | 名札に花が付き、ときどきあなただけにひと言話します |

- 一緒の時間は、庭が見えている10分ごとに数えます。
- なでる、おやつ、会話、水やり、捕まえること、プレゼントも、1日分まで数えます。数分クリックし続けても急には進みません。
- なかよし度は日を重ねて育ちます。
- 離れていても何かが減ることはありません。
- なかよし度は`state.json`の`bonds`に保存されます。

## 少し掘って、木を植える

**穴掘り**
1. 下の入口から**遊ぶ**を開くか、友だちを右クリックして「Cloverと遊ぶ」のような項目を選びます。
2. **穴掘り**から空いた地面を選ぶと、友だちが歩いて掘ります。AI接続は不要です。

- 同じメニューの「Cloverに穴掘りを頼む」を選ぶと、穴掘りの道具をすぐに手に取り、その友だちが先に掘りに行きます。
- 水面、家具、木の根は避けてください。
- **Esc**で取り消せます。
- 到着する前に別の行動をさせた場合、発見はありません。

**穴掘りの道具**
- しまうまで手に残ります。
- 地面を選ぶたびに、手の空いた友だちが掘りに行きます。掘ったばかりの友だちが少し休む間は、ほかの友だちが行きます。
- 下のドックの位置に出る帯から、**木を植える**や**種を植える**へ一度で切り替えられます。
- 帯の閉じるボタンか**Esc**で道具をしまいます。
- 道具を手にしていても、湖や生きものが隠れることはありません。
  - 水や、飛んだり這ったりしている生きものを押すと道具をしまい、その1回で釣りや虫とりをします。
- 空いた地面を右クリックして**ここを掘る**を選ぶと、**遊ぶ**を開かずにその場所を掘ります。

**動きと服**
- Daisy、Clover、Pip、Misoは四季を通じて、専用の動きを見せます：穴掘り、植える動作、竿を振る動作、魚を待つ姿、釣り上げる動作、発見したときの反応。
- Daisy、Pip、Misoは春と秋に同じ普段着を着て、夏服と冬服に着替えます。
- Cloverは春から秋まで青緑のオーバーオールと麦わら帽子。冬はコート、マフラー、ニット帽に着替えます。
- 取り込んだペットも、元の動きで同じ遊びに参加します。

**掘って見つかるもの**
- 花の種、苗木、17種類の小さな発見が出ることも、何も出ないこともあります。
- 発見は**図鑑 → 小さな発見**に記録されます。
- 珍しい発見の後は、全員と全場所で、次の珍しい発見まで24時間待ちます。
- 重複があり、完了時期は保証されません。
- 同じ場所は24時間、追加の報酬がありません。友だちごとに8秒の間隔が必要です。
- 種は20個、苗木は樹種ごとに20個まで。満杯でも別の報酬には変わりません。

**木を植える**
1. まず穴掘りで苗木を見つけます。
2. **木を植える**で、桜、カエデ、松、オーク、白樺、柳の所持数を確認します。
3. 持っている樹種と空いた地面を選びます。植えると同じ樹種の苗木を1個使います。

- 2時間で若木、12時間で成木になります。アプリを閉じた時間も含みます。
- 成木は**図鑑 → 木**に一度記録されます。
- 1か所6本、全体24本まで。
- 木は植えた場所に残ります。ドラッグで移動、右クリック（または選んで**Delete**）ですぐに片づけられます。
- 花と同じく、6秒ほどはお知らせの**元に戻す**で戻せます。図鑑の記録は残りますが、苗木は戻りません。
- 室内では穴掘りや植樹をしません。
- 読み込む背景では、土の利用可否を明示できます。

## 遊び <Since v="0.1.0" />

- 3つの遊びは**遊ぶ → みんなで遊ぶ**にあります。遊べるのは一度にひとつだけです。
- 遊んでいる間、その遊びのボタンは遊びの名前付きの「〜をやめる」（**かくれんぼをやめる**など）になります。クリックするとすぐに終わります。
- 遊びの間はずっと、ほかの遊びと**おやつ**、**種を植える**、**木を植える**は使えません。
- 遊びが終わると、友だちは元いた場所へ歩いて戻ります。

### かくれんぼ

<Shot name="play-hide-and-seek" caption="かくれんぼ。下のバーの上の案内に探す友だちの名前が出ます。" />

1. **かくれんぼ**をクリックすると、友だちが隠れ場所へ散らばります。15秒以内に着かなかった友だちは、その場で隠れます。
2. 下のバーのすぐ上の案内に、**クリックして探す**と探す友だちの名前、続いてまだ隠れているほかの友だちの名前が出ます。遊びの案内、発見のカード、通知など、庭からのお知らせはすべてこの場所に出ます。
3. 名前を呼ばれた友だちを見つけてクリックします。正解なら「見つかっちゃった！」と飛び出し、バナーは次の友だちに進みます。
4. 違う友だちをクリックすると「残念、その友だちではありません。もう一度探してみてください」と通知が出るだけです。その友だちは隠れたままで、探す名前は変わりません。
5. 全員を見つけると「全員見つけました！」で遊びが終わります。

### おさんぽ行列

1. **おさんぽ行列**をクリックすると、選択中の友だちが先頭に立ち、ほかの友だちがその後ろに並びます。
2. 列がそろうと、みんなで庭を1周します。
3. 1周すると先頭の友だちが「一周おわり！」と言い、遊びが終わります。

### おにごっこ

- **おにごっこ**には友だちが2人以上必要です。

1. 選択中の友だちがおにになります。「おにだぞ〜！」と言い、名札に「（おに）」が付きます。
2. おにの友だちはいちばん近い友だちを追いかけ、ほかの友だちはおにから逃げます。
3. おにの友だちが画面上でほかの友だちと重なると、その友だちは捕まります。捕まった友だちが次のおにになり、捕まえた友だちは少しの間安全です。
4. 決まった時間がたつと「おにごっこが終わりました。みんなよく走りました！」で遊びが終わります。

## 作業のそばに置くウィンドウ

**大きさと位置**
- 端や角をドラッグすると、300 × 210まで自由にサイズを変えられます。
- 同じウィンドウで、大きさに合わせて友だち、会話、招待、設定、背景や遊びの道具を使えます。
- 上端の細い透明な部分をドラッグすると移動できます。最後の位置と大きさを覚えています。

**小さな窓**（幅640ピクセル以下、または高さ480ピクセル以下）
- 下のバーが隠れます。
- 代わりに、ポインターを窓に重ねるかTabで移ると、右下に丸いボタンが現れます。
  - 空いた背景を右クリックしたときと同じ短いメニューを開きます。
  - 4項目：**場所と雰囲気**、**遊ぶ**、**友だちと設定**、**常に手前に表示**
- **Cmd/Ctrl + Shift + P**は友だちと設定を開きます。
- 各パネルの項目はタイルで並び、名前は2行になることがあります。
- まとまりの見出しは画面上では隠れます。
- 長いパネルは窓の中でスクロールします。
- 戻り先：

| 操作 | 戻る先 |
|---|---|
| 場所と雰囲気や遊ぶを閉じる | そのまま風景 |
| 友だちの画面と**友だちを招待**の戻る操作 | 友だちと設定 |
| **×** | 庭 |
| 設定の戻る操作 | まとまりからは設定の一覧へ、一覧からは友だちと設定へ |

- **友だちを招待**の読み込みボタンは上部に出ます。

**友だちと右クリック**
- 友だちの名札を押すと、その友だちとの会話が開きます。名札にポインターを重ねると「Cloverに話しかける」のように出ます。
- 友だちを右クリックすると、短いメニューが開きます：「Cloverに話しかける」「Cloverと遊ぶ」「Cloverに穴掘りを頼む」。
  - 遊ぶを選ぶと、その友だちの遊ぶパネルが開きます。
  - 穴掘りを頼むを選ぶと、その友だちが先に行くように穴掘りの道具を手に取ります。
  - 閉じる、Esc、外側のクリックで風景に戻ります。
- 小さな窓専用の遊び欄はありません。
- 空いている背景を右クリックすると、ポインターのそばに短い操作メニューが開きます（小さな窓では右下のボタンからも開けます）。
  - 窓の中に収まり、必要ならスクロールできます。
  - **Esc**または外側のクリックで閉じます。
- 友だち、花、飾りは、それぞれの右クリック操作を維持します。

**全画面**
- **友だちと設定 → ウィンドウとデスクトップ → 全画面表示**で画面いっぱいに広げられます。
- 全画面では、同じ項目が**元のサイズに戻す**に変わります。**Esc**でも戻れます。
- Escは、開いているパネルやメニューを先に閉じます。
- 前のサイズ、位置、固定設定を引き継ぎます。

<Shot name="mini" caption="作業のそばに置いた小さな庭のウィンドウ。" />

**常に手前に表示**
- **友だちと設定 → ウィンドウとデスクトップ → 常に手前に表示**、または右クリックメニューの同じ項目で切り替えます。
- サイズとは独立し、設定を記憶します。
- トレイとmacOSの表示メニューにもあります。
- **Cmd/Ctrl + Shift + M**なら、サイズを変えずに切り替えられます。
- Linuxでは、最前面表示の対応状況がデスクトップやウィンドウマネージャーで異なります。
  - 一部のWayland環境では適用できません。切り替わらない場合は、デスクトップ側のウィンドウ設定を確認してください。

<Shot name="mini-chat" caption="小さな庭のウィンドウの中で、作業のそばで会話できます。" />

**閉じると終了**
- **友だちと設定 → ウィンドウを閉じる**は庭をトレイへ隠し、デスクトップの友だちとエージェント連携を続けます。
- その隣の**PlayPets を終了**は、トレイの終了やmacOSの<kbd>⌘</kbd> <kbd>Q</kbd>と同じく、確認なしにすぐ終了します。会話は保存しません。
- 短い右クリックメニューや右下のボタンからは、友だちと設定を選んで移動します。

**更新の案内**
- 小さな窓では、点の付いた32ピクセルのダウンロードアイコンです。
  - アクセシブルな名前でバージョンを示します。
  - 押すとアプリのアップデートを直接開きます。
- 大きな窓では、バージョン付きボタンを表示します。

**ダイアログ**
- 友だちの設定、読み込み、AI接続のダイアログは、見出しと操作ボタンを固定し、入力部分だけをスクロールします。
- 図鑑と確認ダイアログは、それぞれの本文をスクロールします。
- 確認ダイアログは落ち着いた色で尋ねます。もう一方のボタンは**キャンセル**です。
- 取り戻せないものを失うとき（AI接続の削除、友だちとのお別れ、背景の削除）だけ赤く表示します。もう一方のボタンは**そのままにする**です。
- どの確認ダイアログにも**閉じる**ボタンがあります。
- 花、木、贈り物は確認せず、**元に戻す**を表示します。

## ゆっくり集めるためのヒント

- 図鑑には、水中の生きもの、虫、花、贈り物、木、小さな発見を合わせて100種類あります。
- 探してみましょう：池の生きもの、テントウムシ、コオロギ。
- 土の中では、ビー玉、木のクジラ、フェルトのキノコ、どんぐりのティーカップ、眠るキツネの置物が見つかります。
- 友だちが届けるウサギのじょうろやハリネズミの植木鉢を置く場所も、用意してみましょう。

**時間がかかること**
- 全100種類は、一日や一週間で集める目標ではありません。
- 通常の贈り物16種類は異なる日付に届きます。イベント限定4種類は、暦に分かれたお祭りを待ちます。
- 始めた時期によって、全イベントの贈り物には数か月かかる場合があります。
- 季節を変えてもお祭りは始まりません。
- 花は植えて4時間、木は12時間で育ちます。アプリを閉じた時間も含みます。
- 完成日は保証されません。

**探し方**
- **魚:** 雨の日はナマズとウナギを見つけやすくなります。出会える季節と時間を選び、ガイドでどんな魚が釣れるか調べてみましょう。
- **虫:** 晴れた屋外で探します。蝶とトンボは朝と昼、ホタルは春と夏の夕方と夜に出ます。お祭りは暦に従うため、季節を変えるだけでは始まりません。
- **穴掘り:**
  - 季節、天気、屋外の場所で、出やすい苗木や発見が変わります。
  - 条件が合うと見つけやすくなりますが、合わないものも出ます。
  - 雰囲気で季節と天気を別々に選び、珍しい組み合わせも試せます。
  - 追加した屋外背景でも、季節と天気は反映されます。
  - 同じ場所は24時間結果を保ちます。外れ続きでも、次の発見が出やすくなることはありません。
- **場所を空ける:** 贈り物を片付けても図鑑の記録は残り、次の贈り物を置く場所ができます。種や苗木の袋がいっぱいでも、選ばれた報酬を別のものには変えません。

**ガイド**
- ガイドでは、選んだ条件で出会えるものを確認できます。
- 水や障害物があるため、実際に掘れる区画は背景全体の格子より少なくなります。
