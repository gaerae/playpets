# 庭と遊び

庭は時間帯や天気、季節に合わせて姿を変え、日を追うごとに育っていきます。友だちは穴を掘って花の種や苗木を見つけたり、プレゼントを持ってきたりします。釣りや虫取りで図鑑を埋めていくうちに、友だちとも少しずつ仲良くなります。

季節のイベントがめぐってきて、庭には庭の音があります。友だちと一緒に楽しめる遊びも4つあります。そのうち1つは冬だけの遊びです。

**画面のつくり**

風景がウィンドウいっぱいに広がり、下には**場所と雰囲気**、**遊ぶ**、**友だちと設定**の3つの入口があります。どれを開いても1ページのパネルで、中はいくつかのまとまりに分かれています。タブや戻るボタンはなく、庭のパネルは一度にひとつだけ開きます。

時間帯を自動にしても時計は表示されず、パソコンの時刻に合わせて変わります。

**遊ぶ**

パネルの題は選んでいる友だちに合わせて**Cloverと遊ぶ**のように変わり、中は3つのまとまりに分かれています。

| まとまり | 中身 |
|---|---|
| **見つける** | **穴掘り**、**釣り**、**図鑑** |
| **庭** | **種を植える**（持っている種の数も表示）、**木を植える**、**おやつ** |
| **みんなで遊ぶ** | 4つの遊び（**雪だるま作り**は庭が冬の景色のときだけ）、桜まつりの間の**お花見**、**おしゃべり** |

**おしゃべり**だけは、AIにつながった友だちが2人必要です。ほかの遊びはAIがなくても楽しめます。

**最初の庭と音**

初めて開く庭は、晴れた春の昼から始まります。季節、時間帯、天気を自動で移り変わらせたいときは、それぞれ**自動**を選んでください。選んだ内容は保存され、次に開いたときもそのままです。

音のオン、オフと音量は、**場所と雰囲気 → 雰囲気**の**庭の音**と**音量**で変えられます。最初に何か操作したあと、庭が見えている間だけ鳴ります。雨や鳥、水などの環境音は、場所、天気、季節、時間帯に合わせて変わります。

友だちが自動でおしゃべりする設定は、別の場所の**友だちと設定 → 設定 → 友だちとAI**にあります。

## 時間帯と天気 <Since v="0.1.0" /> {#weather}

季節と天気は別々に決まります。夏に雪を選ぶと、夏の景色と服装のまま雪が降ります。冬に晴れを選んでも、冬景色はそのままです。室内の窓の外や読み込んだ背景も同じです。天気を自動にしたときに雪が降るのは、これまでどおり冬だけです。

<Shot name="yard-spring" caption="晴れた春の昼の庭です。時間帯を自動にすると、時計に合わせて変わります。" />

1. 右下の**場所と雰囲気**を開きます。
2. **場所**のまとまりで、サムネイルを見て背景を選びます。標準の背景と読み込んだ背景が同じ一覧に並びます。
3. **雰囲気**のまとまりで季節、時間帯、天気を選びます。変更はすぐに反映されます。

- **背景を読み込む**と**背景制作室**は、**場所**の見出しの横にあります。
- 読み込んだ背景を選んだときだけ、そこに削除ボタンが出ます。

| 項目 | 選択肢 |
|---|---|
| 場所 | 丘の庭、石造りの中庭、湖畔の家、くつろぎのリビング |
| 時間帯 | 自動、朝、昼、夕方、夜 |
| 天気 | 自動、晴れ、雨、雪 |

**場所**

3つの屋外の場所は、家のかたちも、四季の風景も、釣りをする立ち位置もそれぞれ違います。**くつろぎのリビング**は、同じ落ち着いた雰囲気を室内に持ち込んだ場所です。朝、昼、夕方、夜で照明が変わり、窓の外には春の花、秋の紅葉、冬の雪が見えます。雨や雪が降るのはガラスの外だけです。

どの場所でも、友だちをなでたり、話したり、花を育てたり、遊びをしたりできます。冬だけの**雪だるま作り**は庭が冬の景色のときにしか遊べないので、**くつろぎのリビング**ではできません。釣り、虫取り、屋外の季節の演出は、3つの庭だけで楽しめます。場所は、時間帯や天気とは別に保存されます。

<Shot name="studio-night" caption="夜のくつろぎのリビング。窓の外には静かな村、室内には暖かな明かりが見えます。" />

時間帯を**自動**にすると、パソコンの時計に合わせて進みます。空と地面の色は朝、昼、夕方、夜と移り変わり、太陽は左から右へ空を横切ります。夜には、その夜の満ち欠けのとおりに月が出ます。

天気を**自動**にすると、20分に1回、新しい天気が選ばれます。たいていは晴れで、ときどき雨が降り、雪は冬だけです。インターネットから実際の天気を取ってくることはありません。

屋外の場所は、囲まれた中庭から開けた丘や湖畔まで、構図がそれぞれ違います。色は光に合わせて変わり、背景を描き直すのは風景かウィンドウの大きさが変わったときだけです。

季節を**自動**にすると、屋外の場所は日付に合わせて変わります。春は花と舞う花びら、夏は深い緑、秋は赤や金色の葉、冬は雪景色です。

季節は**場所と雰囲気 → 雰囲気**で選ぶこともできます。パソコンのタイムゾーンが南半球なら、自動の季節は逆になります。

昼に雨が上がると、数分のあいだ丘の上に虹がかかります。虹のふもとの地面がきらめくので、消える前にそこを掘ると、何も出ないことはありません。天気の変わり目には、ほかにも見られる景色があります。晴れた昼に雨が降りだすとお日さまが出たまま天気雨になり、晴れた秋の朝には野原に朝霧がかかります。夜に雪がやむと月明かりの下で雪原がきらめき、晴れた夏の夜にはひと晩じゅう流れ星がよく流れます。晴れた日にはときどき鳥の群れが空を横切り、秋まではチョウが舞い、春と夏の夜にはホタルが光り、秋の夜にはコオロギが出てきます。

時間帯や天気を自分で選ぶと、その状態のまま固定されます。選んだ内容は保存され、次に開いたときも同じです。

天気が変わると、1〜2人の友だちが「雨だ！」「雪だるま作る？」のようにひと言しゃべります。放っておくと、時間帯に合った独り言も言います。

## おしゃべり <Since v="0.1.0" />

**遊ぶ → みんなで遊ぶ**の**おしゃべり**を押すと、AIをつけた友だち（3人まで）が、いまの時間帯と天気について短く話します。セリフは庭の吹き出しになって順番に出てきます。

AIをつけた友だちが2人いないときは、ボタンがオフの見た目になります。押したりポインターを重ねたりすると、理由が表示されます。自分も会話に加わりたいときは、[友だちの画面のグループ会話](./chat.md)を使ってください。

ときどき友だち同士で話してほしいなら、**友だちと設定 → 設定 → 友だちとAI**の**ときどき友だち同士で話します**をオンにします。20分に1回おしゃべりし、ウィンドウが隠れているときや、誰かが返事をしているときは休みます。

## 花を育てる <Since v="0.1.0" />

花の種も苗木も、穴掘りで見つかります。**穴掘り**を選んで友だちを空いた地面へ行かせ、見つけたものを植えましょう。散歩しているだけでは、種や苗木は出てきません。

1. **遊ぶ → 庭**の**種を植える**をクリックします。横の数字は持っている種の数です。
2. 原っぱの植えたい場所をクリックします。続けていくつも植えられます。
3. やめるときは**Esc**を押すか、もう一度ボタンを押します。

- キーボードでは、**種を植える**をEnterかSpaceで選び、もう一度押すと選んでいる友だちのそばに植えます。おやつと同じ操作です。
- 道具を手にしている間は、1、2、3のキーで**穴掘り**、**木を植える**、**種を植える**に持ち替えます。入力欄で文字を打っている間は切り替わりません。

くつろぎのリビングでは、むき出しの土ではなく小さな鉢に花が植わります。場所を変えても、花の育ち具合や図鑑はそのまま引き継がれます。

種は時計どおりに育ち、アプリを閉じている間も育ちます。

| 経過 | 段階 |
|---|---|
| 10分 | 芽 |
| 40分 | 葉 |
| 2時間 | つぼみ |
| 4時間 | 花 |

咲く花は植えた季節で決まり、季節ごとに4種類あります。

| 季節 | 花 |
|---|---|
| 春 | チューリップ、スイセン、クロッカス、ムスカリ |
| 夏 | ひまわり、アジサイ、ラベンダー、カンパニュラ |
| 秋 | コスモス、キク、ダリア、アスター |
| 冬 | 椿、スノードロップ、ヘレボルス、シクラメン |

植物にポインターを重ねると、何の花か、咲くまであとどれくらいかが出ます。クリックすると、いちばん近い友だちが歩いてきて水をやります。友だちは自分から花を見に行くこともあります。

植物はドラッグするか、選んで矢印キーで動かせます。動かした場所でそのまま育ちます。

植物を抜くには、右クリックして**抜く**を選ぶか、選んで**Delete**か**Backspace**を押します。確認なしですぐに抜けますが、下のお知らせに**元に戻す**が6秒ほど出ていて、押すと元の場所に戻ります。

完全に消えるのはそのあとです。それまでにアプリを閉じた場合は残ります。使った種は戻りません。

同じ右クリックメニューには**デスクトップに表示**もあります。花や木をデスクトップに出すと、机の上でも育ちます（[デスクトップモード](./desktop.md#flowers-and-trees-on-the-desktop)）。

- 種は20個、植物は24本まで持てます。
- 花壇は`state.json`の`garden`に保存されます。
- 花は種類ごとに初めて咲いたときに**図鑑**の「花」に載り、届いたプレゼントはすべて「プレゼント」に載ります。

### プレゼント {#gifts}

プレゼントは時間ではなく、友だちが持ってきます。なでる、おやつをあげる、話す、一緒に釣りをするなど、友だちと何かをした日に、その友だちがプレゼントを持ってくることがあります。庭全体で二日に一度までで、庭を開いておくだけでは届きません。届くようになると10〜20分後に届き、最初のプレゼントだけは5分です。

友だちと仲良くなったときにもプレゼントが届きます。**うちとけた仲**から、段階が上がるたびに一つずつ、その友だちと遊んだ日に届きます。**特別な仲**になると、小さなハートの付いたその友だちだけの思い出のプレゼントを持ってきます。ハートは届いてから1日のあいだ表示され、そのあとはプレゼントにポインターを合わせたときや選んだときだけ表示されます。

待ち時間は保存され、アプリを閉じていた時間も数えます。ずっと開いておく必要はありません。友だちはぴょんと跳ねて知らせ、そばにプレゼントを置きます。

最初は、ベンチ、ランタン、巣箱、小さな池、郵便受け、レジャーシート、かざぐるま、たき火、ブランコ、植木鉢、切り株の椅子、テント、道しるべ、風鈴の順に届きます。そのあとは、庭にまだないものを持ってきます。

たき火はランタンと同じように夕方から光ります。友だちはブランコや切り株に腰かけ、風鈴は友だちが近づくと鳴ります。

飾りはドラッグすれば原っぱのどこへでも動かせますし、選んで矢印キーでも動かせます。クリックすると、いちばん近い友だちが歩いてきます。

友だちは自分からも飾りのところへ行き、ベンチに座ったり、シートに集まったり、池をのぞき込んだりします。ランタンは夕方から灯り、池には空が映り、昼は巣箱に鳥がとまります。

飾りを片づけるには、右クリックして**片づける**を選ぶか、選んで**Delete**か**Backspace**を押します。すぐに片づきますが、6秒ほどはお知らせの**元に戻す**で戻せます。それまでにアプリを閉じた場合は残ります。片づけた飾りを、別の日に友だちがまた持ってくることもあります。

- 飾りは12個まで置けます。いっぱいのときは、新しいプレゼントは図鑑の「プレゼント」の巻の上にある**プレゼント箱**で待ちます。箱にも12個まで入り、場所が空いたら箱から押して庭に出せます。
- 片づけても図鑑の記録は残り、残りのプレゼントを置く場所ができます。思い出のプレゼントは片づけるとプレゼント箱に戻ります。箱がいっぱいのときは、ほかのプレゼントと同じように片づけられます。
- 一度届いたプレゼントは、また出せます。庭に場所があれば、図鑑の「プレゼント」の巻でそのカードの**庭に出す**を押します。雪だるまだけは例外で、作り直します。
- 同じ右クリックのメニューから、プレゼントをデスクトップに出すこともできます（[デスクトップのプレゼント](./desktop.md#gifts-on-the-desktop)）。
- プレゼントは、イベントの期間にだけ届く7種類を含めて全部で29種類です。雪だるまもこの29種類のひとつですが、友だちは持ってきません。自分たちで作ります（[雪だるま作り](#snowman)）。思い出のプレゼントもこの29種類のどれかなので、図鑑に新しい枠は増えません。

## 釣りと虫取り <Since v="0.1.0" />

**釣り**

水面をクリックすると、近くの手の空いた友だちが手動で釣りを始めます。浮きが沈んで**!**が出たらクリックしましょう。早すぎても遅すぎても逃げられます。

**遊ぶ → 釣り**なら、選んだ友だちが最後まで自分で釣ります。どちらもその背景の釣り場を使います。釣り竿には淡水エビ、ザリガニ、タニシ、モクズガニ、イシガイもかかり、ときにはスッポンも上がってきます。どれも魚と一緒に**水中の生きもの**の図鑑に記録されます。

**虫**

虫が出るのは晴れた屋外だけで、雨や雪のときは現れません。朝と昼はチョウやトンボを、春と夏の夕方と夜はホタルを、秋の夕方と夜は草むらのコオロギをクリックします。近くの友だちが捕まえてくれます。

**自分から釣る友だち**

なかよし度3から、庭が見えている間、手の空いた友だちは12〜25分ごとに自分から釣りを試みます。遊びや別の釣りの最中、配置ツールを使っている間は休みます。魚がかかると友だちが呼んでくれます。数秒のうちにウキを押すと一緒に釣り上げ、誰も押さなければ逃げてしまいます。図鑑に載るのは、あなたが釣ったものだけです。

**何が見つかるか**

何が釣れて何が飛んでいるかは、季節、時間帯、天気で変わります。ナマズやウナギは暗くなってから出てきて、雨の日はもっと多くなります。ワカサギは冬だけで、黄金ゴイはとても珍しい魚です。魚の大きさは毎回違います。

捕まえるとカードが出て、何を捕まえたか、初めてかどうかを知らせてくれます。図鑑に残るもの（魚、虫、咲いた花、プレゼント、小さな発見、春の芽）のカードには**図鑑で見る**があり、押すとその巻を開いた図鑑が開きます。

新しいものが加わると、図鑑を開くまで**遊ぶ → 見つける**の**図鑑**と下の入口の**遊ぶ**に小さな点が付きます。

**図鑑**

- **遊ぶ → 見つける**の**図鑑**は、花、水中の生きもの、虫、プレゼント、木、小さな発見、足あと、春の芽の8冊です。すべての種類が並びます。
- 捕まえたものは、数と最大の魚の大きさが出ます。
- まだのものは、シルエットと、いつどこで探せばいいかが出ます。
- **レア**は、めったに出ないものと、季節のイベントの間だけ出るものに付きます。イベントのものは日付も出ます。
- レアな発見をまた探せる時刻も案内します。正確な確率は表示しません。
- `state.json`の`album`に保存されます。

## 季節のイベント <Since v="0.1.0" /> {#seasonal-events}

1年に何度か、庭がしばらくのあいだ様子を変えます。風景のラベルの横にイベント名が出て、その年に初めて見たときは始まりを知らせるカードが出ます。友だちもその話をします。

| イベント | 期間 | もたらすもの |
|---|---|---|
| 桜まつり | 4月1日〜20日 | あちこちに花びらが舞い、チョウが増えます。友だちが集まってお花見をします。友だちが桜の飾りを持ってきます |
| ホタルの夜 | 7月20日〜8月20日 | 夜のホタルがぐっと増え、捕まえられる金色のホタルも出ます。友だちがスイカを持ってきます |
| 中秋の名月 | 9月8日〜10月15日 | 中秋の名月のように、期間中最初の満月の前後2日の夜は大きな黄金色の満月が昇ります。ほかの夜はその日の月の形のままです。夜の湖に月光ゴイが現れます。友だちがカボチャを持ってきます |
| 冬のイルミネーション | 12月1日〜31日 | 木々に小さなライトが飾られ、夕方から光ります。友だちが小さなクリスマスツリー、トナカイの赤ちゃん、サンタを順に持ってきます |
| お正月 | 1月1日〜7日 | 友だちが新年のあいさつをします。友だちが凧を持ってきます |

イベントのプレゼントは、イベント中にプレゼントが届く番のたびに1つずつ、決まった順に届き、そのとき限りです。いつ届くかは図鑑に出ています。

南半球では、パソコンのタイムゾーンに合わせて季節のイベントが6か月後になります。冬のイルミネーションとお正月は日付が変わりません。

12月に庭が冬の景色でないときは、1月7日まで冬にするかどうかを一度だけたずねます。冬にすると答えたときは、選んでいた季節が1月8日に戻ります。クリスマスツリー、トナカイの赤ちゃん、サンタは12月1日から1月7日まで、そして庭が冬の景色のときはいつでも、庭とデスクトップに出ます。それ以外は見えないところで待っています。飾り12個の数には入ったままで、片付けるとプレゼント箱に戻ります。

庭が冬の景色で小さなクリスマスツリーが出ているときに、雪の降る夕方から夜になると、ツリーに明かりがともって大きなツリーに育ちます。12月には自然にそんな夜が来ますが、ほかの日でも庭を冬、夜、雪にすれば見られます。雪が降っているあいだは大きなツリーのままで、ときどき電球がきらりと光り、雪がやむと小さなツリーに戻ります。また雪が降りだすと、もう一度育ちます。庭にトナカイの赤ちゃんとサンタが出ていると、夜に二人で空を見上げ、ツリーが育つたびにそりが月の前を一度横切ります。デスクトップに出したツリーも、庭のツリーといっしょに育ちます。くつろぎのリビングでは雪は窓の外にしか降らないので、クリスマスの夜は庭だけで迎えます。

クリスマスツリーを押すと、飾りつけができます。図鑑で見つけた花、木、プレゼント、小さな発見を、1日に3つまで掛けられます。掛けたものは種類ごとに色の違う小さなオーナメントになり、指すと何なのかがわかります。ツリーを替えたいときは、カードからオーナメントを外せます。その日の3つは使った扱いのままです。水中の生きものと虫は水辺と草むらに残ります。オーナメントは庭のツリーにも大きなツリーにも次の12月まで掛かったままで、次の12月は何もないツリーから始まります。飾りつけは、くつろぎのリビングを含むどの場所でもできます。

### お花見 {#flower-viewing}

桜まつりの間、晴れた日の朝から夕方まで、友だちは1日に1回、育てた桜の木の下に集まります。桜の木がなければピクニックシートか庭の真ん中です。見上げて1分ほどおしゃべりしたら、また散らばります。遊びや釣り、穴掘りの邪魔はせず、場所を変えたり、夜や雨になったりしたときは早めに終わります。

自分で呼ぶには、遊びのパネルで**お花見**を選びます。呼べるのは1時間に1回で、友だちがお花見中のときや遊んでいるときはボタンがグレーになります。AIにつながった友だちは、自分の言葉で桜の話をします。友だちが自分たちで集まったときは、**ときどき友だち同士で話します**がオンのときだけ、そうして話します。

お祭りの晴れた日の朝から夕方まで、ときどき花びらが1枚友だちの頭にのります。その友だちが動くか、夜や雨になるまで残ります。お花見の間は花びらが少し多めに降り、頭にのることも増えます。降ってくる花びらを押すとつかまえられ、きらりと光って消えます。その日最初の1枚には、友だちが願いごとをしてくれます。動きを減らす設定のときは、花びらは降らず、つかまえることもできませんが、友だちは集まり、頭の花びらもそのままです。

### 年末の手紙

12月26日から31日の間に初めてPlayPetsを開いた日、いちばん仲のいい友だちが、1年のことを書いた手紙をくれます。図鑑に新しく加わったもの、いっしょに育てた木、どれくらい仲よくなったか、出会ってからの日数などが書かれていて、今年はどうだったか、来年は何をしたいかをたずねてくれます。

庭に郵便受けがあれば手紙はそこで待っていて、なければ友だちが教えてくれます。どちらの場合も、1月7日までは風景のラベルの横の**手紙**チップか、庭のメニューから開けます。返事は200文字まで。書かずにそのままにしてもかまいません。

1月1日から7日の間に初めて開いた日には、友だちが返事を持ってきて、はげましてくれます。来年12月の手紙は、その返事をふり返ります。AI接続のある友だちは、自分の言葉で手紙を書きます。手紙と返事はこのパソコンに保存され、手紙のカードから削除できます。来年の手紙を書く友だちにAIがつながっていれば、そのAIが返事を読んでから手紙を書きます。

## なかよし度 <Since v="0.1.0" /> {#closeness}

友だちは、庭で一緒に過ごす時間や一緒にしたことを通して、少しずつあなたと仲良くなります。どれくらい仲良しかは名札のハートでわかり、友だちの画面では今の段階、次の段階までの距離、次の段階でできるようになることを確かめられます。

段階が表すのは親しさで、お互いの間柄ではありません。恋人やきょうだいでも、友だちと同じ段階の名前で表示されます。間柄は[関係](./chat.md#relationship)で決めます。

| 段階 | できるようになること |
|---|---|
| はじめまして | |
| うちとけた仲 | アプリを開いたときや、しばらくして戻ってきたときに迎えてくれます |
| なかよし | ときどき自分から釣りに行きます |
| 特別な仲 | 思い出のプレゼントを持ってきます |
| かけがえのない仲 | 名札に花が付き、ときどきあなただけにひと言話します |

一緒の時間は、庭が見えている10分ごとに数え、1日1時間分までです。なでる、おやつ、会話、水やり、捕まえること、プレゼントはもっと多く数えますが、1日分までで、なでるだけではその4分の1までしか進みません。ウィンドウを開いておくだけでも、数分クリックし続けても急には進まず、なかよし度は一緒にしたことで日を重ねて育ちます。離れていても減ることはありません。

なかよし度は`state.json`の`bonds`に保存されます。

## 少し掘って、木を植える

**穴掘り**

1. 下の入口から**遊ぶ**を開くか、友だちを右クリックして**Cloverと遊ぶ**のような項目を選びます。
   - 同じメニューの**Cloverに穴掘りを頼む**を選ぶと、穴掘りの道具をすぐ手に取り、その友だちが先に掘りに行きます。
2. **穴掘り**を選んで、空いた地面をクリックします。**Esc**で取り消せます。
3. 友だちが歩いていって掘ります。AI接続は不要です。

水面、家具、木の根は避けてください。友だちが着く前に別のことをさせると、発見はありません。空いた地面を右クリックして**ここを掘る**を選べば、**遊ぶ**を開かずにその場所を掘れます。

**穴掘りの道具**

道具はしまうまで手に持ったままです。地面を選ぶたびに手の空いた友だちが掘りに行き、掘ったばかりの友だちがひと休みしている間は、ほかの友だちが行きます。

下のドックの位置に出る帯から、**木を植える**や**種を植える**へ一度で持ち替えられます。道具をしまうときは、帯の閉じるボタンか**Esc**を押します。

道具を持っていても、湖や生きものが隠れることはありません。水や、飛んだり這ったりしている生きものを押すと、道具をしまいながら、その1回で釣りや虫取りをします。

**動きと服**

Daisy、Clover、Pip、Misoは、穴掘り、植える動作、竿を振る動作、魚を待つ姿、釣り上げる動作、発見したときの反応まで、四季を通じて専用の動きを見せます。取り込んだペットも、元の動きのまま同じ遊びに加わります。

Daisy、Pip、Misoは春と秋に同じ普段着を着て、夏と冬はそれぞれの季節の服に着替えます。Cloverは春から秋まで青緑のオーバーオールに麦わら帽子で、冬になるとコート、マフラー、ニット帽に着替えます。

**掘って見つかるもの**

- 花の種、苗木、25種類の小さな発見のどれかが出ます。何も出ないこともあります。小さな発見は**図鑑 → 小さな発見**に記録されます。
- レアな発見のあとは、すべての友だちと場所で、次のレアな発見まで24時間待ちます。
- 同じものが出ることもあるので、いつそろうかは保証されません。
- 同じ場所からは、24時間は追加の報酬が出ません。
- 友だちごとに、穴掘りの間隔は8秒です。
- 種は20個、苗木は樹種ごとに20個まで。いっぱいでも別の報酬には変わりません。

**木を植える**

1. まず穴掘りで苗木を見つけます。
2. **木を植える**を選ぶと、桜、カエデ、松、オーク、白樺、柳、イチョウ、カキノキ、タケ、モクレン、サルスベリ、メタセコイアの所持数が見られます。
3. 持っている樹種を選び、空いた地面をクリックします。植えると同じ樹種の苗木を1本使います。

- 2時間で若木、12時間で成木になります。アプリを閉じていた時間も含みます。
- 成木になると**図鑑 → 木**に一度だけ記録されます。
- 1か所に6本、全体で24本まで植えられます。木は植えた場所に残ります。
- ドラッグで動かせます。
- 右クリックして**片づける**を選ぶか、選んで**Delete**を押すとすぐに片づきます。花と同じく、6秒ほどはお知らせの**元に戻す**で戻せます。図鑑の記録は残りますが、苗木は戻りません。
- 室内では穴掘りも植樹もしません。読み込む背景では、土を使えるかどうかを明示できます。

### 雪の上の足あと

冬の庭では、雪の上にうっすらと動物の足あとが続きます。足あとは1日に1本つき、雪が降った夜の翌朝にはもう1本つきます。12月26日から1月7日までは、1日1本だけです。

足あとをクリックすると、休んでいる友だちがくんくんしながらたどります。キーボードでは、Tabで足あとまで移動してEnterを押します。たどり着いた先では、茂みの陰からしっぽがちらりとのぞいて、すぐに消えます。その場所には小さなものが埋まっていて、動物ごとに好きな見つけものがあります。

新しい雪が1時間積もると足あとは隠れ、次の日には消えます。くつろぎのリビングにはありません。**図鑑 → 足あと**では、たどるまでは足あとだけが見え、たどるとしっぽと名前がわかります。

### 春の芽

庭が屋外の春のあいだは、雨のあとに芽がいくつか顔を出し、晴れた朝にはひとつ出ます。いちどに立つのは3つまでで、数時間たつと引っ込みます。くつろぎのリビングにはありません。

芽をクリックすると、選んでいる友だちか、いちばん近くで休んでいる友だちが掘りに行きます。掘った芽は**図鑑 → 春の芽**に入ります。ナズナ、ヨモギ、ワラビ、ギョウジャニンニク、タケノコ、ツクシ、アスパラガス、アミガサタケの8種類です。図鑑は集めて楽しむためのもので、野草の手引きではありません。

## 遊び <Since v="0.1.0" />

4つの遊びは**遊ぶ → みんなで遊ぶ**にあり、一度に遊べるのはひとつだけです。遊んでいる間、そのボタンは**かくれんぼをやめる**のように遊びの名前が付いた「やめる」ボタンに変わり、クリックするとすぐに終わります。

遊びが終わるまで、ほかの遊びと**おやつ**、**種を植える**、**木を植える**は使えません。終わると、友だちは元いた場所へ歩いて戻ります。

### かくれんぼ

<Shot name="play-hide-and-seek" caption="かくれんぼ。下のバーの上の案内に探す友だちの名前が出ます。" />

1. **かくれんぼ**をクリックすると、友だちが隠れ場所へ散らばります。15秒以内に着かなかった友だちは、その場で隠れます。
2. 下のバーのすぐ上の案内に、**クリックして探す**と探す友だちの名前、続いてまだ隠れているほかの友だちの名前が出ます。遊びの案内、発見のカード、通知など、庭からのお知らせはすべてこの場所に出ます。
3. 名前を呼ばれた友だちを見つけてクリックします。当たれば「見つかっちゃった！」と飛び出し、バナーは次の友だちに進みます。
4. 違う友だちをクリックすると「残念、その友だちではありません。もう一度探してみてください」と通知が出るだけです。その友だちは隠れたままで、探す名前も変わりません。
5. 全員を見つけると「全員見つけました！」で遊びが終わります。

### おさんぽ行列

1. **おさんぽ行列**をクリックすると、選択中の友だちが先頭に立ち、ほかの友だちがその後ろに並びます。
2. 列がそろうと、みんなで庭を1周します。
3. 1周すると先頭の友だちが「一周おわり！」と言い、遊びが終わります。

### おにごっこ

**おにごっこ**には友だちが2人以上必要です。

1. 選択中の友だちがおにになります。「おにだぞ〜！」と言い、名札に「（おに）」が付きます。
2. おにはいちばん近い友だちを追いかけ、ほかの友だちはおにから逃げます。
3. おにが画面上でほかの友だちと重なると、その友だちは捕まります。捕まった友だちが次のおにになり、捕まえた友だちは少しの間安全です。
4. 決まった時間がたつと「おにごっこが終わりました。みんなよく走りました！」で遊びが終わります。

### 雪だるま作り {#snowman}

庭が冬の景色のとき（**くつろぎのリビング**は除きます）、**遊ぶ → みんなで遊ぶ**の**雪だるま作り**を押すと始まります。ときどき、友だちのほうから「雪だるま作ろう」と言って、雪玉を転がし始めることもあります。2人の友だちが転がすほど雪玉は大きくなります。雪玉を押すと一緒に押してあげられ、ドラッグするか矢印キーを使えば自分で転がせます。通ったあとの雪には薄い青の跡が残り、やがて消えます。雪玉を3つ重ねるときらきらと一緒に雪だるまができあがります。作れるのは1日1回で、同じ日にもう一度頼むと、友だちは「もう作ったよ」と言うだけです。

できあがったら、帽子、マフラー、にんじんの鼻を選びます。あとで変えたいときは、雪だるまを押すか、メニューの**おしゃれ**を選びます。

- 新しい雪だるまを作ると、前の雪だるまはとけます。友だちがそばにいれば、お別れを言ってくれます。
- 雪だるまが庭にいるのは、庭が冬の景色のあいだだけです。メニューの**デスクトップに表示**を選ぶと、着せたままの姿でデスクトップにも出ます。デスクトップでも、見えるのは庭が冬の景色のあいだだけです。片づけるととけます。
- 庭に飾りが12個あって雪だるまがいないときは、友だちが庭がいっぱいだと言って、始まりません。

## 作業のそばに置くウィンドウ

端や角をドラッグすると、300 × 210まで自由に大きさを変えられます。上端の細い透明な部分をドラッグすると移動でき、最後の位置と大きさは覚えておきます。どの大きさでも、同じウィンドウで友だち、会話、招待、設定、背景や遊びの道具が使えます。

**小さなウィンドウ**（幅640ピクセル以下、または高さ480ピクセル以下）

ウィンドウが小さいときは、下のバーが隠れます。代わりに、ポインターをウィンドウに重ねるかTabで移動すると、右下に丸いボタンが出ます。

このボタンで開くのは、空いた背景を右クリックしたときと同じ短いメニューで、**場所と雰囲気**、**遊ぶ**、**友だちと設定**、**常に手前に表示**の4項目です。

- **Cmd/Ctrl + Shift + P**で友だちと設定が開きます。
- 各パネルの項目はタイルで並び、名前は2行になることがあります。まとまりの見出しは画面上では隠れます。
- 長いパネルはウィンドウの中でスクロールします。
- **友だちを招待**の読み込みボタンは上部に出ます。

閉じたり戻ったりしたときの行き先です。

| 操作 | 戻る先 |
|---|---|
| 場所と雰囲気や遊ぶを閉じる | そのまま風景 |
| 友だちの画面と**友だちを招待**の戻る操作 | 友だちと設定 |
| **×** | 庭 |
| 設定の戻る操作 | まとまりからは設定の一覧へ、一覧からは友だちと設定へ |

**友だちと右クリック**

友だちの名札を押すと、その友だちとの会話が開きます。名札にポインターを重ねると、**Cloverに話しかける**のように表示されます。

友だちを右クリックすると、**Cloverに話しかける**、**Cloverと遊ぶ**、**Cloverに穴掘りを頼む**が並んだ短いメニューが開きます。

遊ぶを選ぶとその友だちの遊ぶパネルが開き、穴掘りを頼むを選ぶと、その友だちが先に行くように穴掘りの道具を手に取ります。

閉じる、Esc、外側のクリックで風景に戻ります。小さなウィンドウ専用の遊び欄はありません。

空いている背景を右クリックすると、ポインターのそばに短い操作メニューが開きます。小さなウィンドウでは右下のボタンからも開けます。

メニューはウィンドウの中に収まり、必要ならスクロールでき、**Esc**か外側のクリックで閉じます。友だち、花、飾りを右クリックしたときは、それぞれの操作がそのまま出ます。

**全画面**

**友だちと設定 → ウィンドウとデスクトップ → 全画面表示**で、画面いっぱいに広がります。全画面の間は同じ項目が**元のサイズに戻す**に変わり、**Esc**でも戻れます。パネルやメニューが開いていれば、Escはまずそれを閉じます。

戻ると、前のサイズと位置、常に手前に表示の設定がそのまま引き継がれます。

<Shot name="mini" caption="作業のそばに置いた小さな庭のウィンドウ。" />

**常に手前に表示**

**友だちと設定 → ウィンドウとデスクトップ → 常に手前に表示**か、右クリックメニューの同じ項目で切り替えます。トレイとmacOSの表示メニューにもあり、**Cmd/Ctrl + Shift + M**ならサイズを変えずに切り替えられます。ウィンドウの大きさとは関係なく働き、設定は保存されます。

Linuxでは、最前面表示に対応しているかどうかがデスクトップやウィンドウマネージャーによって違います。一部のWayland環境では適用できないので、切り替わらない場合はデスクトップ側のウィンドウ設定を確認してください。

<Shot name="mini-chat" caption="小さな庭のウィンドウの中で、作業のそばで会話できます。" />

**閉じる、終了する**

**友だちと設定 → ウィンドウを閉じる**は、庭をトレイにしまいます。デスクトップの友だちとエージェント連携は動き続けます。

その隣の**PlayPets を終了**は、トレイの終了やmacOSの<kbd>⌘</kbd> <kbd>Q</kbd>と同じく、確認せずにすぐ終了します。会話は保存されません。短い右クリックメニューや右下のボタンからは、友だちと設定を選べばこれらの項目に進めます。

**更新のお知らせ**

小さなウィンドウでは、新しいバージョンは点の付いた32ピクセルのダウンロードアイコンで表示されます。アクセシブルな名前でバージョンがわかり、押すとアプリのアップデートが直接開きます。大きなウィンドウでは、バージョン付きのボタンが表示されます。

**ダイアログ**

友だちの設定、読み込み、AI接続のダイアログは、見出しと操作ボタンを固定し、入力部分だけをスクロールします。図鑑と確認ダイアログは、それぞれの本文がスクロールします。

確認ダイアログは落ち着いた色で尋ね、もう一方のボタンは**キャンセル**です。取り戻せないものを失うときだけ赤く表示され、もう一方のボタンは**そのままにする**になります。AI接続の削除、友だちとのお別れ、背景の削除がそうです。

どの確認ダイアログにも**閉じる**ボタンがあります。花、木、プレゼントは確認を出さず、代わりに**元に戻す**を表示します。

## ゆっくり集めるためのヒント

図鑑には、水中の生きもの、虫、花、プレゼント、木、足あと、春の芽、小さな発見を合わせて169種類あります。コウライオヤニラミやモクズガニ、寒い夜のめずらしいチョウザメ、草むらのカマキリ、秋の夜のウマオイやコオロギを探してみましょう。タンポポ、アサガオ、ヒガンバナ、パンジーを育てて、イチョウやカキノキも植えてみましょう。

土の中からは、松ぼっくりや紙の舟、ときには四つ葉のクローバーが見つかります。友だちが届けてくれる水車、ハンモック、かめ置き場のために、場所を空けておくのもいいですね。

**時間がかかること**

全169種類は、1日や1週間でそろえる目標ではありません。いつそろうかも保証されません。通常のプレゼント21種類は、それぞれ違う日付に届きます。

イベント限定の7種類は暦のあちこちにあるお祭りを待つ必要があり、始めた時期によっては全部そろうまで数か月かかることもあります。季節を変えてもお祭りは始まりません。

花は植えてから4時間、木は12時間で育ちます。アプリを閉じていた時間も含みます。

**探し方**

- **魚:** 雨の日はナマズとウナギに出会いやすくなります。出てくる季節と時間を選び、ガイドでどんな魚が釣れるか調べてみましょう。
- **虫:** 晴れた屋外で探します。チョウとトンボは朝と昼、ホタルは春と夏の夕方と夜、コオロギは秋の夕方と夜に出ます。お祭りは暦どおりに開かれるので、季節を変えるだけでは始まりません。
- **穴掘り:**
  - 季節、天気、屋外の場所によって、出やすい苗木や発見が変わります。
  - 条件が合うと見つけやすくなりますが、合わないものも出ます。
  - 雰囲気で季節と天気を別々に選べるので、珍しい組み合わせも試せます。
  - 追加した屋外の背景にも、季節と天気が反映されます。
  - 同じ場所は24時間、結果が変わりません。外れが続いても、次の発見が出やすくなることはありません。
- **場所を空ける:** プレゼントを片づけても図鑑の記録は残り、次のプレゼントを置く場所ができます。種や苗木の袋がいっぱいでも、選ばれた報酬が別のものに変わることはありません。

ガイドでは、選んだ条件で出会えるものを確認できます。水や障害物があるため、実際に掘れる区画は背景全体の格子より少なくなります。
