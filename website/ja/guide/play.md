# 庭と遊び

庭は時計と天気と季節に合わせて姿を変え、日ごとに少しずつ育ちます。友だちは穴を掘り、釣りをし、プレゼントを持ってきて一緒に遊びます。見つけたものは図鑑に記録されます。

::: tip 早見表
| したいこと | すること | 詳しく |
|---|---|---|
| 場所、季節、時間帯、天気を変える | 下の**場所と雰囲気** | [時間帯と天気](#weather) |
| 種、苗木、小さな発見を見つける | **遊ぶ → 穴掘り**で空いた地面をクリック | [穴掘り](#digging) |
| 花と木を育てる | **遊ぶ → 種を植える**か**木を植える** | [花を育てる](#the-garden) |
| プレゼントをもらう | その日に友だちと何かをする | [プレゼント](#gifts) |
| 図鑑を埋める | 釣り、虫取り、穴掘り、花と木を育てる | [図鑑](#album) |
| 季節のイベントをいつでも見る | 季節を自分で選び、イベントに合う時間帯と天気にする | [季節のイベント](#seasonal-events) |
| 友だちと仲よくなる | 毎日少しずつなでる、おやつ、会話、遊び | [なかよし度](#closeness) |
| 遊びをする | **遊ぶ → みんなで遊ぶ** | [遊び](#games) |

## 画面のつくり

風景がウィンドウいっぱいに広がり、下の入口からパネルを一度にひとつずつ開きます。どのパネルも1ページで、中はいくつかのまとまりに分かれ、タブや戻るボタンはありません。

| 入口 | 中身 |
|---|---|
| **場所と雰囲気** | **場所**（標準の背景と読み込んだ背景が並ぶ一覧、**背景を読み込む**、**背景制作室**）、**雰囲気**（季節、時間帯、天気、**庭の音**、**音量**） |
| **遊ぶ** | 題は選んでいる友だちに合わせて**Cloverと遊ぶ**のように変わります。**見つける**：**穴掘り**、**釣り**、**図鑑**。**庭**：**種を植える**（持っている種の数も表示）、**木を植える**、**おやつ**。**みんなで遊ぶ**：4つの遊び（**雪だるま作り**は庭が冬の景色のときだけ）、桜まつりの間の**お花見**、**おしゃべり** |
| **友だちと設定** | **友だちと会話**、**友だちを招待**、**ウィンドウとデスクトップ**、**設定**、**ウィンドウを閉じる**、**PlayPets を終了** |

- **おしゃべり**だけは、AIにつながった友だちが2人必要です。ほかはAIがなくても楽しめます。
- 初めての庭は、晴れた春の昼から始まります。季節、時間帯、天気を自然に移り変わらせたいときは**自動**を選びます。選んだ内容はすべて保存されます。

### 音

- **庭の音**と**音量**：**場所と雰囲気 → 雰囲気**にあります。
- 最初に何か操作したあと、庭が見えている間だけ鳴ります。
- 雨や鳥、水などの音は、場所、天気、季節、時間帯に合わせて変わります。
- 友だちが自分たちでおしゃべりする設定は別で、**友だちと設定 → 設定 → 友だちとAI**にあります。

## 時間帯と天気 <Since v="0.1.0" /> {#weather}

どれも自分で選ぶか、**自動**に任せます。変更はすぐに反映されます。

<Shot name="yard-spring" caption="晴れた春の昼の庭です。時間帯を自動にすると、時計に合わせて変わります。" />

1. 右下の**場所と雰囲気**を開きます。
2. **場所**で、サムネイルを見て背景を選びます。削除ボタンは、読み込んだ背景を選んだときだけ出ます。
3. **雰囲気**で季節、時間帯、天気を選びます。

| 項目 | 選択肢 | 自動のとき |
|---|---|---|
| 場所 | 丘の庭、ガーデン工房、自然の庭、湖畔の家、読み込んだ背景 | |
| 季節 | 自動、春、夏、秋、冬 | 屋外の場所は日付に合わせて、花と舞う花びら、深い緑、赤や金色の葉、雪景色に変わります。パソコンのタイムゾーンが南半球なら季節は逆になります |
| 時間帯 | 自動、朝、昼、夕方、夜 | 時計は表示されず、パソコンの時刻に合わせて進みます。空と地面の色が移り変わり、太陽は左から右へ横切り、夜はその夜の満ち欠けのとおりに月が出ます |
| 天気 | 自動、晴れ、雨、雪 | 20分に1回、新しい天気が選ばれます。たいていは晴れで、ときどき雨、雪は冬だけです。インターネットから実際の天気は取ってきません |

- 自分で選んだ季節、時間帯、天気はそのまま固定され、次に開いたときも同じです。
- 季節と天気は別々に決まります。夏に雪を選ぶと夏の景色と服装のまま雪が降り、冬に晴れを選んでも冬景色はそのままです。室内の窓の外や読み込んだ背景も同じです。
- 季節を自分で選ぶと、どの日でも[季節のイベント](#seasonal-events)を呼べます。
- 天気が変わると、1〜2人の友だちが「雨だ！」「雪だるま作る？」のようにひと言しゃべります。放っておくと、時間帯に合った独り言も言います。

### 天気が見せる景色

| 景色 | いつ | すること |
|---|---|---|
| 虹 | 昼に雨が上がったとき。数分のあいだ丘の上にかかります | 虹のふもとのきらめく地面を、消える前に掘ります。何も出ないことはありません |
| 天気雨 | 晴れた昼に雨が降りだしたとき | お日さまが出たまま降る雨をながめます |
| 朝霧 | 晴れた秋の朝 | 野原にかかる霧をながめます |
| 月明かりの雪原 | 夜に雪がやんだとき | 月明かりの下できらめく雪をながめます |
| 流れ星 | 晴れた夏の夜 | ひと晩じゅうよく流れるので、空を見上げます |
| 鳥の群れ | 晴れた日にときどき | 空を横切る群れをながめます |

虫も光と季節に合わせて出てきます。[虫](#bugs)をご覧ください。

### 場所 {#places}

| 場所 | どんなところ |
|---|---|
| 丘の庭 | 開けた丘。家があります |
| 自然の庭 | 野の花に囲まれた、澄んだ池のある自然のままの庭 |
| 湖畔の家 | 湖のほとりの家 |
| ガーデン工房 | ガラス屋根の工房。1年じゅう同じ眺めです |

- 丘の庭、自然の庭、湖畔の家には、それぞれ四季の風景と釣り場があります。色は光に合わせて変わります。
- 背景を描き直すのは、風景かウィンドウの大きさが変わったときだけです。
- 場所は、時間帯や天気とは別に保存されます。
- 場所を変えても、育ち具合や図鑑はそのまま引き継がれます。

### ガーデン工房 <Since v="1.7.0" /> {#garden-workshop}

ガラス屋根の下に、長い作業台が2つ、チェッカー盤のあるお茶のテーブル、手前にベルのついたガーデンベンチがあります。ガラス越しに空と時間帯、天気が見え、雨や雪はガラスの外に降ります。

- 友だちは部屋の中を散歩したり、作業台で種を選んだり、一緒にお茶を飲んだり、ベンチのそばで休んだりします。
- コーディングエージェントとつながった友だちは作業台で作業し、エージェントが確認を待つと手前のベルのそばで待ちます（[友だちがそこですること](./agents.md#where-friends-go)）。

どの場所でも、友だちをなでる、話す、花を育てる、クリスマスツリーを飾る、遊びをすることができます。それ以外は場所によって違います。

| できること | 丘の庭、自然の庭、湖畔の家 | ガーデン工房 |
|---|---|---|
| 花 | 地面に植わります | 小さな鉢に植わります |
| 穴掘り、釣り | できます | できません |
| 木 | 1か所に6本まで | できません |
| 虫 | 晴れた日に出ます | 出ません |
| 季節の景色と演出 | 季節に合わせて変わります | ありません |
| 雪だるま作り、雪の上の足あと | 冬 | ありません |
| 春の芽 | 春 | ありません |
| クリスマスの夜 | 雪の降る冬の夕方か夜 | ありません。雪はガラスの外に降ります |

## おしゃべり <Since v="0.1.0" />

**遊ぶ → みんなで遊ぶ → おしゃべり**を押すと、AIをつけた友だち（3人まで）がいまの時間帯と天気について短く話し、庭の吹き出しに順番に出ます。

- AIをつけた友だちが2人いないときは、ボタンがオフの見た目になります。押すかポインターを重ねると理由が出ます。
- 自分も加わりたいときは、[友だちの画面のグループ会話](./chat.md)を使います。
- 自分たちで話してほしいなら、**友だちと設定 → 設定 → 友だちとAI**の**ときどき友だち同士で話します**をオンにします。20分に1回話し、ウィンドウが隠れているときや誰かが返事をしているときは休みます。

## 花を育てる <Since v="0.1.0" /> {#the-garden}

花の種も苗木も、[穴掘り](#digging)で見つかります。友だちが散歩しているだけでは出てきません。

1. **遊ぶ → 庭 → 種を植える**を選びます。横の数字は持っている種の数です。
2. 原っぱの植えたい場所をクリックします。続けてクリックすればいくつも植えられ、**Esc**かもう一度ボタンを押すと終わります。

- キーボードでは、**種を植える**をEnterかSpaceで選び、もう一度押すと選んでいる友だちのそばに植えます。おやつと同じ操作です。
- 道具を手にしている間は、1、2、3のキーで**穴掘り**、**木を植える**、**種を植える**に持ち替えます。入力欄で文字を打っている間は切り替わりません。

植物は時計どおりに育ち、アプリを閉じている間も育ちます。

| 経過 | 10分 | 40分 | 2時間 | 4時間 |
|---|---|---|---|---|
| 段階 | 芽 | 葉 | つぼみ | 花 |

咲く花は植えた季節で決まります。

| 植えた季節 | 花 |
|---|---|
| 春 | チューリップ、スイセン、クロッカス、ムスカリ |
| 夏 | ひまわり、アジサイ、ラベンダー、カンパニュラ |
| 秋 | コスモス、キク、ダリア、アスター |
| 冬 | 椿、スノードロップ、ヘレボルス、シクラメン |

| 植物に | どうなるか |
|---|---|
| ポインターを重ねる | 何の花か、咲くまであとどれくらいかが出ます |
| クリック | いちばん近い友だちが水をやりに来ます。友だちは自分から花を見に行くこともあります |
| ドラッグか矢印キー | 動かせます。動かした場所でそのまま育ちます |
| 右クリック → **抜く**、または**Delete**か**Backspace** | 確認なしですぐに抜けます。お知らせの**元に戻す**で6秒ほどは戻せ、そのあと完全に消えます。それまでにアプリを閉じた場合は残ります。使った種は戻りません |
| 右クリック → **デスクトップに表示** | 机の上でも育ちます（[デスクトップモード](./desktop.md#flowers-and-trees-on-the-desktop)） |

- 種は20個、植物は24本まで。
- 花は種類ごとに初めて咲いたときに**図鑑**に載ります。
- `state.json`の`garden`に保存されます。

### プレゼント {#gifts}

プレゼントは時間ではなく、一緒に過ごした友だちが持ってきます。

| プレゼント | 届くとき |
|---|---|
| ふだんのプレゼント | なでる、おやつをあげる、話す、一緒に釣りをするなど、友だちと何かをした日。10〜20分後に届きます（最初のひとつだけ5分）。庭全体で二日に一度までで、庭を開いておくだけでは届きません |
| なかよしのプレゼント | **うちとけた仲**から段階が上がるたびにひとつ、その友だちと遊んだ日に届きます |
| 思い出のプレゼント | **特別な仲**になると届く、その友だちだけのプレゼント。1日のあいだ小さなハートが付き、そのあとはポインターを合わせたときか選んだときに出ます |
| イベントのプレゼント | 季節のイベントの日付にだけ届きます（[季節のイベント](#seasonal-events)） |

- 待ち時間は保存され、アプリを閉じていた時間も数えるので、開いたままにしなくても大丈夫です。友だちはぴょんと跳ねて知らせ、そばにプレゼントを置きます。
- 最初はこの順に届きます：ベンチ、ランタン、巣箱、小さな池、郵便受け、レジャーシート、かざぐるま、たき火、ブランコ、植木鉢、切り株の椅子、テント、道しるべ、風鈴。そのあとは、庭にまだないものを持ってきます。

友だちはもらったものを使います。ベンチやブランコ、切り株に腰かけ、シートに集まり、空が映る池をのぞき込みます。ランタンとたき火は夕方から光り、昼は巣箱に鳥がとまり、風鈴は友だちが近づくと鳴ります。

| プレゼントに | どうなるか |
|---|---|
| ドラッグ、または選んで矢印キー | 原っぱのどこへでも動かせます |
| クリック | いちばん近い友だちが歩いてきます |
| 右クリック → **片づける**、または**Delete**か**Backspace** | すぐに片づきます。お知らせの**元に戻す**で6秒ほどは戻せます。それまでにアプリを閉じた場合は残ります。別の日に友だちがまた持ってくることもあります |
| 右クリック → **デスクトップに表示** | デスクトップに出せます（[デスクトップのプレゼント](./desktop.md#gifts-on-the-desktop)） |

- 飾りは12個まで置けます。いっぱいのときは、新しいプレゼントは図鑑の「プレゼント」の巻の上にある**プレゼント箱**で待ちます。箱にも12個まで入り、場所が空いたら箱から押して出せます。
- 片づけても図鑑の記録は残り、これから届くプレゼントの場所ができます。思い出のプレゼントは、箱がいっぱいでなければプレゼント箱に戻ります。
- 一度届いたプレゼントはまた出せます。場所があれば、図鑑の「プレゼント」の巻でそのカードの**庭に出す**を押します。雪だるまだけは例外で、作り直します。
- プレゼントは全部で29種類で、そのうち7種類はイベントの日付にだけ届きます。雪だるまもこの29種類のひとつですが、自分たちで作ります（[雪だるま作り](#snowman)）。思い出のプレゼントもこの29種類のどれかなので、新しい枠は増えません。

## 釣りと虫取り <Since v="0.1.0" />

### 釣り

| やり方 | どうするか |
|---|---|
| 手で釣る | 見えている水面をクリックすると、近くの手の空いた友だちが竿を出します。浮きが沈んで**!**が出たらクリックします。早すぎても遅すぎても逃げられます |
| **遊ぶ → 釣り** | 選んでいる友だちが出かけて、最後まで自分で釣ります |

- どちらもその背景の釣り場を使います。
- 竿には淡水エビ、ザリガニ、タニシ、モクズガニ、イシガイもかかり、ときにはスッポンも上がります。どれも魚と一緒に**水中の生きもの**の図鑑に記録されます。
- 何がかかるかは季節、時間帯、天気で変わります。ナマズやウナギは暗くなってから出てきて、雨の日はもっと増えます。ワカサギは冬だけで、黄金ゴイはとても珍しい魚です。魚の大きさは毎回違います。

### 虫 {#bugs}

虫が出るのは晴れた屋外だけで、雨や雪では現れません。虫をクリックすると、近くの友だちが捕まえます。

| いつ | 虫 |
|---|---|
| 春から秋の朝と昼 | チョウとトンボ、草むらの甲虫とバッタ |
| 春と夏の夕方と夜 | ホタル |
| 秋の夕方と夜 | 草むらのコオロギ |

### 自分から釣る友だち {#fishing-on-its-own}

- なかよし度3から、庭が見えている間、手の空いた友だちは12〜25分ごとに自分から釣りに行くことがあります。
- 遊びや別の釣りの最中、配置の道具を手にしている間は休みます。
- 魚がかかると友だちが呼びます。数秒のうちに浮きを押すと一緒に釣り上げ、押さなければ逃げます。図鑑に載るのは、あなたが釣ったものだけです。

### 図鑑 {#album}

- **遊ぶ → 見つける → 図鑑**。花、水中の生きもの、虫、プレゼント、木、小さな発見、足あと、春の芽の8冊です。
- すべての種類が並びます。捕まえたものは数と最大の魚の大きさ、まだのものはシルエットと、いつどこで探せばいいかが出ます。
- レアな発見をまた探せる時刻も出ます。正確な確率は出ません。
- **レア**は、めったに出ないものと、季節のイベントのときだけ出るものに付きます。イベントのものは、日付と呼び出せる景色が出ます。
- 捕まえるとカードが出て、初めてならそう知らせます。図鑑に残るもの（魚、虫、咲いた花、プレゼント、小さな発見、春の芽）のカードには**図鑑で見る**があり、その巻が開きます。
- 新しいものが加わると、図鑑を開くまで**図鑑**と下の入口の**遊ぶ**に小さな点が付きます。
- `state.json`の`album`に保存されます。

## 季節のイベント <Since v="0.1.0" /> {#seasonal-events}

1年に何度か、庭がしばらく様子を変えます。イベントは日付が来ると自然に始まり、ほかの日でも**場所と雰囲気 → 雰囲気**で景色を自分で選べば呼べます。

| イベント | 自然に始まる日 | いつでも自分で選ぶなら |
|---|---|---|
| 桜まつり | 4月1日〜20日、庭が春の景色のとき | <SceneChips lang="ja" event="blossom" label="いつでも自分で選ぶなら" /> |
| ホタルの夜 | 7月20日〜8月20日、庭が夏の景色のとき | <SceneChips lang="ja" event="fireflies" label="いつでも自分で選ぶなら" /> |
| 中秋の名月 | 9月8日〜10月15日、庭が秋の景色のとき | <SceneChips lang="ja" event="harvest" label="いつでも自分で選ぶなら" /> |
| 冬のイルミネーション | 12月1日〜31日、どの季節でも | <SceneChips lang="ja" event="lights" label="いつでも自分で選ぶなら" /> |
| お正月 | 1月1日〜7日、どの季節でも | <SceneChips lang="ja" event="newyear" label="いつでも自分で選ぶなら" /> |

| イベント | 庭では | プレゼント（その日付だけ） |
|---|---|---|
| 桜まつり | あちこちに花びらが舞い、チョウが増えます。友だちが集まって[お花見](#flower-viewing)をします | 桜の苗木 |
| ホタルの夜 | 夜のホタルが増え、捕まえられる金色のホタルも出ます | スイカ |
| 中秋の名月 | 夜の湖に月光ゴイが現れます。自分で呼んだときは満月が出ます。日付で始まったときは、期間中最初の満月の前後2日の夜（中秋の名月やチュソクのころ）に大きな黄金色の月が昇り、ほかの夜はその日の月の形のままです | カボチャ |
| 冬のイルミネーション | 木々に小さなライトが飾られ、夕方から光ります | 小さなクリスマスツリー、トナカイの赤ちゃん、サンタの順 |
| お正月 | 友だちが新年のあいさつをします | 凧 |

- 風景のラベルの横にイベント名が出て、その年に初めて見たときは始まりを知らせるカードが出ます。友だちもその話をします。
- 季節が**自動**のときは、日付だけがイベントを連れてきます。暦のイベントが先で、12月のイルミネーションはどんな景色を選んでも続きます。
- 金色のホタルや月光ゴイのようなイベントの魚と虫は、どちらの始まり方でも、イベントの間なら出ます。
- イベントのプレゼントは、日付の間にプレゼントが届く番のたびにひとつずつ、決まった順に届き、そのとき限りです。もらったプレゼントはずっと残ります。いつ届くかは図鑑に出ています。
- 南半球では（パソコンのタイムゾーンで判断）、桜まつり、ホタルの夜、中秋の名月が6か月遅れで来ます。冬のイルミネーションとお正月は同じ日付です。

### 12月

12月に庭が冬の景色でないときは、1月7日まで冬にするかを一度だけたずねます。冬にすると答えると、選んでいた季節は1月8日に戻ります。

- クリスマスツリー、トナカイの赤ちゃん、サンタは、12月1日から1月7日まで、そして庭が冬の景色のときはいつでも、庭とデスクトップに出ます。
- それ以外は見えないところで待っていて、飾り12個の数には入ったままです。片づけるとプレゼント箱に戻ります。

### クリスマスの夜 {#christmas-night}

丘の庭、自然の庭、湖畔の家のどこかで小さなクリスマスツリーを出しておくと、この景色の日ならいつでも、ツリーに明かりがともって大きなツリーに育ちます。

<SceneChips lang="ja" :when="['season:winter', 'period:evening|night', 'weather:snow', 'gift:xmas_tree']" label="そろえるもの" />

- 雪が降っているあいだは大きなツリーのままで、ときどき電球がきらりと光ります。雪がやむと戻り、また降りだすともう一度育ちます。
- トナカイの赤ちゃんとサンタも出ていると、夜に二人で空を見上げ、ツリーが育つたびにそりが月の前を横切ります。
- デスクトップに出したツリーも、庭のツリーといっしょに育ちます。

### クリスマスツリーの飾りつけ

クリスマスツリーを押すと飾りつけができます。

- 図鑑で見つけた花、木、プレゼント、小さな発見を、1日に3つまで掛けられます。水中の生きものと虫は水辺と草むらに残ります。
- 掛けたものは種類ごとに色の違う小さなオーナメントになり、指すと何なのかがわかります。
- ツリーを替えたいときは、カードからオーナメントを外します。その日の3つは使った扱いのままです。
- オーナメントは庭のツリーにも大きなツリーにも掛かったままで、次の12月は何もないツリーから始まります。

### お花見 {#flower-viewing}

桜まつりの間、友だちは育てた桜の木の下に集まり、見上げて1分ほどおしゃべりしたら、また散らばります。

| 呼び方 | 内容 |
|---|---|
| 自分たちで | 晴れた日の朝から夕方まで、1日に1回。**ときどき友だち同士で話します**がオンのときだけです |
| 自分で呼ぶ | **遊ぶ → みんなで遊ぶ → お花見**、1時間に1回。お花見中や遊びの最中はグレーになります |
| どこで | 育てた桜の木の下。なければレジャーシートか庭の真ん中 |
| 早めに終わる | 場所を変えたり、夜や雨になったりしたとき。遊びや釣り、穴掘りの邪魔はしません |

- AIにつながった友だちは、自分の言葉で桜の話をします。
- お祭りの晴れた日の朝から夕方まで、ときどき花びらが友だちの頭にのります。その友だちが動くか、夜や雨になるまで残ります。お花見の間は花びらが多めに降り、頭にのることも増えます。
- 降ってくる花びらを押すとつかまえられ、きらりと光って消えます。その日最初の1枚には、友だちが願いごとをしてくれます。
- 動きを減らす設定のときは、花びらは降らず、つかまえることもできませんが、友だちは集まり、頭の花びらもそのままです。

### 年末の手紙

12月26日から31日の間に初めてPlayPetsを開いた日、いちばん仲のいい友だちが一年をふり返る手紙をくれます。図鑑に加わったもの、いっしょに育てた木、どれくらい仲よくなったか、出会ってからの日数が書かれていて、今年はどうだったか、来年は何をしたいかをたずねてくれます。

- 庭に郵便受けがあれば手紙はそこで待ち、なければ友だちが教えてくれます。1月7日までは、風景のラベルの横の**手紙**チップか庭のメニューから開けます。
- 返事は200文字まで。書かずにそのままにしてもかまいません。
- 1月1日から7日の間に初めて開いた日には、友だちが返事を持ってきてはげましてくれます。来年12月の手紙は、その返事をふり返ります。
- AI接続のある友だちは自分の言葉で書き、来年の手紙を書くときにはそのAIが返事を読みます。
- 手紙と返事はこのパソコンに保存され、手紙のカードから削除できます。

## なかよし度 <Since v="0.1.0" /> {#closeness}

名札のハートで、友だちとどれくらい仲よしかがわかります。友だちの画面では、今の段階、次の段階までの距離、次にできるようになることを確かめられます。

| 段階 | できるようになること |
|---|---|
| はじめまして | どの友だちもここから始まります |
| うちとけた仲 | アプリを開いたときや、しばらくして戻ってきたときに迎えてくれます |
| なかよし | ときどき[自分から釣り](#fishing-on-its-own)に行きます |
| 特別な仲 | 思い出のプレゼントを持ってきます |
| かけがえのない仲 | 名札に花が付き、ときどきあなただけにひと言話します |

- 段階が表すのは親しさで、お互いの間柄ではありません。間柄は[関係](./chat.md#relationship)で決めます。
- 一緒の時間は、庭が見えている10分ごとに数え、1日1時間分までです。
- なでる、おやつ、会話、水やり、捕まえること、プレゼントはもっと多く数えますが、1日分までです。なでるだけでは、その4分の1までしか進みません。
- ウィンドウを開いておくだけでも、数分クリックし続けても急には進みません。離れていても減ることはありません。
- `state.json`の`bonds`に保存されます。

## 穴掘りと木

### 穴掘り {#digging}

1. **遊ぶ → 見つける → 穴掘り**を選ぶか、友だちを右クリックして**Cloverに穴掘りを頼む**（その友だちの名前）を選ぶと、その友だちが先に行きます。
2. 空いた地面をクリックします。**Esc**で取り消せます。
3. 友だちが歩いていって掘ります。AIは要りません。

- 近道：空いた地面を右クリックして**ここを掘る**を選びます。
- 水面、家具、木の根は掘れません。友だちが着く前に別のことをさせると、発見はありません。
- 道具はしまうまで手に持ったままです。地面を選ぶたびに手の空いた友だちが行き、掘ったばかりの友だちはひと休みします。
- 下の入口の位置に出る帯から、**木を植える**や**種を植える**へ一度で持ち替えられます。帯の閉じるボタンか**Esc**で道具をしまいます。
- 道具を持っていても湖や生きものは隠れません。水や生きものを押すと、道具をしまってその1回で釣りや虫取りをします。

| 掘って見つかるもの | きまり |
|---|---|
| 花の種、苗木、25種類の小さな発見（**図鑑 → 小さな発見**）のどれか。何も出ないこともあります | レアな発見のあとは、すべての友だちと場所で24時間、次のレアを待ちます。同じ場所からは24時間何も出ません。友だちごとに掘る間隔は8秒です。同じものが出ることもあるので、そろうまで時間がかかることがあります |

- 種は20個、苗木は樹種ごとに20個まで。いっぱいでも、見つけたものが別のものに変わることはありません。

### 木を植える

1. 穴掘りで苗木を見つけます。
2. **遊ぶ → 庭 → 木を植える**で所持数を見ます：桜、カエデ、松、オーク、白樺、柳、イチョウ、カキノキ、タケ、モクレン、サルスベリ、メタセコイア。
3. 持っている樹種を選び、空いた地面をクリックします。苗木を1本使います。

- アプリを閉じていた時間も含めて、2時間で若木、12時間で成木になります。成木は**図鑑 → 木**に一度だけ記録されます。
- 1か所に6本、全体で24本まで。木は植えた場所に残ります。
- ドラッグで動かせます。右クリック → **片づける**、または**Delete**ですぐに片づき、6秒ほどは**元に戻す**で戻せます。図鑑の記録は残りますが、苗木は戻りません。
- 読み込む背景では、土を使えるかどうかを決められます。

### 雪の上の足あと

冬の庭では、雪の上にうっすらと動物の足あとが続きます。1日に1本、雪が降った夜の翌朝にはもう1本つきます（12月26日から1月7日までは1日1本だけ）。

- 足あとをクリックすると（またはTabで移動してEnter）、休んでいる友だちがくんくんしながらたどります。
- 行き着いた先では、茂みの陰からしっぽがちらりとのぞいて消えます。その場所には小さなものが埋まっていて、動物ごとに好きな見つけものがあります。
- 新しい雪が1時間積もると足あとは隠れ、次の日には消えます。
- **図鑑 → 足あと**では、たどるまでは足あとだけが見え、たどるとしっぽと名前がわかります。

### 春の芽

庭が屋外の春のあいだは、雨のあとに芽がいくつか顔を出し、晴れた朝にはひとつ出ます。いちどに立つのは3つまでで、それぞれ数時間で引っ込みます。

- 芽をクリックすると、選んでいる友だちか、いちばん近くの手の空いた友だちが掘ります。
- **図鑑 → 春の芽**は8種類：ナズナ、ヨモギ、ワラビ、ギョウジャニンニク、タケノコ、ツクシ、アスパラガス、アミガサタケ。集めて楽しむためのもので、野草の手引きではありません。

### 動きと服

- Daisy、Clover、Pip、Misoは、穴掘り、植える、竿を振る、魚を待つ、釣り上げる、発見に反応する動きを四季それぞれに持っています。取り込んだペットも元の動きのまま加わります。
- Daisy、Pip、Misoは春と秋に普段着を着て、夏と冬は季節の服に着替えます。Cloverは秋まで青緑のオーバーオールに麦わら帽子で、冬はコート、マフラー、ニット帽に着替えます。

## 遊び <Since v="0.1.0" /> {#games}

4つの遊びは**遊ぶ → みんなで遊ぶ**にあり、一度にひとつだけ遊べます。遊んでいる間、そのボタンは**かくれんぼをやめる**のように変わり、クリックするとすぐ終わります。終わるまで、ほかの遊びと**おやつ**、**種を植える**、**木を植える**は使えません。終わると友だちは元いた場所へ歩いて戻ります。

| 遊び | 流れ | 終わり |
|---|---|---|
| かくれんぼ | 友だちが隠れます（15秒以内に着かなければその場で隠れます）。下の入口の上の案内に、**クリックして探す**と探す友だち、続いてまだ隠れている友だちが出ます。当たれば「見つかっちゃった！」と飛び出し、案内は次の友だちへ。違う友だちは「残念、その友だちではありません」と出るだけで、隠れたままです | 「全員見つけました！」 |
| おさんぽ行列 | 選んでいる友だちが先頭に立ち、ほかの友だちが後ろに並び、列がそろうと庭を1周します | 「一周おわり！」 |
| おにごっこ | 友だちが2人以上必要です。選んでいる友だちがおに（名札に「（おに）」）で、いちばん近い友だちを追いかけます。画面上で重なると捕まり、捕まった友だちが次のおにに。捕まえた友だちは少しの間安全です | 決まった時間のあとに「おにごっこが終わりました。みんなよく走りました！」 |
| 雪だるま作り | 庭が冬の景色のとき。2人の友だちが雪玉を転がし、3つ重ねて雪だるまにします（[雪だるま作り](#snowman)） | 雪だるまができたとき |

<Shot name="play-hide-and-seek" caption="かくれんぼ。下のバーの上の案内に探す友だちの名前が出ます。" />

遊びの案内、発見、お知らせなど、庭からのお知らせはすべて下の入口の上のこの場所に出ます。

### 雪だるま作り {#snowman}

1. 庭が冬の景色のとき、**遊ぶ → みんなで遊ぶ → 雪だるま作り**を押します。ときどき友だちのほうから言いだして、雪玉を転がし始めることもあります。
2. 2人の友だちが転がすほど雪玉は大きくなります。押すと一緒に押し、ドラッグか矢印キーで自分でも転がせます。通ったあとには薄い青の跡が残り、やがて消えます。
3. 雪玉を3つ重ねると、きらきらと一緒に雪だるまができあがります。
4. 帽子、マフラー、にんじんの鼻を選びます。あとで変えるときは、雪だるまを押すか、メニューの**おしゃれ**を選びます。

- 作れるのは1日1回です。もう一度頼むと、友だちは「もう作ったよ」と言うだけです。
- 新しい雪だるまを作ると前の雪だるまはとけます。友だちがそばにいれば、お別れを言います。
- 雪だるまが庭にいるのは庭が冬の景色のあいだだけです。メニューの**デスクトップに表示**で、同じ姿のままデスクトップにも出ます（庭が冬の景色のあいだ）。片づけるととけます。
- 庭に飾りが12個あって雪だるまがいないときは、友だちが庭がいっぱいだと言って、始まりません。

## 作業のそばに置くウィンドウ {#a-window-beside-your-work}

端や角をドラッグすると、300 × 210まで大きさを変えられます。上端の細い透明な部分をドラッグすると移動できます。位置と大きさは覚えておき、どの大きさでも友だち、会話、招待、設定、背景の道具、遊びが使えます。デスクトップ全体を庭のように使うなら、[デスクトップモード](./desktop.md)をオンにします。ウィンドウの大きさに関係なく一緒に使えます。

<Shot name="mini" caption="作業のそばに置いた小さな庭のウィンドウ。" />

### 小さなウィンドウ

幅640ピクセル以下、または高さ480ピクセル以下のウィンドウです。

- 下の入口が隠れます。ポインターをウィンドウに重ねるかTabで移動すると、右下に丸いボタンが出ます。空いた背景を右クリックしたときと同じ短いメニューで、**場所と雰囲気**、**遊ぶ**、**友だちと設定**、**常に手前に表示**が開きます。
- **Cmd/Ctrl + Shift + P**で友だちと設定が開きます。
- パネルの項目はタイルで並び（名前は2行になることがあります）、まとまりの見出しは隠れ、ウィンドウの中でスクロールします。
- 新しいバージョンは、バージョン付きのボタンの代わりに点の付いた32ピクセルのダウンロードアイコンで出ます。名前でバージョンがわかり、押すとアプリのアップデートが開きます。

<Shot name="mini-chat" caption="小さな庭のウィンドウの中で、作業のそばで会話できます。" />

### メニューと戻り方

| どこで | どうなるか |
|---|---|
| 友だちの名札 | その友だちと話します（ポインターを重ねると**Cloverに話しかける**のように出ます） |
| 友だちを右クリック | **話しかける**、**遊ぶ**（その友だちの遊ぶパネル）、**穴掘りを頼む**（穴掘りの道具を手に取り、その友だちが先に行きます） |
| 空いた背景を右クリック、または右下のボタン | ポインターのそばに短い操作メニュー。ウィンドウの中に収まり、必要ならスクロールします |
| 友だち、植物、プレゼント | それぞれの右クリック操作が出ます |
| 閉じる、**Esc**、外側のクリック | 風景に戻ります |
| 場所と雰囲気、遊ぶ | 閉じるとそのまま風景に戻ります |
| 友だちの画面、友だちを招待 | **戻る**で友だちと設定へ、**×**で庭へ。招待では読み込みが上部に出ます |
| 設定 | **戻る**で、まとまりから一覧へ、一覧から友だちと設定へ |

### ウィンドウの操作

| 操作 | 場所 | どうなるか |
|---|---|---|
| **全画面表示** | **友だちと設定 → ウィンドウとデスクトップ** | 画面いっぱいに広がります。項目は**元のサイズに戻す**に変わり、**Esc**でも戻れます（パネルやメニューが開いていれば先にそれを閉じます）。大きさ、位置、常に手前に表示が元に戻ります |
| **常に手前に表示** | **ウィンドウとデスクトップ**、短い右クリックメニュー、トレイ、macOSの表示メニュー、**Cmd/Ctrl + Shift + M** | 庭をほかのウィンドウより手前に置きます。大きさに関係なく働き、保存されます。Linuxではデスクトップによって違い、一部のWayland環境では適用できないので、ウィンドウの設定を確認してください |
| **ウィンドウを閉じる** | **友だちと設定** | 庭をトレイにしまいます。デスクトップの友だちとエージェント連携は動き続けます |
| **PlayPets を終了** | **友だちと設定**、トレイ、macOSの<kbd>⌘</kbd> <kbd>Q</kbd> | 確認せずにすぐ終了します。会話は保存されません |

### ダイアログと確認

- 友だちの設定、読み込み、AI接続のダイアログは、見出しと操作ボタンを固定し、入力部分だけをスクロールします。図鑑と確認ダイアログは、それぞれの本文がスクロールします。
- 確認は落ち着いた色でたずね、もう一方のボタンは**キャンセル**です。取り戻せないものを失うとき（AI接続の削除、友だちとのお別れ、背景の削除）だけ赤く出て、もう一方は**そのままにする**になります。
- どの確認にも**閉じる**ボタンがあります。花、木、プレゼントは確認を出さず、代わりに**元に戻す**を出します。

## ゆっくり集めるためのヒント

図鑑には、水中の生きもの、虫、花、プレゼント、木、足あと、春の芽、小さな発見を合わせて169種類あります。コウライオヤニラミやモクズガニ、寒い夜のめずらしいチョウザメ、草むらのカマキリ、秋の夜のウマオイやコオロギを探してみましょう。タンポポ、アサガオ、ヒガンバナ、パンジーを育て、イチョウやカキノキを植え、松ぼっくりや紙の舟、ときには四つ葉のクローバーを掘りあて、友だちが届けてくれる水車、ハンモック、かめ置き場のために場所を空けておきましょう。

### 時間がかかること

- 全169種類は、1日や1週間でそろえる目標ではなく、いつそろうかも決まっていません。
- 通常のプレゼント21種類は、それぞれ違う日に届きます。
- イベントのプレゼント7種類はイベントの日付にだけ届き、暦のあちこちにあるので、始めた時期によっては全部そろうまで数か月かかります。季節を選んで呼べるのはイベントの景色で、プレゼントではありません。
- 花は植えてから4時間、木は12時間で育ちます。アプリを閉じていた時間も含みます。

### 探し方

| 対象 | コツ |
|---|---|
| 魚 | 雨の日はナマズとウナギに出会いやすくなります。出てくる季節と時間を選び、発見ガイドで何が釣れそうか確かめましょう |
| イベントの魚と虫 | イベントの季節を選び、合う時間帯と天気にすると、どの日でも金色のホタルや月光ゴイに出会えます |
| 穴掘り | 季節、天気、屋外の場所で、出やすい苗木や小さな発見が変わりますが、ほかのものも出ます。雰囲気で季節と天気を別々に選べるので、珍しい組み合わせも試せます。追加した屋外の背景にも反映されます |
| 同じ場所 | 24時間、結果が変わりません。外れが続いても、次が出やすくなることはありません |
| 場所を空ける | プレゼントを片づけても図鑑の記録は残り、次のプレゼントの場所ができます。種や苗木の袋がいっぱいでも、見つけたものが別のものに変わることはありません |

発見ガイドでは、選んだ条件で出会えるものを確かめられます。水や障害物があるので、実際に掘れる区画は背景全体の格子より少なくなります。
