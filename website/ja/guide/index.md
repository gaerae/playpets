# 使い方

PlayPetsは、友だちが暮らす庭です。友だちはあなたとも、友だち同士でもおしゃべりします。付属のペットを招待するか、対応するコミュニティのペットファイルを取り込んで、名前、性格、あなたとの関係を決めましょう。Codex本体はなくてもかまいません。

## できること

| こと | ひとことで | ページ |
|---|---|---|
| 友だちを招待 | はじめから4人いて、Codexのペットも迎えられます。一度に12人まで | [最初の友だち](./first-friend.md) |
| 話す | ローカルモデルやログイン済みのCLIなどのAI接続が必要です | [友だちと話す](./chat.md) |
| 庭で遊ぶ | 最初の庭は春の晴れた昼です。季節、時間帯、天気は自分で選ぶか自動に任せます。友だちは散歩をしたり、おやつを食べたり、4種類の遊び（ひとつは冬だけ）をしたりします | [庭と遊び](./play.md) |
| 育てて集める | 穴を掘ると花の種や苗木が見つかります。花を育て、釣りや虫取りで図鑑を埋めます | [庭と遊び](./play.md) |
| プレゼントとなかよし度 | 一緒に遊んだ友だちがプレゼントを持ってきます。庭全体で二日に一度、さらに仲良くなるたびに一つ届きます | [プレゼント](./play.md#gifts) |
| 作業の横に置く | ウィンドウを小さくして作業の横に置くか、デスクトップモードで友だちをほかのウィンドウの上へ出します | [デスクトップモード](./desktop.md) |
| コーディングエージェント | 連携は任意です。エージェントが働くと友だちが反応します | [コーディングエージェント](./agents.md) |

## 必要なもの

| 項目 | 内容 |
|---|---|
| OS | macOS、Windows、Linux |
| AI | 任意。招待、遊び、デスクトップモードは接続なしで使えます |
| コーディングエージェント | 任意。Claude Code、Codex CLI、Gemini CLI、Cursor、Grok Build、Qoder、Kimi Code、MCPを使うツールと連携できます |
| インターネット | ダウンロード、コミュニティのペットの取り込み、更新、外部AIとの会話に必要。庭での遊びと、ダウンロード済みのローカルOllamaモデルはオフラインでも使えます |

Tauriで作られていて、OSに備わっているWebViewを使います。ブラウザーを丸ごと同梱してはいません。

## ペットと友だち

| ことば | 意味 |
|---|---|
| ペット | キャラクターのファイルです。`pet.json`とスプライトシートが入ったフォルダー1つで、ペット1匹になります。Codexのペットフォルダーにあるペットは自動で表示され、コミュニティのサイトから取り込んだり、手元のフォルダーを選んだりもできます |
| 友だち | 庭に招待したペットです。同じペットを何度か招待すれば友だちが何人もでき、名前、性格、大きさ、AIを友だちごとに決められます |

## はじめる

1. PlayPetsをインストールして（[インストール](./install.md)）開きます。庭が**だれと遊びますか？**とたずねます。
2. 4人の友だちから1人をクリックします。その子が庭に入ってきて手を振ります。もう一度クリックしてなでると、跳ねてハートを出します。
3. AIを接続します。このパソコンにClaude CodeかCodex CLIがあれば、**次にすること**カードの**すぐつなぐ**を押します。なければ[接続を作る](./chat.md#connect)の手順に進みます。友だちの名札をクリックしてあいさつすると、会話と庭の吹き出しに返事が出ます。
4. 必要なら：**友だちと設定 → 設定 → 開発ツール連携**で、使っているツールの隣の**接続**を押して確認します。エージェントで新しいセッションを始めます。エージェントが作業している間、友だちの名札で名前の横にある点がオレンジに点滅します（[コーディングエージェント連携](./agents.md)）。

うまくいかないときは[よくある質問の表](./faq.md#troubleshooting)を見てください。
