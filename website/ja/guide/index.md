# 使い方

PlayPetsは、仲間たちが暮らす庭です。仲間はあなたとも、友だち同士でもおしゃべりします。

- 付属のペットを招待するか、対応するコミュニティのペットファイルを取り込みます。
- 名前、性格、あなたとの関係を選びます。Codex本体は不要です。
- 最初の庭は春の晴れた昼。季節、時間帯、天気は選べて、自動にもできます。
- 友だちは散歩し、おやつを食べ、3種類の遊びを楽しみます。
- 花の種や苗木は穴掘りで見つけます。
- 贈り物は現地の日付で庭全体に一日最大一つ。全員で回数を共有します。
- 花を育て、釣りや虫取りで図鑑を埋めながら、少しずつ仲良くなります。
- ウィンドウを小さくして、作業の横に庭を置けます。
- デスクトップモードでは、友だちがほかのウィンドウの上を歩きます。
- 会話にはAI接続（ローカルモデル、ログイン済みのCLIなど）が必要です。
- コーディングエージェントとの連携は任意です。

## 必要なもの

| 項目 | 内容 |
|---|---|
| OS | macOS、Windows、Linux |
| AI | 任意。招待、遊び、デスクトップモードは接続なしで使えます |
| コーディングエージェント | 任意。Claude Code、Codex CLI、Gemini CLI、Cursor、Grok Build、MCPを使うツールと連携できます |
| インターネット | ダウンロード、コミュニティのペットの取り込み、更新、外部AIとの会話に必要。庭での遊びと、ダウンロード済みのローカルOllamaモデルはオフラインでも使えます |

- TauriでOSのWebViewを使って作られています。ブラウザー全体は同梱していません。

## ペットと友だち

- **ペット**はキャラクターのファイルです。
  - `pet.json`とスプライトシートを入れたフォルダー1つが1匹です。
  - Codexのペットフォルダーにあるペットは自動で表示されます。
  - コミュニティのサイトから取り込むことも、手元のフォルダーを選ぶこともできます。
- **友だち**は庭へ招待したペットです。
  - 同じペットを何度か招待すると、友だちが複数できます。
  - それぞれ別の名前、性格、大きさ、AIを持てます。
