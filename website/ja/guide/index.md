# 使い方

PlayPetsは、あなたとも友だち同士でもおしゃべりする仲間たちが一緒に暮らす庭です。付属のペットを招待したり、対応するコミュニティのペットファイルを取り込んだりして、名前、性格、あなたとの関係を選びます。Codex本体は必要ありません。

最初の庭は春の晴れた昼から始まります。季節、時間帯、天気を選べて、自動にも切り替えられます。友だちは散歩し、おやつを食べ、3種類の遊びを楽しみます。花の種や苗木は穴掘りで見つけます。贈り物は現地の日付で庭全体に一日最大一つ、全員で回数を共有します。花を育てたり、釣りや虫取りで図鑑を埋めたりしながら、少しずつ仲良くなります。ウィンドウを小さくして庭を作業の横に置けます。デスクトップモードでは、友だちがほかのウィンドウの上を歩きます。会話にはローカルモデル、ログイン済みのCLIなどのAI接続が必要です。コーディングエージェントとの連携は任意です。

## 必要なもの

| 項目 | 内容 |
|---|---|
| OS | macOS、Windows、Linux |
| AI | 任意です。招待、遊び、デスクトップモードは接続なしで使えます |
| コーディングエージェント | 任意です。Claude Code、Codex CLI、Gemini CLI、Cursor、MCPを使うツールと連携できます |
| インターネット | ダウンロード、コミュニティのペットの取り込み、更新、外部AIとの会話に必要です。庭での遊びや、ダウンロード済みのローカルOllamaモデルはオフラインでも使えます |

TauriでOSのWebViewを使って作られています。アプリにブラウザー全体を同梱していません。

## ペットと友だち

- **ペット**はキャラクターのファイルです。`pet.json`とスプライトシートを入れたフォルダー1つが1匹のペットです。Codexのペットフォルダーにあるペットは自動で表示されます。コミュニティのサイトから取り込んだり、手元のフォルダーを選んだりもできます。
- **友だち**は庭へ招待したペットです。同じペットを何度か招待すると友だちが複数でき、それぞれ別の名前、性格、大きさ、AIを持てます。
