# 背景制作室

<CreationStudio lang="ja" kind="background" />

## 標準の場所と自作の背景

| | 標準の場所 | 自作の背景 |
|---|---|---|
| 場所 | 丘の庭、石造りの中庭、湖畔の家、ガーデン工房 | 取り込んだファイルごとに一つ |
| リアルタイムの空 | 屋外は透明な空から、工房はガラス越しに見えます | スカイライン上の本当の透明部分から見えます（屋外） |
| 室内の天気 | 工房のガラスの中だけ | 窓の四角形の中だけ（最大12個） |
| 釣り | 屋外の3か所 | 水の楕円と、乾いた地面の釣りの立ち位置 |
| 季節 | 屋外は4枚、工房は1枚 | 季節の画像は任意 |
| コーディングエージェントの友だち | 工房：テーブル、手前のベル付きベンチ、お茶のコーナー | その場で作業し、承認待ちのときは手前に出てきます |

- テーブル、承認のベンチ、お茶のコーナー（`geometry.stations`）は標準の工房だけのものです。背景ファイルにはまだありません。
- 友だちは床のどこでも散歩するので、床全体を空けておきます。

<details>
<summary>実行環境とファイル形式</summary>

このサイトはブラウザーの中でKITを用意するだけです。画像を生成したりファイルをアップロードしたりはせず、その先はAIツールで作業します。

| 必要なもの | メモ |
|---|---|
| ファイルを扱えるAIエージェント | 画像を作るだけのツールでは検査とパッケージ作成のスクリプトを動かせません |
| Python 3とPillow | 自動ではインストールされません |
| 画像生成ツール | 先に料金を確かめます。ChatGPTの契約だけでは画像APIは使えません |

SKILLが用意するもの：
- 1536 × 1024の背景画像
- 歩く床、水、釣りの立ち位置、窓の四角形
- 任意の季節画像

そのあと：
1. 通常のウィンドウと小さなウィンドウのサイズで確認します。
2. 完成したJSONを、**場所と雰囲気**の**背景を読み込む**から取り込みます。

[背景パッケージの仕様、英語](/dev/how-to/add-a-world#portable-backgrounds)

</details>
