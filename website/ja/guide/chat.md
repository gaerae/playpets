# 友だちと話す

招待や遊びはAIがなくてもできますが、話すにはAIをひとつ接続します。AIがないうちは、会話欄に「遊ぶ準備ができました！会話したくなったらAIを接続してください。」という言葉と**AIを接続する**ボタンが出ます。

<Shot name="friend-chat" caption="友だちとの会話（名札を押して開きます）。入力欄の下に、AIと一緒に話す友だちがあります。" />

## AI接続の種類 <Since v="0.1.0" /> {#connections}

| 種類 | 話し方 | 料金とデータ |
|---|---|---|
| Claude Code | このコンピューターでログインしているClaude Codeを使います | サブスクリプションでログインならプランの利用枠、APIキーでログインならAPI課金 |
| Codex CLI | このコンピューターでログインしているCodex CLIを使います | ChatGPTでログインならプランの利用枠、APIキーでログインならAPI課金 |
| Ollama | `http://127.0.0.1:11434`のOllamaを通してモデルを使います | ローカルモデルなら会話はこのコンピューターに留まり、ホスト型推論の料金はかかりません。クラウドモデルはそのサービスの条件に従います |
| OpenAI API | APIキーでOpenAIに接続します | 会話はOpenAIへ送られ、API料金がかかる場合があります |
| Grok API | xAI APIキーでGrokに接続します | 会話はxAIへ送られ、API料金がかかる場合があります |
| OpenAI互換サーバー | サーバーのアドレスを自分で入力し、サーバーが求めるときはAPIキーも入力します | 会話はそのサーバーへ送られ、料金がかかる場合があります |

接続の窓には、種類ごとに必要なものを書いたカードが並びます。このコンピューターでClaude Code、Codex CLI、Ollamaが見つかると、そのカードに**インストール済み**と付き、最初から選ばれています。ひとつも見つからなければ何も選ばれず、カードを選んだところで入力欄が出ます。

- APIキーはこのコンピューターの安全な保管場所にだけ保管し、設定ファイルには入れません。
  - macOS: キーチェーン
  - Windows: 資格情報マネージャー
  - Linux: Secret Service
- サブスクリプションでログインしていれば、CLIでの会話に別のAPI請求はありません。
  - ただし、ほかのCLI作業と同じ利用枠を使い、プランの上限も適用されます。
  - 任意で購入したクレジットには追加の料金がかかることがあります。
- オフラインで話したいときは、ダウンロードしたローカルのOllamaモデルを選びます。Ollamaのクラウドモデルでは、会話はそのサービスへ送られます。

## 接続を作る <Since v="0.1.0" /> {#connect}

1. **友だちと設定 → 友だちと会話**で友だちの画面を開き、話したい友だちを選びます。友だちが何人もいると、名前が選択リストになります。
2. 会話の**AIを接続する**ボタンを押すか、入力欄の左下のAIのリストから**＋ 新しいAIを接続…**を選びます。
3. **AIの種類**でカードを選びます。種類によっては、サーバーのアドレスやAPIキーも入力します。
4. **モデル名**を選ぶか入力します。
   - 欄をクリックすると、そのAIが提供するモデルの一覧が出ます。キーやアドレスが必要な種類では、それを入力した後に出ます。
   - Claude CodeとCodex CLIは、空欄なら既定のモデルを使います。`sonnet`のような短い名前なら、いつも最新のバージョンになります。
   - OllamaとAPIの接続にはモデル名が必要です。
5. **保存して接続**を押します。AIのないほかの友だちがいれば「AIのないほかの友だちにもこのAIを使う」スイッチがオンになっているので、全員が一度に話せるようになります。

先に接続しておかなくても大丈夫です。AIがまだない友だちにメッセージを書いて送ると接続の窓が開き、つながったところでメッセージが届きます。

初めて起動したときにこのコンピューターにClaude CodeかCodex CLIがあれば、庭の最初の案内カードにその名前が出ます。**すぐつなぐ**を押すだけで、キーなしで全員に一度に接続されます。友だちが2人以上なら、そのあとすぐ友だち同士で話し始めます。

接続はひとりの友だち専用ではありません。一度作った接続はほかの友だちも使えますし、友だちごとにAIのリストで別の接続を選べば、それぞれ違うAIと話します。

- 編集や削除は、次のどちらかから開きます。
  - 友だちの名前の横の**⋯**メニュー → **AI接続の設定**。ここで開いた接続はその友だちが使います。
  - **友だちと設定 → 設定 → 友だちとAI**で、その接続の**編集**。ここにはすべての接続が並び、**AIを接続する**で新しい接続も作れます。フォームはその場で開き、ここで編集しても友だちがその接続に移ることはありません。
- 削除する前には確認があります。保存したキーも一緒に消え、その接続で話していた友だちはAIなしで遊びます。

## 話す <Since v="0.1.0" />

- 下の欄に入力してEnterを押します。改行はShift+Enterです。

AIのある友だちとまだ話していないときは、「今日は何してた？」のような最初のひとことの候補が出ます。選べばワンクリックで送れます。

会話では、メッセンジャーのように友だちの番がその友だちの絵から始まります。答えを待つ間は「考えています」の吹き出しが出て、■ボタンで止められます。答えは庭にいる友だちの上にも吹き出しで浮かびます。

- 友だちの名前の横の**⋯**メニュー → **会話を消す**で、この友だちとの会話をすべて消します。名前と性格は残ります。
- 会話の履歴はメモリーの中にだけあり、アプリを終了すると消えます。ファイルには保存されません。
- 会話の画面には、友だちごとに最新のメッセージが500件まで残ります。友だちが答えるときに思い出すのは、そのうち最新の24件です。Claude Codeの友だちは、セッションが開いている間はそれより前の話も覚えています。

## 性格を決める <Since v="0.1.0" />

性格とは、友だちが答えるときの口調や態度のことです。決め方は2つあります。

| 方法 | やり方 |
|---|---|
| **友だち設定に書く** | 「強がるけれど褒められるとすぐとろける。答えは短め。」くらいで十分。保存すると次の会話から使われます |
| **会話の中で言う** | 「これからはもっとくだけて話して」のように言うと、友だちがそれを性格として保存します。「（名前）の性格を保存しました」と通知が出て、友だち設定で確認できます |

## 関係を決める <Since v="0.1.0" /> {#relationship}

友だち設定の**関係**で、この友だちがあなたにとってどんな存在かを選びます。カードには、それぞれどんな話し方になるかが書いてあります。

- **友だち**（既定）
- **恋人**
- **頼れる先輩**
- **いたずら好きな弟、妹**

友だちの画面で名前の横の関係チップを押すと同じカードが開き、ワンクリックで変えられます。

関係によって、あなたへの話し方や呼び方、一日の様子の聞き方が変わります。一緒に話す友だち同士も、お互いの関係を知っています。恋人、先輩、弟、妹は、AIがなくても自分らしい声で話します。おかえりと迎えるとき、仲が深まったとき、あなたが自分にとってどんな存在かを伝えるときです。

**呼んでほしい名前**に「ハニー」やあなたの名前を書くと、そう呼んでくれます。欄の例は関係に合わせて変わります。

Codexのペットには人の姿のものが多く、恋人や先輩によく合います。関係の中で何が話されるかは、アプリではなく接続したAIの方針に従います。

## 一緒に話す <Since v="0.1.0" />

AIを接続した友だちが2人以上いると、入力欄の下に**友だちを呼ぶ**が出ます。

1. **友だちを呼ぶ**を押し、一緒に話したい友だちをクリックします。3人まで選べます。
2. メッセージを送ると、今の友だちが最初に答え、続いて選んだ友だちが順番に答えます。それぞれ自分のAIと性格で話します。
3. 新しいメッセージなしで友だち同士に話を続けてもらうには、**遊ぶ → みんなで遊ぶ**の**おしゃべり**を押します。AIのある友だちが時刻や天気について1巡話し、庭に吹き出しで出ます。

友だちの名前の下の小さなチップには、この友だちに報告するコーディングエージェントが出ます（**担当、Claude Code**）。庭では、友だち同士が話す様子を吹き出しで見られます。

## 「何をしていたの？」 <Since v="0.1.0" />

[コーディングエージェント連携](./agents.md)を設定しておくと、エージェントが最近したことを友だちが覚えています。会話で「何をしていたの？」と聞けば、その作業について自分の言葉で話してくれます。

この連携は、会話に使うAI接続とは別に動きます。
