# プライバシーポリシー

- 最終更新：2026年10月29日。
- 運営者：[PlayPets](https://github.com/gaerae/playpets)のメンテナーgaerae。
- 本方針はデスクトップアプリと本サイトに適用され、この版の公開日から有効です。

## アプリに保存する情報

- PlayPetsのアカウントは要りません。開発者が運営するチャットサーバーもありません。
- アプリには、広告、利用分析、クラッシュ報告の自動送信の機能がありません。
- ふだんの移動、遊び、収集にAI接続は要りません。
- 端末に保存するもの：友だちの名前、性格、関係、収集記録、読み込んだ素材、AI接続設定、アプリ設定。
- PlayPetsで保存したAPIキーは、JSON設定とは別に、OSの資格情報ストアに保管します。
- 取り込んだ背景と、選んだ場所や天気は、ほかの記録と一緒にデータフォルダーに保存します。表示済みのヒントなど画面の記録の一部は、WebViewのローカルストレージに保存します。

会話履歴は実行中のメモリーに置き、データフォルダーに会話全文は保存しません。ただし、会話から作った性格や設定は、その機能を使うと保存されることがあります。接続先のAIやCLIが記録を残さない、という意味ではありません。

## AIとコーディングエージェント

AIを接続すると、次の情報がプロンプトに含まれ、選んだサービスやローカルサーバーに送られることがあります。
- メッセージと最近の会話
- 友だちの名前、性格、関係
- 関連するエージェント情報

自動のおしゃべりも、オンの間はこの接続を使います。
- 外部サービスは国外で情報を処理することがあります。保存、学習、削除には提供者の方針が適用されます。
- ローカルモデルでも、外部と通信するかどうかは、選んだツールと設定によります。
- Claude CodeとCodexの接続は、端末にインストールしてログインしたCLIを実行します。
  - そのツールと提供者は、独自にファイル、セッション、ログを残すことがあります。PlayPetsはその保存期間を管理しません。
- エージェント連携は、送るよう設定した状態とレポートを、トークンで保護したループバック接続で受け取ります。
- 会話、性格、レポートには、秘密情報や機微な個人情報を入れないでください。

## ダウンロードと更新

- コミュニティのペットを読み込んだりギャラリーを開いたりすると、選んだ外部サービスに接続します。
- GitHub版は、更新を自動で確認してダウンロードするために、GitHubに接続することがあります。
- MSIX版はGitHubのEXEをダウンロードしてインストールせず、パッケージ管理の仕組みで更新します。
- Store版の更新はMicrosoft Storeが担当します。
- このとき、IPアドレスなどの通常のリクエスト情報が外部サービスに渡り、各サービスの方針が適用されます。

## ウェブサイト

サイトはGitHub Pagesで配信しています。ブラウザーは次の場所に接続することがあります。
- リリース情報とダウンロード：GitHub
- フォント：Google FontsとjsDelivr

各ホストは独自の方針に基づいて、IPアドレスやブラウザーのヘッダーを受け取ります。
- 言語やテーマの設定には、ブラウザーストレージを使うことがあります。
- 広告や利用分析サービスは追加していません。
- 制作キットとスキルは、選んだツールで使うためにダウンロードする資料です。
- 本サイトがPlayPetsのAIサーバーで画像を生成することはありません。
- 外部AIツールに渡したファイルには、そのツールの方針が適用されます。

## 保存期間と削除

- ローカル設定は、削除するまで残ります。
- 保存したAPIキーは、設定からAI接続を削除すると消えます。
- アプリを完全に終了すると、メモリー上の会話履歴は消えます。

初期化の手順：
1. 設定からAI接続を削除します。アプリがキーを特定して消せるよう、データフォルダーより先に行ってください。
2. 設定からデータフォルダーを開きます。
3. アプリを終了し、必要なファイルを削除します。

アンインストールだけでは、データ、資格情報、バックアップが残ることがあります。外部サービスの記録やCLIのログは、それぞれのサービスやツールで削除してください。

| OS | 標準の保存先 |
|---|---|
| macOS | `~/Library/Application Support/app.playpets/` |
| Windows | `%APPDATA%\app.playpets\` |
| Linux | `~/.local/share/app.playpets/` |

- MSIXではWindowsのパスが仮想化されることがあります。アプリのデータフォルダーを開く機能を使ってください。
- 保存先を変更している場合は、その場所を使います。

## お問い合わせと変更

- プライバシーに関する質問や依頼は、[プロジェクトのメンテナー](https://github.com/gaerae/playpets/issues/new/choose)に連絡してください。
- GitHubのIssueは公開されます。個人情報、キー、会話ログ、身分証は投稿しないでください。
- 機微な内容は書かずに、非公開の連絡先だけを求めることもできます。
- 運営者は、端末のファイルや他の提供者が持つ記録を直接削除できません。
- 方針を変えたときは、このページと更新日を書き換えます。
