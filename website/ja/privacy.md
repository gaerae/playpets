# プライバシーポリシー

- 最終更新：2026年10月18日。
- 運営者：[PlayPets](https://github.com/gaerae/playpets)のメンテナーgaerae。
- 本方針はデスクトップアプリと本サイトに適用され、この版の公開日から有効です。

## アプリに保存する情報

- PlayPetsのアカウントは不要です。開発者が運営するチャットサーバーもありません。
- アプリに広告、利用分析、自動クラッシュ報告の送信機能はありません。
- 通常の移動、遊び、収集にAI接続は不要です。
- 次の情報は端末に保存します：友だちの名前、性格、関係、収集記録、読み込んだ素材、AI接続設定、アプリ設定。
- PlayPetsで保存したAPIキーはJSON設定と分け、OSの資格情報ストアに保管します。
- 一部の画面設定はWebViewのローカルストレージに保存します。
- PlayPetsの会話履歴は実行中のメモリーに保持し、データフォルダーに会話全文を保存しません。
  - ただし、会話から作った性格や設定は、対応する機能を使うと保存される場合があります。
  - 接続先AIやCLIが記録しないという意味ではありません。

## AIとコーディングエージェント

- AIを接続すると、次の情報がプロンプトに含まれ、選んだサービスやローカルサーバーに送信される場合があります：メッセージ、最近の会話、友だちの名前、性格、関係、関連するエージェント情報。
- 自動のおしゃべりも、有効な間はこの接続を使います。
- 外部サービスは国外で情報を処理する場合があります。保存、学習、削除には提供者の方針が適用されます。
- ローカルモデルの外部通信は、選んだツールと設定によります。
- Claude CodeとCodex接続は、端末にインストールしログインしたCLIを実行します。
  - そのツールと提供者は独自のファイル、セッション、ログを保存できます。PlayPetsは保存期間を管理しません。
- エージェント連携は、送信するよう設定した状態とレポートを、トークンで保護されたループバック接続で受け取ります。
- 会話、性格、レポートに秘密情報や機微な個人情報を含めないでください。

## ダウンロードと更新

- コミュニティのペットの読み込みやギャラリー表示では、外部サービスに接続します。
- GitHub版は、更新の自動確認やダウンロードのためGitHubに接続する場合があります。
- MSIX版はGitHubのEXEをダウンロードしてインストールせず、パッケージ管理による更新を使います。
- Store版の更新はMicrosoft Storeが担当します。
- IPアドレスなどの通常のリクエスト情報が外部サービスに渡り、各サービスの方針が適用されます。

## ウェブサイト

- サイトはGitHub Pagesで配信します。
- ブラウザーは次に接続できます。
  - リリース情報、ダウンロードのため：GitHub
  - フォントのため：Google FontsとjsDelivr
- 各ホストは独自の方針に基づき、IPアドレスやブラウザーヘッダーを受け取ります。
- 言語、テーマ設定にはブラウザーストレージを使う場合があります。
- 広告や利用分析サービスは追加していません。
- 制作キットとスキルは、選んだツールで使うためのダウンロード資料です。
- 本サイトがPlayPetsのAIサーバーで画像を生成することはありません。
- 外部AIツールに渡したファイルには、そのツールの方針が適用されます。

## 保存期間と削除

- ローカル設定は削除するまで残ります。
- 保存したAPIキーは、設定からAI接続を削除すると消去します。
- アプリを完全終了すると、メモリー上の会話履歴は消えます。
- 初期化の手順：
  1. 設定からAI接続を削除します。キーを特定して削除できるよう、データフォルダーより先に行ってください。
  2. 設定からデータフォルダーを開きます。
  3. アプリを終了し、必要なファイルを削除します。
- アンインストールだけでは、データ、資格情報、バックアップが残る場合があります。
- 外部サービスの記録やCLIログは、各サービスやツールで削除してください。

| OS | 標準の保存先 |
|---|---|
| macOS | `~/Library/Application Support/app.playpets/` |
| Windows | `%APPDATA%\app.playpets\` |
| Linux | `~/.local/share/app.playpets/` |

- MSIXではWindowsのパスが仮想化される場合があります。アプリのデータフォルダーを開く機能を使ってください。
- 保存先を変更した場合は、その場所を使います。

## お問い合わせと変更

- プライバシーに関する質問は[プロジェクトのメンテナー](https://github.com/gaerae/playpets/issues/new/choose)に連絡できます。
- GitHubのIssueは公開されます。個人情報、キー、会話ログ、身分証を投稿しないでください。
- 機微な内容を書かずに、非公開の連絡先を求めることができます。
- 運営者は、端末のファイルや他の提供者の記録を直接削除できません。
- 変更時は、このページと更新日を改めます。
