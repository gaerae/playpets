This is the first public release. Look after friends in the yard, send them out onto the desktop, chat through the Claude Code or Codex subscription you already use, and watch your friends react while a coding agent works.

### Added
- The yard: bring friends in from Codex pet files, pat them, give treats and say hi together, and watch them stroll through scenery that changes with the time of day and weather. The games are hide and seek (find by name), parade and tag.
- Mini mode: shows only the yard in a small window.
- Desktop mode: friends come out on every monitor and stroll around, can be dragged, and follow the mouse with their eyes. They float on top of other apps' full screen too (macOS).
- Chat: connect an AI for each friend (Claude Code or Codex subscription, Ollama, OpenAI-compatible server). Set a personality or change it through the chat, and have several friends talk together.
- Coding agent hooks: through the hooks and MCP of Claude Code, Codex, Gemini CLI and Cursor, friends react while the agent works and tell you about recent work. The app executable receives it directly, without Node.js.
- Import a pet: from a community pet page address, a GitHub folder or a folder on your computer. The Invite tab groups pets by where they are and opens that folder for you.
- Languages: 한국어, English and 日本語. Follows the system language at first; change it in Settings.
- Release files: macOS dmg, Windows installer, Linux deb and AppImage (GitHub releases); Windows portable zip and a trial MSIX from local builds.

### Known limitations
- The release files are not code-signed, so macOS Gatekeeper and Windows SmartScreen block the first launch. How to get past it is in [Install](../guide/install.md).
- The Windows build has not been tested enough on real machines yet.
