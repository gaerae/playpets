# 1.3.0

<ReleaseMeta />

Grok moved into the yard: a friend keeps Grok Build company while it codes, and friends can chat through Grok.

<Downloads version="1.3.0" />

## What changed

- A friend reacts while Grok Build thinks, uses a tool, waits for you and finishes.
- Friends can chat through Grok with an xAI API key, kept in your system's secure storage.
- Grok Build also runs Claude Code and Cursor hooks; its work now shows only on its own friend.
- <Only os="macOS" /> The app is notarized by Apple, so it opens right away.
- The seed count stays inside the Plant a seed tile when the tile is narrow.

## Also

- Install from the Microsoft Store or winget on Windows, or Homebrew on macOS. See [Install](../guide/install.md).
- The user guide is rewritten, with button names that match the app.
- Security updates for the libraries PlayPets uses.

To set up Grok Build, read [Coding agent hooks](../guide/agents.md); to chat through Grok, see [Chat with a friend](../guide/chat.md).
