# 1.3.0

<ReleaseMeta />

PlayPets 1.3.0 adds Grok: Grok Build reports to a friend while it works, and friends can talk through Grok. The macOS app is now signed and notarized, and you can install from the Microsoft Store, winget or Homebrew.

<Downloads version="1.3.0" />

## What changed

- Grok Build joins Claude Code, Codex, Gemini CLI and Cursor. Copy its settings from Settings → Coding tools and save them in `~/.grok/hooks/`; a friend then shows when Grok thinks, uses a tool, waits for you and finishes.
- Grok also runs Claude Code's and Cursor's hooks, so its work no longer shows on the Claude Code or Cursor friend.
- Friends can talk through Grok: pick **Grok API** when you connect an AI and enter an xAI API key. The key stays in your system's secure storage.
- The macOS app is signed with Apple's Developer ID and notarized by Apple, so it opens without the Open Anyway steps.
- Install from the Microsoft Store, signed by Microsoft, or with `winget install --id 9NSKXQ6R187M --source msstore`. On macOS, `brew install gaerae/tap/playpets` installs it with Homebrew.
- The seed count stays inside the Plant a seed tile when the tile is narrow.
- The user guide is rewritten in all four languages, with button names that match the app.
- Security updates for the Rust libraries behind the Linux keyring, the update check and AI connections.

Read [Coding agent hooks](../guide/agents.md) and [Install](../guide/install.md) for details.
