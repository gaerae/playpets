# 0.1.0

This is the first public release. Look after friends in the yard, send them out onto the desktop, chat through the Claude Code or Codex subscription you already use, and watch your friends react while a coding agent works.

### Added
- The yard: pat your friends, put down treats and say hi together. Friends stroll through scenery that changes with the time of day, the weather and the season (the sun and moon follow the clock, the moon shows its phase, and blossoms, autumn leaves and a rainbow after rain come and go), and play hide and seek (find by name), parade and tag. Click a friend's name tag to chat. Patting shows hearts, and treats and an agent's finished work scatter sparkles. With reduced motion turned on, these effects all stop.
- Starter pets: Tabby, Smoky and Mochi come with the app, so you can invite a friend on the very first start. They are under **PlayPets starter pets** in the Invite tab.
- On first start the empty yard asks who to play with and shows the starter pets: one click brings one in. A small card then lists what is left and ticks off what is done. With Claude Code or Codex CLI on the computer, one **Connect now** gives every friend an AI with no key.
- Start at login: one switch in Settings. With desktop mode on, only your friends come out at login.
- Mini mode: shows only the yard in a small window that stays on top, in the screen's corner the first time and where you left it after that, with the care buttons rising under the pointer.
- Desktop mode: friends come out on every monitor and stroll around, can be dragged, and follow the mouse with their eyes. Point at a friend and its name shows as a button that opens the chat. They float on top of other apps' full screen too (macOS).
- Chat: connect an AI for each friend (Claude Code or Codex subscription, Ollama, OpenAI-compatible server). Set a personality or change it through the chat, and have several friends talk together.
- Relationships: in Friend settings, choose Friend, Partner, Reliable senior or Playful younger sibling, and fill in **What it calls you**. The way your friend talks and what it calls you change, and friends chatting together know each other's relationship.
- Let them chat: press **Let them chat** in the yard toolbar and the friends with an AI talk among themselves about the time and the weather. Turn on **Let them chat now and then** in Settings and they do it every 20 minutes on their own.
- Coding agent hooks: through Claude Code, Gemini CLI and Cursor hooks, Codex notifications and MCP, friends react while the agent works and tell you about recent work. Each agent can report to a friend you choose, and the agent shows on the name tag and as a chip in the Friend tab. The dot by a friend's head shows the agent's state (working, waiting, done, trouble). The app executable receives it directly, without Node.js.
- Import a pet: from a community pet page address, a GitHub folder or a folder on your computer. Opening a `playpets://import?url=<pet page address>` link imports that pet and opens the Invite tab. The Invite tab groups pets by where they are, and the **Shape** filter (All, People, Animals, Other) narrows it down.
- Languages: 한국어, English, 日本語 and 简体中文. Follows the system language at first; change it in Settings. The desktop windows switch to the new language too.
- Updates and menus: a newer version shows as a button in the top bar and a dot on the **Settings** tab, and opens an update window with **What's new**, **Later** and **Install and restart** (with download progress). Settings is grouped into General, Coding agent hooks and **About PlayPets** (the version, updates and the project's pages). The tray menu shows the mini view, desktop mode and strolling with check marks, and its icon gets a small mark when a coding agent is waiting for you; the tray menu and the macOS menu bar have Settings, Check for updates and About; <kbd>⌘</kbd> <kbd>,</kbd> or <kbd>Ctrl</kbd> <kbd>,</kbd> opens Settings.
- Installer screens: the macOS disk image shows the yard and asks you to drag the app to Applications, and the Windows installer carries pet artwork. Linux software centers show a description and screenshots.
- Release files: the GitHub release has a macOS dmg (Apple Silicon and Intel), the Windows installer and portable zip (x64, arm64), and Linux deb and AppImage (x64, arm64). Only the trial MSIX is a local build.

### Security
- Importing a pet fetches files only from the site of the pasted address (its subdomains, and the hosts of a listed community), and does not follow a page that points elsewhere. Private addresses are blocked when the name is resolved.
- A pet file's description reaches the AI marked as a description, not an instruction, and a personality saved during a chat keeps that mark.

### Known limitations
- The release files are not code-signed, so macOS Gatekeeper and Windows SmartScreen block the first launch. How to get past it is in [Install](../guide/install.md).
- The Windows build was checked in a virtual machine (the x64 installer on Windows 11 ARM), installing and running, but has not been tested enough on real machines yet.
