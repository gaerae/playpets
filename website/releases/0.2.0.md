## Highlights

- Welcome Miso alongside Daisy, Clover and Pip. Each friend has a baseline outfit for spring and autumn, plus summer and winter outfits.
- Use character and background kits with reference sheets, a complete creation request and a portable skill. Generate, validate and package with your chosen tool, then import the finished files into the app.
- Resize one frameless yard instead of switching Mini mode. Toggle Always on top, open fullscreen and return to the previous size and position.
- Find Friends, Invite, Settings and Place & atmosphere through a shared menu, including in small windows. Right-click the yard or use Cmd/Ctrl+Shift+P.
- Start a new yard in sunny spring daylight, with clearer notices and controls. Existing friends and scene choices remain saved.
