# 1.3.0

<ReleaseMeta />

Grok 来到了院子：Grok Build 编码时有伙伴陪着，伙伴们也能通过 Grok 聊天。

<Downloads version="1.3.0" />

## 更新内容

- Grok Build 思考、使用工具、等你回复和完成时，伙伴都会做出反应。
- 填入 xAI API 密钥，伙伴们就能通过 Grok 聊天。密钥保存在系统的安全存储里。
- Grok Build 也会运行 Claude Code 和 Cursor 的钩子，现在它的工作只显示在自己的伙伴那里。
- <Only os="macOS" /> 应用已通过 Apple 公证，可以直接打开。
- “播种”格子较窄时，种子数量也不会超出格子。

## 其他

- 也可以通过 Microsoft Store、winget 或 macOS 上的 Homebrew 安装，详见[安装](../guide/install.md)。
- 用户指南已重写，按钮名称与应用一致。
- 包含应用所用库的安全更新。

Grok Build 的设置方法见[编码代理联动](../guide/agents.md)，通过 Grok 聊天见[和伙伴聊天](../guide/chat.md)。
