# 1.3.0

<ReleaseMeta />

PlayPets 1.3.0 开始支持 Grok：伙伴会显示 Grok Build 的工作状态，伙伴们也能通过 Grok 聊天。macOS 应用已经过签名和公证，也可以通过 Microsoft Store、winget 和 Homebrew 安装。

<Downloads version="1.3.0" />

## 更新内容

- 在 Claude Code、Codex、Gemini CLI 和 Cursor 之外，新增 Grok Build。在设置 → 编码工具连接里复制设置，保存到 `~/.grok/hooks/`，伙伴就会显示 Grok 正在思考、使用工具、等你回复和完成任务。
- Grok 也会运行 Claude Code 和 Cursor 的钩子。现在 Grok 的工作不会再出现在负责 Claude Code 或 Cursor 的伙伴身上。
- 伙伴们可以通过 Grok 聊天：连接 AI 时选择 **Grok API**，输入 xAI API 密钥。密钥保存在系统的安全存储里。
- macOS 应用使用 Apple Developer ID 签名并通过 Apple 公证，不用再走“仍要打开”的步骤就能打开。
- 可以从 Microsoft Store 安装由 Microsoft 签名的应用，也可以用 `winget install --id 9NSKXQ6R187M --source msstore` 安装。在 macOS 上，可以用 `brew install gaerae/tap/playpets` 通过 Homebrew 安装。
- “播种”格子较窄时，种子数量也不会超出格子。
- 用户指南的四种语言全部重写，按钮名称与应用一致。
- 包含 Linux 钥匙串、更新检查和 AI 连接所用 Rust 库的安全更新。

详情请看[编码代理联动](../guide/agents.md)和[安装](../guide/install.md)。
