# 1.7.0

<ReleaseMeta />

帮编码代理干活的伙伴有了玻璃屋顶的花园工坊。户外场所换上了同一种柔和色调的新画面，石屋庭院变成了自然花园。

<Downloads version="1.7.0" />

## 更新内容

- 玻璃屋顶下的花园工坊取代了温馨客厅。
- 在工坊里，工作的伙伴坐在盆栽桌旁，等你批准时站在铃铛边。
- 没有代理时，工坊里的伙伴也会看书、喝茶、休息，然后去散步。
- 伙伴会显示代理的状态：原地不动，上前询问，然后回去。
- 代理状态点在名牌里，伙伴名字旁边。
- 户外场所换上新画面，草坪四季都是同样柔和的绿色。
- 石屋庭院变成了自然花园：有池塘和大橡树的开阔草地。
- 伙伴、花、树和礼物可以去画面里任何有地面的地方，直到门前。
- 选一个合季节的场景，哪天都能迎来节日。
- 挂饰挂在圣诞树的枝上，地上的礼物投下柔和的影子。
- 夜里礼物和植物染上夜色的蓝，灯笼照亮地面。
- 萤火虫更少、更柔和，多是淡淡的光。
- 伙伴把捕虫网和钓竿拿在身前。
- 鱼漂浮在水里，泛起涟漪。
- 中秋满月夜，月亮是圆圆的满月。
- 拖动中的花和树紧跟指针，拿着时不再摇摆。
- 花园再热闹，拖动种下的树也很流畅。
