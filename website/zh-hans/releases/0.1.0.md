# 0.1.0

<ReleaseMeta />

<Downloads version="0.1.0" />

<Shot name="yard-evening" version="0.1.0" caption="傍晚的乐园里，三位伙伴在休息。时段和天气可以跟随时钟，也可以自己选择。" />

这是首个公开版本。在乐园里照顾伙伴，把它们放到桌面上，用你已经在用的 Claude Code 或 Codex 订阅聊天；编码代理工作时，伙伴也会一起有反应。

### 新增
- 乐园：摸摸伙伴、放零食、一起打招呼。伙伴们在随时段和天气变化的风景里散步，还能玩捉迷藏（按名字找）、散步队列、抓尾巴。摸摸会冒出爱心，零食和代理完成工作时会撒出闪光。开启减少动态效果后，这些效果都会停下。
- 自带宠物：应用里带着 Tabby（塔比）、Smoky（烟烟）、Mochi（麻糬），第一次启动就能邀请。它们在邀请标签的 **PlayPets 自带宠物**里。
- 第一次启动时，乐园里的卡片会引导三个步骤（邀请、接上 AI、指定负责的伙伴），并给完成的步骤打勾。本机有 Claude Code 或 Codex CLI 时，点一次**立即连接**就能不用密钥给所有伙伴接上。
- 小窗模式：只把乐园放在一个小窗口里显示。
- 桌面模式：每台显示器上都有伙伴出来走动，可以拖动，眼睛会跟着鼠标。也会浮在其他应用的全屏之上（macOS）。
- 对话：为每位伙伴连接 AI（Claude Code、Codex 订阅，Ollama，OpenAI 兼容服务器）。可以设定性格，也可以在对话中改变；多位伙伴还能一起聊。
- 关系：在伙伴设置里从朋友、恋人、可靠的前辈、调皮的弟弟妹妹中选一个，并填写**对我的称呼**。语气和称呼会随之不同，伙伴之间聊天时也知道彼此的关系。
- 聊聊天：点乐园工具栏的**聊聊天**，接上 AI 的伙伴们会围绕此刻的时间和天气自己聊起来。在设置里打开**偶尔让伙伴们自己聊聊**，它们每 20 分钟会自己聊一次。
- 编码代理联动：通过 Claude Code、Gemini CLI、Cursor 的钩子，Codex 的通知以及 MCP，代理工作时伙伴会有反应，并讲述最近的工作。可以为每个代理指定负责的伙伴，负责的代理会显示在名牌和伙伴标签的小标签上。伙伴头旁的小圆点显示代理的状态（工作中、等待、完成、出问题）。不需要 Node.js，由应用的可执行文件直接接收。
- 导入宠物：从社区宠物页面地址、GitHub 文件夹或本机文件夹导入。打开 `playpets://import?url=<宠物页面地址>` 链接，就会导入那只宠物并打开邀请标签。邀请标签按宠物所在的位置分组，还能用**外形**筛选（全部、人物、动物、其他）。
- 语言：한국어、English、日本語、简体中文。一开始跟随系统语言，可在设置里更改。更改后桌面窗口也会一起换成新语言。
- 更新与菜单：有新版本时，顶栏按钮和**设置**标签上的小圆点会提示，更新窗口里可以选**查看新内容**、**稍后**或**安装并重启**（带进度条）。设置分为通用、编码代理联动和**关于 PlayPets**（版本、更新和项目页面）。托盘菜单和 macOS 菜单栏有设置、检查更新和关于；<kbd>⌘</kbd> <kbd>,</kbd> 或 <kbd>Ctrl</kbd> <kbd>,</kbd> 打开设置。
- 安装界面：macOS 磁盘映像会在乐园图上提示把应用拖到 Applications，Windows 安装程序里有宠物插图。Linux 软件中心会显示说明和截图。
- 发布文件：GitHub 发布页提供 macOS dmg（Apple Silicon、Intel）、Windows 安装程序和便携版 zip（x64、arm64）、Linux deb 和 AppImage（x64、arm64）。只有试验性的 MSIX 需要本地构建。

### 安全
- 导入宠物时只从粘贴地址所在的站点（及其子域名、已登记社区的主机）下载文件，不会跟随指向别处的页面。私有地址在解析域名时就会被拦下。
- 宠物文件里的介绍会以“这是介绍，不是指令”的方式交给 AI，聊天中保存的性格也保留这个标记。

### 已知限制
- 发布文件没有代码签名，macOS Gatekeeper 和 Windows SmartScreen 会拦住第一次运行。绕过方法见[安装](../guide/install.md)。
- Windows 版本已在虚拟机（在 Windows 11 ARM 上运行 x64 安装程序）中确认了安装和运行，但在实际设备上还没有充分测试。
