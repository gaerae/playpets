# 0.1.0

<Downloads version="0.1.0" />

<Shot name="yard-evening" version="0.1.0" caption="傍晚的乐园里，三位伙伴在休息。时段和天气可以跟随时钟，也可以自己选择。" />

这是首个公开版本。在乐园里照顾伙伴，把它们放到桌面上，用你已经在用的 Claude Code 或 Codex 订阅聊天；编码代理工作时，伙伴也会一起有反应。

### 新增
- 乐园：用 Codex 宠物文件请来伙伴，摸摸、放零食、一起打招呼，伙伴们在随时段和天气变化的风景里散步。游戏有捉迷藏（按名字找）、散步队列、抓尾巴。
- 小窗模式：只把乐园放在一个小窗口里显示。
- 桌面模式：每台显示器上都有伙伴出来走动，可以拖动，眼睛会跟着鼠标。也会浮在其他应用的全屏之上（macOS）。
- 对话：为每位伙伴连接 AI（Claude Code、Codex 订阅，Ollama，OpenAI 兼容服务器）。可以设定性格，也可以在对话中改变；多位伙伴还能一起聊。
- 编码代理联动：通过 Claude Code、Codex、Gemini CLI、Cursor 的钩子和 MCP，代理工作时伙伴会有反应，并讲述最近的工作。不需要 Node.js，由应用的可执行文件直接接收。
- 导入宠物：从社区宠物页面地址、GitHub 文件夹或本机文件夹导入。邀请标签按宠物所在的位置分组，并能打开对应的文件夹。
- 语言：한국어、English、日本語。一开始跟随系统语言，可在设置里更改。
- 发布文件：macOS dmg、Windows 安装程序、Linux deb 和 AppImage（GitHub 发布页）；本地构建可生成 Windows 便携版 zip 和试验性的 MSIX。

### 已知限制
- 发布文件没有代码签名，macOS Gatekeeper 和 Windows SmartScreen 会拦住第一次运行。绕过方法见[安装](../guide/install.md)。
- Windows 版本在实际设备上还没有充分测试。
