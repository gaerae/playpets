## 包含的功能

- 提供 Daisy、Clover 和 Pip 三位插画伙伴，以及夏季和冬季服装。可以导入兼容的社区宠物，也可以在[角色制作室](../guide/creator-kit.md)准备自己的伙伴。
- 从户外花园到温馨客厅，共有四种场景。在**场景与氛围**中选择季节、时段和天气，也能导入用[背景制作室](../guide/background-kit.md)制作的背景。
- 场景铺满窗口，场景选择和菜单集中在小巧的控件中。迷你模式隐藏菜单；桌面模式让伙伴在其他窗口上方散步。
- 抚摸伙伴，一起分享野餐零食。种花、钓鱼、捕虫、收集礼物，还能玩捉迷藏、游行和追逐游戏。另有季节活动和可选的声音。
- 对话需要连接本地 Ollama 模型、已登录的 Claude Code 或 Codex CLI，或 OpenAI 兼容服务器。连接服务的使用限额和收费规则适用。游戏和园艺不需要 AI 连接。
- 编码代理钩子和 MCP 让伙伴对工作作出反应。应用和使用指南支持韩语、英语、日语和简体中文。
- 有新版本时，更新按钮出现在场景选择之前。更新窗口显示下载、验证和安装进度；重启后会短暂提示已安装的版本。

## 安装前

首次公开发布和带签名的更新文件仍在准备中。macOS 公证和安装文件的可信发布者签名尚未配置，系统可能显示安全警告。请阅读[安装指南](../guide/install.md)，了解各平台要求和可用的操作步骤。Windows 便携 ZIP 需要手动替换为新文件。
