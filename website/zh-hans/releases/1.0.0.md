# 1.0.0

<ReleaseMeta />

PlayPets 1.0.0让小窗口只留下风景与伙伴，想玩时再轻轻点开。

<Downloads version="1.0.0" />

## 更新内容

- 在小窗口中从伙伴打开简短的玩耍选项。大窗口将场景与氛围、玩耍、菜单分开。
- 让伙伴挖土，收集八种小小发现，种下樱花树、枫树或松树，关闭应用后也会生长。图鉴指南说明概率，没有每日任务。
- 家具比例更适合伙伴，菜单的间距和分组边界更统一。
- 在原来的乐园中查看更新进度，下载时可以收起；安装和重启仍由你选择。
- 背景制作套件可指定是否有挖土、种树所需的土壤。
- 应用版本为1.0.0，MSIX按要求使用四段版本1.0.0.0。MSIX由包管理方式更新，GitHub安装版使用带签名的更新程序。

Microsoft Store审核与公开独立于GitHub发布。此页面不代表Store已上架。
