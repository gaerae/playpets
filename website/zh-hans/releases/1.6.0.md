# 1.6.0

<ReleaseMeta />

乐园迎来冬天：和伙伴一起滚雪人、跟着雪地脚印走、装饰圣诞树，还会收到最亲近的伙伴写来的信。

<Downloads version="1.6.0" />

## 更新内容

- 在冬天的乐园里和伙伴一起滚雪球堆雪人，还能给它打扮。
- 雪地上有动物脚印，和伙伴跟着走，灌木丛里藏着小发现。
- 冬日灯光（12月1日至31日）期间，伙伴会送来圣诞树、小驯鹿和圣诞老人。
- 圣诞树上每天可以挂最多三样图鉴里找到的东西。
- 下雪的12月夜里圣诞树会变大，小驯鹿和圣诞老人都在时，雪橇会飞过月亮。
- 12月26日起，最亲近的伙伴会写来年末的信，你也可以回信。
- 春雨过后会冒出嫩芽，伙伴挖出来收进图鉴的新册子。
- 樱花节时伙伴们会聚在一起赏花，还能接住飘落的花瓣。
- 图鉴增加到8册、169种，新加了脚印和春日嫩芽两册。
- 萤火虫、棒花鱼、冬天的树等以前很像的东西，现在容易分辨了。
- Claude Code 和 Codex CLI 可以在应用里登录，不用终端。
- 关于窗口里的**举报 AI 回复**可以简短反馈，不必附上对话。
- 伙伴的 AI 回复始终适合13岁以上。
- 在伙伴或礼物前面飞的蝴蝶和蜻蜓也能抓到。
- 调整窗口大小时，钓鱼会继续。
- 窗口被遮住时乐园会休息，下载文件也变小了。
- <Only os="Windows" /> Store 版会在 Store 检查新版本，并在应用里显示。
- <Only os="Windows" /> 没有 WebView2 时，不再直接关闭，而是告诉你去哪里下载。
- <Only os="Windows" /> Store 版需要 Windows 10 2004 或更高版本，ARM 电脑会收到 ARM64 版。
- <Only os="macOS" /> 从磁盘映像里打开的应用，更新前会提示先移到"应用程序"。
