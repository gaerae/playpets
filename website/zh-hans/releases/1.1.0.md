# 1.1.0

<ReleaseMeta />

PlayPets 1.1.0 让朋友们在挖土时能发现更多东西，更新检查也会安静等待，直到你选择安装。

<Downloads version="1.1.0" />

## 更新内容

- Daisy、Clover、Pip 和 Miso 会在每套季节服装中展现专属的挖土、种植、钓鱼和发现动作。导入的宠物继续使用原有动画表。
- 收集季节花卉、水中生物、昆虫、礼物、树木和小发现，完成 100 项图鉴。指南提供实用的栖息条件，不显示精确概率。
- 通过挖土找到树苗并存入口袋，种植时消耗一棵库存树苗。共有樱花树、枫树、松树、橡树、白桦树和柳树六种，关闭应用后，种下的树也会继续生长。
- 可收集十七种小小发现。种子通过挖土获得，花种和树苗都能在同一次探索中找到。
- 启动 20 秒后静默检查更新，此后每 6 小时检查，失败时也会静默重试。发现新版本只显示版本入口，不会打开设置或开始安装。
- 设置中的**应用更新**集中显示检查结果、更新内容、下载进度、错误和重试操作。选择**安装并重启**后才开始。下载时关闭设置也会继续，重新打开不会重复下载。
- Microsoft Store 包继续通过独立的包管理方式更新。
- 精简场景、游玩和管理操作，让小窗口与大窗口都能保持庭院清晰可见。

详情请查看[发现指南](../guide/play.md#discovery-guide)和[更新说明](../guide/install.md#更新)。Microsoft Store 审核与公开独立于 GitHub 发布。
