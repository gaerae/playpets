# 1.7.2

<ReleaseMeta />

八种新树和八种新花在乐园里生长。放到桌面上会马上出现，聊天和保存的时候乐园也一样顺畅。

<Downloads version="1.7.2" />

## 更新内容

- 可以种八种新树和八种新花，图鉴有 185 格了。
- 重画了几种树的季节图，长大的松树变成了赤松的样子。
- 放到桌面上会马上出现，第一次放出去或刚把所有东西收回来之后也一样。
- 乐园打开得更快。
- 伙伴聊天、编程代理报告、移动指针的时候，乐园也很顺畅。
- 很长的对话会从最新的话打开，往上滚动时前面的话会接着出现。
- Windows 笔记本用电池时，伙伴也能顺畅地走路。
- 把窗口移到分辨率不同的屏幕上，背景和天气依然清晰。
- 抚摸伙伴、选择风景、移动东西和托盘开关都不再等待保存。
- 伙伴再多，乐园也不会每十分钟卡一下。
- 导入了背景，应用也打开得更快，占用的内存更少。
- 在小窗口里，面板、对话、气泡和名牌在任何语言下都能完整显示。
- 伙伴站在树、花或礼物后面时，前面的东西会变淡，伙伴不会消失不见。
- 随电脑启动并留在托盘里时，乐园不再在屏幕上闪一下。
- 第一次打开应用时，窗口出现在屏幕中间。
- 桌面上的伙伴更省 CPU，在有多个屏幕的 Windows 上尤其明显。

把伙伴和礼物放到桌面上的方法在[桌面模式](../guide/desktop.md)。
