# 1.4.0

<ReleaseMeta />

礼物现在由伙伴送来，而不是靠时间：和伙伴一起玩，它可能会带来点什么；关系更亲近时也会送礼物。

<Downloads version="1.4.0" />

## 更新内容

- 礼物最多每两天一件，由你当天一起玩过的伙伴送来。
- 伙伴每变亲近一级就送一件礼物，到“特别要好”时还会送纪念礼物。
- 乐园放满时送来的礼物，会在图鉴的礼物盒里等着。
- 亲密度靠一起玩来增长：开着乐园的时间每天最多算一小时。
- 独自钓鱼的伙伴咬钩时会叫你，点一下浮漂才能钓上来。
- 可以从 ZIP 文件导入宠物，也能在“邀请伙伴”里删除宠物。
- 导入的背景和选好的地点、季节、天气会随数据一起保留。
- 在设置里一键连接编码代理，Qoder 和 Kimi Code 也加入了。
- Claude Code 伙伴只在 Claude 提问时等待，失败的回合也会告诉你。
- 每次会话的聊天记录最多保留 500 条，长聊天里伙伴也不会忘了自己是谁。
- <Only os="macOS, Linux" /> 能找到用 nvm、fnm、Volta 等安装的 Claude Code 和 Codex CLI。
- <Only os="Windows" /> Store 版能打开宠物图库链接，登录时启动也能用了。
- <Only os="Windows" /> 修复了 Claude Code、Gemini CLI 和 Cursor 的钩子，请点**重新连接**。
- 拔掉显示器后窗口会回到屏幕内，顶部按钮可重置窗口大小。
- 新伙伴也能用已连接的 AI，没写完的话会留给原来那位伙伴。
- 修复了保存、托盘、挖掘、捉迷藏、树木、移动礼物和地点按钮的问题。
