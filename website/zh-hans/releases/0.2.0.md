# 0.2.0

<ReleaseMeta />

四位伙伴、可重复使用的制作套件，以及自由调整的庭院。下方下载区域会显示 GitHub 正式发布的安装文件。

<Downloads version="0.2.0" />

## 主要变化

- 水獭 Miso 加入 Daisy、Clover 和 Pip。每位伙伴都有春秋基础服装、夏装和冬装。
- 角色和背景套件提供参考图、完整制作请求与技能。在所选工具中完成生成、验证和打包，再将成品文件导入应用。
- 迷你模式合并为一个可自由调整大小的无边框庭院窗口。可以切换始终置顶、进入全屏，并返回原来的大小和位置。
- 小窗口也能通过统一菜单打开伙伴、邀请、设置与地点和氛围。右键点击庭院，或按 Cmd/Ctrl+Shift+P。
- 新庭院从晴朗的春日白天开始。提示和操作更加清晰，已有伙伴和场景设置会保留。
