# 乐园和游戏

乐园跟着时钟、天气和季节变化，一天天慢慢长大。伙伴们会挖土、钓鱼、送礼物、陪你玩，找到的东西都会收进图鉴。

::: tip 速查
| 想要 | 这样做 | 详见 |
|---|---|---|
| 换地点、季节、时段或天气 | 底部栏的**场景与氛围** | [时段和天气](#weather) |
| 找花种、树苗和小小发现 | **玩耍 → 挖土**，再点一块空地 | [挖土](#digging) |
| 种花种树 | **玩耍 → 播种**或**种树** | [花园](#the-garden) |
| 收到礼物 | 当天和伙伴一起做点什么 | [礼物](#gifts) |
| 填满图鉴 | 钓鱼、捉虫、挖土、种花种树 | [图鉴](#album) |
| 任何一天都能看到季节活动 | 手动选择它的季节，再选好它需要的时段和天气 | [季节活动](#seasonal-events) |
| 和伙伴更亲近 | 每天摸摸它、喂零食、聊天、一起玩一会儿 | [亲密度](#closeness) |
| 玩游戏 | **玩耍 → 一起玩** | [游戏](#games) |
| 把乐园放在工作旁边 | 拖动窗口边缘或角落 | [放在工作旁边的窗口](#a-window-beside-your-work) |
:::

## 底部栏

风景铺满整个窗口，底部栏一次打开一个面板。每个面板都是一页，分成几个分区，里面没有标签，也没有返回按钮。

| 入口 | 内容 |
|---|---|
| **场景与氛围** | **场景**（内置背景和导入的背景在同一个图库里，还有**导入背景**和**背景制作室**），**氛围**（季节、时段、天气、**乐园声音**、**音量**） |
| **玩耍** | 标题跟着选中的伙伴变，比如**和Clover玩耍**。**寻找**：**挖土**、**钓鱼**、**图鉴**。**花园**：**播种**（旁边显示你有几颗种子）、**种树**、**野餐**。**一起玩**：四种游戏（**堆雪人**只在乐园显示冬天时才有）、樱花节期间的**赏花**、**聊聊天** |
| **伙伴与设置** | **伙伴与聊天**、**邀请伙伴**、**窗口与桌面**、**设置**、**关闭窗口**、**退出 PlayPets** |

- **聊聊天**需要至少两位接上 AI 的伙伴，其他活动都不用 AI。
- 第一次打开时，乐园是晴朗的春日。想让季节、时段或天气自己变化，就选**自动**。选好的设置都会保存。

### 声音

- **乐园声音**和**音量**：在**场景与氛围 → 氛围**里。
- 你第一次操作之后才会有声音，而且只在乐园可见时播放。
- 雨声、鸟叫、水声这些环境音，会随地点、天气、季节和时段变化。
- 让伙伴们自己聊天是另一个设置：**伙伴与设置 → 设置 → 伙伴与 AI**。

## 时段和天气 <Since v="0.1.0" /> {#weather}

每一项都可以自己选，也可以交给**自动**。改了马上生效。

<Shot name="yard-spring" caption="晴朗春日的乐园。选择自动时段后，跟随电脑时间变化。" />

1. 点右下角的**场景与氛围**。
2. 在**场景**里看缩略图选背景。只有选中导入的背景时，那里才会出现**删除**。
3. 在**氛围**里选季节、时段和天气。

| 选择 | 选项 | 设为自动时 |
|---|---|---|
| 地点 | 山丘花园、花园工坊、自然花园、湖畔小屋，以及你自己的背景 | |
| 季节 | 自动、春、夏、秋、冬 | 室外地点按日期变化：花朵和飘落的花瓣、一片浓绿、红黄相间的叶子、雪景。电脑时区在南半球时，季节会反过来 |
| 时段 | 自动时段、早晨、白天、傍晚、夜晚 | 跟着电脑时钟走，风景上不显示时钟。天空和地面的颜色会变，太阳从左往右越过天空，夜里的月亮就是今晚的月相 |
| 天气 | 自动天气、晴、雨、雪 | 每 20 分钟重新定一次天气：大多是晴天，偶尔下雨，只有冬天会下雪。不会从网上获取真实天气 |

- 自己选的季节、时段或天气会固定下来，下次打开还是一样。
- 季节和天气分开设定。夏天选下雪，夏季风景和服装都不变，只是飘起雪来；冬天选晴天，冬季风景照样保留。室内的窗景和导入的背景也是这样。
- 手动选择季节，在任何一天都可能叫来[季节活动](#seasonal-events)。
- 天气一变，会有一两位伙伴说上一句，比如“下雨了！”“堆雪人吗？”。不去管它们时，它们也会说些符合时段的自言自语。

### 天气带来的景色

| 景色 | 什么时候 | 可以做什么 |
|---|---|---|
| 彩虹 | 白天雨停后，在山丘上挂几分钟 | 趁它消失前，去挖彩虹尽头闪光的地面，一定不会空手而归 |
| 太阳雨 | 晴朗的白天下起雨 | 看看出着太阳落下的雨 |
| 薄雾 | 晴朗的秋天早晨 | 看看田野上的一层薄雾 |
| 月光雪地 | 夜里雪停后 | 看看月光下闪闪发光的雪地 |
| 流星 | 晴朗的夏夜 | 抬头看，整夜都会频频划过 |
| 鸟群 | 晴天，偶尔 | 看鸟群飞过天空 |

虫子也会随光线和季节出现：见[捉虫](#bugs)。

### 地点 {#places}

| 地点 | 是什么样的地方 |
|---|---|
| 山丘花园 | 开阔的山坡，有自己的房子 |
| 自然花园 | 野花环绕清澈小池的天然花园 |
| 湖畔小屋 | 湖边的小屋，有自己的房子 |
| 花园工坊 | 玻璃屋顶的工坊，一年四季都是同一个样子 |

- 山丘花园、自然花园和湖畔小屋各有四季的景色和自己的钓鱼站位，色调随光线变化。
- 只有景色或窗口大小改变时，才会重绘背景。
- 地点和时段、天气的选择分开保存。
- 换了地点，生长进度和图鉴都会保留。

### 花园工坊 <Since v="1.7.0" /> {#garden-workshop}

玻璃屋顶下有两张长长的工作台、一张摆着跳棋的茶桌，前面还有一张挂着铃铛的花园长椅。透过玻璃能看到天空、时段和天气，雨和雪只落在玻璃外面。

- 伙伴们会散步、在工作台前挑种子、一起喝茶，或在长椅旁歇一会儿。
- 连接了编程代理的伙伴会在工作台前工作，代理等你确认时就到铃铛旁等着（[伙伴们在那里做什么](./agents.md#where-friends-go)）。

在哪个地点都能抚摸伙伴、聊天、种花、装饰圣诞树、玩游戏。其他的就看地点了：

| 活动 | 山丘花园、自然花园、湖畔小屋 | 花园工坊 |
|---|---|---|
| 花 | 种在地里 | 种在小花盆里 |
| 挖土、钓鱼 | 可以 | 不可以 |
| 树 | 可以，每个地点六棵 | 不可以 |
| 虫 | 晴天出现 | 没有 |
| 季节景色和效果 | 随季节变化 | 没有 |
| 堆雪人、雪地上的脚印 | 冬天 | 没有 |
| 春日嫩芽 | 春天 | 没有 |
| 圣诞夜 | 下雪的冬日傍晚或夜里 | 没有，雪只落在玻璃外 |

## 聊聊天 <Since v="0.1.0" />

点**玩耍 → 一起玩 → 聊聊天**，接上 AI 的伙伴（最多三位）会围绕现在的时段和天气简短地聊几句，话会变成乐园里的气泡冒出来。

- 接上 AI 的伙伴不到两位时，按钮看起来是关着的，点一下或把指针移上去就会告诉你原因。
- 想自己加入，就用[伙伴面板里的一起聊](./chat.md)。
- 想让它们自己聊，就打开**伙伴与设置 → 设置 → 伙伴与 AI**里的**偶尔让伙伴们自己聊聊**。它们每 20 分钟聊一次，窗口隐藏或有人正在回答时会暂停。

## 花园 <Since v="0.1.0" /> {#the-garden}

花种和树苗都是[挖土](#digging)挖出来的，伙伴光散步不会冒出来。

1. 选**玩耍 → 花园 → 播种**。旁边的数字是你有几颗种子。
2. 点草地上想种的位置。接着点就能种好几颗；按 **Esc** 或再点一次工具就停止。

- 用键盘时，按 Enter 或空格选中**播种**，再按一次就种在选中的伙伴旁边，和野餐一样。
- 手上拿着工具时，按 1、2、3 可以换成**挖土**、**种树**或**播种**。在输入框里打字时不会切换。

花按真实时间生长，关掉应用也照样长：

| 经过 | 10 分钟 | 40 分钟 | 2 小时 | 4 小时 |
|---|---|---|---|---|
| 阶段 | 发芽 | 长叶 | 结花苞 | 开花 |

开什么花，取决于种下时的季节：

| 种下的季节 | 花 |
|---|---|
| 春 | 郁金香、水仙、番红花、葡萄风信子 |
| 夏 | 向日葵、绣球花、薰衣草、风铃草 |
| 秋 | 波斯菊、菊花、大丽花、紫菀 |
| 冬 | 山茶花、雪滴花、铁筷子花、仙客来 |

| 对植物 | 会怎样 |
|---|---|
| 把指针移上去 | 显示它是什么花、还要多久开花 |
| 点一下 | 离得最近的伙伴走过去浇水。伙伴们也会自己去看花 |
| 拖动，或按方向键 | 挪到哪儿就在哪儿接着长 |
| 右键 → **拔掉**，或按 **Delete**、**Backspace** | 马上拔掉，不会先问你。底部提示里的**撤销**大约六秒内能放回，过了就彻底移除。在那之前关闭应用，植物会留下来。用掉的种子不会回来 |
| 右键 → **在桌面上显示** | 在桌面上也接着长（[桌面模式](./desktop.md#flowers-and-trees-on-the-desktop)） |

- 上限：20 颗种子、24 株植物。
- 每种花第一次开花时，会收进**图鉴**。
- 保存在 `state.json` 的 `garden` 里。

### 礼物 {#gifts}

礼物不是到点就来，而是和你一起玩的伙伴送来的。

| 礼物 | 什么时候来 |
|---|---|
| 平常的礼物 | 在你和伙伴一起做过事的那天：摸摸它、喂零食、聊天或一起钓鱼。之后 10 到 20 分钟送到（第一件只要 5 分钟）。整个乐园每两天最多一件，只开着乐园不会收到 |
| 亲密度礼物 | 从**熟络**开始每升一级送一件，在你和它一起玩的那天送来 |
| 纪念礼物 | 到了**特别要好**，送来只属于它的礼物，一天里带着小爱心；之后把指针移上去或选中时才显示爱心 |
| 活动礼物 | 只在季节活动的日期送来（[季节活动](#seasonal-events)） |

- 等待时间会保存，关闭应用的时间也照样算，所以不用一直开着。伙伴会跳一下告诉你，再把礼物放在身边。
- 最先送来的依次是：长椅、灯笼、鸟屋、小池塘、信箱、野餐垫、风车、篝火、秋千、花盆、树桩凳、帐篷、路标、风铃。之后伙伴会带来乐园里还没有的东西。

伙伴们会用上收到的东西：坐在长椅、秋千和树桩上，聚在野餐垫上，看看映着天空的池塘。灯笼和篝火从傍晚开始发光，白天鸟屋上落着一只小鸟，伙伴走近风铃时，它会叮铃作响。

| 对摆设 | 会怎样 |
|---|---|
| 拖动，或选中后按方向键 | 挪到草地上的任何地方 |
| 点一下 | 离得最近的伙伴走过去 |
| 右键 → **收起来**，或按 **Delete**、**Backspace** | 马上收起。提示里的**撤销**大约六秒内能放回。在那之前关闭应用，它会留下来。改天伙伴可能还会再带来 |
| 右键 → **在桌面上显示** | 放到桌面上（[桌面上的礼物](./desktop.md#gifts-on-the-desktop)） |

- 乐园最多放 12 件摆设。放满时，新礼物会在图鉴“礼物”册上方的**礼物盒**里等着，礼物盒还能再放 12 件。有空位后点一下就能摆出来。
- 收起一件仍保留图鉴记录，也为后面的礼物腾出位置。纪念礼物收起后会回到礼物盒，除非礼物盒满了。
- 收到过的礼物都能再拿出来：乐园有空位时，在图鉴“礼物”册里点卡片上的**摆出来**。雪人是例外，要重新堆。
- 图鉴里共 29 种礼物，其中 7 种只在对应活动的日期送来。雪人也是这 29 种之一，但要自己堆（[堆雪人](#snowman)）。纪念礼物也在这 29 种里，所以不会多出新的一格。

## 钓鱼和捉虫 <Since v="0.1.0" />

### 钓鱼

| 方式 | 怎么做 |
|---|---|
| 手动 | 点看得见的水面，离得最近的空闲伙伴就会抛竿。浮漂下沉、出现 **!** 时点一下。太早或太晚，鱼都会跑掉 |
| **玩耍 → 钓鱼** | 选中的伙伴会自己钓完整个过程 |

- 两种方式都用该背景的钓鱼站位。
- 钓竿也能钓上淡水虾、螯虾、田螺、绒螯蟹和河蚌，偶尔还会钓到中华鳖。它们和鱼一起收在图鉴的**水中生物**里。
- 钓到什么要看季节、时段和天气。鲶鱼和鳗鱼天黑后才出来，下雨时更多。西太公鱼只在冬天出现，黄金鲤非常少见。每次钓到的鱼大小都不一样。

### 捉虫 {#bugs}

虫子只在晴朗的户外出现，下雨或下雪时不会出来。点一下虫子，离得最近的伙伴就会去捉。

| 什么时候 | 虫子 |
|---|---|
| 春天到秋天的早晨和白天 | 蝴蝶和蜻蜓，还有草丛里的甲虫和蚱蜢 |
| 春夏的傍晚和夜里 | 萤火虫 |
| 秋天的傍晚和夜里 | 草丛里的蟋蟀 |

### 自己去钓鱼 {#fishing-on-its-own}

- 亲密度到 3 级后，乐园可见时，空闲的伙伴每 12～25 分钟可能会自己去钓鱼。
- 玩游戏、正在钓别的鱼或手上拿着摆放工具时会暂停。
- 鱼咬钩时伙伴会叫你，几秒内点一下浮漂就能一起拉上来。没人点的话鱼就跑了，所以图鉴里只收你亲手钓到的。

### 图鉴 {#album}

- **玩耍 → 寻找 → 图鉴**。共八册：花、水中生物、虫、礼物、树木、小小发现、脚印、春日嫩芽。
- 每个种类都列出来。捉到的：显示捉了几次和最大尺寸。没捉到的：显示剪影，以及该在何时何地找。
- 会告诉你稀有发现什么时候能再找到，但不显示精确的百分比。
- **稀有**标在很少出现的种类上，也标在只随季节活动出现的种类上。活动的卡片会写出日期，以及能叫来它的场景。
- 捉到后会弹出卡片，第一次捉到时也会告诉你。图鉴会收录的东西（鱼、虫、开好的花、礼物、小小发现或春日嫩芽），卡片上有**在图鉴中查看**，点一下就打开对应的那一册。
- 有新东西时，**图鉴**和底部栏的**玩耍**会带一个小圆点，直到你打开图鉴。
- 保存在 `state.json` 的 `album` 里。

## 季节活动 <Since v="0.1.0" /> {#seasonal-events}

一年里有几次，乐园会变个样子一阵子。活动到了日期会自己开始；在别的日子，只要在**场景与氛围 → 氛围**里手动选好它的场景，也会开始。

| 活动 | 自动开始 | 任何一天手动选择 |
|---|---|---|
| 樱花节 | 4 月 1 日至 20 日，乐园显示春天时 | <SceneChips lang="zh-hans" event="blossom" label="任何一天手动选择" /> |
| 萤火虫之夜 | 7 月 20 日至 8 月 20 日，乐园显示夏天时 | <SceneChips lang="zh-hans" event="fireflies" label="任何一天手动选择" /> |
| 中秋月圆 | 9 月 8 日至 10 月 15 日，乐园显示秋天时 | <SceneChips lang="zh-hans" event="harvest" label="任何一天手动选择" /> |
| 冬日灯光 | 12 月 1 日至 31 日，任何季节 | <SceneChips lang="zh-hans" event="lights" label="任何一天手动选择" /> |
| 新年 | 1 月 1 日至 7 日，任何季节 | <SceneChips lang="zh-hans" event="newyear" label="任何一天手动选择" /> |

| 活动 | 乐园里 | 礼物（仅限活动日期） |
|---|---|---|
| 樱花节 | 花瓣纷飞，蝴蝶更多；伙伴们会聚在一起[赏花](#flower-viewing) | 樱花树苗 |
| 萤火虫之夜 | 夜里萤火虫更多，还有能捉的金色萤火虫 | 西瓜 |
| 中秋月圆 | 夜里湖中会有月光鲤。手动叫来时，会升起满月。按日期自动开始时，像中秋和韩国的秋夕一样，活动期间第一次满月的前后各两晚升起又大又黄的圆月，其他夜晚月亮保持当天的月相 | 南瓜 |
| 冬日灯光 | 树木上挂起小彩灯，从傍晚开始发光 | 依次是小圣诞树、小驯鹿、圣诞老人 |
| 新年 | 伙伴们一起向你拜年 | 风筝 |

- 场景名称旁会显示活动名，当年第一次看到时会弹出开始的卡片，伙伴们也会聊起它。
- 季节设为**自动**时，只有日期能带来活动。日历上的活动优先：12 月不管选什么场景，冬日灯光都在。
- 活动限定的鱼和虫，比如金色萤火虫和月光鲤，只要活动在进行就会出现，不管是怎么开始的。
- 活动礼物会在活动日期内每轮到送礼时送来一件，按固定顺序，只有那时才有。收到的礼物会一直留着，什么时候送来，图鉴里写着。
- 在南半球（按电脑的时区判断），樱花节、萤火虫之夜和中秋月圆会晚六个月，冬日灯光和新年的日期不变。

### 12 月

12 月里如果乐园没有显示冬天，PlayPets 会问一次要不要显示到 1 月 7 日。选择显示的话，你自己选的季节会在 1 月 8 日回来。

- 小圣诞树、小驯鹿和圣诞老人在 12 月 1 日至 1 月 7 日，以及乐园显示冬天的任何时候，都会出现在乐园和桌面上。
- 其余时间它们悄悄待在看不见的地方，仍算在 12 件摆设里。收起来就会回到礼物盒。

### 圣诞夜 {#christmas-night}

在山丘花园、自然花园或湖畔小屋里摆出小圣诞树，只要场景是这样，不管哪一天，树都会亮起灯，长成一棵大圣诞树：

<SceneChips lang="zh-hans" :when="['season:winter', 'period:evening|night', 'weather:snow', 'gift:xmas_tree']" label="需要" />

- 下雪时它一直是大树的样子，彩灯时不时闪一下。雪停了就变回小树，雪再下起来又会长大。
- 小驯鹿和圣诞老人也在乐园里的话，夜里会一起抬头望天，树每长大一次，雪橇就从月亮前飞过一次。
- 摆到桌面上的圣诞树也会和乐园里的一起长大。

### 装饰圣诞树

点一下圣诞树就能装饰它。

- 每天最多可以挂三样在图鉴里找到的东西：花、树木、礼物和小小发现。水中生物和虫留在水里和草丛里。
- 它们会变成按种类上色的小装饰，把指针移上去就能看到是什么。
- 想换换样子，可以在卡片上把装饰取下来，当天的三个名额仍算用掉。
- 装饰会一直留在乐园里的树上，大圣诞树上也一样，直到下一个 12 月树又变回光秃秃的。

### 赏花 {#flower-viewing}

樱花节期间，伙伴们会聚到你种的樱花树下，抬头看花，聊上一分钟左右就散开。

| 方式 | 说明 |
|---|---|
| 自己聚起来 | 晴天的早晨到傍晚，每天一次，只在打开**偶尔让伙伴们自己聊聊**时 |
| 手动叫 | **玩耍 → 一起玩 → 赏花**，每小时一次。伙伴们正在赏花或有游戏进行时，按钮是灰的 |
| 在哪里 | 你种的樱花树下；没有樱花树，就去野餐垫上或乐园中间 |
| 提前结束 | 乐园换了地点，或者天黑、下雨时。不会打断游戏、钓鱼和挖土 |

- 接上 AI 的伙伴会用自己的话聊花。
- 节日里晴天的早晨到傍晚，偶尔有一片花瓣落在伙伴头上，等它动一动，或者入夜、下雨了才掉。赏花时花瓣落得更密，落在头上的也更多。
- 点一下飘落的花瓣就能接住，它会转着闪一下消失；每天接到的第一片，伙伴会帮你许个愿。
- 开启减少动态时，花瓣不会飘落，也接不到，但伙伴们照样聚在一起，头上的花瓣也照样停着。

### 年末的信

12 月 26 日到 31 日之间，你第一次打开 PlayPets 的那天，最亲近的伙伴会写一封关于你们这一年的信：图鉴里新添了什么，一起种大的那棵树，你们变得多亲近，认识了多少天。它还会问你这一年过得怎么样，明年想做什么。

- 乐园里有信箱的话，信就放在那里等你；没有的话，伙伴会告诉你。1 月 7 日之前，点场景名称旁边的**信**，或从乐园菜单都能打开。
- 回信最多 200 个字，也可以不写。
- 1 月 1 日到 7 日之间你第一次打开的那天，伙伴会把你的回信带回来，给你加油。明年 12 月的信会回顾这份回信。
- 连接了 AI 的伙伴会用自己的话来写，写明年的信时，那个 AI 会先读你的回信。
- 信和回信保存在这台电脑上，可以在信的卡片里删除。

## 亲密度 <Since v="0.1.0" /> {#closeness}

名牌上的爱心表示伙伴和你有多亲近。伙伴面板里能看到它的等级、离下一级还差多少，以及下一级会带来什么。

| 等级 | 带来什么 |
|---|---|
| 初识 | 每位伙伴都从这里开始 |
| 熟络 | 打开应用时、离开一阵子回来时，它会迎接你 |
| 亲近 | 偶尔会[自己去钓鱼](#fishing-on-its-own) |
| 特别要好 | 会送你一件纪念礼物 |
| 珍视彼此 | 名牌上开出一朵花，偶尔会说只对你说的话 |

- 等级只表示有多亲近，不表示你们是什么关系；关系在[设定关系](./chat.md#设定关系)里设定。
- 乐园可见时，每十分钟累积一次相处时间，每天最多算一小时。
- 抚摸、零食、聊天、浇水、钓鱼捉虫和礼物累积得更多，每天最多算一天的量。只靠抚摸，最多填满其中四分之一。
- 所以只开着窗口或几分钟里猛点都不会更快变亲近，你离开时也不会减少。
- 保存在 `state.json` 的 `bonds` 里。

## 挖土和种树

### 挖土 {#digging}

1. 选**玩耍 → 寻找 → 挖土**，或右键点伙伴，选**请Clover挖土**（显示这位伙伴的名字），让它先去。
2. 点一块空地。按 **Esc** 取消。
3. 伙伴会走过去挖。不需要 AI。

- 捷径：右键点空地，选**在这里挖土**。
- 水面、家具和树根所在的地方不能挖。伙伴到达前把它叫走，就不会有发现。
- 工具会一直拿在手上：每选一块空地，就派下一位空闲的伙伴去挖，刚挖过的伙伴歇一会儿。
- 底部栏的位置会换成工具条，点一下就能切换到**种树**或**播种**。点条上的关闭按钮或按 **Esc** 收起工具。
- 拿着工具也不会挡住湖面和小生物：点水面或小生物，工具会先收起，接着就钓鱼或捕捉。

| 挖到什么 | 规则 |
|---|---|
| 花种、树苗、25 种小小发现之一（**图鉴 → 小小发现**），或者什么都没有 | 挖到稀有发现后，所有伙伴和地点都要等 24 小时才能再挖到稀有的。同一地块 24 小时内不再给东西。每位伙伴两次挖土之间隔 8 秒。可能重复，所以集齐要花些时间 |

- 上限：花种 20 个，每种树苗 20 个。库存满了也不会改成别的发现。

### 种树

1. 先挖土找到树苗。
2. 选**玩耍 → 花园 → 种树**，看看你有哪些：樱花树、枫树、松树、橡树、白桦、柳树、银杏、柿子树、竹子、玉兰、紫薇和水杉。
3. 选一种你有的树，点空地。会用掉一棵树苗。

- 关闭应用的时间也算：两小时长成幼树，十二小时成熟。成熟后会在**图鉴 → 树木**记录一次。
- 每个地点六棵，总共 24 棵。树会留在种下它的地点。
- 拖动可以挪位置。右键 → **移除**，或按 **Delete**：马上移除，大约六秒内可以**撤销**。图鉴记录会保留，树苗不会退回。
- 导入的背景可以设置有没有可用的土壤。

### 雪地上的脚印

冬天的乐园里，雪地上会有淡淡的动物脚印：每天一串，下过雪的夜晚之后的早晨再多一串（12 月 26 日到 1 月 7 日每天只有一串）。

- 点一下脚印（或用 Tab 移过去按 Enter），休息好的伙伴就会一路闻着跟过去。
- 走到头，灌木后面会探出一条尾巴，一晃就不见了。那里埋着一样小东西，每种动物都有自己爱找的东西。
- 新雪下满一小时，脚印就会被盖住，第二天也会消失。
- **图鉴 → 脚印**里，没跟过的只看得到脚印，跟过之后就会显示尾巴和名字。

### 春日嫩芽

乐园是户外春天时，雨后会冒出几株嫩芽，晴朗的早晨会再冒出一株。同一时间最多三株，每株只留几个小时。

- 点一下嫩芽，选中的伙伴，或者离得最近的空闲伙伴，就会去把它挖出来。
- **图鉴 → 春日嫩芽**一共八种：荠菜、艾草、蕨菜、熊葱、竹笋、笔头菜、芦笋和羊肚菌。图鉴是用来收集的，不是野生植物指南。

### 动作和服装

- Daisy、Clover、Pip 和 Miso 一年四季都有专属动作：挖土、种植、抛竿、等鱼上钩、收竿，还有发现东西时的反应。导入的宠物会用原有的动作一起参加。
- Daisy、Pip 和 Miso 春秋穿日常服装，夏冬换上应季的衣服。Clover 从春到秋都穿青绿色背带裤、戴草帽，冬天换上外套、围巾和针织帽。

## 游戏 <Since v="0.1.0" /> {#games}

四种游戏都在**玩耍 → 一起玩**里，一次只能玩一种。游戏进行时，它的按钮会变成“结束”加游戏名，比如**结束捉迷藏**，点一下就结束。结束之前，其他游戏和**野餐**、**播种**、**种树**都用不了；结束后，伙伴们会走回原来的位置。

| 游戏 | 怎么玩 | 结束 |
|---|---|---|
| 捉迷藏 | 伙伴们四散去躲（15 秒内没赶到藏身处的就在原地躲）。底部栏上方的提示写着**点一下找出来**、要找的伙伴，后面是其他还躲着的伙伴。点对了，它会喊着“被发现啦！”跳出来，提示换到下一位。点错了只会出现“可惜，不是这位”，那位继续躲着 | “全都找到了！” |
| 散步队列 | 选中的伙伴站到最前面，其他伙伴排在后面，排好后一起绕乐园走一圈 | “一圈走完！” |
| 鬼抓人 | 需要两位以上的伙伴。选中的伙伴当鬼（名牌上标着“鬼”），去追最近的伙伴；在屏幕上重叠就算抓到，被抓的成为新的鬼，抓到人的暂时安全 | 过了规定时间，“鬼抓人结束了。大家都跑得很棒！” |
| 堆雪人 | 乐园显示冬天时。两位伙伴滚雪球，三个雪球叠成雪人（[堆雪人](#snowman)） | 雪人堆好时 |

<Shot name="play-hide-and-seek" caption="捉迷藏。底部栏上方的提示写着要找的伙伴的名字。" />

游戏提示、发现和提示消息这些乐园要告诉你的内容，都出现在底部栏上方的同一个位置。

### 堆雪人 {#snowman}

1. 乐园显示冬天时，选**玩耍 → 一起玩 → 堆雪人**。有时伙伴也会自己提议，然后动手滚起雪球。
2. 两位伙伴滚得越久，雪球越大。点一下雪球可以帮着推，拖动它或用方向键就能自己来滚。滚过的雪地上会留下一道淡淡的蓝色痕迹，过一会儿就消失。
3. 三个雪球叠起来，伴着亮晶晶的光点，雪人就堆好了。
4. 挑帽子、围巾和胡萝卜鼻子。想以后再换，点一下雪人，或在它的菜单里选**打扮**。

- 每天一次。同一天再提，伙伴会说今天已经堆过了。
- 堆新的雪人时，原来的那个会融化；有伙伴在旁边时，它会跟雪人道别。
- 雪人只在乐园显示冬天时留在乐园里。在它的菜单里选**在桌面上显示**，它会穿戴着原样出现在桌面上，同样只在乐园显示冬天时可见。收起它就会融化。
- 乐园里已有 12 件摆设又没有雪人时，伙伴会说乐园满了，游戏不会开始。

## 放在工作旁边的窗口 {#a-window-beside-your-work}

### 小窗口

宽度不超过 640 像素，或高度不超过 480 像素，就算小窗口。

- 底部栏会隐藏。指针移到窗口上，或用 Tab 移过去时，右下角会出现一个圆形按钮。它打开的简短菜单和右键点空白背景时一样：**场景与氛围**、**玩耍**、**伙伴与设置**、**始终置顶**。

- 各面板的操作排成方块（名字可能分成两行），分区标题不显示，较长的面板在窗口内滚动。
- 有更新时，会显示一个带圆点的 32 像素下载图标，代替带版本号的按钮。它的名称标着版本号，点一下打开应用更新。

### 对话框和确认

- 伙伴设置、导入和 AI 连接的对话框会固定标题和操作按钮，只滚动表单。图鉴和确认对话框各自滚动正文。

- 每个确认对话框都有**关闭**按钮。花、树和礼物不会先问你，而是提供**撤销**。

## 慢慢收集的小技巧

图鉴一共有 169 种，包括水中生物、昆虫、花、礼物、树木、脚印、春日嫩芽和小小发现。去找找朝鲜少鳞鳜和绒螯蟹、寒夜里难得的鲟鱼、草丛里的螳螂，还有秋夜的螽斯和蟋蟀吧。种些蒲公英、牵牛花、石蒜和三色堇，栽一棵银杏或柿子树，从土里挖出松果、纸船，偶尔还有四叶草，再给伙伴送来的水车、吊床和酱缸台留个位置。

### 收集需要时间

- 集齐图鉴不是一天或一周的目标，也没有固定的完成日期。
- 21 种普通礼物会在不同的日子送来。
- 7 种活动礼物只在各自活动的日期送来，分布在一年的日历上，根据你开始玩的时间，集齐可能要几个月。手动选择季节能叫来活动的场景，但叫不来它的礼物。
- 花种下 4 小时后开花，树 12 小时后成熟，关闭应用的时间也算在内。

### 小技巧

| 类别 | 小技巧 |
|---|---|
| 鱼 | 下雨时更容易遇到鲶鱼和鳗鱼。选它们出现的季节和时段，再用发现指南看看能钓到什么 |
| 活动限定的鱼和虫 | 手动选择活动的季节，再选好它需要的时段和天气，任何一天都可能遇到金色萤火虫或月光鲤 |
| 挖土 | 季节、天气和室外地点会让某些树苗和小小发现更容易出现，其他的也照样能找到。可以在氛围里分别选季节和天气，试试少见的组合；你自己的室外背景也会受影响 |
| 同一地块 | 24 小时内结果不变。连续挖空也不会让下次更容易有收获 |
| 腾出位置 | 收起礼物会保留图鉴记录，也给后面的礼物腾出位置。种子或树苗库存满了，也不会把发现换成别的 |

发现指南会列出在所选条件下可能遇到的发现。水面和障碍物会占掉一些地块，所以实际能挖的地块比背景的完整网格少。
