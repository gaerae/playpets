# 桌面模式

- 把伙伴们放到乐园窗口外面，让它们住在桌面上。
- 用别的应用工作时也能看到伙伴。

<Shot name="desktop" caption="桌面模式。伙伴住在其他窗口上面，用气泡显示编码代理的状态。" />

## 开启和关闭 <Since v="0.1.0" />

1. 在**伙伴与设置 → 窗口与桌面**里打开**在桌面上显示**。
2. 紧跟其后的**在桌面散步**一直显示，开启桌面模式后才能用。

- 两个开关都显示当前状态，切换时菜单保持打开。
- 关闭**在桌面上显示**，伙伴们就会回来。
- 没有伙伴时，无法开启桌面模式。
- 托盘图标的菜单里也有同样的项目，不打开乐园窗口也能开关。

## 在桌面上能做的事 <Since v="0.1.0" />

| 做什么 | 方法 |
|---|---|
| 抚摸 | 用左键点一下伙伴 |
| 移动 | 拖动伙伴再放下。也可以移到另一台显示器上 |
| 聊天 | 鼠标移到伙伴身上，下方出现带对话图标的名字。点名字，乐园窗口会打开到那位伙伴的聊天。右键点伙伴也一样 |
| 对视 | 在休息中的伙伴脸上移动鼠标，它的眼睛会跟着走。只有带 16 方向视线图的 v2 宠物可以 |

- 双击没有反应，免得移动伙伴时不小心打开窗口。
- 第一次打开桌面模式时，会提示怎么聊天。
- 名字只在鼠标移上去时显示，让伙伴自然融进桌面。
- [编码代理](./agents.md)的状态和伙伴说的话以气泡浮在头顶，长的话在三行后以“…”结尾。

## 每台显示器上都有伙伴 <Since v="0.1.0" />

- 有多台显示器时，伙伴可以在任意一台上。
- 拖到另一台显示器，它就留在那里。
- 各显示器缩放比例不同时，鼠标位置也按那台显示器的比例对应。

## 在桌面散步 <Since v="0.1.0" />

- 打开**在桌面散步**，伙伴们会在桌面上慢慢散步。
- 它们朝走的方向转身，偶尔停下来休息。
- 关掉后，就停在你放下它们的位置。
- 正被拖动的伙伴不会走开。

## 在其他应用的全屏上面 <Since v="0.1.0" />

| 系统 | 表现 |
|---|---|
| macOS | 其他应用全屏时，伙伴也浮在上面。桌面窗口是一种特殊面板，全屏空间里也看得到 |
| Windows、Linux | 浮在普通窗口上面 |
| Linux Wayland 会话 | 不给应用提供始终置顶或获知鼠标位置的方法，伙伴可能跑到其他窗口后面，也不会跟着鼠标看 |
| Linux X11 会话 | 一切正常 |

## 关掉窗口后还在 <Since v="0.1.0" />

- 所有系统都不显示标题栏和窗口按钮，只呈现乐园。
- 拖动顶部边缘狭窄的透明区域移动窗口；拖动边缘或角落调整大小，最小 300 × 210。
- 选**伙伴与设置 → 关闭窗口**或用系统关闭窗口快捷键，只会隐藏窗口。桌面伙伴和代理联动继续运行。
- macOS：关掉窗口后 Dock 图标也一起消失，免得 Dock 里留下点了没反应的图标。重新打开乐园，Dock 图标就回来。
- Windows 和 Linux：从任务栏消失，只留在托盘里。

## 重新打开的方法

- 点菜单栏（macOS）或任务栏（Windows、Linux）里的托盘图标，选**打开乐园**。
- 点桌面上伙伴的名字（或右键点伙伴），也会打开乐园窗口。

## 完全退出

- 选**伙伴与设置 → 退出 PlayPets**、托盘菜单的**退出 PlayPets**，或在 macOS 上按 <kbd>⌘</kbd> <kbd>Q</kbd>。都不再询问，立即退出。
- 小窗口里，点右下角的按钮或右键空白背景，进入伙伴与设置。
- 聊过的对话不会保存，桌面上的伙伴们也一起消失。
- 伙伴的名字、性格、大小，以及桌面模式是否开着，都会记住，下次打开还是原样。
