# 桌面模式

把伙伴们放出乐园窗口，它们就住到桌面上，待在你工作的应用上面。

::: tip 速查
| 想做的事 | 怎么做 | 详见 |
|---|---|---|
| 放一位伙伴出去 | 在乐园里右键 → **在桌面上显示** | [开启和关闭](#turning-it-on-and-off) |
| 全部放出去 | **伙伴与设置 → 窗口与桌面 → 在桌面上显示** | [开启和关闭](#turning-it-on-and-off) |
| 让伙伴走动 | 紧挨着的**在桌面散步** | [在桌面散步](#stroll-on-desktop) |
| 用礼物、花和树装点桌面 | 在乐园里右键 → **在桌面上显示** | [礼物](#gifts-on-the-desktop)、[花和树](#flowers-and-trees-on-the-desktop) |
| 和伙伴聊天 | 鼠标移上去，点名字 | [能做的事](#things-to-do-on-the-desktop) |
| 收回来 | 右键 → **从桌面移走** | [能做的事](#things-to-do-on-the-desktop) |
| 只藏起窗口、伙伴留着 | **伙伴与设置 → 关闭窗口** | [关闭、重新打开、退出](#close-reopen-and-quit) |
:::

## 开启和关闭 <Since v="0.1.0" /> {#turning-it-on-and-off}

一位伙伴：在乐园里右键点它，选**在桌面上显示**。出去时会打上勾，再选一次它就回来。每位伙伴各自出去，乐园里也还在。

所有伙伴一起：

1. 打开**伙伴与设置 → 窗口与桌面**。
2. 打开**在桌面上显示**。
3. 想让它们走动，再打开紧挨着的**在桌面散步**。桌面上有东西时才能用。

- 两个开关都显示当前状态，切换时菜单不会关上。
- 关闭**在桌面上显示**，伙伴、礼物、花和树都会回到乐园。
- 没有伙伴时，无法开启桌面模式。
- 托盘图标的菜单里也有同样的项目，不打开乐园窗口也能开关。

## 在桌面上能做的事 <Since v="0.1.0" /> {#things-to-do-on-the-desktop}

| 做什么 | 方法 |
|---|---|
| 抚摸 | 用左键点一下伙伴 |
| 移动 | 拖动伙伴再放下，也可以移到另一台显示器上 |
| 聊天 | 鼠标移到伙伴身上，下方出现带对话图标的名字。点名字，乐园会打开到那位伙伴的聊天 |
| 菜单 | 右键点伙伴，会出现**和它聊天**和**从桌面移走**。礼物、花和树有**从桌面移走** |
| 对视 | 在休息中的伙伴脸上移动鼠标，它的眼睛会跟着转。只有带 16 方向视线图的 v2 宠物可以 |

- 双击没有反应，这样移动伙伴时不会不小心打开窗口。
- 第一次把东西放到桌面上时，会提示你怎么聊天、怎么收回来。
- 名字只在鼠标移上去时才显示，伙伴们能自然地融进你的桌面。
- [编码代理](./agents.md)的状态和伙伴说的话，会以气泡浮在它头顶。话太长时，三行之后以“…”结尾。

## 桌面上的礼物 <Since v="1.5.0" /> {#gifts-on-the-desktop}

在乐园里右键点长椅、花盆这样的礼物，选**在桌面上显示**。礼物在乐园里也还在。

- 拖动就能挪动，也能移到另一台显示器上，放在哪儿就待在哪儿。
- 在桌面散步的伙伴时不时会走到礼物旁边，说上一句。
- 在乐园里收起礼物，它也会从桌面上消失。收到过的礼物可以从图鉴里再摆出来（[礼物](./play.md#gifts)）。
- 雪人和圣诞礼物只在乐园里显示时才出现在桌面上（[季节活动](./play.md#seasonal-events)）。雪人戴着围巾、帽子和鼻子，圣诞树挂着装饰。
- 到了[圣诞夜](./play.md#christmas-night)，桌面上的圣诞树也会和乐园里的一起长大。

## 桌面上的花和树 <Since v="1.6.1" /> {#flowers-and-trees-on-the-desktop}

在乐园里右键点你种下的花或树，选**在桌面上显示**。它在乐园里也还在。

- 在桌面上也和乐园里一样生长。放一株新芽出去，它会在桌面上开花。
- 长成的树会换上乐园当前显示的季节模样。
- 别的地点的树，不管乐园显示哪个地点，都会留在桌面上。
- 和礼物一样，拖动就能挪动。在桌面散步的伙伴时不时会走过去看看。
- 在乐园里拔掉或移除，它也会从桌面上消失。

## 在桌面散步 <Since v="0.1.0" /> {#stroll-on-desktop}

- 打开**在桌面散步**，伙伴们会在桌面上慢慢散步，朝着走的方向转身，偶尔停下来休息。
- 正被你拖着的时候不会走开。
- 关掉后，它们就待在你放下的位置。

## 每台显示器上都有伙伴 <Since v="0.1.0" />

- 有多台显示器时，伙伴可以待在任意一台上。拖过去放下，它就留在那里。
- 各台显示器的缩放比例不同也没关系，鼠标位置会按那台显示器的比例来对应。

## 在其他应用的全屏上面 <Since v="0.1.0" />

| 系统 | 伙伴浮在哪里 |
|---|---|
| macOS | 其他应用全屏时也在最上面。桌面窗口会变成一种特殊面板，全屏空间里也看得到 |
| Windows、Linux | 普通窗口上面 |
| Linux Wayland 会话 | 无法保证。Wayland 不给应用提供始终置顶或获知鼠标位置的方法，伙伴可能跑到其他窗口后面，也不会跟着鼠标看。点击和拖动伙伴也还没有验证过 |
| Linux X11 会话 | 普通窗口上面，也会跟着鼠标看 |

## 关闭、重新打开、退出 <Since v="0.1.0" /> {#close-reopen-and-quit}

| 想做的事 | 方法 | 结果 |
|---|---|---|
| 藏起窗口 | **伙伴与设置 → 关闭窗口**，或系统的关闭窗口快捷键 | 乐园藏进托盘，桌面上的伙伴和代理联动继续运行。在 macOS 上，Dock 图标也会消失，免得留下点了没反应的图标，重新打开乐园就回来。在 Windows 和 Linux 上，它会从任务栏消失 |
| 重新打开 | 点菜单栏（macOS）或任务栏（Windows、Linux）里的托盘图标 → **打开乐园**；点桌面上伙伴的名字，或在它的菜单里选**和它聊天**也可以 | 乐园窗口打开 |
| 退出 | **伙伴与设置 → 退出 PlayPets**、托盘菜单的**退出 PlayPets**，或在 macOS 上按 <kbd>⌘</kbd> <kbd>Q</kbd> | 立即退出，不再询问。聊过的对话不会保存，桌面上的伙伴们也会一起离开 |

- 所有系统都没有标题栏和窗口按钮。拖动顶部边缘狭窄的透明区域来移动，拖动边缘或角落调整大小，最小 300 × 210。
- 小窗口里，点右下角的按钮或右键空白背景，进入伙伴与设置。
- 退出后，伙伴的名字、性格、大小，以及哪些伙伴、礼物、花和树在桌面上，都会记住。
