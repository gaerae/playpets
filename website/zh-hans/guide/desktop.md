# 桌面模式

可以把伙伴们放到乐园窗口外面，让它们住在桌面上。在用别的应用工作时也能看到伙伴。

<Shot name="desktop" caption="桌面模式。伙伴住在其他窗口上面，用气泡显示编码代理的状态。" />

## 开启和关闭 <Since v="0.1.0" />

点乐园右上角、时钟旁边显示按钮中的**显示在桌面上**。一位伙伴都没有时，按钮是不可用的。它是一个开关：开启时按钮保持按下的样子（和托盘里的勾选一样），旁边会出现**走动**开关。再点一次，伙伴们就回来了。

托盘图标的菜单里也有同样的项目，不打开乐园窗口也能开启和关闭。

## 在桌面上能做的事 <Since v="0.1.0" />

| 做什么 | 方法 |
|---|---|
| 抚摸 | 用左键点一下伙伴 |
| 移动 | 拖动伙伴再放下。也可以移到另一台显示器上 |
| 聊天 | 把鼠标移到伙伴身上，下方会出现带对话图标的名字。点名字，乐园窗口就会打开到那位伙伴的聊天。用右键点伙伴也一样 |
| 对视 | 在休息中的伙伴脸上移动鼠标，它的眼睛会跟着鼠标走。只有带 16 方向视线图的 v2 宠物才可以 |

双击不会有任何反应，这样移动伙伴时不会不小心打开窗口。第一次打开桌面模式时，会有提示告诉你怎么聊天。

名字只在鼠标移上去时显示，让伙伴自然地融进你的桌面。[编码代理](./agents.md)的状态和伙伴说的话会以气泡的形式浮在头顶，长的话在三行后以“…”结尾。

## 每台显示器上都有伙伴 <Since v="0.1.0" />

有多台显示器时，伙伴可以在任意一台上。拖着它到另一台显示器，它就会留在那里。即使每台显示器的缩放比例不同，鼠标位置也会按那台显示器的比例来对应。

## 在桌面上走动 <Since v="0.1.0" />

打开**在桌面上走动**开关后，伙伴们会在桌面上慢慢走动。它们会朝着走的方向转身，偶尔停下来休息。关掉后就停在你放下它们的位置不动。拖动的时候不会走动。

## 在其他应用的全屏上面 <Since v="0.1.0" />

在 macOS 上，即使其他应用处于全屏，伙伴也会浮在上面。桌面窗口被做成了一种特殊面板，所以在全屏空间里也能看到。在 Windows 和 Linux 上，它浮在普通窗口上面。Linux 的 Wayland 会话不给应用提供让窗口始终置顶或获知鼠标位置的方法，所以伙伴可能跑到其他窗口后面，也不会跟着鼠标看。X11 会话下一切正常。

## 关掉窗口后还在 <Since v="0.1.0" />

乐园窗口的关闭按钮不会退出应用，只是隐藏窗口。把鼠标放到关闭按钮上，会提示“关闭（可从托盘重新打开）”。桌面上的伙伴们原样留着，代理联动也继续运行。

- 在 macOS 上，关掉窗口后 Dock 图标也会一起消失，这是为了不在 Dock 里留下一个点了没反应的图标。重新打开乐园，Dock 图标也会回来。
- 在 Windows 和 Linux 上，它会从任务栏消失，只留在托盘里。

## 重新打开的方法

- 点菜单栏（macOS）或任务栏（Windows、Linux）里的托盘图标，选**打开乐园**。
- 点桌面上伙伴的名字（或用右键点伙伴），也会打开乐园窗口。

## 完全退出

要真正退出应用，在托盘菜单里选**退出**，或者点设置标签底部的**完全退出应用**。聊过的对话不会保存，桌面上的伙伴们也会一起消失。伙伴的名字、性格、大小，以及桌面模式是否开着，都会被记住，下次打开时还是原样。
