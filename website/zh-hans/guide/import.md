# 导入宠物

- 宠物是角色文件。
- 应用自带的宠物和 Codex 宠物文件夹（`~/.codex/pets`）里的宠物会自动出现在邀请伙伴里。
- 其他宠物需要导入。

## 用链接一键导入 <Since v="0.1.0" />

1. 宠物画廊里有**在 PlayPets 中打开**这样的链接时，点一下。
2. 装了 PlayPets 的话，它会问“要导入这只宠物吗？”，并显示链接来自哪个站点。
3. 确认后导入那只宠物，再打开邀请伙伴。

- 链接形式是 `playpets://import?url=<宠物页面地址>`。
- 运营画廊的话，请在宠物页面上加上这个链接。

```text
playpets://import?url=https%3A%2F%2Fpetdex.dev%2Fpets%2Fboba
```

## 导入宠物窗口 <Since v="0.1.0" />

点**邀请伙伴**上方的**导入宠物**打开窗口。两种方法：

- 在**宠物页面地址**里粘贴社区站点的宠物页面地址或 GitHub 宠物文件夹地址，点**导入**。
- 点**从本机文件夹导入**，选一个宠物文件夹。

导入后：

- 那只宠物会立刻作为伙伴邀请到乐园，并提示“已导入新宠物并邀请到乐园。”。
- 文件只从 https 地址下载，且只从你粘贴的地址所在的站点（及其子域名）下载。
- 宠物页面指向其他站点上的文件时，不会导入。

## 支持的站点 <Since v="0.1.0" />

- **发现更多宠物**默认折叠，方便找到地址输入框和导入按钮。展开后显示紧凑的站点列表和导入说明。
- 打开站点，把喜欢的宠物页面地址复制到上面的输入框即可。
- 这些是社区链接，列出站点不代表合作关系。

| 站点 | 站点地址 |
|---|---|
| OpenPets Registry | openpets.sh |
| Petdex | petdex.dev |
| Codex PokéPets | github.com/dnnyngyen/codex-pokepets |
| Awesome Codex Pet | codexpet.top |
| Codex Pets | codex-pets.net |

- 不在表里也能导入：
  - GitHub 上宠物文件夹（含 `pet.json` 的文件夹）的地址
  - 用 codex-pet-share 搭建的站点上的宠物页面地址
- 以上站点有专门的导入支持。
- 标记为**（仅浏览）**的发现站点没有专门的导入器，但兼容的通用宠物页面仍可能通过粘贴地址导入。
- 只添加站点链接，不会自动增加导入支持。
- 地址不对或站点没有响应时，窗口里会显示原因。
- 导入过程中无法关闭窗口。

## 本机的文件夹 <Since v="0.1.0" />

- 用**从本机文件夹导入**选的文件夹不会被复制，应用直接读取原位置。
- 所以它显示在邀请伙伴的**从本机选择的宠物**分组里，带着文件夹名。
- 制作套件生成的 ZIP，先解压到长期保存的位置，再选文件夹。
- 使用期间请勿移动或删除所选文件夹。

::: warning 移动了文件夹，伙伴会等着
- 伙伴靠宠物文件夹的路径识别宠物。
- 移动或删除了选中的文件夹（或拔掉了它所在的硬盘），下次打开应用时，那只宠物的伙伴就没法来到乐园。
- 它不会被删除，而是带着原来的亲密度等着，并有提示告诉你有几位伙伴在等。
- 把文件夹放回原位，它就会回来。
:::

## 保存在哪里 <Since v="0.1.0" />

- 通过地址导入的宠物，作为一个文件夹保存在[数据文件夹](./install.md#数据文件夹)的 `pets/` 里。
- **通过地址导入的宠物**、**PlayPets 自带宠物**、**Codex 宠物文件夹**分组都有**打开文件夹**按钮。
- **从本机选择的宠物**分组没有这个按钮，而是在每张卡片上写着文件夹名。
- 导入的宠物的 `pet.json` 会记录来源。卡片上用一行显示站点、作者和许可，比如“Petdex, 作者, CC BY-NC 4.0”。
- 社区宠物是各位作者的作品，请确认许可后再使用。
- 不再用的宠物，删掉 `pets/` 里对应的文件夹就行。
  - 用它做的伙伴会像上面说的那样，从下次启动起在乐园外等着。
  - 也不想要这位伙伴的话，先把它送走。

## 自己制作

- 一只宠物就是一个文件夹，里面有 `pet.json` 和一张精灵图（PNG 或 WebP）。
- 格式和 Codex 宠物相同，为 Codex 制作的宠物可以直接用。

```json
{
  "id": "white",
  "displayName": "White",
  "kind": "animal",
  "description": "A puppy.",
  "spriteVersionNumber": 2,
  "spritesheetPath": "spritesheet.webp"
}
```

| 项目 | 规格 |
|---|---|
| 精灵图 | 宽 1536px，每格 192×208px，每行 8 格 |
| v1 | 9 行（1872px）：休息、向右走、向左走、挥手、跳跃、出错、等待、工作、完成 |
| v2 | 11 行（2288px）：多两行 16 方向的视线，在桌面上会用眼睛跟着鼠标 |

- `description` 会成为新伙伴最初的性格。
- 各行的动画和检查规则见开发者文档[宠物文件格式](/dev/standards/pet-files)。
- 做好的文件夹用**从本机文件夹导入**直接邀请。
