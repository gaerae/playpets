# 导入宠物

宠物就是角色文件。应用自带的宠物和 Codex 宠物文件夹（`~/.codex/pets`）里的宠物，会自动出现在邀请伙伴里。其他宠物需要导入。

## 用链接一键导入 <Since v="0.1.0" />

1. 在宠物画廊里看到**在 PlayPets 中打开**这类链接，点一下。链接形式是 `playpets://import?url=<宠物页面地址>`。
2. 装了 PlayPets 的话，它会问“要导入这只宠物吗？”，并显示链接来自哪个站点。
3. 确认后就会导入这只宠物，再打开邀请伙伴。

如果你在运营画廊，请在宠物页面上加上这个链接：

```text
playpets://import?url=https%3A%2F%2Fpetdex.dev%2Fpets%2Fboba
```

## 导入宠物窗口 <Since v="0.1.0" />

点**邀请伙伴**上方的**导入宠物**打开窗口。有三种方法：

- 在**宠物页面地址**里粘贴社区站点的宠物页面地址或 GitHub 宠物文件夹地址，点**导入**。
- 点**从本机文件夹导入**，选一个宠物文件夹。
- 点**从本机 ZIP 文件导入**，选一个宠物 ZIP，比如制作套件生成的 ZIP。

导入完成后，这只宠物会马上作为伙伴被邀请到乐园，并提示“已导入新宠物并邀请到乐园。”

- 文件只从 https 地址下载，而且只从你粘贴的地址所在的站点（及其子域名）下载。
- 宠物页面指向其他站点上的文件时，不会导入。

## 支持的站点 <Since v="0.1.0" />

**发现更多宠物**默认是折叠的，这样地址输入框和导入按钮更好找。展开后能看到紧凑的站点列表和导入说明。打开站点，把喜欢的宠物页面地址复制到上面的输入框就行。

这些是社区链接，列出某个站点并不代表有合作关系。

| 站点 | 站点地址 |
|---|---|
| OpenPets Registry | openpets.sh |
| Petdex | petdex.dev |
| Codex PokéPets | github.com/dnnyngyen/codex-pokepets |
| Awesome Codex Pet | codexpet.top |
| Codex Pets | codex-pets.net |

以上站点有专门的导入支持。不在表里的地方也能导入：

- GitHub 上宠物文件夹（含 `pet.json` 的文件夹）的地址
- 用 codex-pet-share 搭建的站点上的宠物页面地址

标着“**（仅浏览）**”的发现站点没有专门的导入器，不过兼容的通用宠物页面，粘贴地址后仍可能导入。只在列表里加上站点链接，并不会因此多出导入支持。

- 地址不对或者站点没有响应时，窗口里会显示原因。
- 导入过程中不能关闭窗口。

## 本机的文件夹 <Since v="0.1.0" />

用**从本机文件夹导入**选的文件夹不会被复制，应用直接在原位置读取。所以它会出现在邀请伙伴的**从本机选择的宠物**分组里，并带着文件夹名。

制作套件生成的 ZIP 不用解压，按下面的 [ZIP 文件](#zip-文件)导入即可。用文件夹选的宠物没有副本，请把那个文件夹放在长期保存的位置，使用期间不要移动或删除。

::: warning 移动了文件夹，伙伴会等着
伙伴是靠宠物文件夹的路径认出自己的宠物的。如果移动或删除了选中的文件夹（或者拔掉了它所在的硬盘），下次打开应用时，这只宠物的伙伴就没法来到乐园。

不过它不会被删掉，而是带着原来的亲密度等着，还会有提示告诉你有几位伙伴在等。把文件夹放回原处，它就会回来。
:::

## ZIP 文件 <Since v="1.4.0" />

用**从本机 ZIP 文件导入**选的 ZIP 会被复制进应用，所以导入后移动或删除 ZIP 都没关系。它会出现在邀请伙伴的**通过地址或 ZIP 导入的宠物**分组里。

- 制作套件的 ZIP 可以，自己把宠物文件夹压缩成的 ZIP 也可以。`pet.json` 要放在 ZIP 的最上层，或其中唯一的文件夹里。
- 同一个 ZIP 再导入一次也只有一份。内容变了的 ZIP 会作为新宠物出现在原来那只旁边。

## 保存在哪里 <Since v="0.1.0" />

通过地址或 ZIP 导入的宠物，会作为一个文件夹保存在[数据文件夹](./install.md#数据文件夹)的 `pets/` 里。

- **通过地址或 ZIP 导入的宠物**、**PlayPets 自带宠物**、**Codex 宠物文件夹**这几个分组都有**打开文件夹**按钮。
- **从本机选择的宠物**分组没有这个按钮，而是在每张卡片上写着文件夹名。

导入的宠物会在 `pet.json` 里记下来源。卡片上用一行显示站点、作者和许可，比如“Petdex, 作者, CC BY-NC 4.0”。社区宠物是各位作者的作品，使用前请先确认许可。

## 删除宠物 <Since v="1.4.0" />

自己带进来的宠物，在邀请伙伴里的卡片旁边有一个垃圾桶按钮。

- 通过地址或 ZIP 导入的宠物：`pets/` 里对应的文件夹会被删除。想再用时重新导入。
- 从本机选择的宠物：只是从列表里移除，文件夹留在原处。
- 用这只宠物邀请的伙伴还在乐园里时，不能删除。请先把它们送走。
- 因乐园满了而之后才回来的伙伴还在用这只宠物时，也不能删除。会告诉你是哪位伙伴。

PlayPets 自带宠物和 Codex 宠物文件夹里的宠物没有垃圾桶按钮。

## 自己制作

一只宠物就是一个文件夹，里面放着 `pet.json` 和一张精灵图（PNG 或 WebP）。格式和 Codex 宠物一样，为 Codex 做的宠物可以直接用。

```json
{
  "id": "white",
  "displayName": "White",
  "kind": "animal",
  "description": "A puppy.",
  "spriteVersionNumber": 2,
  "spritesheetPath": "spritesheet.webp"
}
```

| 项目 | 规格 |
|---|---|
| 精灵图 | 宽 1536px，每格 192×208px，每行 8 格 |
| v1 | 9 行（1872px）：休息、向右走、向左走、挥手、跳跃、出错、等待、工作、完成 |
| v2 | 11 行（2288px）：多两行 16 方向的视线，在桌面上会用眼睛跟着鼠标 |

- `description` 会成为新伙伴最初的性格。
- 各行的动画和检查规则见开发者文档[宠物文件格式](/dev/standards/pet-files)。

做好的文件夹，用**从本机文件夹导入**就能直接邀请。
