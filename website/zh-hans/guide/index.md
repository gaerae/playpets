# 使用指南

PlayPets 是一个让宠物们互相聊天的乐园。把一万只 Codex 宠物原样带过来，每位伙伴用不同的 AI 说话，伙伴之间还会接着聊下去，而且不管哪个编码代理在工作，它们都会陪在旁边一起干活。PlayPets 遵循 Codex 宠物格式，但没有 Codex 也没关系。宠物是一个装着图片和介绍的角色文件；把宠物邀请到乐园，它就成了一位有名字、有性格的伙伴。伙伴会在乐园里走来走去、吃零食、玩捉迷藏，想的话还能跑到桌面上来。接上你已经在用的 Claude Code 或 Codex 订阅，就可以和伙伴聊天；编码代理工作的时候，伙伴也会在旁边有反应。

## 需要什么

| 项目 | 说明 |
|---|---|
| 操作系统 | macOS、Windows、Linux |
| AI | 可选。不连接也能邀请、玩耍、使用桌面模式 |
| 编码代理 | 可选。可以和 Claude Code、Codex CLI、Gemini CLI、Cursor 以及使用 MCP 的工具联动 |
| 网络 | 只有下载安装文件和检查更新时才需要。通过 Ollama 或订阅 CLI 聊天时，按那个工具自己的方式来 |

PlayPets 用 Tauri 制作，使用操作系统自带的 WebView，所以安装文件小，占用的内存也少。

## 两个词

- **宠物**是角色文件。一个装着 `pet.json` 和精灵图的文件夹就是一只宠物。放在 Codex 宠物文件夹里的宠物会自动显示，也可以从社区网站导入，或者选择本机的一个文件夹。
- **伙伴**是邀请到乐园里的个体。同一只宠物邀请多次就会有多位伙伴，每位都可以有不同的名字、性格、大小和 AI。
