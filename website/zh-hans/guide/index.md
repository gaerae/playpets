# 使用指南

PlayPets 是一个大家共同的乐园，伙伴们会和你聊天，也会彼此聊天。邀请内置角色，或导入兼容的社区宠物文件，再给它定好名字、性格和关系就行。不需要安装 Codex。

第一次打开时，乐园是晴朗的春日。季节、时段和天气可以自己选，也可以交给自动。伙伴们会散步、吃零食，还会玩三种游戏。挖挖土，就能找到花种和树苗。

礼物按本地日期算，整个乐园每天最多一件，所有伙伴共用这一次。种花、钓鱼、捉虫，把图鉴慢慢填满，你和伙伴也会越来越亲近。

把窗口调小，乐园就能陪在你的工作旁边；切到桌面模式，伙伴还会跑到其他窗口上面。

想聊天，需要本地模型、已登录的 CLI 或其他 AI 连接。编码代理联动是可选的。

## 需要什么

| 项目 | 说明 |
|---|---|
| 操作系统 | macOS、Windows、Linux |
| AI | 可选。不连接也能邀请、玩耍、使用桌面模式 |
| 编码代理 | 可选。可以和 Claude Code、Codex CLI、Gemini CLI、Cursor、Grok Build 以及使用 MCP 的工具联动 |
| 网络 | 下载、导入社区宠物、更新和使用远程 AI 时需要。乐园里的活动和已下载到本机的 Ollama 模型可以离线使用 |

PlayPets 用 Tauri 制作，直接使用操作系统自带的 WebView，不会捆绑一整个浏览器。

## 两个词

宠物是角色文件。一个装着 `pet.json` 和精灵图的文件夹，就是一只宠物。Codex 宠物文件夹里的宠物会自动显示，你也可以从社区网站导入，或者选择本机的某个文件夹。

伙伴是你邀请进乐园的宠物。同一只宠物邀请几次，就会有几位伙伴，每位都可以有自己的名字、性格、大小和 AI。
