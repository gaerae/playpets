# 使用指南

PlayPets 是伙伴们一起住的乐园，伙伴会和你聊天，也会彼此聊天。邀请内置角色，或导入兼容的社区宠物文件，再定好名字、性格和关系就行。不需要安装 Codex。

## 能做什么

| 事情 | 一句话 | 页面 |
|---|---|---|
| 邀请伙伴 | 自带四位伙伴，Codex 宠物也能加入，最多 12 位 | [第一位伙伴](./first-friend.md) |
| 聊天 | 需要本地模型、已登录的 CLI 或其他 AI 连接 | [和伙伴聊天](./chat.md) |
| 在乐园里玩 | 第一次打开是晴朗的春日。季节、时段和天气可以自己选，也可以交给自动。伙伴们会散步、吃零食，还会玩四种游戏（其中一种只在冬天） | [乐园和游戏](./play.md) |
| 种花和收集 | 挖土能找到花种和树苗。种花、钓鱼、捉虫，把图鉴慢慢填满 | [乐园和游戏](./play.md) |
| 礼物和亲密度 | 一起玩的伙伴会送来礼物：整个乐园每两天一件，伙伴和你更亲近时还会再送一件 | [礼物](./play.md#gifts) |
| 陪在工作旁边 | 把窗口调小放在工作旁边，或切到桌面模式，让伙伴跑到其他窗口上面 | [桌面模式](./desktop.md) |
| 编码代理 | 联动是可选的。代理工作时伙伴会做出反应 | [编码代理联动](./agents.md) |

## 需要什么

| 项目 | 说明 |
|---|---|
| 操作系统 | macOS、Windows、Linux |
| AI | 可选。不连接也能邀请、玩耍、使用桌面模式 |
| 编码代理 | 可选。可以和 Claude Code、Codex CLI、Gemini CLI、Cursor、Grok Build、Qoder、Kimi Code 以及使用 MCP 的工具联动 |
| 网络 | 下载、导入社区宠物、更新和使用远程 AI 时需要。乐园里的活动和已下载到本机的 Ollama 模型可以离线使用 |

PlayPets 用 Tauri 制作，直接使用操作系统自带的 WebView，不会捆绑一整个浏览器。

## 两个词

| 词 | 意思 |
|---|---|
| 宠物 | 角色文件。一个装着 `pet.json` 和精灵图的文件夹，就是一只宠物。Codex 宠物文件夹里的宠物会自动显示，也可以从社区网站导入，或者选择本机的某个文件夹 |
| 伙伴 | 你邀请进乐园的宠物。同一只宠物邀请几次，就有几位伙伴，每位都可以有自己的名字、性格、大小和 AI |

## 开始使用

1. 安装 PlayPets（[安装](./install.md)）并打开。乐园会问**想和谁一起玩？**
2. 在四位伙伴里点一位。它会来到乐园，向你挥手。再点它一下就是摸摸，它会跳起来，冒出爱心。
3. 连接 AI。如果这台电脑上有 Claude Code 或 Codex CLI，在**接下来**卡片上点**立即连接**。没有的话，按[创建连接](./chat.md#创建连接)操作。然后点伙伴的名牌打个招呼，回答会出现在聊天里，也会在乐园里以气泡显示。
4. 可选：打开**伙伴与设置 → 设置 → 编码工具连接**，点你所用工具旁边的**连接**并确认，再在代理里开始新的会话。代理工作时，伙伴名牌上名字旁边的小点会闪橙色（[编码代理联动](./agents.md)）。

遇到问题时，请看[常见问题里的表格](./faq.md#troubleshooting)。
