# 使用指南

PlayPets 是伙伴们与你聊天、也互相聊天的共同乐园。邀请内置角色，或导入兼容的社区宠物文件，再设定名字、性格和关系。不需要安装 Codex。

初次打开的是晴朗的春日乐园。可以选择季节、时段和天气，也可以切换为自动。伙伴会散步、吃零食、玩三种游戏。花种和树苗通过挖土获得。按本地日期，整个庭院每天最多收到一件礼物，所有伙伴共享次数。种花、钓鱼、捉虫来填满图鉴，慢慢变得亲近。小窗口让乐园陪在工作旁边；桌面模式让伙伴出现在其他窗口上。聊天需要本地模型、已登录的 CLI 或其他 AI 连接。编码代理联动是可选功能。

## 需要什么

| 项目 | 说明 |
|---|---|
| 操作系统 | macOS、Windows、Linux |
| AI | 可选。不连接也能邀请、玩耍、使用桌面模式 |
| 编码代理 | 可选。可以和 Claude Code、Codex CLI、Gemini CLI、Cursor 以及使用 MCP 的工具联动 |
| 网络 | 下载、导入社区宠物、更新和使用远程 AI 时需要。院子里的活动和已下载到本机的 Ollama 模型可以离线使用 |

PlayPets 用 Tauri 制作，使用操作系统的 WebView，不在应用内捆绑完整浏览器。

## 两个词

- **宠物**是角色文件。一个装着 `pet.json` 和精灵图的文件夹就是一只宠物。放在 Codex 宠物文件夹里的宠物会自动显示，也可以从社区网站导入，或者选择本机的一个文件夹。
- **伙伴**是邀请到乐园里的个体。同一只宠物邀请多次就会有多位伙伴，每位都可以有不同的名字、性格、大小和 AI。
