# 和伙伴聊天

不连接 AI 也能邀请伙伴、一起玩，但要聊天就得先连接一个 AI。还没连接时，聊天窗口会显示「准备好一起玩了！想聊天的时候请连接 AI。」和**连接 AI** 按钮。

## AI 连接的种类 <Since v="0.1.0" />

| 种类 | 怎么聊 | 费用和数据 |
|---|---|---|
| Claude Code | 用本机已登录的 Claude Code | 订阅登录使用套餐额度，API 密钥登录按 API 计费 |
| Codex CLI | 用本机已登录的 Codex CLI | ChatGPT 登录使用套餐额度，API 密钥登录按 API 计费 |
| Ollama | 通过 `http://127.0.0.1:11434` 的 Ollama 使用模型 | 本地模型的对话留在本机，没有托管推理费用；云端模型遵循该服务的条款 |
| OpenAI API | 用 API 密钥连接 OpenAI | 对话内容会发送给 OpenAI，可能产生 API 费用 |
| Grok API | 用 xAI API 密钥连接 Grok | 对话内容会发送给 xAI，可能产生 API 费用 |
| OpenAI 兼容服务器 | 自己填服务器地址，服务器要求时再填 API 密钥 | 对话内容会发送到那台服务器，可能产生费用 |

连接窗口把每种 AI 显示成一张卡片，写明需要什么。如果在本机找到 Claude Code、Codex CLI 或 Ollama，对应的卡片会标上**已安装**并预先选好。一个都没找到时什么也不预选，选了卡片才会出现输入框。

- API 密钥只保存在本机的安全存储里（macOS 钥匙串、Windows 凭据管理器、Linux Secret Service），不会写进设置文件。
- 用订阅登录时，CLI 聊天不会另外产生 API 账单。
  - 不过它和你其他的 CLI 工作共用同一份额度，套餐限制照样适用。
  - 自己额外购买的点数可能要付费。
- 想离线聊天，就选已下载的本地 Ollama 模型。Ollama 云端模型仍会把对话发送到相应的服务。

## 创建连接 <Since v="0.1.0" />

1. 从**伙伴与设置 → 伙伴与聊天**打开**伙伴**面板，选要聊天的伙伴。伙伴有好几位时，名字的位置会变成列表。
2. 点聊天窗口里的**连接 AI**，或在输入框左下方的 AI 列表里选**＋ 连接新的 AI…**。
3. 在 **AI 类型**里选一张卡片，再按类型填服务器地址或 API 密钥。
4. 选择或填写**模型名称**。
   - 点输入框会列出那个 AI 提供的模型。需要密钥或地址的种类，要先填好才会列出。
   - Claude Code 和 Codex CLI：留空就用默认模型。填 `sonnet` 这样的短名称，会一直连到最新版本。
   - Ollama 和 API 连接必须填模型名称。
5. 点**保存并连接**。如果还有别的伙伴没有 AI，「让另外几位还没有 AI 的伙伴也用这个 AI」开关是开着的，大家一下子都能说话了。

不先连接也没关系。给还没有 AI 的伙伴写句话，点发送就会打开连接窗口，连好后那句话就发出去了。

第一次启动时，如果本机装有 Claude Code 或 Codex CLI，乐园的开始卡片会显示它的名字。点一次**立即连接**就给所有伙伴接上，不需要密钥。伙伴有两位以上的话，连好后它们马上就会互相聊起来。

连接不只属于某一位伙伴。你创建的连接，其他伙伴也能用；在每位伙伴的 AI 列表里选不同的连接，它们就各用各的 AI。

- 修改或删除连接，可以从这两个地方打开：
  - 名字旁 **⋯** 菜单里的 **AI 连接设置**。从这里打开的连接会给这位伙伴使用。
  - **伙伴与设置 → 设置 → 伙伴与 AI**里那个连接的**编辑**。这里列出所有连接，点**连接 AI**可以新建。表单就在这个分区里展开，在这里修改不会把任何伙伴换到这个连接上。
- 删除前会先确认。保存的密钥会一起删除，原来用这个连接聊天的伙伴会在没有 AI 的状态下继续玩。

## 聊天 <Since v="0.1.0" />

- 在下方输入框打字，按 Enter 发送，Shift+Enter 换行。

伙伴接上 AI、你们还没开始聊时，会出现几句开场白，比如「今天做了什么？」，点一下就直接发出去。

和聊天软件一样，伙伴每次开口都带着它的头像。等回答时会出现「正在思考」气泡，按 ■ 按钮可以停下。回答也会以气泡浮在乐园里伙伴的头上。

- 在名字旁的 **⋯** 菜单里选**清空对话**，会清除和这位伙伴的全部对话。名字和性格保留。
- 对话记录只在内存里，关掉应用就没了，不会存成文件。
- 对话框里每位伙伴最多保留最近 500 条消息。伙伴回答时会记得其中最近的 24 条。

## 设定性格 <Since v="0.1.0" />

性格就是伙伴回答时的语气和态度，有两种设定方法：

| 方法 | 怎么做 |
|---|---|
| 在伙伴设置里直接写 | 写「傲娇但经不起夸。回答简短随意。」这样的话就行。保存后从下一次对话开始生效 |
| 在聊天中说 | 说「以后说话随意点」之类的话，伙伴会把它保存为性格。会弹出「已保存伙伴的性格」，可以在伙伴设置里查看 |

## 设定关系 <Since v="0.1.0" />

在伙伴设置的**关系**里，选这位伙伴对你来说是什么人。每张关系卡片上都写着它会用什么语气：

- 朋友（默认）
- 恋人
- 可靠的前辈
- 调皮的弟弟妹妹

伙伴面板里名字旁有个关系标签，点一下就能打开这些卡片，直接换掉。

关系会影响伙伴对你说话的语气、怎么称呼你，以及怎么问你今天过得如何。伙伴之间聊天时也知道彼此的关系。就算没有 AI，恋人、前辈和弟弟妹妹在迎接你回来、和你变得更亲近、说出你对它有多重要时，也都有自己的语气。

在**对我的称呼**里写「亲爱的」或你的名字，它就会这样叫你。输入框里的示例会随关系变化。

Codex 宠物里有很多人形角色，很适合设成恋人或前辈。关系里能说到什么程度，不由应用决定，而是遵循你所连接的 AI 的政策。

## 一起聊天 <Since v="0.1.0" />

接上 AI 的伙伴有两位以上时，输入框下方会出现**叫上伙伴**。

1. 展开后点要一起聊的伙伴，最多选 3 位。
2. 发送消息后，当前伙伴先回答，选中的伙伴们再依次接着回答。每位都用自己的 AI 和性格说话。
3. 想让伙伴们不等新消息、自己接着聊，就点**玩耍 → 一起玩**里的**聊聊天**。接上 AI 的伙伴们会围绕此刻的时间和天气聊一轮，以气泡显示在乐园里。

伙伴名字下方的小标签，显示哪些编码代理在向它汇报（负责，Claude Code）。在乐园里，伙伴们互相聊天的话会以气泡显示。

## 「刚才在做什么？」 <Since v="0.1.0" />

做好[编码代理联动](./agents.md)后，伙伴会记住代理最近做过的事。在聊天中问「刚才在做什么？」，它会用自己的话讲讲那些工作。

联动和聊天用的 AI 连接是分开运作的。
