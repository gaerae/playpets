# 和伙伴聊天

要和伙伴聊天，需要先连接一个 AI。不连接也能邀请、玩耍，但聊天窗口只会显示「连接 AI 后就可以聊天了」。

<Shot name="friend-chat" caption="在伙伴标签里选 AI、聊天。一起聊天的伙伴也在这里选。" />

## AI 连接的种类 <Since v="0.1.0" />

| 种类 | 怎么聊 | 费用和数据 |
|---|---|---|
| Claude Code | 用本机已登录的 Claude Code | 没有额外的 API 费用 |
| Codex CLI | 用本机已登录的 Codex CLI（ChatGPT 套餐） | 没有额外的 API 费用 |
| Ollama | 用安装在 `http://127.0.0.1:11434` 的 Ollama 上的模型 | 对话只在本机内处理 |
| OpenAI API | 用 API 密钥连接 OpenAI | 对话内容会发送给 OpenAI，可能产生 API 费用 |
| OpenAI 兼容服务器 | 自己填服务器地址和 API 密钥 | 对话内容会发送到那台服务器，可能产生费用 |

连接窗口会把每种 AI 显示成卡片，并写明需要什么。本机找到的种类（Claude Code、Codex CLI、Ollama）会标上**已安装**并预先选好；什么都没找到时不会预选，选了卡片后才会出现需要填写的输入框。

API 密钥只保存在本机的安全存储里（macOS 钥匙串、Windows 凭据管理器、Linux Secret Service），不会写进设置文件。

## 创建连接 <Since v="0.1.0" />

1. 打开**伙伴**标签，选要聊天的伙伴。伙伴有好几位时，名字的位置会变成一个列表。
2. 点聊天窗口里的**连接 AI** 按钮，或者在输入框左下方的 AI 列表里选**＋ 连接新的 AI…**。
3. 在 **AI 类型**里选一张卡片，再按类型填入服务器地址或 API 密钥。
4. 选择或填写**模型名称**。点输入框会列出那个 AI 提供的模型（需要密钥或地址的种类，要先填好）。Claude Code 和 Codex CLI 留空则使用默认模型，用 `sonnet` 这样的短名称会始终连接最新版本。Ollama 和 API 连接需要填模型名称。
5. 点**保存并连接**。如果还有其他伙伴没有 AI，「也给还没有 AI 的另外几位伙伴用这个 AI」开关会是开着的，这样大家一次就都能说话了。

没有 AI 的伙伴也可以先写话：发送时会打开连接窗口，连上后那句话就会发出去。第一次启动时，如果本机有 Claude Code 或 Codex CLI，乐园的开始卡片会显示它的名字，点一次**立即连接**就能给所有伙伴接上，不需要密钥。伙伴有两位以上时，连接之后他们就会开始互相聊天。

创建过的连接，其他伙伴也可以一起用。在每位伙伴的 AI 列表里选不同的连接，就能让每位伙伴用不同的 AI 聊天。要修改或删除连接，点 AI 列表旁边的齿轮按钮。删除连接时保存的密钥也会一起删除，用那个连接聊天的伙伴就会变成没有 AI 地玩耍。

## 聊天 <Since v="0.1.0" />

- 在下方的输入框里写字，按 Enter。Shift+Enter 是换行。
- 还没开始聊天时，点一下显示的开场白（比如「今天做了什么？」）就能直接发送。
- 等待回答时会看到「正在思考」气泡，可以用 ■ 按钮停止。
- 回答也会以气泡的形式浮在乐园里的伙伴头上。
- 在名字旁的 **⋯** 菜单里选**清空对话**，会清除和这位伙伴的全部对话。名字和性格会保留。

对话记录只在内存里。关掉应用就没了，不会保存成文件。

## 设定性格 <Since v="0.1.0" />

性格是伙伴回答时的语气和态度。有两种设定方法。

- **在伙伴设置里直接写。**像「傲娇但经不起夸。回答简短随意。」这样写就行。保存后从下一次对话开始生效。
- **在聊天中说。**说「以后说话随意点」之类的话，伙伴就会把它保存为性格。会弹出「已保存伙伴的性格」的通知，可以在伙伴设置里查看。

## 设定关系 <Since v="0.1.0" />

在伙伴设置的**关系**里选这位伙伴和我是什么关系：朋友（默认）、恋人、可靠的前辈、调皮的弟弟妹妹，四选一。设定关系后，语气、称呼和问候的方式都会不同，伙伴之间聊天时也知道彼此的关系。在**对我的称呼**里写上「亲爱的」或名字，它就会这样叫你。Codex 宠物里人形角色很多，很适合设成恋人或前辈。表达的尺度不由应用决定，而是遵循所连接 AI 的政策。

## 一起聊天 <Since v="0.1.0" />

接上 AI 的伙伴有两位以上时，输入框下方会出现**叫上伙伴**。

1. 展开后点要一起聊的伙伴。最多可以选 3 位。
2. 发送消息后，当前伙伴先回答，选中的伙伴们依次接着回答。每位都用自己的 AI 和性格说话。
3. 想让伙伴们不靠新消息自己接着聊，点乐园工具栏的**聊聊天**。接上 AI 的伙伴们会围绕此刻的时间和天气聊上一轮，在乐园里以气泡显示。

伙伴名字下方的小标签显示哪个编码代理在向这位伙伴汇报（负责 · Claude Code）。

在乐园里能看到伙伴们用气泡互相聊天的样子。

## 「刚才在做什么？」 <Since v="0.1.0" />

做好[编码代理联动](./agents.md)后，伙伴会记住代理最近做过的事。在聊天中问「刚才在做什么？」，它就会用自己的话讲讲那些工作。联动和聊天用的 AI 连接是分开运作的。
