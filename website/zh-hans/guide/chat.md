# 和伙伴聊天

- 和伙伴聊天，要先连接一个 AI。
- 不连接也能邀请、玩耍。这时聊天窗口显示「准备好一起玩了！想聊天的时候请连接 AI。」和**连接 AI** 按钮。

## AI 连接的种类 <Since v="0.1.0" />

| 种类 | 怎么聊 | 费用和数据 |
|---|---|---|
| Claude Code | 用本机已登录的 Claude Code | 订阅登录使用套餐额度，API 密钥登录按 API 计费 |
| Codex CLI | 用本机已登录的 Codex CLI | ChatGPT 登录使用套餐额度，API 密钥登录按 API 计费 |
| Ollama | 通过 `http://127.0.0.1:11434` 的 Ollama 使用模型 | 本地模型的对话留在本机，无托管推理费用；云端模型遵循服务条款 |
| OpenAI API | 用 API 密钥连接 OpenAI | 对话内容会发送给 OpenAI，可能产生 API 费用 |
| OpenAI 兼容服务器 | 自己填服务器地址和 API 密钥 | 对话内容会发送到那台服务器，可能产生费用 |

- 连接窗口把每种 AI 显示成卡片，写明需要什么。
- 本机找到的种类（Claude Code、Codex CLI、Ollama）会标上**已安装**并预先选好。
- 什么都没找到时不预选；选了卡片后才出现要填的输入框。
- API 密钥只保存在本机的安全存储里（macOS 钥匙串、Windows 凭据管理器、Linux Secret Service），不写进设置文件。
- 订阅登录的 CLI 聊天不另付 API 账单，但和其他 CLI 工作共用额度。
- 套餐限制仍然适用，主动购买额外点数也可能产生费用。
- 想离线聊天，选已下载的本地 Ollama 模型。Ollama 云端模型的对话仍会发送到相应服务。

## 创建连接 <Since v="0.1.0" />

1. 从**伙伴与设置 → 伙伴与聊天**打开**伙伴**面板，选要聊天的伙伴。伙伴有好几位时，名字的位置会变成列表。
2. 点聊天窗口里的**连接 AI**，或在输入框左下方的 AI 列表里选**＋ 连接新的 AI…**。
3. 在 **AI 类型**里选一张卡片，再按类型填服务器地址或 API 密钥。
4. 选择或填写**模型名称**。
   - 点输入框会列出那个 AI 提供的模型（需要密钥或地址的种类，要先填好）。
   - Claude Code 和 Codex CLI 留空则用默认模型；用 `sonnet` 这样的短名称会始终连接最新版本。
   - Ollama 和 API 连接必须填模型名称。
5. 点**保存并连接**。还有其他伙伴没有 AI 时，「让另外几位还没有 AI 的伙伴也用这个 AI」开关是开着的，大家一次都能说话。

- 没有 AI 的伙伴也可以先写话：发送时打开连接窗口，连上后那句话就发出去。
- 第一次启动时，本机有 Claude Code 或 Codex CLI 的话，乐园的开始卡片会显示它的名字。点一次**立即连接**就给所有伙伴接上，不需要密钥。
- 伙伴有两位以上时，连接后它们就会开始互相聊天。

管理连接：

- 创建过的连接，其他伙伴也能用。每位伙伴的 AI 列表里选不同连接，就能各用不同的 AI。
- 修改或删除：在名字旁的 **⋯** 菜单里选 **AI 连接设置**，或在**伙伴与设置 → 设置 → 伙伴与 AI**里点那个连接的**编辑**。
- 设置里列出所有连接，点**连接 AI**可以新建。连接表单直接在这个分区里展开。
- 在设置里修改连接，不会把任何伙伴换到这个连接上。从伙伴自己的菜单打开的连接，会给那位伙伴使用。
- 删除前会先确认。保存的密钥会一起删除，用这个连接的伙伴会变成没有 AI 地玩耍。

## 聊天 <Since v="0.1.0" />

- 在下方输入框写字，按 Enter 发送。Shift+Enter 换行。
- 接上 AI 后、还没开始聊时，会显示几句开场白（比如「今天做了什么？」），点一下直接发送。
- 像聊天软件一样，伙伴每次开口前都带着它的头像。
- 等待回答时显示「正在思考」气泡，可以用 ■ 按钮停止。
- 回答也会以气泡浮在乐园里的伙伴头上。
- 在名字旁的 **⋯** 菜单里选**清空对话**，清除和这位伙伴的全部对话。名字和性格保留。
- 对话记录只在内存里。关掉应用就没了，不会存成文件。

## 设定性格 <Since v="0.1.0" />

性格是伙伴回答时的语气和态度。两种设定方法：

| 方法 | 怎么做 |
|---|---|
| 在伙伴设置里直接写 | 写「傲娇但经不起夸。回答简短随意。」这样的话。保存后从下一次对话开始生效 |
| 在聊天中说 | 说「以后说话随意点」之类的话，伙伴会把它保存为性格。会弹出「已保存伙伴的性格」，可在伙伴设置里查看 |

## 设定关系 <Since v="0.1.0" />

1. 在伙伴设置的**关系**里，从四张关系卡片中选一张：朋友（默认）、恋人、可靠的前辈、调皮的弟弟妹妹。每张都写着会是什么语气。
2. 在**对我的称呼**里写「亲爱的」或名字，它就这样叫你。输入框里的示例随关系变化。

- 伙伴面板名字旁有关系标签，点一下打开这些卡片。
- 设定关系后，语气、称呼和问候方式都会不同；伙伴之间聊天时也知道彼此的关系。
- 没有 AI 时，恋人、前辈和弟弟妹妹也各有语气：迎接你回来、变得更亲近、说出你对它有多重要时都是这样。
- Codex 宠物里人形角色很多，很适合设成恋人或前辈。
- 表达的尺度不由应用决定，而是遵循所连接 AI 的政策。

## 一起聊天 <Since v="0.1.0" />

接上 AI 的伙伴有两位以上时，输入框下方会出现**叫上伙伴**。

1. 展开后点要一起聊的伙伴，最多选 3 位。
2. 发送消息后，当前伙伴先回答，选中的伙伴们依次接着回答。每位都用自己的 AI 和性格。
3. 想让伙伴们不靠新消息自己接着聊，点**玩耍 → 一起玩**的**聊聊天**。接上 AI 的伙伴们会围绕此刻的时间和天气聊一轮，以气泡显示在乐园里。

- 伙伴名字下方的小标签显示哪个编码代理在向它汇报（负责, Claude Code）。
- 在乐园里能看到伙伴们用气泡互相聊天。

## 「刚才在做什么？」 <Since v="0.1.0" />

- 做好[编码代理联动](./agents.md)后，伙伴会记住代理最近做过的事。
- 在聊天中问「刚才在做什么？」，它会用自己的话讲讲那些工作。
- 联动和聊天用的 AI 连接是分开运作的。
