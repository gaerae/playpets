# 邀请第一位伙伴

第一次打开应用时，空空的乐园会问**想和谁一起玩？**，并显示四个会动的伙伴选项。点其中一个，它就会来到乐园向你挥手。点**看看其他宠物**会打开列出本机所有宠物的**邀请**标签。

## 应用自带的伙伴 <Since v="0.1.0" />

第一次启动时，邀请标签的 **PlayPets 自带宠物**先显示探险家 Daisy、园丁小猫 Clover、开朗小狗 Pip 和温柔水獭 Miso。Clover 是应用的主要吉祥物。不论哪种语言，卡片上显示的都是这些英文名字。它们使用 Codex 宠物格式，所以和其他宠物一样可以邀请、放到桌面上、接上 AI。宠物文件解压在数据文件夹的 `builtin/` 下。


内置伙伴为Daisy、Clover、Pip和Miso。之前的内置伙伴保留已保存的名称、设置和亲密度，外观分别由Aria改为Daisy、Noah改为Pip、原来的猫咪改为Clover。自行导入的宠物不变。对话仅在本次运行中保留，重启后不会恢复。

Daisy、Clover、Pip、Miso 会跟随设置中选择的季节（自动模式跟随本地日历），自动换上轻便的夏装或温暖的冬装，乐园和桌面模式都适用。春秋共用日常叠穿服装，面容、配饰和动作保持一致。

## 伙伴的小故事 <span id="companion-stories"></span>

这些小故事用来介绍伙伴。实际聊天使用的性格可在伙伴设置中修改，并在连接 AI 后生效。白色花瓣、金黄花芯的小花，是四位伙伴共同的标记。

### Daisy, 转角处的小发现

黛西总对别人匆匆经过的小路充满好奇。一朵刚开的花，或一片像鲸鱼的云，就能让一天值得记住。比起抢先到达，她更喜欢和伙伴一起发现。

### Clover, 今天又长大了一点

三叶草是照料花园的温柔小猫，也是 PlayPets 的主要吉祥物。它总是最先发现新叶，并给伙伴留一处晒太阳的位置。对它来说，小小的变化也值得耐心等待。

### Pip, 再来一位也欢迎

皮普总会第一个向新朋友挥手。穿着靛蓝牛仔夹克和象牙色短裤，它让散步和游戏变得热闹，也会回头看看有没有伙伴落下。能让所有人一起参与，就是它喜欢的午后。

### Miso, 池边的一页书

米索是一只温柔的水獭，喜欢随身带一本书，也愿意留出一点发呆的时间。穿着淡紫色针织背心，它看着水面波纹，让思绪慢慢安静下来。有时候，不必说话，坐在一起就很好。


## 接下来 <Since v="0.1.0" />

第一位伙伴来了以后，角落里的小卡片**接下来**会显示剩下的事：给伙伴接上 AI（**连接**），以及选一位伙伴转达编码代理的消息（**选择**）。本机有 Claude Code 或 Codex CLI 时，第一个按钮会变成**立即连接**，不用密钥就能一次给所有伙伴接上（见[和伙伴聊天](./chat.md#创建连接)）。完成的事会打勾，全部完成后卡片消失；想提前收起，点**不再显示**。乐园里没有伙伴时，游玩工具会隐藏，但**伙伴与设置 → 邀请伙伴**仍然可用。

## 邀请标签 <Since v="0.1.0" />

<Shot name="invite" caption="邀请标签按宠物所在的位置把卡片分组显示。" />

邀请标签按宠物文件所在的位置，把卡片分成四组。没有宠物的分组不会显示。

| 分组 | 宠物从哪里来 |
|---|---|
| PlayPets 自带宠物 | 应用自带的四位伙伴，解压在数据文件夹的 `builtin/` 里 |
| Codex 宠物文件夹 | `~/.codex/pets` 里的 Codex 宠物。会自动显示 |
| 通过地址导入的宠物 | 用**导入宠物**拿到的社区宠物。保存在数据文件夹的 `pets/` 里 |
| 从本机选择的宠物 | 你自己选的文件夹里的宠物。不复制，直接读取那个文件夹 |

前三组有**打开文件夹**按钮，可以用资源管理器或 Finder 打开那个文件夹。从本机选择的宠物，每张卡片上都写着文件夹名。一张卡片都没有的话，请先从[导入宠物](./import.md)开始。

用架子上方的**类型**标签（全部, 人物, 动物, 其他）可以只筛出人形宠物。挑要设为恋人或前辈的伙伴时很方便。它依据的是宠物文件里的 `kind` 值。

类型筛选可与**搜索宠物**一起使用。输入名称或作者，就能进一步缩小同一架子的结果。点击**显示全部**会同时清除搜索和类型筛选。

## 邀请伙伴 <Since v="0.1.0" />

1. 点一张卡片（右侧的 `+`）。已经在乐园里的伙伴，卡片上会写着「再邀请一位」。
2. 伙伴出现在乐园里挥手。面板切换到伙伴标签。
3. 再点同一只宠物，就变成「再邀请一位」。从第二位伙伴起，名字后面会加上编号，方便区分。

乐园里最多可以放 12 位伙伴。

## 伙伴设置 <Since v="0.1.0" />

在伙伴标签里打开名字旁的 **⋯** 菜单，选**伙伴设置**（铅笔图标），可以修改名字、性格、关系、对我的称呼和大小。点名字旁的关系标签也能打开它。

- **名字**：显示在乐园的名牌和聊天窗口里。最多 24 个字。
- **性格**：聊天时会按这个性格回答。一开始用的是宠物文件里的介绍，修改或补充后保存，就会换成新的内容。点**填入宠物文件的介绍**可以重新取回原来的介绍。最多 400 个字。没有连接 AI 的话，性格暂时还用不上。
- **关系**：在朋友、恋人、可靠的前辈、调皮的弟弟妹妹中选一个。语气、称呼和问候都会随之不同。
- **对我的称呼**：伙伴会这样叫你。最多 24 个字。两者在[和伙伴聊天](./chat.md#设定关系)里有详细说明。
- **大小**：非常小、小、中、大、非常大，共五档。拖动滑块，乐园里会立刻变化。

窗口底部显示伙伴 ID。在[编码代理联动](./agents.md)里指定某位伙伴时会用到。

想把伙伴从乐园送走，在 **⋯** 菜单里选**送走**，或者在伙伴设置里点**从乐园送走**。和它聊过的内容也会一起清除，但宠物仍留在邀请标签里，随时可以再次邀请。

## 在乐园里能做的事 <Since v="0.1.0" />

点击伙伴可以摸摸它，拖动可以换位置。第一次邀请的伙伴会告诉你怎么聊天。可以对伙伴做这些事：

| 做什么 | 怎么做 |
|---|---|
| 摸摸 | 点一下伙伴。伙伴会跳起来，冒出爱心 |
| 移动 | 拖动伙伴再放下。乐园里的位置会被记住 |
| 聊天 | 点伙伴的名牌：鼠标移上去时名牌上会出现对话图标和**和Clover聊天**这样的提示。伙伴标签会以这位伙伴打开。对话会随窗口大小调整，留在同一个窗口内。双击伙伴也一样；右键点伙伴会打开一个简短菜单，可以选聊天或玩耍 |
| 放零食 | 点**玩耍 → 花园**的**野餐**，再选择乐园里的位置（用键盘时再按一次，就会放在选中的伙伴旁边）。野餐垫上会摆好便当、水果和零食，伙伴们会围过来。如果还有伙伴没到，15秒后会收起；如果都吃到了，则在最后一位吃完6秒后收起 |

伙伴脚下有**名牌**。选中一位伙伴后，名牌会变成选中的样子；编码代理工作期间，名牌旁边会显示状态。

不管它们的时候，伙伴们会在乐园里慢慢走动，自言自语。下雨时会说「有伞吗？」之类的话，到了夜晚就会犯困。时段和天气在[乐园和游戏](./play.md)里说明。
