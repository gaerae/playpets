# 邀请第一位伙伴

第一次打开应用时，空空的乐园会问**想和谁一起玩？**，并显示三只会动的自带宠物。点其中一只，它就会来到乐园向你挥手。点**看看其他宠物**会打开列出本机所有宠物的**邀请**标签。

## 自带的三只宠物 <Since v="0.1.0" />

第一次启动时，邀请标签的 **PlayPets 自带宠物**里有 Tabby（塔比）、Smoky（烟烟）和 Mochi（麻糬）。不论哪种语言，卡片上显示的都是这几个英文名字。它们是用吉祥物画成的 Codex 宠物格式的宠物，所以和其他宠物一样可以邀请、放到桌面上、接上 AI。宠物文件解压在数据文件夹的 `builtin/` 下。

## 接下来 <Since v="0.1.0" />

第一位伙伴来了以后，角落里的小卡片**接下来**会显示剩下的事：给伙伴接上 AI（**连接**），以及选一位伙伴转达编码代理的消息（**选择**）。本机有 Claude Code 或 Codex CLI 时，第一个按钮会变成**立即连接**，不用密钥就能一次给所有伙伴接上（见[和伙伴聊天](./chat.md#创建连接)）。完成的事会打勾，全部完成后卡片消失；想提前收起，点**不再显示**。乐园里没有伙伴时，还没有可以喂零食的对象，所以工具栏会隐藏。

## 邀请标签 <Since v="0.1.0" />

<Shot name="invite" caption="邀请标签按宠物所在的位置把卡片分组显示。" />

邀请标签按宠物文件所在的位置，把卡片分成四组。没有宠物的分组不会显示。

| 分组 | 宠物从哪里来 |
|---|---|
| PlayPets 自带宠物 | 应用自带的三只宠物，解压在数据文件夹的 `builtin/` 里 |
| Codex 宠物文件夹 | `~/.codex/pets` 里的 Codex 宠物。会自动显示 |
| 通过地址导入的宠物 | 用**导入宠物**拿到的社区宠物。保存在数据文件夹的 `pets/` 里 |
| 从本机选择的宠物 | 你自己选的文件夹里的宠物。不复制，直接读取那个文件夹 |

前三组有**打开文件夹**按钮，可以用资源管理器或 Finder 打开那个文件夹。从本机选择的宠物，每张卡片上都写着文件夹名。一张卡片都没有的话，请先从[导入宠物](./import.md)开始。

用架子上方的**外形**标签（全部 · 人物 · 动物 · 其他）可以只筛出人形宠物。挑要设为恋人或前辈的伙伴时很方便。它依据的是宠物文件里的 `kind` 值。

## 邀请伙伴 <Since v="0.1.0" />

1. 点一张卡片（右侧的 `+`）。已经在乐园里的伙伴，卡片上会写着「再邀请一位」。
2. 伙伴出现在乐园里挥手。面板切换到伙伴标签。
3. 再点同一只宠物，就变成「再邀请一位」。从第二位伙伴起，名字后面会加上编号，方便区分。

乐园里最多可以放 12 位伙伴。

## 伙伴设置 <Since v="0.1.0" />

在伙伴标签里点**伙伴设置**（铅笔图标），可以修改名字、性格、关系、对我的称呼和大小。

- **名字**：显示在乐园的名牌和聊天窗口里。最多 24 个字。
- **性格**：聊天时会按这个性格回答。一开始用的是宠物文件里的介绍，修改或补充后保存，就会换成新的内容。点**填入宠物文件的介绍**可以重新取回原来的介绍。最多 400 个字。没有连接 AI 的话，性格暂时还用不上。
- **关系**：在朋友、恋人、可靠的前辈、调皮的弟弟妹妹中选一个。语气、称呼和问候都会随之不同。
- **对我的称呼**：伙伴会这样叫你。最多 24 个字。两者在[和伙伴聊天](./chat.md#设定关系)里有详细说明。
- **大小**：非常小、小、中、大、非常大，共五档。拖动滑块，乐园里会立刻变化。

窗口底部显示伙伴 ID。在[编码代理联动](./agents.md)里指定某位伙伴时会用到。

想把伙伴从乐园送走，点**送走**。到目前为止的对话也会一起清除，但宠物仍留在邀请标签里，随时可以再次邀请。

## 在乐园里能做的事 <Since v="0.1.0" />

第一次摸伙伴之前，乐园上方的提示行会写着「点击摸摸，拖动换个位置」，第一次邀请的伙伴也会告诉你怎么聊天。可以对伙伴做这些事：

| 做什么 | 怎么做 |
|---|---|
| 摸摸 | 点一下伙伴。伙伴会跳起来，冒出爱心 |
| 移动 | 拖动伙伴再放下。乐园里的位置会被记住 |
| 聊天 | 点伙伴的名牌：鼠标移上去时名牌上会出现对话图标。伙伴标签会以这位伙伴打开（在小窗里也会先回到原来大小再打开）。双击或右键点伙伴也一样 |
| 放零食 | 点工具栏的**放零食**，再点乐园里要放的地方。伙伴们都会走过来吃，然后说「好吃，谢谢！」。零食 15 秒后消失 |

伙伴脚下有**名牌**。选中一位伙伴后，名牌会变成选中的样子；编码代理工作期间，名牌旁边会显示状态。

不管它们的时候，伙伴们会在乐园里慢慢走动，自言自语。下雨时会说「有伞吗？」之类的话，到了夜晚就会犯困。时段和天气在[乐园和游戏](./play.md)里说明。
