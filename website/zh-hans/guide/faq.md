# 常见问题

## 要花钱吗？

应用免费，是 MIT 许可的开源软件。通过订阅登录的 Claude Code 或 Codex CLI 使用套餐额度，无需另付 API 账单；套餐限制和主动购买的额外点数仍然适用。本地 Ollama 模型在你的电脑上运行，无托管推理费用。API 密钥连接、兼容服务器和 Ollama 云端模型遵循提供方的计费规则。详见 [AI 连接的种类](./chat.md#ai-连接的种类)。

## 没有网络也能用吗？

邀请、游戏、桌面模式、时段和天气都不需要网络。“自动天气”也不会去获取真实天气，而是按时钟决定。需要网络的是导入社区宠物、检查更新，以及和使用网络的 AI 对话。已下载的本地 Ollama 模型可以离线聊天，对话留在本机。Ollama 云端模型需要网络。

## 我的代码或提示词会发给宠物吗？

[编码代理联动](./agents.md)省略用户提示词和工具输入。本地桥接使用 `127.0.0.1` 和令牌认证。简短的完成或通知报告（包括截取的代理回复）可能包含工作细节，并可能随伙伴对话发送给所选 AI 服务。请检查通过终端或 MCP 发送的消息；需要将这些内容留在本机时，使用已下载的本地模型。

## 在 macOS 上打不开。

发布文件没有签名和公证，macOS 可能会显示警告。请先确认文件来自本项目的发布页面。如果系统提供**仍要打开**选项，可按[安装指南](./install.md#macos)操作。可用选项取决于警告类型和系统策略。

## Windows 上出现警告。

SmartScreen 可能会对未签名或不常见的下载显示警告。请先核实文件来源。部分系统提供**更多信息**和**仍要运行**选项，受管理的设备可能不允许继续。详情见[安装指南](./install.md#windows)。代码签名已在计划中。

## Windows 上无法进行 AI 对话。

如果 Claude Code 或 Codex CLI 是用 npm 安装的，它们需要在 `%APPDATA%\npm` 里，应用才能找到。请先在终端确认 `claude` 或 `codex` 能运行，再看看连接窗口里对应的卡片上是否标着“已安装”。Windows 版本在实际设备上还没有充分测试，如果仍然不行，请通过 [Issue](https://github.com/gaerae/playpets/issues) 告诉我们。

## 宠物很慢，或者很耗电。

伙伴只在有动作时才频繁绘制，静止时很少绘制。关闭乐园窗口把它隐藏后，乐园就不再绘制。如果还是占用很多，可以减少伙伴数量，或者关掉**在桌面上散步**试试。如果能一起告诉我们是在哪种状态下（只有乐园、只有桌面、两者都有）出现的，会对修复很有帮助。

## 可以自己做宠物吗？

可以。一个装有 `pet.json` 和精灵图的文件夹就是一只宠物。格式和 Codex 宠物相同。做好的文件夹可以通过**导入宠物**里的**从本机文件夹导入**直接邀请。详细规则见[导入宠物](./import.md#自己制作)和开发者文档[宠物文件格式](/dev/standards/pet-files)。

## 有多台显示器时会怎样？

在[桌面模式](./desktop.md)下，伙伴可以在任何一台显示器上。把它拖到另一台显示器，它就会留在那里。各显示器的缩放比例不同也没关系。

## 数据在哪里？

macOS 在 `~/Library/Application Support/app.playpets/`，Windows 在 `%APPDATA%\app.playpets\`，Linux 在 `~/.local/share/app.playpets/`。伙伴和设置在 `state.json`，导入的宠物在 `pets/`，自带宠物在 `builtin/`。API 密钥不在这里，而在操作系统的安全存储里。PlayPets 不会把对话记录保存到文件，仅在当前应用会话中保留。连接服务的对话保存遵循该服务的政策。详细内容见[设置](./settings.md#数据文件夹)。
