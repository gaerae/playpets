# 常见问题

## 要花钱吗？

应用免费，是 MIT 许可的开源软件。对话若用你已经在用的 Claude Code 或 Codex CLI 订阅，没有额外费用；Ollama 则在你自己的电脑上运行。只有连接 OpenAI API 或兼容服务器时，才可能产生那项服务的使用费。

## 没有网络也能用吗？

邀请、游戏、桌面模式、时段和天气都不需要网络。“天气自动”也不会去获取真实天气，而是按时钟决定。需要网络的只有导入社区宠物、检查更新，以及和使用网络的 AI 对话。用 Ollama 对话时，这部分也只在你的电脑里处理。

## 我的代码或提示词会发给宠物吗？

不会。[编码代理联动](./agents.md)只发送状态和简短的句子，不会发送你输入给代理的内容或代码。联动只在这台电脑内（`127.0.0.1`，令牌认证）进行。和伙伴的对话只会发往你另外选择的 AI 连接。

## 在 macOS 上打不开。

发布文件没有签名和公证，所以 Gatekeeper 会拦住第一次运行。打开“系统设置 > 隐私与安全性”，点击下方的**仍要打开**即可。只需做一次，之后就能直接打开。详细步骤见[安装](./install.md#macos)。

## Windows 上出现警告。

原因相同。在 SmartScreen 的“Windows 已保护你的电脑”窗口中点击**更多信息**，再选择**仍要运行**，安装就会继续。代码签名已在计划中。

## Windows 上无法进行 AI 对话。

如果 Claude Code 或 Codex CLI 是用 npm 安装的，它们需要在 `%APPDATA%\npm` 里，应用才能找到。请先在终端确认 `claude` 或 `codex` 能运行，再看看连接窗口上方是否显示“本机已安装”。Windows 版本在实际设备上还没有充分测试，如果仍然不行，请通过 [Issue](https://github.com/gaerae/playpets/issues) 告诉我们。

## 宠物很慢，或者很耗电。

伙伴只在有动作时才频繁绘制，静止时很少绘制。关闭乐园窗口把它隐藏后，乐园就不再绘制。如果还是占用很多，可以减少伙伴数量，或者关掉**在桌面上走动**试试。如果能一起告诉我们是在哪种状态下（只有乐园、只有桌面、两者都有）出现的，会对修复很有帮助。

## 可以自己做宠物吗？

可以。一个装有 `pet.json` 和精灵图的文件夹就是一只宠物。格式和 Codex 宠物相同。做好的文件夹可以通过**导入宠物**里的**从本机文件夹导入**直接邀请。详细规则见[导入宠物](./import.md#自己制作)和开发者文档[宠物文件格式](/en/dev/standards/pet-files)。

## 有多台显示器时会怎样？

在[桌面模式](./desktop.md)下，伙伴可以在任何一台显示器上。把它拖到另一台显示器，它就会留在那里。各显示器的缩放比例不同也没关系。

## 数据在哪里？

macOS 在 `~/Library/Application Support/app.playpets/`，Windows 在 `%APPDATA%\app.playpets\`，Linux 在 `~/.local/share/app.playpets/`。伙伴和设置在 `state.json`，导入的宠物在 `pets/`，自带宠物在 `builtin/`。API 密钥不在这里，而在操作系统的安全存储里。对话记录不会保存在任何地方。详细内容见[设置](./settings.md#数据文件夹)。
