# 设置

**伙伴与设置 → 设置**包括**语言与启动**、**伙伴与 AI**、**编码工具连接**、**应用更新**和**关于 PlayPets**。在大窗口里，列表像系统设置一样留在左侧，选中的分区在旁边打开；再次打开时显示上次查看的分区。在小窗口里，先看到列表，一次打开一个分区。[编码工具连接](./agents.md)另有说明。有新版本时，菜单里的“设置”上会出现一个小点。

在大窗口里，返回会回到伙伴与设置。在小窗口里，在分区里返回会回到设置列表，在列表里返回会回到伙伴与设置。托盘和 macOS 菜单栏里的**关于 PlayPets**、**检查更新…**，以及新版本提示，会直接打开对应分区；在小窗口里，返回时同样回到列表。关闭回到风景。季节、声音和音量在**场景与氛围 → 氛围**中调节。

## 语言 <Since v="0.1.0" />

可以在 한국어、English、日本語、简体中文 中选择。一开始跟随系统语言；更改后，乐园和桌面窗口都会用新语言重新载入。托盘菜单和窗口标题也会一起改变。所选语言保存在 `state.json` 的 `language` 里。

伙伴的自言自语和问候使用所选语言。AI默认也使用该语言，你可以在新消息中明确要求改用其他语言。更换语言会取消正在生成的回复，之前的对话会保留原文，不会自动翻译。应用与编程代理及终端使用英语交流。

启动时给出环境变量 `PLAYPETS_LANG=ko|en|ja|zh-hans`，它会优先于保存的语言。这是测试用的。

## 登录时启动 PlayPets <Since v="0.1.0" />

打开后，每次登录电脑时 PlayPets 都会一起启动。默认是关闭的。桌面模式开着时，登录时不会打开乐园窗口，只有伙伴们出现在桌面上，窗口在托盘里等着。这个选择由系统保存（macOS 的登录项、Windows 的启动项、Linux 的自动启动项），所以在哪一边关掉都算关掉。

## 伙伴与 AI <Since v="1.2.0" />

**伙伴与 AI**列出所有 AI 连接，并显示各有几位伙伴在用。点**编辑**或用来新建连接的**连接 AI**，连接表单会直接在这个分区里展开，不会在设置上面再弹出窗口。按 **Esc** 会收起表单；如果已经输入了内容，就不会收起，而是提示「这里有改动。请保存，或者点“取消”放弃改动。」。在这里修改连接，不会把任何伙伴换到这个连接上。还没有连接时，伙伴们也会玩耍和回应。怎么建立连接见[和伙伴聊天](./chat.md#创建连接)。

## 偶尔让伙伴们自己聊聊 <Since v="0.1.0" />

打开“伙伴与 AI”里的这个开关后，每 20 分钟，接上 AI 的伙伴们会短短地聊几句。默认是关闭的。这些调用会消耗套餐额度或按提供商的政策计费；本地 Ollama 模型没有服务器推理费用。需要时再打开。窗口隐藏或有人正在回答时，那一轮会跳过。

## 偶尔自己去挖土玩 <Since v="1.2.0" />

打开“伙伴与 AI”里的这个开关后，乐园显示时，空闲的伙伴每隔几分钟会自己挑一处挖土。默认是关闭的，也无需连接 AI。游戏进行中或你手上拿着工具时，伙伴不会自己去挖；像温馨客厅这样没有泥土的地方也不会挖。挖到的东西和其他挖土一样保存。

## 关于 PlayPets <Since v="0.1.0" />

**关于 PlayPets**显示版本及网站、使用指南、版本记录、GitHub、问题反馈、许可证链接。链接在浏览器中打开，更新在“应用更新”里进行。

## 应用更新 <Since v="0.1.0" />

Microsoft Store 安装版由 Store 管理更新。请打开 **Microsoft Store → 库**检查。下方通过 GitHub 安装程序更新的说明适用于非 MSIX 安装版；测试用 MSIX 同样使用包管理更新。存储与外部通信详情见[隐私政策](../privacy.md)。

这一行显示当前版本。点击**检查更新**，应用会读取 GitHub 发布页的 `latest.json`；已是最新时会提示“已是最新版本”。

应用启动20秒后静默检查，之后每六小时重新检查，也可以手动检查。更新入口会打开**伙伴与设置 → 设置 → 应用更新**。

**查看新内容**在浏览器中打开版本页面。**安装并重启**、下载进度、验证、安装及失败后的重试都在应用更新中完成，不会打开单独的更新窗口。无法取得下载大小时，进度不显示百分比。重启后伙伴与设置会保留，并短暂提示已安装的版本。

## 退出 PlayPets <Since v="0.1.0" />

**伙伴与设置**里的**关闭窗口**将乐园隐藏到托盘，桌面伙伴和代理联动继续运行。旁边的**退出 PlayPets**和托盘里的**退出 PlayPets**、macOS 的 <kbd>⌘</kbd> <kbd>Q</kbd> 一样，不再询问，立即退出，对话不会保存。背景右键菜单不直接列出关闭和退出，请先打开伙伴与设置。

## 菜单与快捷键 <Since v="0.1.0" />

- **托盘菜单**（菜单栏或任务栏里的小猫）：**打开乐园**、有伙伴时的**伙伴**、**邀请伙伴…**、**始终置顶**、**在桌面上显示**、桌面模式开启时的**在桌面散步**、**乐园声音**、**设置…**、**检查更新…**、**关于 PlayPets**和**退出 PlayPets**。没有伙伴时仍可使用始终置顶；有伙伴后才会显示桌面开关。声音开启时显示勾选标记。有新版本时，更新项会改为**更新到 v…**。Windows 上左键打开乐园，右键打开菜单。代理等待你回应或遇到问题时会显示蓝点或红点，提示文字里显示伙伴名字。
- **macOS 菜单栏**：**PlayPets** → **关于 PlayPets**、**检查更新…**、**设置…**、隐藏和**退出 PlayPets**；在输入框里剪切、拷贝、粘贴用的**编辑**；**显示** → **伙伴与设置**、**伙伴**、**邀请伙伴…**，以及用勾选标记开关的**始终置顶**和**在桌面上显示**（还没有伙伴时桌面开关是灰的），以及用勾选标记开关的**乐园声音**；以及**窗口**。
- **快捷键**（macOS 用 <kbd>⌘</kbd>，Windows 和 Linux 用 <kbd>Ctrl</kbd>）：

| 按键 | 作用 |
|---|---|
| <kbd>⌘</kbd> <kbd>1</kbd> | 打开伙伴与聊天 |
| <kbd>⌘</kbd> <kbd>2</kbd> | 打开邀请伙伴 |
| <kbd>⌘</kbd> <kbd>,</kbd> | 打开设置 |
| <kbd>⌘</kbd> <kbd>Shift</kbd> <kbd>P</kbd> | 打开伙伴与设置 |
| <kbd>⌘</kbd> <kbd>Shift</kbd> <kbd>M</kbd> | 开关始终置顶 |
| <kbd>⌘</kbd> <kbd>Shift</kbd> <kbd>D</kbd> | 开关在桌面上显示 |
| <kbd>⌘</kbd> <kbd>Shift</kbd> <kbd>S</kbd> | 开关乐园声音 |
| <kbd>⌘</kbd> <kbd>Q</kbd> | 退出 PlayPets（macOS） |

## 数据文件夹 <Since v="0.1.0" />

| 操作系统 | 位置 |
|---|---|
| macOS | `~/Library/Application Support/app.playpets/` |
| Windows | `%APPDATA%\app.playpets\` |
| Linux | `~/.local/share/app.playpets/` |

| 文件 | 内容 |
|---|---|
| `state.json` | 伙伴（名字、性格及其来源、关系、对我的称呼、大小、位置、所选的 AI 连接）、AI 连接列表（不含密钥）、语言、桌面模式和散步、各代理负责的伙伴、自动聊天、自动挖土、乐园声音和音量、窗口的位置和大小、始终置顶设置、花园和摆设（`garden`）、图鉴（`album`）、亲密度（`bonds`）、手动选择的宠物文件夹、文件格式编号（`schema`）。旧版本打开新版本写的文件时，会先留一份副本，只读取自己认识的部分 |
| `bridge.json` | 代理联动用的端口和令牌。每次启动应用都会重新写入 |
| `pets/` | 通过地址导入的宠物文件夹 |
| `builtin/` | 四个内置宠物，每次启动检查并解压。每位伙伴都有独立的基础图像 |

启动时无法加载伙伴的话，乐园顶部会出现折叠的**启动提示**卡片，不会缩小乐园区域。展开卡片即可查看详情。如果提示找不到宠物文件，请检查原来的宠物文件夹和文件，必要时恢复文件，再完全退出并重新打开 PlayPets。如果伙伴已达到 12 位上限，请先腾出位置，再重新打开应用。这些提示不会删除已保存的伙伴记录。关闭卡片后，它会在本次运行期间隐藏；有新提示时会再次出现。

## 环境变量

| 变量 | 作用 |
|---|---|
| `PLAYPETS_DATA` | 把数据文件夹换到别的位置。终端命令（`playpets say` 等）也读同一个值 |
| `CODEX_HOME` | Codex 的主文件夹。邀请标签里的 Codex 宠物文件夹会变成 `$CODEX_HOME/pets` |
| `PLAYPETS_LANG` | 强制指定语言（`ko`、`en`、`ja`、`zh-hans`） |
| `PLAYPETS_PET` | 终端命令的默认伙伴。和 `--pet` 选项相同 |
| `PLAYPETS_BRIDGE` | 终端命令要读取的 `bridge.json` 路径。和 `--bridge` 选项相同 |

变量需要放在运行应用的环境里。可以从终端打开应用，或使用操作系统的环境变量设置。

## 会保存与不会保存的内容 <Since v="0.1.0" />

**会保存**

- 伙伴的名字、性格、关系、对我的称呼、大小、在乐园里的位置
- 每位伙伴的亲密度
- 花园、乐园里的摆设和图鉴
- AI 连接的类型、服务器地址、模型名称
- 语言、桌面模式和散步、窗口的位置和大小、始终置顶设置、所选的时段、天气和季节
- 导入的宠物文件及其来源

**以另一种方式保存**

- API 密钥不会写进 `state.json`。它只保存在这台电脑的安全存储里（macOS 钥匙串、Windows 凭据管理器、Linux Secret Service），删除连接时会一起删除。

**不会保存**

- 和伙伴的对话。只存在内存里，关闭应用就会消失。
- 编码代理最近活动的记忆。关闭应用就会消失。
- 游戏中的位置。游戏结束后会回到原来的地方。

卸载应用后若想清除所有痕迹，请把数据文件夹和安全存储里的 PlayPets 条目一起删除。
