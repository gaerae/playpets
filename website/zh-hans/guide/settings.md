打开**伙伴与设置 → 设置**，里面有五个分区：**语言与启动**、**伙伴与 AI**、**编码工具连接**、**应用更新**、**关于 PlayPets**。

## 语言 <Since v="0.1.0" /> {#language}

可以选 한국어、English、日本語、简体中文。一开始跟着系统语言走。

- 换了语言，乐园和桌面窗口会用新语言重新载入，托盘菜单和窗口标题也跟着变。
- 正在生成的回复会取消，之前的对话保留原文，不会翻译。
- 伙伴们会用你选的语言打招呼、自言自语，AI 默认也用这种语言回答。想换一种语言听，在新消息里直接说就行。
- 应用和编码代理、终端之间用英语交流。
- 所选语言保存在 `state.json` 的 `language` 里。
- 测试用：启动时带上环境变量 `PLAYPETS_LANG=ko|en|ja|zh-hans`，只在这次运行中优先于保存的语言，保存的语言不会改变。

## 登录时启动 PlayPets <Since v="0.1.0" /> {#start-at-login}

打开后，每次登录电脑，PlayPets 都会跟着启动。默认是关的。

- 如果桌面模式开着，登录时不会打开乐园窗口。只有放到桌面上的伙伴和东西会出现，窗口在托盘里等着。
- 这个选择由系统记着：macOS 是登录项，Windows 是启动项，Linux 是自动启动项。在哪一边关掉都算关掉。
- Microsoft Store 版：在 Windows 里关掉 PlayPets 后，无法在应用里重新开启，请到 Windows 的 **设置 → 应用 → 启动** 里开启。

## 伙伴与 AI <Since v="1.2.0" /> {#friends-ai}

这里列出所有 AI 连接，每个连接旁边写着有几位伙伴在用，还有**编辑**按钮。还没有连接也没关系，伙伴们照样会玩耍、会回应。

- 点**编辑**，或者点新建用的**连接 AI**，连接表单会直接在这个分区里展开，不会在设置上面再弹出窗口。
- 在这里改连接，不会把任何伙伴换到这个连接上。
- 按 **Esc** 收起表单。已经输入了内容时不会收起，而是提示「这里有改动。请保存，或者点“取消”放弃改动。」。
- 怎么建立连接见[和伙伴聊天](./chat.md#创建连接)。

### 开关 {#switches}

| 开关 | 默认 | 作用 | 要连 AI 吗 |
|---|---|---|---|
| **偶尔让伙伴们自己聊聊** <Since v="0.1.0" /> | 关 | 接上 AI 的伙伴们每 20 分钟短短地聊几句。窗口隐藏或有人正在回答时，那一轮就跳过 | 要 |
| **偶尔自己去挖土玩** <Since v="1.2.0" /> | 关 | 乐园显示着的时候，空闲的伙伴每隔几分钟自己挑一处挖一挖。挖到的东西和平时挖土一样会留下来 | 不要 |

- 每次聊天都会消耗套餐额度，或按提供商的政策计费，想用的时候再打开。本地 Ollama 模型没有服务器推理费用。
- 游戏进行中、你手上拿着工具时、像花园工坊这样没有泥土的地方，伙伴不会自己去挖。

## 应用更新 <Since v="0.1.0" /> {#app-updates}

怎么更新，取决于你从哪里安装。测试用 MSIX 和 Store 版一样，通过安装包更新。

| | Microsoft Store | GitHub 安装程序 |
|---|---|---|
| 谁来安装更新 | Store | PlayPets，只在你选择时安装 |
| 自动检查 | PlayPets 启动时，之后每 6 小时 | 启动 20 秒后，之后每 6 小时 |
| **检查更新** | 立即询问 Store | 读取 GitHub 发布页的 `latest.json` |
| 有新版本时 | 显示在乐园和这里。点**在 Microsoft Store 中打开**，会打开 Store 中的 PlayPets 页面 | 更新入口会打开**伙伴与设置 → 设置 → 应用更新** |
| 安装期间 | PlayPets 会先关闭，再重新打开 | PlayPets 下载、验证并安装，然后重启 |

| 在这个分区里 | 作用 |
|---|---|
| 版本这一行 | 显示当前版本。下方写着：会静默检查，只在你选择时安装 |
| **检查更新** | 已是最新时提示“已是最新版本” |
| **本版本的更新内容** | 打开你正在用的版本的发布页面 |
| **查看新内容** | 在浏览器中打开新版本的页面 |
| **安装并重启** | 下载、验证、安装都在这个分区里完成，不打开单独的更新窗口。进度、失败后重试和错误也都在这里。取不到下载大小时，进度不显示百分比 |

- 重启后伙伴和设置都还在，应用会短暂提示装好的版本。
- 会保存什么、和哪里通信，详见[隐私政策](../privacy.md)。

## 退出 PlayPets <Since v="0.1.0" /> {#quit}

| 在**伙伴与设置**里 | 作用 |
|---|---|
| **关闭窗口** | 把乐园隐藏到托盘，桌面伙伴和代理联动继续运行 |
| **退出 PlayPets** | 不再询问，立即退出，对话不会保存。和托盘里的**退出 PlayPets**、macOS 的 <kbd>⌘</kbd> <kbd>Q</kbd> 一样 |

- 背景的右键菜单里没有直接的关闭和退出，请先打开伙伴与设置。

## 菜单与快捷键 <Since v="0.1.0" /> {#menus}

- 把指针移到乐园顶部，就会出现重置窗口大小、最小化和关闭按钮。背景的右键菜单里也有**重置窗口大小**。
- 拔掉显示器后窗口放不下时，它会自己回到剩下的屏幕里。

### 托盘菜单

从菜单栏或任务栏里的小猫打开，项目依次是：

1. **打开乐园**、有伙伴时的**伙伴**、**邀请伙伴…**
2. **重置窗口大小**：把乐园放回屏幕中间，恢复平常的大小
3. 显示开关：**始终置顶**、**在桌面上显示**、桌面模式开启时的**在桌面散步**
4. **乐园声音**、**设置…**、**检查更新…**、**关于 PlayPets**、**退出 PlayPets**

- 没有伙伴时仍可用始终置顶；有伙伴后才显示桌面开关。
- 声音开启时显示勾选标记。
- 有新版本时，更新项改为**更新到 v…**。
- Windows 上左键打开乐园，右键打开菜单。
- 代理等待你回应或遇到问题时显示蓝点或红点，提示文字里显示伙伴名字。

### macOS 菜单栏

| 菜单 | 项目 |
|---|---|
| **PlayPets** | **关于 PlayPets**、**检查更新…**、**设置…**、隐藏、**退出 PlayPets** |
| **编辑** | 在输入框里剪切、拷贝、粘贴 |
| **显示** | **伙伴与设置**、**伙伴**、**邀请伙伴…**；用勾选标记开关的**始终置顶**、**在桌面上显示**（还没有伙伴时是灰的）和**乐园声音** |
| **窗口** | **重置窗口大小**、最小化、关闭 |

## 数据文件夹 <Since v="0.1.0" /> {#data-folder}

| 操作系统 | 位置 |
|---|---|
| macOS | `~/Library/Application Support/app.playpets/` |
| Windows | `%APPDATA%\app.playpets\`。Microsoft Store（包括用 winget 安装）：在安装包专用的文件夹里 |
| Linux | `~/.local/share/app.playpets/` |

| 文件 | 内容 |
|---|---|
| `state.json` | 伙伴、AI 连接、设置和乐园的进度（见下方列表） |
| `bridge.json` | 代理联动用的端口和令牌。每次启动应用都会重新写入 |
| `pets/` | 通过地址或 ZIP 导入的宠物文件夹 |
| `backgrounds/` | 导入的背景，每个背景一个文件 |
| `builtin/` | 四个内置宠物，每次启动检查并解压。每位伙伴都有独立的基础图像 |

- `state.json` 里保存：
  - 伙伴：名字、性格及其来源、关系、对我的称呼、大小、位置、所选的 AI 连接
  - AI 连接列表（不含密钥）
  - 语言、桌面模式和散步、各代理负责的伙伴、自动聊天、自动挖土、乐园声音和音量
  - 窗口的位置和大小、始终置顶设置
  - 为乐园选择的地点、季节、时段和天气（`scene`）
  - 花园和摆设（`garden`）、图鉴（`album`）、亲密度（`bonds`）
  - 年末的信和我的回信（`letters`）
  - 手动选择的宠物文件夹
  - 文件格式编号（`schema`）
- 旧版本打开新版本写的 `state.json` 时，会先留一份副本，只读取自己认识的部分。

### 启动提示 {#startup-notices}

打开应用时如果有伙伴加载不了，底部栏正上方会出现一张折叠的**启动提示**卡片，乐园区域不会因此变小。展开卡片就能看到详情。

| 卡片内容 | 怎么做 |
|---|---|
| 找不到宠物文件 | 1. 检查原来的宠物文件夹和文件。2. 必要时恢复文件。3. 完全退出 PlayPets，再重新打开 |
| 伙伴已达 12 位上限 | 先腾出位置，再重新打开应用 |

- 这些提示不会删除已保存的伙伴记录。
- 关掉卡片后，本次运行期间不再显示；有新提示时会再出现。

## 环境变量 {#environment-variables}

| 变量 | 作用 |
|---|---|
| `PLAYPETS_DATA` | 把数据文件夹换到别的位置。终端命令（`playpets say` 等）也读同一个值 |
| `CODEX_HOME` | Codex 的主文件夹。邀请伙伴里的 Codex 宠物文件夹会变成 `$CODEX_HOME/pets` |
| `PLAYPETS_LANG` | 强制指定语言（`ko`、`en`、`ja`、`zh-hans`） |
| `PLAYPETS_PET` | 终端命令的默认伙伴。和 `--pet` 选项相同 |
| `PLAYPETS_BRIDGE` | 终端命令要读取的 `bridge.json` 路径。和 `--bridge` 选项相同 |

- 变量要设在运行应用的环境里：从终端打开应用，或者用操作系统的环境变量设置。

## 会保存与不会保存的内容 <Since v="0.1.0" /> {#what-is-saved}

### 会保存

- 伙伴的名字、性格、关系、对我的称呼、大小、在乐园里的位置
- 每位伙伴的亲密度
- 年末的信和我的回信（信的内容保留到1月7日，之后只留回信）
- 花园、乐园里的摆设和图鉴
- AI 连接的类型、服务器地址、模型名称
- 语言、桌面模式和散步、窗口的位置和大小、始终置顶设置、所选的时段、天气和季节
- 导入的宠物文件及其来源

### 以另一种方式保存

- API 密钥不写进 `state.json`，只保存在这台电脑的安全存储里（macOS 钥匙串、Windows 凭据管理器、Linux Secret Service）。
- 删除连接时，密钥也一起删除。

### 不会保存

- 和伙伴的对话。只在内存里，关闭应用就消失。
- 编码代理最近活动的记忆。关闭应用就消失。
- 游戏中的位置。游戏结束后回到原来的地方。

卸载后想不留痕迹，请把数据文件夹和安全存储里的 PlayPets 条目一起删掉。
