# 设置

打开**伙伴与设置 → 设置**，里面有五个分区：**语言与启动**、**伙伴与 AI**、**编码工具连接**、**应用更新**、**关于 PlayPets**。[编码工具连接](./agents.md)另有说明。

季节、声音和音量不在这里，要到**场景与氛围 → 氛围**里调。有新版本时，菜单里的“设置”上会出现一个小点。

| 窗口 | 布局 | 返回 |
|---|---|---|
| 大窗口 | 列表像系统设置一样留在左侧，选中的分区在旁边打开；再次打开时显示上次查看的分区 | 回到伙伴与设置 |
| 小窗口 | 先看到列表，一次打开一个分区 | 分区里返回到设置列表，列表里返回到伙伴与设置 |

- 托盘和 macOS 菜单栏里的**关于 PlayPets**、**检查更新…**，以及新版本提示，会直接打开对应分区；小窗口里返回时同样回到列表。
- 关闭后回到风景。

## 语言 <Since v="0.1.0" />

可以选 한국어、English、日本語、简体中文。一开始跟着系统语言走。

换了语言，乐园和桌面窗口会用新语言重新载入，托盘菜单和窗口标题也跟着变。正在生成的回复会取消，之前的对话保留原文，不会翻译。

伙伴们会用你选的语言打招呼、自言自语，AI 默认也用这种语言回答。想换一种语言听，在新消息里直接说就行。应用和编码代理、终端之间用英语交流。

- 所选语言保存在 `state.json` 的 `language` 里。
- 测试用：启动时带上环境变量 `PLAYPETS_LANG=ko|en|ja|zh-hans`，只在这次运行中优先于保存的语言，保存的语言不会改变。

## 登录时启动 PlayPets <Since v="0.1.0" />

打开后，每次登录电脑，PlayPets 都会跟着启动。默认是关的。

如果桌面模式开着，登录时不会打开乐园窗口。只有伙伴们出现在桌面上，窗口在托盘里等着。

这个选择由系统记着：macOS 是登录项，Windows 是启动项，Linux 是自动启动项。在哪一边关掉都算关掉。

Microsoft Store 版在 Windows 里关掉 PlayPets 后，无法在应用里重新开启，请到 Windows 的 **设置 → 应用 → 启动** 里开启。

## 伙伴与 AI <Since v="1.2.0" />

这里列出所有 AI 连接，每个连接旁边写着有几位伙伴在用。还没有连接也没关系，伙伴们照样会玩耍、会回应。

点**编辑**，或者点新建用的**连接 AI**，连接表单会直接在这个分区里展开，不会在设置上面再弹出窗口。在这里改连接，不会把任何伙伴换到这个连接上。

- 按 **Esc** 收起表单。已经输入了内容时不会收起，而是提示「这里有改动。请保存，或者点“取消”放弃改动。」。
- 怎么建立连接见[和伙伴聊天](./chat.md#创建连接)。

## 偶尔让伙伴们自己聊聊 <Since v="0.1.0" />

这是“伙伴与 AI”里的一个开关，默认关闭。打开后，接上 AI 的伙伴们每 20 分钟会短短地聊几句。窗口隐藏或有人正在回答时，那一轮就跳过。

每次聊天都会消耗套餐额度，或按提供商的政策计费。本地 Ollama 模型没有服务器推理费用。想用的时候再打开。

## 偶尔自己去挖土玩 <Since v="1.2.0" />

这也是“伙伴与 AI”里的开关，默认关闭，不需要连接 AI。打开后，只要乐园显示着，空闲的伙伴每隔几分钟就会自己挑一处挖一挖。挖到的东西和平时挖土一样会留下来。

以下情况伙伴不会自己去挖：
- 游戏进行中
- 你手上拿着工具时
- 像温馨客厅这样没有泥土的地方

## 关于 PlayPets <Since v="0.1.0" />

## 应用更新 <Since v="0.1.0" />

从 Microsoft Store 安装的版本由 Store 管理更新，请在 **Microsoft Store → 库**里检查。测试用 MSIX 同样走包管理更新。下面讲的 GitHub 安装程序更新，适用于非 MSIX 安装版。

会保存什么、和哪里通信，详见[隐私政策](../privacy.md)。

| 项目 | 作用 |
|---|---|
| 当前版本 | 显示在这一行 |
| **检查更新** | 读取 GitHub 发布页的 `latest.json`；已是最新时提示“已是最新版本” |
| **本版本的更新内容** | 打开你正在用的版本的发布页面 |
| **查看新内容** | 在浏览器中打开版本页面 |
| **安装并重启** | 下载进度、验证、安装及失败后的重试都在应用更新中完成，不打开单独的更新窗口 |

- 应用启动 20 秒后静默检查，之后每六小时重新检查。只有你选择时才安装，分区下方也写着这一点。也可以手动检查。
- 更新入口会打开**伙伴与设置 → 设置 → 应用更新**。
- 取不到下载大小时，进度不显示百分比。

重启后伙伴和设置都还在，应用会短暂提示装好的版本。

## 退出 PlayPets <Since v="0.1.0" />

- **伙伴与设置**里的**关闭窗口**：把乐园隐藏到托盘，桌面伙伴和代理联动继续运行。
- 旁边的**退出 PlayPets**、托盘里的**退出 PlayPets**、macOS 的 <kbd>⌘</kbd> <kbd>Q</kbd>：不再询问，立即退出，对话不会保存。
背景的右键菜单里没有直接的关闭和退出，请先打开伙伴与设置。

## 菜单与快捷键 <Since v="0.1.0" />

把指针移到乐园顶部，就会出现重置窗口大小、最小化和关闭按钮。背景的右键菜单里也有**重置窗口大小**。拔掉显示器后窗口放不下时，它会自己回到剩下的屏幕里。

**托盘菜单**（菜单栏或任务栏里的小猫）：

- 项目：**打开乐园**、有伙伴时的**伙伴**、**邀请伙伴…**、**重置窗口大小**、**始终置顶**、**在桌面上显示**、桌面模式开启时的**在桌面散步**、**乐园声音**、**设置…**、**检查更新…**、**关于 PlayPets**、**退出 PlayPets**。
- 没有伙伴时仍可用始终置顶；有伙伴后才显示桌面开关。
- 声音开启时显示勾选标记。
- 有新版本时，更新项改为**更新到 v…**。
- Windows 上左键打开乐园，右键打开菜单。
- 代理等待你回应或遇到问题时显示蓝点或红点，提示文字里显示伙伴名字。

**macOS 菜单栏**：

| 菜单 | 项目 |
|---|---|
| **PlayPets** | **关于 PlayPets**、**检查更新…**、**设置…**、隐藏、**退出 PlayPets** |
| **编辑** | 在输入框里剪切、拷贝、粘贴 |
| **显示** | **伙伴与设置**、**伙伴**、**邀请伙伴…**；用勾选标记开关的**始终置顶**、**在桌面上显示**（还没有伙伴时是灰的）和**乐园声音** |
| **窗口** | **重置窗口大小**、最小化、关闭 |

**快捷键**（macOS 用 <kbd>⌘</kbd>，Windows 和 Linux 用 <kbd>Ctrl</kbd>）：

| 按键 | 作用 |
|---|---|
| <kbd>⌘</kbd> <kbd>1</kbd> | 打开伙伴与聊天 |
| <kbd>⌘</kbd> <kbd>2</kbd> | 打开邀请伙伴 |
| <kbd>⌘</kbd> <kbd>,</kbd> | 打开设置 |
| <kbd>⌘</kbd> <kbd>Shift</kbd> <kbd>P</kbd> | 打开伙伴与设置 |
| <kbd>⌘</kbd> <kbd>Shift</kbd> <kbd>M</kbd> | 开关始终置顶 |
| <kbd>⌘</kbd> <kbd>Shift</kbd> <kbd>D</kbd> | 开关在桌面上显示 |
| <kbd>⌘</kbd> <kbd>Shift</kbd> <kbd>S</kbd> | 开关乐园声音 |
| <kbd>⌘</kbd> <kbd>0</kbd> | 重置窗口大小 |
| <kbd>⌘</kbd> <kbd>Q</kbd> | 退出 PlayPets（macOS） |

## 数据文件夹 <Since v="0.1.0" /> {#data-folder}

| 操作系统 | 位置 |
|---|---|
| macOS | `~/Library/Application Support/app.playpets/` |
| Windows | `%APPDATA%\app.playpets\`。Microsoft Store（包括用 winget 安装）：在安装包专用的文件夹里 |
| Linux | `~/.local/share/app.playpets/` |

| 文件 | 内容 |
|---|---|
| `state.json` | 伙伴（名字、性格及其来源、关系、对我的称呼、大小、位置、所选的 AI 连接）、AI 连接列表（不含密钥）、语言、桌面模式和散步、各代理负责的伙伴、自动聊天、自动挖土、乐园声音和音量、窗口的位置和大小、始终置顶设置、为乐园选择的地点、季节、时段和天气（`scene`）、花园和摆设（`garden`）、图鉴（`album`）、亲密度（`bonds`）、手动选择的宠物文件夹、文件格式编号（`schema`）。旧版本打开新版本写的文件时，会先留一份副本，只读取自己认识的部分 |
| `bridge.json` | 代理联动用的端口和令牌。每次启动应用都会重新写入 |
| `pets/` | 通过地址或 ZIP 导入的宠物文件夹 |
| `backgrounds/` | 导入的背景，每个背景一个文件 |
| `builtin/` | 四个内置宠物，每次启动检查并解压。每位伙伴都有独立的基础图像 |

启动时无法加载伙伴：

打开应用时如果有伙伴加载不了，底部栏正上方会出现一张折叠的**启动提示**卡片，乐园区域不会因此变小。展开卡片就能看到详情。

提示找不到宠物文件时：
1. 检查原来的宠物文件夹和文件。
2. 必要时恢复文件。
3. 完全退出 PlayPets，再重新打开。

如果伙伴已达 12 位上限，先腾出位置，再重新打开应用。

这些提示不会删除已保存的伙伴记录。关掉卡片后，本次运行期间不再显示；有新提示时会再出现。

## 环境变量

| 变量 | 作用 |
|---|---|
| `PLAYPETS_DATA` | 把数据文件夹换到别的位置。终端命令（`playpets say` 等）也读同一个值 |
| `CODEX_HOME` | Codex 的主文件夹。邀请伙伴里的 Codex 宠物文件夹会变成 `$CODEX_HOME/pets` |
| `PLAYPETS_LANG` | 强制指定语言（`ko`、`en`、`ja`、`zh-hans`） |
| `PLAYPETS_PET` | 终端命令的默认伙伴。和 `--pet` 选项相同 |
| `PLAYPETS_BRIDGE` | 终端命令要读取的 `bridge.json` 路径。和 `--bridge` 选项相同 |

- 变量要设在运行应用的环境里：从终端打开应用，或者用操作系统的环境变量设置。

## 会保存与不会保存的内容 <Since v="0.1.0" />

**会保存**

- 伙伴的名字、性格、关系、对我的称呼、大小、在乐园里的位置
- 每位伙伴的亲密度
- 花园、乐园里的摆设和图鉴
- AI 连接的类型、服务器地址、模型名称
- 语言、桌面模式和散步、窗口的位置和大小、始终置顶设置、所选的时段、天气和季节
- 导入的宠物文件及其来源

**以另一种方式保存**

- API 密钥不写进 `state.json`，只保存在这台电脑的安全存储里（macOS 钥匙串、Windows 凭据管理器、Linux Secret Service）。删除连接时一起删除。

**不会保存**

- 和伙伴的对话。只在内存里，关闭应用就消失。
- 编码代理最近活动的记忆。关闭应用就消失。
- 游戏中的位置。游戏结束后回到原来的地方。

卸载后想不留痕迹，请把数据文件夹和安全存储里的 PlayPets 条目一起删掉。
