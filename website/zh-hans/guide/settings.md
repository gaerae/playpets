# 设置

**设置**标签分三组：**通用**（语言和自动聊天开关**偶尔让伙伴们自己聊聊**）、**编码代理联动**、**关于 PlayPets**（版本、应用更新和项目页面），最下面是退出应用。编码代理联动[另有说明](./agents.md)。可以点标签打开，也可以按 <kbd>⌘</kbd> <kbd>,</kbd> 或 <kbd>Ctrl</kbd> <kbd>,</kbd>，或用托盘菜单里的**设置…**。

## 语言 <Since v="0.1.0" />

可以在 한국어、English、日本語、简体中文 中选择。一开始跟随系统语言；更改后，乐园和桌面窗口都会用新语言重新载入。托盘菜单和窗口标题也会一起改变。所选语言保存在 `state.json` 的 `language` 里。

伙伴们的自言自语和问候也会用所选的语言。不过，和 AI 的对话取决于性格和你说的话；对编码代理和终端，应用说的是英语。

启动时给出环境变量 `PLAYPETS_LANG=ko|en|ja|zh-hans`，它会优先于保存的语言。这是测试用的。

## 偶尔让伙伴们自己聊聊 <Since v="0.1.0" />

打开语言正下方的这个开关后，每 20 分钟，接上 AI 的伙伴们会短短地聊几句。默认是关闭的。订阅制 CLI 没有额外费用，但调用次数会增加，所以想要时再打开。窗口隐藏或有人正在回答时，那一轮会跳过。

## 关于 PlayPets <Since v="0.1.0" />

设置标签的最后一组显示版本和**应用更新**，还可以打开本站和 GitHub 上的项目：**网站**、**使用指南**、**版本记录**、**GitHub**、**反馈问题**（新建 issue）和**许可证**（MIT），都会在浏览器中打开。

### 应用更新 <Since v="0.1.0" />

这一行显示当前版本。点击**检查更新**，应用会读取 GitHub 发布页的 `latest.json`；已是最新时会提示“已是最新版本”。

有新版本时（无论是这次检查、应用启动 20 秒后的静默检查，还是从菜单发起的检查发现的）：

- 顶栏会出现写着新版本的按钮（窗口较窄时只显示图标），**设置**标签上会出现小圆点。
- 点按钮会打开更新窗口：**查看新内容**打开本站该版本的页面；**稍后**会把顶栏按钮收起，直到下次启动（那一行和小圆点会保留）；**安装并重启**会显示进度条下载、验证签名，然后以新版本重新启动。伙伴和设置都会保留。
- “关于”里的那一行也有**查看新内容**和**安装并重启**。

如果没能检查成功，请看看网络，并记住 Windows 便携版 zip 不在自动更新范围内。详细内容见[安装](./install.md#更新)。

## 完全退出应用 <Since v="0.1.0" />

乐园窗口的关闭按钮只会隐藏窗口，应用仍留在托盘里。桌面上的伙伴和代理联动会继续运行。

要真正结束，请点击设置标签底部的**完全退出应用**。会弹出“要退出 PlayPets 吗？”的确认框。对话不会保存，桌面上的伙伴也会一起消失。托盘菜单里的**退出**也是一样的。

## 菜单与快捷键 <Since v="0.1.0" />

- **托盘菜单**（菜单栏或任务栏里的小猫）：**打开乐园**、**显示 / 隐藏桌面宠物**、**开启 / 关闭桌面走动**，接着是**设置…**、**检查更新…**（知道有新版本后会变成**更新到 v…**）和**关于 PlayPets**，最后是**退出**。
- **macOS 菜单栏**：**PlayPets** → **关于 PlayPets**、**检查更新…**、**设置…**、隐藏和**退出 PlayPets**；在输入框里剪切、拷贝、粘贴用的**编辑**；以及**窗口**。
- **快捷键**：<kbd>⌘</kbd> <kbd>,</kbd>（macOS）或 <kbd>Ctrl</kbd> <kbd>,</kbd>（Windows、Linux）打开设置；macOS 上 <kbd>⌘</kbd> <kbd>Q</kbd> 退出。

## 数据文件夹 <Since v="0.1.0" />

| 操作系统 | 位置 |
|---|---|
| macOS | `~/Library/Application Support/app.playpets/` |
| Windows | `%APPDATA%\app.playpets\` |
| Linux | `~/.local/share/app.playpets/` |

| 文件 | 内容 |
|---|---|
| `state.json` | 伙伴（名字、性格及其来源、关系、大小、位置、所选的 AI 连接）、AI 连接列表（不含密钥）、语言、桌面模式和走动、各代理负责的伙伴、自动聊天、手动选择的宠物文件夹、文件格式编号（`schema`）。旧版本打开新版本写的文件时，会先留一份副本，只读取自己认识的部分 |
| `bridge.json` | 代理联动用的端口和令牌。每次启动应用都会重新写入 |
| `pets/` | 通过地址导入的宠物文件夹 |
| `builtin/` | 应用自带的三只基础宠物（Tabby、Smoky、Mochi）。每次启动都会检查并解压出来 |

## 环境变量

| 变量 | 作用 |
|---|---|
| `PLAYPETS_DATA` | 把数据文件夹换到别的位置。终端命令（`playpets say` 等）也读同一个值 |
| `CODEX_HOME` | Codex 的主文件夹。邀请标签里的 Codex 宠物文件夹会变成 `$CODEX_HOME/pets` |
| `PLAYPETS_LANG` | 强制指定语言（`ko`、`en`、`ja`、`zh-hans`） |
| `PLAYPETS_PET` | 终端命令的默认伙伴。和 `--pet` 选项相同 |
| `PLAYPETS_BRIDGE` | 终端命令要读取的 `bridge.json` 路径。和 `--bridge` 选项相同 |

变量需要放在运行应用的环境里。可以从终端打开应用，或使用操作系统的环境变量设置。

## 会保存与不会保存的内容 <Since v="0.1.0" />

**会保存**

- 伙伴的名字、性格、大小、在乐园里的位置
- AI 连接的类型、服务器地址、模型名称
- 语言、桌面模式和走动、小窗模式、所选的时段和天气
- 导入的宠物文件及其来源

**以另一种方式保存**

- API 密钥不会写进 `state.json`。它只保存在这台电脑的安全存储里（macOS 钥匙串、Windows 凭据管理器、Linux Secret Service），删除连接时会一起删除。

**不会保存**

- 和伙伴的对话。只存在内存里，关闭应用就会消失。
- 编码代理最近活动的记忆。关闭应用就会消失。
- 游戏中的位置。游戏结束后会回到原来的地方。

卸载应用后若想清除所有痕迹，请把数据文件夹和安全存储里的 PlayPets 条目一起删除。
