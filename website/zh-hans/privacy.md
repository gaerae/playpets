# 隐私政策

- 最后更新：2026年10月18日。
- 维护者：[PlayPets](https://github.com/gaerae/playpets) 项目维护者 gaerae。
- 本政策涵盖桌面应用和本网站，自此版本发布之日起生效。

## 应用保存的信息

- 无需 PlayPets 账户，开发者也不运营聊天服务器。
- 应用未加入广告、使用分析或自动崩溃报告上传。
- 日常移动、游戏与收集不需要连接 AI。
- 保存在设备上：伙伴的名字、性格、关系、收集进度、导入素材、AI 连接配置和应用设置。
- 通过 PlayPets 保存的 API 密钥单独存放在操作系统凭据库中，不在 JSON 设置文件里。
- 部分界面偏好保存在应用 WebView 的本地存储中。
- PlayPets 的对话历史只在应用运行期间保存在内存中，不会把完整对话写入数据文件夹。
- 但使用相应功能时，从对话生成的性格或设置可能会被保存。
- 这不代表连接的 AI 服务或 CLI 不会保存记录。

## AI 与编程代理

- 启用 AI 连接后，提示词可能包含消息、最近对话、伙伴的名字、性格、关系设置及相关代理信息，并发送到你选择的服务或本地服务器。
- 自动聊天开启期间也会使用该连接。
- 远程提供者可能在境外处理信息，其保存、训练与删除政策适用。
- 即使选择本地模型，是否对外通信仍取决于所用工具及其配置。
- Claude Code 和 Codex 连接会运行设备上已安装并登录的 CLI。
- 这些工具及提供者可能建立自己的文件、会话与日志，PlayPets 不控制其保留期限。
- 编码代理联动通过令牌保护的本机回环连接，接收你的配置发送的状态和报告。
- 不要在对话、性格或代理报告中加入密钥或敏感个人信息。

## 下载与更新

- 导入社区宠物或打开画廊，会连接你选择的外部服务。
- GitHub 安装版可能自动连接 GitHub 检查和下载更新。
- MSIX 安装版使用包管理更新，不会下载 GitHub EXE 安装程序来更新。
- Store 安装版由 Microsoft Store 管理更新。
- 外部服务会收到 IP 地址等常规请求信息，这些服务适用其自身政策。

## 本网站

- 网站托管于 GitHub Pages。
- 浏览器可能连接 GitHub 获取版本信息和下载，连接 Google Fonts 和 jsDelivr 获取字体。
- 这些主机依据各自政策接收 IP 地址和浏览器请求头等信息。
- 语言与主题偏好可能使用浏览器存储。
- 网站未添加广告或使用分析服务。
- 制作套件和技能是供你下载后在自选工具中使用的资料。
- 本网站不通过 PlayPets AI 服务器生成图片。
- 提交给外部 AI 工具的文件，适用该工具的政策。

## 保留与删除

- 本地设置会保留到你删除为止。
- 要删除保存的 API 密钥，请在设置中删除对应的 AI 连接。
- 完全退出应用会清除内存中的对话。
- 重置本地数据：
  1. 在设置中删除 AI 连接，让应用仍能识别需要移除的密钥。
  2. 从设置打开数据文件夹。
  3. 退出应用，再删除需要重置的文件。
- 只卸载应用，可能留下数据、凭据或备份。
- 外部服务记录与 CLI 日志，需通过对应服务或工具删除。

| 操作系统 | 默认位置 |
|---|---|
| macOS | `~/Library/Application Support/app.playpets/` |
| Windows | `%APPDATA%\app.playpets\` |
| Linux | `~/.local/share/app.playpets/` |

- MSIX 可能将 Windows 路径虚拟化，请用应用中的打开数据文件夹功能。
- 如果指定了其他数据位置，以该位置为准。

## 联系与变更

- 隐私问题可[联系项目维护者](https://github.com/gaerae/playpets/issues/new/choose)。
- GitHub 议题公开可见，请勿上传个人数据、密钥、聊天日志或身份证件。
- 可以不提供敏感内容，只请求私下联系方式。
- 维护者无法直接删除你设备上的文件或其他提供者持有的记录。
- 政策变更会在本页公布并更新日期。
