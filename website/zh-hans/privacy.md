# 隐私政策

- 最后更新：2026年10月18日。
- 维护者：[PlayPets](https://github.com/gaerae/playpets) 项目维护者 gaerae。
- 本政策涵盖桌面应用和本网站，自此版本发布之日起生效。

## 应用保存的信息

- 不需要 PlayPets 账户，开发者也不运营聊天服务器。
- 应用没有加入广告、使用分析或自动上传崩溃报告的功能。
- 平时走动、玩游戏和收集都不需要连接 AI。
- 保存在设备上的有：伙伴的名字、性格、关系、收集进度、导入的素材、AI 连接配置和应用设置。
- 通过 PlayPets 保存的 API 密钥单独放在操作系统的凭据库里，不写进 JSON 设置文件。
- 部分界面偏好保存在应用 WebView 的本地存储中。

PlayPets 的对话历史只在应用运行期间留在内存里，不会把完整对话写进数据文件夹。不过使用相应功能时，从对话生成的性格或设置可能会保存下来。这并不代表你连接的 AI 服务或 CLI 也不保存记录。

## AI 与编程代理

启用 AI 连接后，提示词可能包含下面这些信息，并发送到你选择的服务或本地服务器：
- 消息和最近的对话
- 伙伴的名字、性格和关系设置
- 相关的代理信息

自动聊天开启期间，也会使用这个连接。
- 远程提供者可能在境外处理信息，保存、训练和删除都适用其自身政策。
- 即使选择本地模型，是否对外通信仍取决于所用工具和配置。
- Claude Code 和 Codex 连接会运行你在设备上安装并登录的 CLI。
- 这些工具和提供者可能会留下自己的文件、会话和日志，PlayPets 不控制它们的保留期限。
- 编码代理联动通过受令牌保护的本机回环连接，接收你让代理发送的状态和报告。
- 不要在对话、性格或代理报告里放密钥或敏感的个人信息。

## 下载与更新

- 导入社区宠物或打开画廊时，会连接你选择的外部服务。
- GitHub 安装版可能会自动连接 GitHub，检查并下载更新。
- MSIX 安装版通过包管理更新，不会下载 GitHub 的 EXE 安装程序来更新。
- Store 安装版的更新由 Microsoft Store 负责。
- 这些服务会收到 IP 地址等常规请求信息，并适用它们各自的政策。

## 本网站

网站托管在 GitHub Pages 上。你的浏览器可能会连接：
- GitHub，获取版本信息和下载
- Google Fonts 和 jsDelivr，获取字体

这些主机按各自的政策接收 IP 地址、浏览器请求头等信息。
- 语言和主题偏好可能会用到浏览器存储。
- 网站没有加入广告或使用分析服务。
- 制作套件和技能是下载资料，供你在自己选的工具里使用。
- 本网站不会通过 PlayPets AI 服务器生成图片。
- 交给外部 AI 工具处理的文件，适用该工具的政策。

## 保留与删除

- 本地设置会一直保留，直到你删除。
- 在设置中删除 AI 连接，保存的 API 密钥也会一起删除。
- 完全退出应用后，内存里的对话就会清空。

重置本地数据：
1. 先在设置中删除 AI 连接，这样应用还能找到需要移除的密钥。
2. 从设置打开数据文件夹。
3. 退出应用，再删除想要重置的文件。

只卸载应用，可能会留下数据、凭据或备份。外部服务的记录和 CLI 日志，需要到对应的服务或工具里删除。

| 操作系统 | 默认位置 |
|---|---|
| macOS | `~/Library/Application Support/app.playpets/` |
| Windows | `%APPDATA%\app.playpets\` |
| Linux | `~/.local/share/app.playpets/` |

- MSIX 可能会把 Windows 路径虚拟化，请使用应用里的打开数据文件夹功能。
- 如果你另外指定了数据位置，就以那个位置为准。

## 联系与变更

- 有隐私方面的问题或请求，可以[联系项目维护者](https://github.com/gaerae/playpets/issues/new/choose)。
- GitHub 议题是公开的，请不要上传个人数据、密钥、聊天日志或身份证件。
- 你可以不写敏感内容，只请求一个私下联系的方式。
- 维护者无法直接删除你设备上的文件，也无法删除其他提供者持有的记录。
- 政策变更会在本页公布，并更新日期。
