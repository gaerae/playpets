# 1.0.0

<ReleaseMeta />

PlayPets 1.0.0은 작은 창에 풍경과 친구를 남기고, 내가 고를 때만 잠깐 놀 수 있게 다듬었어요.

<Downloads version="1.0.0" />

## 달라진 점

- 작은 창에서 친구를 누르면 짧은 놀이 선택창이 열려요. 큰 창에서는 배경과 분위기·놀기·메뉴를 나눴어요.
- 친구에게 땅파기를 시켜 여덟 가지 작은 발견을 모으고, 벚나무·단풍나무·소나무를 심을 수 있어요. 앱을 꺼도 나무는 자라요. 도감 안내에서 확률을 볼 수 있고 매일 할 일은 없어요.
- 친구에 맞게 가구를 키우고, 메뉴의 여백과 구분선을 정리했어요.
- 업데이트는 기존 놀이터 위에서 진행 상황을 보고 접을 수 있어요. 설치와 재시작은 직접 선택해요.
- 배경 제작 키트에서 땅파기와 나무 심기에 쓸 흙이 있는지 정할 수 있어요.
- 앱 버전은 1.0.0, MSIX는 필수 네 번째 자리를 붙인 1.0.0.0이에요. MSIX는 패키지 관리 방식, GitHub 설치판은 서명된 자동 업데이트를 사용해요.

Microsoft Store 심사와 공개는 GitHub 릴리스와 별도예요. 이 페이지가 Store 공개 완료를 뜻하지는 않아요.
