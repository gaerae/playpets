# 1.3.0

<ReleaseMeta />

Grok이 놀이터에 왔어요. Grok Build가 코딩하는 동안 친구가 옆에 있어 주고, 친구들은 Grok으로 대화도 해요.

<Downloads version="1.3.0" />

## 달라진 점

- Grok Build가 생각하고, 도구를 쓰고, 답을 기다리고, 끝낼 때 친구가 반응해요.
- xAI API 키를 넣으면 친구들이 Grok으로 대화해요. 키는 운영체제의 안전한 저장소에 보관돼요.
- Grok Build는 Claude Code와 Cursor 훅도 실행하지만, 이제 자기 친구에게만 보여요.
- <Only os="macOS" /> 앱이 Apple의 공증을 받아 바로 열려요.
- 씨앗 심기 칸이 좁아도 씨앗 수가 칸 밖으로 넘치지 않아요.

## 그 밖에

- Microsoft Store, winget, macOS의 Homebrew로도 설치할 수 있어요. 설치 방법은 [설치하기](../guide/install.md)에 있어요.
- 사용 설명서를 새로 쓰고 버튼 이름을 앱과 맞췄어요.
- 앱이 쓰는 라이브러리의 보안 업데이트가 들어갔어요.

Grok Build 연결 방법은 [코딩 에이전트 연동](../guide/agents.md)에, Grok으로 대화하는 방법은 [친구와 대화하기](../guide/chat.md)에 있어요.
