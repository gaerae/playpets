# 1.3.0

<ReleaseMeta />

Grok이 마당에 왔어요. Grok Build가 코딩하는 동안 친구가 곁을 지키고, 친구들이 Grok으로 대화도 해요.

<Downloads version="1.3.0" />

## 달라진 점

- Grok Build가 생각하고, 도구를 쓰고, 기다리고, 끝낼 때 친구가 반응해요.
- xAI API 키를 넣으면 친구들이 Grok으로 대화해요. 키는 안전한 저장소에 보관돼요.
- Grok의 작업이 Claude Code나 Cursor 친구에게 섞여 보이지 않아요.
- <Only os="macOS" /> Apple의 서명과 공증을 받아 바로 열려요.
- 씨앗 심기 칸이 좁아도 씨앗 수가 칸 밖으로 넘치지 않아요.

## 그 밖에

- Microsoft Store, winget, macOS의 Homebrew로도 설치할 수 있어요. [설치하기](../guide/install.md)에서 확인해요.
- 사용 설명서를 새로 쓰고 버튼 이름을 앱과 맞췄어요.
- 앱이 쓰는 라이브러리의 보안 업데이트가 들어갔어요.

Grok Build 연결 방법은 [코딩 에이전트 연동](../guide/agents.md)에 있어요.
