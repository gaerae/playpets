# 1.3.0

<ReleaseMeta />

PlayPets 1.3.0에서는 Grok을 지원해요. Grok Build가 일하는 모습을 친구가 보여 주고, 친구들이 Grok으로 대화할 수도 있어요. macOS 앱은 이제 서명과 공증을 거쳤고, Microsoft Store, winget, Homebrew로도 설치할 수 있어요.

<Downloads version="1.3.0" />

## 달라진 점

- Claude Code, Codex, Gemini CLI, Cursor에 Grok Build가 더해졌어요. 설정 → 코딩 도구 연결에서 설정을 복사해 `~/.grok/hooks/`에 저장하면, Grok이 생각하고 도구를 쓰고 기다리고 끝내는 모습을 친구가 보여 줘요.
- Grok은 Claude Code와 Cursor의 훅도 함께 실행해요. 이제 Grok의 작업이 Claude Code나 Cursor를 맡은 친구에게 나타나지 않아요.
- 친구들이 Grok으로 대화할 수 있어요. AI를 연결할 때 **Grok API**를 고르고 xAI API 키를 넣어요. 키는 운영체제의 안전한 저장소에 보관돼요.
- macOS 앱이 Apple Developer ID로 서명되고 Apple의 공증을 받아서, '그래도 열기' 단계 없이 바로 열려요.
- Microsoft가 서명한 Microsoft Store 앱으로 설치하거나, `winget install --id 9NSKXQ6R187M --source msstore`로 설치할 수 있어요. macOS에서는 `brew install gaerae/tap/playpets`로 Homebrew 설치가 돼요.
- 씨앗 심기 칸이 좁아도 씨앗 수가 칸 밖으로 나가지 않아요.
- 사용 설명서를 네 언어 모두 새로 썼고, 버튼 이름을 앱과 맞췄어요.
- Linux 키링, 업데이트 확인, AI 연결에 쓰는 Rust 라이브러리의 보안 업데이트가 들어갔어요.

자세한 내용은 [코딩 에이전트 연동](../guide/agents.md)과 [설치하기](../guide/install.md)에서 확인할 수 있어요.
