# 1.1.0

<ReleaseMeta />

PlayPets 1.1.0에서는 친구들이 땅을 파며 찾을 거리가 더 많아지고, 업데이트 확인은 설치를 고를 때까지 조용히 기다려요.

<Downloads version="1.1.0" />

## 달라진 점

- Daisy, Clover, Pip, Miso가 사계절 옷차림에 맞춘 땅파기, 심기, 낚시, 발견 동작을 보여줘요. 가져온 펫은 원래 동작 시트를 그대로 사용해요.
- 계절 꽃, 물속 생물, 곤충, 선물, 나무, 작은 발견을 모아 100종 도감을 채워요. 안내에는 정확한 확률 대신 도움이 되는 서식지 단서를 담았어요.
- 땅파기로 묘목을 찾아 주머니에 모아 두고, 심을 때 하나씩 사용해요. 벚나무, 단풍나무, 소나무, 참나무, 자작나무, 버드나무 여섯 종류를 만날 수 있어요. 앱을 꺼도 심은 나무는 자라요.
- 작은 발견 열일곱 가지를 모을 수 있어요. 씨앗은 땅파기로 얻으며, 꽃씨와 나무 묘목을 같은 탐색에서 찾을 수 있어요.
- 앱을 시작한 뒤 20초, 이후에는 6시간마다 조용히 업데이트를 확인해요. 실패해도 조용히 다시 시도해요. 새 버전 표시만 남기고 설정을 열거나 설치를 시작하지 않아요.
- 설정의 **PlayPets 정보**에서 확인 결과, 새로운 점, 다운로드 진행 상황, 오류, 다시 시도를 한곳에서 볼 수 있어요. **설치하고 다시 시작**을 직접 고르면 진행해요. 다운로드 중 설정을 닫아도 계속 받고, 다시 열어도 중복해서 받지 않아요.
- Microsoft Store 패키지는 별도의 패키지 관리 방식으로 업데이트해요.
- 작은 창과 큰 창 모두에서 놀이터를 가리지 않도록 배경, 놀이, 관리 조작을 간결하게 정리했어요.

자세한 내용은 [발견 안내](../guide/play.md#discovery-guide)와 [업데이트 안내](../guide/install.md#업데이트)에서 확인할 수 있어요. Microsoft Store 심사와 공개는 GitHub 공개와 별도예요.
