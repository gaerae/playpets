# 1.4.0

<ReleaseMeta />

이제 선물은 시간이 아니라 친구가 가져와요. 친구와 놀면 무언가 들고 오고, 더 가까워질 때도 선물이 와요.

<Downloads version="1.4.0" />

## 달라진 점

- 선물은 그날 함께 논 친구가 이틀에 한 번까지 가져와요.
- 친구가 가까워질 때마다 선물을 주고, 각별한 사이가 되면 추억의 선물을 줘요.
- 놀이터가 가득 찼을 때 온 선물은 도감의 선물 상자에서 기다려요.
- 친밀도는 놀이로 쌓여요. 놀이터를 띄워 둔 시간은 하루 한 시간까지 쳐요.
- 혼자 낚시하던 친구가 입질이 오면 불러요. 찌를 눌러야 잡혀요.
- ZIP 파일에서 펫을 가져오고, 친구 초대하기에서 펫을 지울 수 있어요.
- 가져온 배경과 고른 장소, 계절, 날씨가 데이터와 함께 남아요.
- 설정에서 코딩 에이전트를 한 번에 연결해요. Qoder와 Kimi Code도 함께해요.
- Claude Code 친구는 Claude가 물을 때만 기다리고, 실패한 턴도 알려요.
- 대화 기록이 세션마다 500개까지 남고, 긴 대화에서도 친구가 자기다움을 지켜요.
- <Only os="macOS, Linux" /> nvm, fnm, Volta 등으로 설치한 Claude Code와 Codex CLI를 찾아요.
- <Only os="Windows" /> Store 버전에서 펫 갤러리 링크가 열리고 로그인 시 시작도 돼요.
- <Only os="Windows" /> Claude Code, Gemini CLI, Cursor 훅을 고쳤어요. **다시 연결**해 주세요.
- 모니터를 빼도 창이 화면 안으로 돌아오고, 위쪽 버튼으로 크기를 맞춰요.
- 저장, 트레이, 땅 파기, 숨바꼭질, 나무, 선물 옮기기, 장소 버튼의 오류를 고쳤어요.

## 그 밖에

- 선물, 선물 상자, 추억의 선물이 오는 방법을 [놀이터와 놀이](../guide/play.md)에 적었어요.
- 펫 ZIP 가져오기는 [펫 가져오기](../guide/import.md)에 있어요.

코딩 에이전트마다 알릴 수 있는 것은 [코딩 에이전트 연동](../guide/agents.md)에, Linux 바탕화면의 제약은 [바탕화면 모드](../guide/desktop.md)에 있어요.
