# 1.7.2

<ReleaseMeta />

바탕화면으로 내보내면 바로 나타나요. 친구들이 수다를 떨고, 코딩 에이전트가 일하고, 저장하는 동안에도 놀이터가 매끄러워요.

<Downloads version="1.7.2" />

## 달라진 점

- 바탕화면으로 내보내면 바로 나타나요. 처음 내보낼 때도, 모두 들여온 직후에도요.
- 놀이터가 더 빨리 열려요.
- 친구들이 수다를 떨거나 코딩 에이전트가 알리거나 포인터를 움직여도 놀이터가 매끄러워요.
- 긴 대화는 최근 말부터 바로 열리고, 위로 올리면 앞의 말이 이어서 나와요.
- Windows 노트북을 배터리로 쓸 때도 친구들이 매끄럽게 걸어요.
- 해상도가 다른 화면으로 창을 옮겨도 배경과 날씨가 또렷해요.
- 친구 쓰다듬기, 풍경 고르기, 물건 옮기기, 트레이 스위치가 저장을 기다리지 않아요.
- 친구가 많아도 10분마다 놀이터가 잠깐 멈칫하지 않아요.

친구와 선물을 내보내는 방법은 [바탕화면 모드](../guide/desktop.md)에 있어요.
