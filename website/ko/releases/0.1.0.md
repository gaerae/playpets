## 포함된 기능

- 일러스트 기본 친구 Daisy, Clover, Pip과 여름·겨울 의상을 제공해요. 호환되는 커뮤니티 펫을 가져오거나 [캐릭터 제작실](../guide/creator-kit.md)에서 나만의 친구를 준비할 수 있어요.
- 야외 정원부터 포근한 거실까지 네 가지 장소가 있어요. **배경과 분위기**에서 계절·시간대·날씨를 고르고, [배경 제작실](../guide/background-kit.md)에서 만든 배경도 가져올 수 있어요.
- 풍경이 창을 채우고 배경 선택과 메뉴는 작게 모여 있어요. 미니 모드는 메뉴 없이 풍경에 집중하고, 바탕화면 모드에서는 친구가 다른 창 위를 산책해요.
- 친구를 쓰다듬고 피크닉 간식을 나눠 먹어요. 꽃 키우기, 낚시, 곤충 채집, 선물 수집과 숨바꼭질·산책 행렬·술래잡기를 즐길 수 있어요. 계절 이벤트와 선택 가능한 소리도 있어요.
- 대화하려면 로컬 Ollama 모델, 로그인된 Claude Code·Codex CLI 또는 OpenAI 호환 서버를 연결해요. 연결한 서비스의 사용 한도와 요금이 적용돼요. 놀이와 정원 활동에는 AI 연결이 필요 없어요.
- 코딩 에이전트 훅과 MCP를 연결하면 친구가 작업에 반응해요. 앱과 사용 안내는 한국어·영어·일본어·중국어 간체를 지원해요.
- 새 버전이 있으면 배경 선택 앞에 업데이트 버튼이 나타나요. 업데이트 창에서 다운로드·검증·설치 진행을 확인하고, 재시작 후에는 설치된 버전을 짧게 알려줘요.

## 설치 전 확인

업데이트 파일은 서명되어 있지만 macOS 공증과 설치 파일의 신뢰할 수 있는 배포자 서명은 아직 준비되지 않아 보안 경고가 나타날 수 있어요. Linux 설치 파일은 Tauri 안정판의 GTK 3 의존성을 사용하며, 관련 GLib 보안 권고를 계속 추적하고 있어요. 운영체제별 요구 사항과 가능한 절차는 [설치 안내](../guide/install.md)를 확인해 주세요.
