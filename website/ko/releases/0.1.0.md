첫 공개 버전이에요. 놀이터에서 친구를 돌보고, 바탕화면에 내보내고, 이미 쓰는 Claude Code나 Codex 구독으로 대화하고, 코딩 에이전트가 일하는 동안 친구가 함께 반응해요.

### 추가
- 놀이터: 친구를 쓰다듬고 간식을 놓아요. 시간대와 날씨, 계절이 바뀌는 풍경(시계를 따라 움직이는 해와 달, 달의 모양, 벚꽃과 단풍, 비 갠 뒤 무지개)에서 친구들이 산책하고, 숨바꼭질(이름으로 찾기)·산책 행렬·꼬리잡기를 해요. 이름표를 누르면 대화가 열려요. 쓰다듬으면 하트가, 간식과 에이전트의 작업 완료에는 반짝임이 흩어져요. 움직임을 줄인 설정에서는 이런 효과가 모두 멈춰요.
- 그림 같은 놀이터: 언덕과 나무, 구름을 애니메이션 배경처럼 그렸어요. 해가 있는 쪽에서 빛이 들고, 골짜기의 작은 호수에는 하늘이 비쳐요.
- 낚시와 채집: 호수를 누르면 친구가 낚시를 하고(찌가 들어가면 눌러요), 나비·잠자리·반딧불이를 누르면 친구가 뛰어 잡아요. 계절과 시간, 날씨에 따라 물고기 12종과 곤충 9종이 도감을 채워요.
- 놀이터 소리: 산들바람, 호숫가 물결, 낮의 새소리, 따뜻한 밤의 귀뚜라미, 그리고 친구들이 무언가 할 때 나는 작은 소리. 처음엔 작게 켜져 있고 쉽게 끌 수 있어요(시계 옆 스피커, 설정, Cmd/Ctrl+Shift+S).
- 우정: 놀이터에서 함께 보낸 시간과 함께 한 일로 친구와 가까워져요. 이름표의 하트로 얼마나 친한지 보이고, 단계마다 반겨 주기부터 혼자 낚시하기까지 새로운 일이 생겨요.
- 정원: 산책하던 친구가 씨앗을 찾아와요. 심으면 실제 시간을 따라 자라 계절의 꽃이 피고, 날이 갈수록 놀이터가 나만의 모습이 돼요. 하루에 한 번은 친구가 벤치, 등불, 새집, 작은 연못, 우체통, 돗자리 같은 선물도 가져와요. 원하는 곳으로 끌어다 놓으면 돼요.
- 기본 펫: Tabby(타비)·Smoky(스모키)·Mochi(모찌)가 앱에 들어 있어 처음 켜도 바로 초대할 수 있어요. 초대 탭의 **PlayPets 기본 펫**에 보여요.
- 처음 켜면 빈 놀이터가 누구와 함께할지 물으며 기본 펫을 보여 주고, 한 번 누르면 놀이터로 와요. 그다음 작은 카드가 남은 일을 보여 주고 끝난 일을 체크해요. Claude Code나 Codex CLI가 있으면 **바로 연결** 한 번으로 모든 친구에게 키 없이 붙어요.
- 로그인할 때 시작: 설정의 스위치 하나로 켜요. 바탕화면 모드가 켜져 있으면 로그인할 때 친구들만 나와요.
- 작게 보기: 놀이터만 늘 위에 뜨는 작은 창으로 띄워요. 처음에는 화면 구석에, 그다음부터는 마지막으로 둔 자리에 열리고, 마우스를 올리면 간식·수다 버튼이 떠올라요.
- 바탕화면 모드: 모니터마다 친구가 나와 돌아다니고, 끌어서 옮기고, 마우스를 따라 봐요. 친구에게 마우스를 올리면 대화를 여는 이름 버튼이 나와요. 다른 앱의 전체 화면 위에도 떠요(macOS).
- 대화: 친구마다 AI를 연결해요(Claude Code·Codex 구독, Ollama, OpenAI 호환 서버). 성격을 정하거나 대화로 바꿀 수 있고, 친구 여럿이 함께 이야기해요.
- 관계: 친구 설정에서 친구·연인·든든한 선배·장난꾸러기 동생 가운데 고르고 **나를 부르는 말**을 적어요. 말투와 호칭이 달라지고, 친구들끼리 이야기할 때도 서로의 관계를 알아요.
- 수다 떨기: 놀이터 도구줄의 **수다 떨기**를 누르면 AI가 붙은 친구들이 지금 시간과 날씨를 두고 자기들끼리 이야기해요. 설정에서 **가끔 자기들끼리 이야기해요**를 켜면 20분마다 알아서 이야기해요.
- 코딩 에이전트 연동: Claude Code·Gemini CLI·Cursor 훅, Codex 알림, MCP로 에이전트가 일하는 동안 친구가 반응하고, 최근 작업을 이야기해요. 에이전트마다 담당 친구를 정할 수 있고, 담당 에이전트가 이름표와 친구 탭의 칩에 보여요. 친구 머리 옆의 점은 에이전트의 상태(일하는 중, 기다림, 완료, 문제)를 보여 줘요. Node.js 없이 앱 실행 파일이 직접 받아요.
- 펫 가져오기: 커뮤니티 펫 페이지 주소, GitHub 폴더, 내 컴퓨터의 폴더에서 가져와요. `playpets://import?url=<펫 페이지 주소>` 링크를 열면 그 펫을 가져오고 초대 탭이 열려요. 초대 탭은 펫이 있는 곳별로 묶어 보여 주고, **모양** 필터(전체·사람·동물·그 밖)로 추려 볼 수 있어요.
- 언어: 한국어·English·日本語·简体中文. 처음에는 시스템 언어를 따르고 설정에서 바꿔요. 바꾸면 바탕화면 창도 함께 새 언어가 돼요.
- 업데이트와 메뉴: 새 버전이 있으면 상단바 버튼과 **설정** 탭의 점으로 알려 주고, 업데이트 창에서 **새로운 점 보기**, **나중에**, **설치하고 다시 시작**(진행 막대)을 고를 수 있어요. 설정은 일반, 코딩 에이전트 연동, **PlayPets 정보**(버전, 업데이트, 프로젝트 페이지)로 묶었어요. 트레이 메뉴는 작게 보기, 바탕화면 모드, 돌아다니기를 체크 표시로 보여 주고, 코딩 에이전트가 나를 기다리면 아이콘에 작은 점이 붙어요. 트레이 메뉴와 macOS 메뉴 막대에 설정, 업데이트 확인, 정보가 있고, <kbd>⌘</kbd> <kbd>,</kbd> · <kbd>Ctrl</kbd> <kbd>,</kbd>로 설정을 열어요.
- 설치 화면: macOS 디스크 이미지는 놀이터 그림 위에서 앱을 Applications로 끌어다 놓으라고 안내하고, Windows 설치 프로그램에는 펫 그림이 들어가요. Linux 소프트웨어 센터에는 설명과 스크린샷이 보여요.
- 배포 파일: GitHub 릴리스에 macOS dmg(Apple Silicon·Intel), Windows 설치 파일과 포터블 zip(x64·arm64), Linux deb·AppImage(x64·arm64)가 올라가요. 시험용 MSIX만 로컬 빌드로 만들어요.

### 보안
- 펫 가져오기는 붙여 넣은 주소의 사이트(와 그 하위 도메인, 등록된 커뮤니티의 호스트)에서만 파일을 받고, 다른 곳을 가리키는 페이지는 따라가지 않아요. 사설 주소는 이름을 푸는 단계에서 막아요.
- 펫 파일의 설명은 AI에게 지시가 아니라 설명으로 전해지고, 대화 중에 저장된 성격도 그 표시를 유지해요.

### 알려진 제한
- 배포 파일에 코드 서명이 없어 macOS Gatekeeper와 Windows SmartScreen이 처음 실행을 막아요. 넘어가는 방법은 [설치하기](../guide/install.md)에 있어요.
- Windows 빌드는 가상 머신(Windows 11 ARM에서 x64 설치 파일)으로 설치와 실행을 확인했고, 실제 기기에서는 아직 충분히 확인하지 않았어요.
