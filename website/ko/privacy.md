# 개인정보처리방침

최종 갱신일: 2026년 10월 18일. 운영자: [PlayPets](https://github.com/gaerae/playpets) 유지관리자 gaerae. 이 방침은 데스크톱 앱과 웹사이트에 적용하며, 이 버전의 방침이 게시되는 날부터 효력이 있어요.

## 앱에 저장하는 정보

PlayPets 계정은 필요하지 않으며, 개발자가 운영하는 대화 서버도 없어요. 앱에 광고, 이용 분석이나 자동 오류 보고 전송 기능을 넣지 않았어요. 일반적인 이동, 놀이와 수집에는 AI 연결이 필요하지 않아요.

친구의 이름·성격·관계, 수집 기록, 가져온 에셋, AI 연결 설정과 앱 설정은 기기에 저장해요. PlayPets에서 저장한 API 키는 JSON 설정 파일과 분리하여 운영체제의 자격 증명 저장소에 보관해요. 화면 설정 일부는 앱 웹뷰의 로컬 저장소에 남아요.

PlayPets의 대화 기록은 앱 실행 중 메모리에 유지하며 데이터 폴더에 대화 전문을 기록하지 않아요. 다만 대화로 만든 성격이나 설정은 해당 기능을 사용하면 저장될 수 있어요. 연결한 AI 서비스나 CLI도 기록을 남기지 않는다는 뜻은 아니에요.

## AI와 코딩 도구 연결

AI를 연결하면 메시지, 최근 대화, 친구의 이름·성격·관계 설정과 관련 에이전트 정보가 프롬프트에 포함되어 선택한 서비스나 로컬 서버로 전송될 수 있어요. 자동 수다를 켜면 이 연결을 사용해요. 외부 서비스는 국외에서 정보를 처리할 수 있으며, 보관·학습·삭제에는 해당 제공자의 정책이 적용돼요. 로컬 모델도 선택한 도구와 설정에 따라 외부 통신 여부가 달라져요.

Claude Code와 Codex 연결은 기기에 설치하고 로그인한 CLI를 실행해요. 그 도구와 제공자는 별도로 파일·세션·로그를 남길 수 있으며 PlayPets가 보관을 통제하지 않아요. 코딩 에이전트 연동은 사용자가 보내도록 설정한 상태와 보고를 토큰으로 보호된 기기 내부 연결로 받아요. 대화·성격·에이전트 보고에는 비밀키나 민감한 개인정보를 넣지 마세요.

## 다운로드와 업데이트

커뮤니티 펫을 가져오거나 갤러리를 열면 선택한 외부 서비스에 접속해요. GitHub 설치본은 자동 업데이트 확인과 다운로드를 위해 GitHub에 접속할 수 있어요. MSIX 설치본은 GitHub EXE를 내려받아 설치하지 않고 패키지 관리 방식으로 업데이트해요. Store 설치본의 업데이트는 Microsoft Store가 담당해요. 이 과정에서 IP 주소 등 일반적인 요청 정보가 외부 서비스에 전달되며 각 서비스의 개인정보 정책이 적용돼요.

## 웹사이트

사이트는 GitHub Pages에서 제공해요. 브라우저는 릴리스 정보와 다운로드를 위해 GitHub에, 글꼴을 위해 Google Fonts와 jsDelivr에 접속할 수 있어요. 해당 호스트는 자체 정책에 따라 IP 주소와 브라우저 요청 헤더 등을 받아요. 언어·테마 설정에는 브라우저 저장소를 사용할 수 있어요. 사이트에 광고나 이용 분석 서비스를 추가하지 않았어요.

제작 키트와 스킬은 원하는 도구에서 사용하도록 내려받는 자료예요. 웹사이트가 PlayPets AI 서버로 이미지를 생성하지 않아요. 외부 AI 도구에 제공한 파일에는 해당 도구의 정책이 적용돼요.

## 보관과 삭제

로컬 설정은 삭제할 때까지 기기에 남아요. 저장한 API 키는 설정에서 AI 연결을 삭제하면 지워요. 앱을 완전히 종료하면 메모리의 대화 기록이 사라져요. 로컬 데이터를 초기화하려면 먼저 설정에서 데이터 폴더를 열고 앱을 종료한 다음 필요한 파일을 삭제하세요. 데이터 폴더를 지우기 전에 AI 연결을 삭제해야 앱이 삭제할 키를 확인할 수 있어요. 앱 제거만으로 데이터·자격 증명·백업까지 모두 지워지지는 않을 수 있어요. 외부 서비스의 기록과 CLI 로그는 해당 서비스나 도구에서 별도로 삭제해야 해요.

기본 위치는 macOS의 `~/Library/Application Support/app.playpets/`, Windows의 `%APPDATA%\app.playpets\`, Linux의 `~/.local/share/app.playpets/`예요. MSIX는 Windows 경로가 가상화될 수 있으므로 앱의 데이터 폴더 열기를 사용하세요. 별도 데이터 경로를 지정했다면 그 위치를 사용해요.

## 문의와 변경

개인정보 관련 문의는 [프로젝트 유지관리자에게 요청](https://github.com/gaerae/playpets/issues/new/choose)할 수 있어요. GitHub 이슈는 공개되므로 개인정보·비밀키·대화 로그·신분증을 올리지 마세요. 민감한 내용을 쓰지 않고 비공개 연락 경로를 요청할 수 있어요. 운영자가 기기의 파일이나 다른 제공자가 가진 기록을 직접 삭제할 수는 없어요. 방침이 바뀌면 이 페이지와 갱신일을 수정해요.
