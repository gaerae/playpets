# 개인정보처리방침

- 최종 갱신일: 2026년 10월 18일
- 운영자: [PlayPets](https://github.com/gaerae/playpets) 유지관리자 gaerae
- 적용 범위: 데스크톱 앱과 웹사이트
- 효력: 이 버전의 방침을 게시한 날부터

## 앱에 저장하는 정보

- PlayPets 계정은 필요 없어요.
- 개발자가 운영하는 대화 서버는 없어요.
- 앱에는 광고, 이용 분석, 오류 보고 자동 전송 기능을 넣지 않았어요.
- 평소에 돌아다니고 놀고 모으는 데는 AI 연결이 필요 없어요.

기기에 저장하는 것:
- 친구의 이름, 성격, 관계, 수집 기록, 가져온 에셋, AI 연결 설정, 앱 설정
- PlayPets에서 저장한 API 키는 JSON 설정 파일과 따로 운영체제의 자격 증명 저장소에 보관해요.
- 화면 설정 일부는 앱 웹뷰의 로컬 저장소에 남아요.

대화 기록:

대화 기록은 앱이 켜져 있는 동안 메모리에 두고, 데이터 폴더에 대화 전문을 쓰지 않아요. 다만 대화로 만든 성격이나 설정은 그 기능을 쓰면 저장될 수 있어요. 연결한 AI 서비스나 CLI까지 기록을 남기지 않는다는 뜻은 아니에요.

## AI와 코딩 도구 연결

AI를 연결하면 아래 정보가 프롬프트에 담겨 선택한 서비스나 로컬 서버로 갈 수 있어요.
- 메시지, 최근 대화
- 친구의 이름, 성격, 관계 설정
- 관련 에이전트 정보

자동 수다를 켜 두면 이 연결을 써요.
- 외부 서비스는 국외에서 정보를 처리할 수 있어요. 보관, 학습, 삭제는 그 제공자의 정책을 따라요.
- 로컬 모델도 외부와 통신하는지는 선택한 도구와 설정에 달려 있어요.
- Claude Code와 Codex 연결은 기기에 설치하고 로그인한 CLI를 실행해요.
  - 그 도구와 제공자가 따로 파일, 세션, 로그를 남길 수 있어요.
  - PlayPets는 그 보관을 통제하지 않아요.
- 코딩 에이전트 연동은 에이전트가 보내도록 설정한 상태와 보고를 받아요. 기기 안에서만 오가는 연결이고, 토큰으로 보호해요.
- 대화, 성격, 에이전트 보고에는 비밀키나 민감한 개인정보를 넣지 마세요.

## 다운로드와 업데이트

- 커뮤니티 펫을 가져오거나 갤러리를 열면 선택한 외부 서비스에 접속해요.
- GitHub 설치본은 업데이트를 자동으로 확인하고 내려받으려고 GitHub에 접속할 수 있어요.
- MSIX 설치본은 GitHub EXE를 내려받아 설치하지 않고, 패키지 관리 방식으로 업데이트해요.
- Store 설치본은 Microsoft Store가 업데이트를 맡아요.
- 이때 IP 주소 같은 일반적인 요청 정보가 외부 서비스로 가고, 각 서비스의 개인정보 정책이 적용돼요.

## 웹사이트

사이트는 GitHub Pages에서 제공해요. 브라우저가 접속할 수 있는 곳은 다음과 같아요.
- GitHub: 릴리스 정보와 다운로드
- Google Fonts와 jsDelivr: 글꼴

이 호스트들은 자체 정책에 따라 IP 주소, 브라우저 요청 헤더 같은 정보를 받아요.
- 언어와 테마 설정에는 브라우저 저장소를 쓸 수 있어요.
- 사이트에 광고나 이용 분석 서비스를 넣지 않았어요.
- 제작 키트와 스킬은 원하는 도구에서 쓰도록 내려받는 자료예요.
- 웹사이트가 PlayPets AI 서버로 이미지를 생성하지는 않아요.
- 외부 AI 도구에 넘긴 파일에는 그 도구의 정책이 적용돼요.

## 보관과 삭제

- 로컬 설정은 직접 지울 때까지 기기에 남아요.
- 저장한 API 키는 설정에서 AI 연결을 삭제하면 함께 지워져요.
- 앱을 완전히 종료하면 메모리에 있던 대화 기록이 사라져요.

로컬 데이터 초기화:
1. 설정에서 AI 연결부터 삭제해요. 데이터 폴더보다 먼저 지워야 앱이 삭제할 키를 찾을 수 있어요.
2. 설정에서 데이터 폴더를 열어요.
3. 앱을 종료해요.
4. 초기화할 파일을 삭제해요.

앱을 제거하는 것만으로는 데이터, 자격 증명, 백업이 다 지워지지 않을 수 있어요. 외부 서비스의 기록과 CLI 로그는 그 서비스나 도구에서 따로 지워야 해요.

| 운영체제 | 기본 위치 |
|---|---|
| macOS | `~/Library/Application Support/app.playpets/` |
| Windows | `%APPDATA%\app.playpets\` |
| Linux | `~/.local/share/app.playpets/` |

- MSIX에서는 Windows 경로가 가상화될 수 있어요. 앱의 데이터 폴더 열기를 쓰세요.
- 데이터 경로를 따로 지정했다면 그 위치를 써요.

## 문의와 변경

- 개인정보 관련 질문이나 요청은 [프로젝트에서 유지관리자에게 연락](https://github.com/gaerae/playpets/issues/new/choose)해 주세요.
- GitHub 이슈는 누구나 볼 수 있어요. 개인정보, 비밀키, 대화 로그, 신분증은 올리지 마세요.
- 민감한 내용은 적지 않고 비공개 연락 경로만 요청해도 돼요.
- 운영자는 기기에 있는 파일이나 다른 제공자가 가진 기록을 직접 지울 수 없어요.
- 방침이 바뀌면 이 페이지에 올리고 갱신일을 고쳐요.
