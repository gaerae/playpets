# 바탕화면 모드

친구들을 놀이터 창 밖으로 내보내면 바탕화면에서, 일하는 앱들 위에서 지내요.

::: tip 한눈에 보기
| 하고 싶은 것 | 이렇게 해요 | 자세히 |
|---|---|---|
| 친구 하나 내보내기 | 놀이터에서 오른쪽 버튼 → **바탕화면에 보이기** | [켜고 끄기](#turning-it-on-and-off) |
| 모두 내보내기 | **친구와 설정 → 창과 바탕화면 → 바탕화면에 보이기** | [켜고 끄기](#turning-it-on-and-off) |
| 돌아다니게 하기 | 바로 아래 **바탕화면 산책** | [바탕화면 산책](#stroll-on-desktop) |
| 선물, 꽃, 나무로 책상 꾸미기 | 놀이터에서 오른쪽 버튼 → **바탕화면에 보이기** | [선물](#gifts-on-the-desktop), [꽃과 나무](#flowers-and-trees-on-the-desktop) |
| 친구와 대화하기 | 마우스를 올리고 이름 누르기 | [바탕화면에서 하는 일](#things-to-do-on-the-desktop) |
| 다시 들이기 | 오른쪽 버튼 → **바탕화면에서 빼기** | [바탕화면에서 하는 일](#things-to-do-on-the-desktop) |
| 창만 숨기고 친구는 두기 | **친구와 설정 → 창 닫기** | [닫기, 다시 열기, 끝내기](#close-reopen-and-quit) |
:::

## 켜고 끄기 <Since v="0.1.0" /> {#turning-it-on-and-off}

친구 하나: 놀이터에서 그 친구를 오른쪽 버튼으로 누르고 **바탕화면에 보이기**를 골라요. 나가 있으면 체크 표시가 붙고, 한 번 더 고르면 돌아와요. 친구마다 따로 나가고, 놀이터에도 그대로 있어요.

친구 모두 한 번에:

1. **친구와 설정 → 창과 바탕화면**을 열어요.
2. **바탕화면에 보이기**를 켜요.
3. 원하면 바로 아래 **바탕화면 산책**도 켜요. 바탕화면에 무언가 나가 있을 때만 쓸 수 있어요.

- 두 스위치에서 지금 상태를 바로 볼 수 있고, 바꾸는 동안 메뉴는 닫히지 않아요.
- **바탕화면에 보이기**를 끄면 친구, 선물, 꽃, 나무가 모두 놀이터로 돌아와요.
- 친구가 없으면 바탕화면 모드를 켤 수 없어요.
- 트레이 아이콘 메뉴에도 같은 항목이 있어서 놀이터 창을 열지 않아도 돼요.

## 바탕화면에서 하는 일 <Since v="0.1.0" /> {#things-to-do-on-the-desktop}

| 하는 일 | 방법 |
|---|---|
| 쓰다듬기 | 친구를 왼쪽 버튼으로 한 번 눌러요 |
| 옮기기 | 친구를 끌어다 놓아요. 다른 모니터로도 옮길 수 있어요 |
| 대화하기 | 친구에게 마우스를 올리면 아래에 말풍선 표시와 이름이 나와요. 이름을 누르면 놀이터가 그 친구의 대화로 열려요 |
| 메뉴 | 친구를 오른쪽 버튼으로 누르면 **말 걸기**와 **바탕화면에서 빼기**가 나와요. 선물, 꽃, 나무에는 **바탕화면에서 빼기**가 있어요 |
| 눈 맞추기 | 쉬고 있는 친구의 얼굴 위로 마우스를 움직이면 눈이 따라와요. 16방향 시선 그림이 든 v2 펫만 돼요 |

- 더블 클릭에는 아무 반응이 없어요. 친구를 옮기다 실수로 창이 열리지 않게요.
- 처음 무언가를 내보내면 대화하는 법과 다시 들이는 법을 알림으로 알려 줘요.
- 이름은 마우스를 올렸을 때만 나타나서 친구들이 책상 위에 자연스럽게 섞여요.
- [코딩 에이전트](./agents.md)의 상태나 친구가 하는 말은 머리 위 말풍선에 떠요. 긴 말은 세 줄 뒤에 "…"로 끝나요.

## 바탕화면의 선물 <Since v="1.5.0" /> {#gifts-on-the-desktop}

벤치나 화분 같은 선물을 놀이터에서 오른쪽 버튼으로 누르고 **바탕화면에 보이기**를 골라요. 놀이터에도 그대로 있어요.

- 끌어서 옮겨요. 다른 모니터로도 옮길 수 있고, 놓아둔 자리에 머물러요.
- 바탕화면을 산책하는 친구가 가끔 선물 옆으로 걸어가 한마디 해요.
- 놀이터에서 선물을 치우면 바탕화면에서도 빠져요. 한 번 받은 선물은 도감에서 다시 꺼낼 수 있어요([선물](./play.md#gifts)).
- 눈사람과 크리스마스 선물은 놀이터에 보일 때만 바탕화면에도 보여요([계절 이벤트](./play.md#seasonal-events)). 눈사람은 목도리, 모자, 코를, 트리는 장식을 그대로 달고 나가요.
- [크리스마스 밤](./play.md#christmas-night)에는 바탕화면 트리도 놀이터 트리와 함께 커져요.

## 바탕화면의 꽃과 나무 <Since v="1.6.1" /> {#flowers-and-trees-on-the-desktop}

심은 꽃이나 나무를 놀이터에서 오른쪽 버튼으로 누르고 **바탕화면에 보이기**를 골라요. 놀이터에도 그대로 있어요.

- 바탕화면에서도 놀이터와 똑같이 자라요. 새싹을 내놓으면 책상 위에서 꽃이 피어요.
- 다 자란 나무는 놀이터가 보여 주는 계절 모습이에요.
- 다른 장소의 나무도 놀이터가 어느 장소를 보여 주든 바탕화면에 남아요.
- 선물처럼 끌어서 옮겨요. 바탕화면을 산책하는 친구가 가끔 옆으로 걸어가요.
- 놀이터에서 뽑거나 정리하면 바탕화면에서도 빠져요.

## 바탕화면 산책 <Since v="0.1.0" /> {#stroll-on-desktop}

- **바탕화면 산책**을 켜면 친구들이 바탕화면을 천천히 돌아다녀요. 걷는 쪽으로 몸을 돌리고 가끔 멈춰 쉬어요.
- 끌고 있는 동안에는 돌아다니지 않아요.
- 끄면 놓아둔 자리에 가만히 있어요.

## 모니터마다 친구 <Since v="0.1.0" />

- 모니터가 여러 대라면 친구는 어느 모니터에든 있을 수 있어요. 끌어다 놓으면 그 모니터에 머물러요.
- 모니터마다 배율이 달라도 마우스 위치는 각 모니터의 배율에 맞춰 계산해요.

## 다른 앱의 전체 화면 위 <Since v="0.1.0" />

| 운영체제 | 친구가 떠 있는 곳 |
|---|---|
| macOS | 다른 앱의 전체 화면 위에도 떠요. 바탕화면 창이 전체 화면 공간에도 보이는 특별한 패널로 바뀌어요 |
| Windows, Linux | 보통 창 위 |
| Linux Wayland | 보장되지 않아요. Wayland는 앱이 항상 위에 머물거나 마우스 위치를 알 방법을 주지 않아서, 친구가 다른 창 뒤로 갈 수 있고 마우스를 눈으로 따라가지 않아요. 친구를 누르거나 끌어 옮기는 동작도 아직 확인하지 못했어요 |
| Linux X11 | 보통 창 위, 마우스도 따라가요 |

## 닫기, 다시 열기, 끝내기 <Since v="0.1.0" /> {#close-reopen-and-quit}

| 하고 싶은 것 | 방법 | 어떻게 되나요 |
|---|---|---|
| 창 숨기기 | **친구와 설정 → 창 닫기**, 또는 운영체제의 창 닫기 단축키 | 놀이터가 트레이로 숨고, 바탕화면 친구와 에이전트 연동은 계속 돌아가요. macOS에서는 반응 없는 아이콘이 남지 않게 Dock 아이콘도 사라졌다가 놀이터를 다시 열면 돌아와요. Windows와 Linux에서는 작업 표시줄에서 사라져요 |
| 다시 열기 | 메뉴 막대(macOS)나 작업 표시줄(Windows, Linux)의 트레이 아이콘 → **놀이터 열기**. 바탕화면에서 친구 이름을 누르거나 메뉴의 **말 걸기**를 골라도 돼요 | 놀이터 창이 열려요 |
| 끝내기 | **친구와 설정 → PlayPets 종료**, 트레이 메뉴의 **PlayPets 종료**, macOS의 <kbd>⌘</kbd> <kbd>Q</kbd> | 묻지 않고 바로 끝나요. 나눈 대화는 저장되지 않고 바탕화면 친구들도 함께 사라져요 |

- 어느 운영체제에서나 제목 표시줄과 창 버튼이 없어요. 맨 위의 좁고 투명한 부분을 끌어 옮기고, 가장자리나 모서리를 끌어 300 × 210까지 크기를 바꿔요.
- 작은 창에서는 구석 버튼이나 빈 배경의 오른쪽 버튼으로 친구와 설정을 열어요.
- 끝낸 뒤에도 친구의 이름, 성격, 크기와 어떤 친구, 선물, 꽃, 나무가 바탕화면에 나가 있었는지는 기억해요.
