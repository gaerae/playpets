# 바탕화면 모드

친구들을 놀이터 창 밖으로 내보내면 바탕화면에서 지내요. 다른 앱으로 일하는 동안에도 친구가 계속 보여요.

<Shot name="desktop" caption="바탕화면 모드. 친구가 다른 창 위에서 지내고, 코딩 에이전트의 상태를 말풍선으로 보여 줘요." />

## 켜고 끄기 <Since v="0.1.0" />

1. **친구와 설정 → 창과 바탕화면**에서 **바탕화면에 보이기** 스위치를 켜요.
2. 원하면 바로 아래 **바탕화면 산책** 스위치도 켜요. 바탕화면 모드가 켜져 있을 때만 쓸 수 있어요.

두 스위치에서 지금 상태를 바로 볼 수 있고, 바꾸는 동안 메뉴는 닫히지 않아요. **바탕화면에 보이기**를 끄면 친구들이 놀이터로 돌아와요.

- 친구가 없으면 바탕화면 모드를 켤 수 없어요.
- 트레이 아이콘 메뉴에도 같은 항목이 있어서, 놀이터 창을 열지 않고도 켜고 끌 수 있어요.

## 바탕화면에서 하는 일 <Since v="0.1.0" />

| 하는 일 | 방법 |
|---|---|
| 쓰다듬기 | 친구를 왼쪽 버튼으로 한 번 눌러요 |
| 옮기기 | 친구를 끌어다 놓아요. 다른 모니터로도 옮길 수 있어요 |
| 대화하기 | 친구에게 마우스를 올리면 아래에 말풍선 표시와 이름이 나와요. 이름을 누르면 놀이터 창이 그 친구의 대화로 열려요. 오른쪽 버튼으로 눌러도 같아요 |
| 눈 맞추기 | 쉬고 있는 친구의 얼굴 위로 마우스를 움직이면 눈이 마우스를 따라와요. 16방향 시선 그림이 든 v2 펫만 돼요 |

더블 클릭에는 아무 반응이 없어요. 친구를 옮기다가 실수로 창이 열리지 않게 하려고요. 바탕화면 모드를 처음 켜면 대화하는 방법을 알림으로 알려 줘요.

이름은 마우스를 올렸을 때만 나타나서, 친구들이 책상 위에 자연스럽게 섞여요. [코딩 에이전트](./agents.md)의 상태나 친구가 하는 말은 머리 위 말풍선에 떠요. 긴 말은 세 줄 뒤에 "…"로 끝나요.

## 모니터마다 친구 <Since v="0.1.0" />

모니터가 여러 대라면 친구는 어느 모니터에든 있을 수 있어요. 다른 모니터로 끌어다 놓으면 그 모니터에 머물러요. 모니터마다 배율이 달라도 마우스 위치는 각 모니터의 배율에 맞춰 계산해요.

## 바탕화면 산책 <Since v="0.1.0" />

**바탕화면 산책**을 켜면 친구들이 바탕화면을 천천히 돌아다녀요. 걷는 쪽으로 몸을 돌리고 가끔 멈춰 쉬지만, 끌고 있는 동안에는 돌아다니지 않아요. 끄면 놓아둔 자리에 가만히 있어요.

## 다른 앱의 전체 화면 위 <Since v="0.1.0" />

| 운영체제 | 동작 |
|---|---|
| macOS | 다른 앱의 전체 화면 위에도 떠요. 바탕화면 창이 전체 화면 공간에도 보이는 특별한 패널로 바뀌어요 |
| Windows, Linux | 보통 창 위에 떠요 |
| Linux Wayland | 보장되지 않아요. Wayland는 앱이 항상 위에 머물거나 마우스 위치를 알 방법을 주지 않아서, 친구가 다른 창 뒤로 갈 수 있고 마우스를 눈으로 따라가지 않아요 |
| Linux X11 | 보통 창 위에 뜨고, 마우스도 따라가요 |

## 창을 닫아도 계속 <Since v="0.1.0" />

- 어느 운영체제에서나 제목 표시줄과 창 버튼 없이 놀이터만 보여요.
  - 옮기기: 맨 위 가장자리의 좁고 투명한 부분을 끌어요.
  - 크기 바꾸기: 가장자리나 모서리를 끌어요. 300 × 210까지 줄일 수 있어요.

**친구와 설정 → 창 닫기**나 운영체제의 창 닫기 단축키를 쓰면 창을 숨기기만 해요. 바탕화면 친구와 에이전트 연동은 계속 돌아가요.

macOS에서는 창을 닫으면 Dock 아이콘도 함께 사라져요. 눌러도 반응하지 않는 아이콘을 Dock에 남기지 않으려고요. 놀이터를 다시 열면 아이콘도 돌아와요. Windows와 Linux에서는 작업 표시줄에서 사라지고 트레이에만 남아요.

## 다시 여는 법

메뉴 막대(macOS)나 작업 표시줄(Windows, Linux)의 트레이 아이콘을 누르고 **놀이터 열기**를 고르면 돼요. 바탕화면에서 친구 이름을 누르거나 친구를 오른쪽 버튼으로 눌러도 놀이터 창이 열려요.

## 완전히 끝내기

- 아래 중 하나를 고르면 묻지 않고 바로 끝나요.
  - **친구와 설정 → PlayPets 종료**
  - 트레이 메뉴의 **PlayPets 종료**
  - macOS의 <kbd>⌘</kbd> <kbd>Q</kbd>
- 작은 창에서는 구석 버튼을 누르거나 빈 배경을 오른쪽 버튼으로 눌러 친구와 설정을 열어요.

끝내면 나눈 대화는 저장되지 않고, 바탕화면에 있던 친구들도 함께 사라져요. 친구의 이름, 성격, 크기와 바탕화면 모드를 켜 두었는지는 기억해서, 다음에 열면 그대로예요.
