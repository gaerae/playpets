# 설정

- **친구와 설정 → 설정**의 묶음: **언어와 시작**, **친구와 AI**, **코딩 도구 연결**, **앱 업데이트**, **PlayPets 정보**.
- [코딩 도구 연결](./agents.md)은 따로 설명해요.
- 새 버전이 있으면 메뉴의 설정에 점이 붙어요.
- 계절, 소리, 소리 크기는 **배경과 분위기 → 분위기**에서 조절해요.

| 창 크기 | 보이는 모양 | 뒤로 가기 |
|---|---|---|
| 큰 창 | 시스템 설정처럼 목록이 왼쪽에 남고, 고른 묶음이 옆에 열려요. 다시 열면 마지막으로 본 묶음이 보여요 | 친구와 설정으로 돌아와요 |
| 작은 창 | 목록부터 보이고 묶음을 하나씩 열어요 | 묶음에서는 설정 목록으로, 목록에서는 친구와 설정으로 돌아와요 |

- 트레이와 macOS 메뉴 막대의 **PlayPets 정보**, **업데이트 확인…**, 새 버전 알림은 해당 묶음을 바로 열어요. 작은 창에서는 이때도 뒤로 가기가 목록으로 돌아와요.
- 닫으면 풍경으로 돌아와요.

## 언어 <Since v="0.1.0" />

- 한국어, English, 日本語, 简体中文 중에서 골라요.
- 처음에는 시스템 언어를 따라요.
- 바꾸면 놀이터와 바탕화면 창을 모두 새 언어로 다시 불러와요. 트레이 메뉴와 창 제목도 함께 바뀌어요.
- 고른 언어는 `state.json`의 `language`에 저장돼요.
- 친구의 혼잣말과 인사는 고른 언어로 해요.
- AI 답변도 기본으로 고른 언어를 써요. 새 메시지에서 다른 언어로 답해 달라고 할 수 있어요.
- 언어를 바꾸면 생성 중인 답변은 취소해요. 이전 대화는 번역하지 않고 그대로 둬요.
- 코딩 에이전트와 터미널에는 영어로 말해요.
- 환경 변수 `PLAYPETS_LANG=ko|en|ja|zh-hans`를 주고 실행하면 저장된 언어보다 우선해요. 테스트용이에요.

## 컴퓨터를 켜면 PlayPets도 시작해요 <Since v="0.1.0" />

- 켜 두면 컴퓨터에 로그인할 때마다 PlayPets가 함께 시작해요. 기본값은 꺼짐이에요.
- 바탕화면 모드가 켜져 있으면 놀이터 창은 열리지 않아요. 친구들만 바탕화면에 나오고, 창은 트레이에서 기다려요.
- 이 선택은 시스템이 보관해요(macOS의 로그인 항목, Windows의 시작 프로그램, Linux의 자동 시작 항목). 어느 쪽에서 꺼도 꺼져요.

## 친구와 AI <Since v="1.2.0" />

- 모든 AI 연결이 쓰는 친구 수와 함께 보여요.
- **편집**이나 새 연결을 더하는 **AI 연결하기**를 누르면 창이 뜨지 않고, 이 묶음 안에 연결 양식이 펼쳐져요.
- **Esc**를 누르면 양식이 접혀요. 입력한 내용이 있으면 접히는 대신 "바꾼 내용이 있어요. 저장하거나, 버리려면 취소를 눌러 주세요."라고 알려 줘요.
- 여기서 연결을 고쳐도 친구가 그 연결로 옮겨 가지 않아요.
- 연결이 없어도 친구들은 놀고 반응해요.
- 연결 만드는 법은 [친구와 대화하기](./chat.md#연결-만들기)에 있어요.

## 가끔 자기들끼리 이야기해요 <Since v="0.1.0" />

- 친구와 AI의 이 스위치를 켜면 AI를 연결한 친구들이 20분마다 짧게 수다를 떨어요. 기본은 꺼짐이에요.
- 호출은 구독 한도를 쓰거나 제공 업체의 요금 정책을 따라요. 로컬 Ollama 모델은 서버 추론 요금이 없어요.
- 원할 때만 켜세요.
- 창이 숨겨져 있거나 누가 답하는 중이면 그 차례는 건너뛰어요.

## 가끔 알아서 땅을 파며 놀아요 <Since v="1.2.0" />

- 친구와 AI의 이 스위치를 켜면 놀이터가 보이는 동안 쉬고 있는 친구가 몇 분마다 스스로 고른 한 곳을 파요.
- 기본은 꺼짐이고, AI 연결은 필요 없어요.
- 게임 중이거나 도구를 들고 있는 동안에는 알아서 파지 않아요. 포근한 거실처럼 흙이 없는 곳에서도 쉬어요.
- 찾은 것은 다른 땅파기와 똑같이 남아요.

## PlayPets 정보 <Since v="0.1.0" />

- **PlayPets 정보**에는 버전과 세 묶음이 있어요.

| 묶음 | 들어 있는 것 |
|---|---|
| **도움말** | 사용 안내, 문제 알리기, **데이터 폴더 열기**(친구, 설정, 백업이 저장된 곳. [데이터 폴더](#data-folder) 참고) |
| **프로젝트** | 사이트, 버전 기록, GitHub |
| **개인정보와 라이선스** | 개인정보처리방침, 라이선스 |

- 링크는 브라우저에서 열려요. 업데이트는 앱 업데이트 묶음에서 해요.

## 앱 업데이트 <Since v="0.1.0" />

- Microsoft Store 설치본은 Store에서 업데이트해요. **Microsoft Store → 라이브러리**에서 확인해 주세요.
- 아래 안내는 MSIX가 아닌 GitHub 설치본에 해당해요. 테스트용 MSIX도 패키지 관리 방식으로 업데이트해요.
- 저장과 외부 통신은 [개인정보처리방침](../privacy.md)에 있어요.

확인:
- 줄에 지금 버전이 보여요.
- **업데이트 확인**을 누르면 GitHub 릴리스의 `latest.json`을 읽어요. 최신이면 "최신 버전이에요"라고 알려 줘요.
- 앱 시작 20초 뒤 조용히 확인하고, 6시간마다 다시 확인해요. 직접 확인할 수도 있어요.
- 설치는 직접 고를 때만 해요. 묶음 아래에도 그렇게 적혀 있어요.
- **이번 버전에서 달라진 점**은 지금 쓰는 버전의 릴리스 페이지를 열어요.
- 새 버전 알림을 누르면 **친구와 설정 → 설정 → 앱 업데이트**가 열려요.

설치:
- **새로운 점 보기**는 브라우저에서 버전 페이지를 열어요.
- **설치하고 다시 시작**, 다운로드 진행률, 검증과 설치, 실패 후 재시도까지 모두 앱 업데이트 안에서 해요. 별도 업데이트 창은 열지 않아요.
- 다운로드 크기를 알 수 없으면 백분율 없이 진행을 표시해요.
- 다시 시작해도 친구와 설정은 유지돼요. 설치한 버전을 잠깐 알려 줘요.

## PlayPets 종료 <Since v="0.1.0" />

| 항목 | 하는 일 |
|---|---|
| **친구와 설정**의 **창 닫기** | 창을 트레이로 숨겨요. 바탕화면 친구와 에이전트 연동은 계속 실행해요 |
| 그 옆의 **PlayPets 종료** | 묻지 않고 바로 앱을 종료해요. 트레이의 **PlayPets 종료**, macOS의 <kbd>⌘</kbd> <kbd>Q</kbd>와 같아요. 대화는 저장되지 않아요 |

- 빈 배경 우클릭에는 종료 항목이 바로 나오지 않아요. 먼저 친구와 설정을 열어요.

## 메뉴와 단축키 <Since v="0.1.0" />

**트레이 메뉴**(메뉴 막대나 작업 표시줄의 고양이):
- 항목: **놀이터 열기**, **친구**(친구가 있을 때), **친구 초대…**, **항상 위에 표시**, **바탕화면에 보이기**, **바탕화면 산책**(바탕화면 모드가 켜졌을 때), **놀이터 소리**, **설정…**, **업데이트 확인…**, **PlayPets 정보**, **PlayPets 종료**.
- 친구가 없어도 항상 위에 표시는 쓸 수 있어요. 바탕화면 스위치는 친구가 오면 나타나요.
- 소리가 켜지면 체크 표시가 붙어요.
- 새 버전이 있으면 업데이트 항목이 **새 버전 v… 설치…**로 바뀌어요.
- Windows에서는 왼쪽 클릭으로 놀이터를, 오른쪽 클릭으로 메뉴를 열어요.
- 에이전트가 기다리거나 문제가 생기면 파란 점이나 빨간 점이 붙고, 툴팁에 친구 이름이 보여요.

**macOS 메뉴 막대**:
- **PlayPets** → **PlayPets 정보**, **업데이트 확인…**, **설정…**, 가리기, **PlayPets 종료**
- **편집**: 입력란에서 오려두기, 복사, 붙여넣기
- **보기** → **친구와 설정**, **친구**, **친구 초대…**, **항상 위에 표시**, **바탕화면에 보이기**, **놀이터 소리**
  - 항상 위에 표시, 바탕화면에 보이기, 놀이터 소리는 체크 표시로 켜고 꺼요.
  - 바탕화면 스위치는 친구가 오기 전에는 흐리게 꺼져 있어요.
- **윈도우**

**단축키**(macOS는 <kbd>⌘</kbd>, Windows와 Linux는 <kbd>Ctrl</kbd>):

| 키 | 하는 일 |
|---|---|
| <kbd>⌘</kbd> <kbd>1</kbd> | 친구와 대화 열기 |
| <kbd>⌘</kbd> <kbd>2</kbd> | 친구 초대 열기 |
| <kbd>⌘</kbd> <kbd>,</kbd> | 설정 열기 |
| <kbd>⌘</kbd> <kbd>Shift</kbd> <kbd>P</kbd> | 친구와 설정 열기 |
| <kbd>⌘</kbd> <kbd>Shift</kbd> <kbd>M</kbd> | 항상 위에 표시 켜고 끄기 |
| <kbd>⌘</kbd> <kbd>Shift</kbd> <kbd>D</kbd> | 바탕화면에 보이기 켜고 끄기 |
| <kbd>⌘</kbd> <kbd>Shift</kbd> <kbd>S</kbd> | 놀이터 소리 켜고 끄기 |
| <kbd>⌘</kbd> <kbd>Q</kbd> | PlayPets 종료(macOS) |

## 데이터 폴더 <Since v="0.1.0" /> {#data-folder}

| 운영체제 | 위치 |
|---|---|
| macOS | `~/Library/Application Support/app.playpets/` |
| Windows | `%APPDATA%\app.playpets\` |
| Linux | `~/.local/share/app.playpets/` |

| 파일 | 내용 |
|---|---|
| `state.json` | 친구와 설정 전체(아래 목록). 새 판이 쓴 파일을 옛 판이 열면 사본을 두고 아는 부분만 읽어요 |
| `bridge.json` | 에이전트 연동용 포트와 토큰. 앱을 켤 때마다 새로 써요 |
| `pets/` | 주소로 가져온 펫 폴더 |
| `builtin/` | 기본 펫 네 개를 켤 때마다 확인하고 풀어 둬요. 각자 독립된 기본 그림을 써요 |

`state.json`에 든 것:
- 친구: 이름, 성격과 그 출처, 관계, 나를 부르는 말, 크기, 위치, 고른 AI 연결
- AI 연결 목록(키는 빼고), 언어
- 바탕화면 모드와 돌아다니기, 에이전트별 담당 친구, 자동 수다, 자동 땅파기
- 놀이터 소리와 소리 크기, 창의 위치와 크기, 항상 위에 표시 설정
- 정원과 소품(`garden`), 도감(`album`), 친밀도(`bonds`)
- 직접 고른 펫 폴더, 파일 형식 번호(`schema`)

친구를 불러오지 못했을 때:
- 앱을 켤 때 친구를 불러오지 못하면 아래 바 바로 위에 접힌 **시작 안내** 카드가 떠요. 놀이터 크기는 줄어들지 않아요.
- 카드를 펼쳐 내용을 확인해 주세요.
- 펫 파일이 없다고 나오면 원래 펫 폴더와 파일을 확인해요. 필요하면 복구한 뒤 PlayPets를 완전히 종료했다가 다시 열어 주세요.
- 친구가 최대 12명이라면 자리를 비운 뒤 앱을 다시 열어 주세요.
- 이런 안내가 나와도 저장된 친구 기록은 삭제되지 않아요.
- 카드를 닫으면 이번 실행 동안 숨겨지고, 새 안내가 생기면 다시 나타나요.

## 환경 변수

| 변수 | 하는 일 |
|---|---|
| `PLAYPETS_DATA` | 데이터 폴더를 다른 곳으로 바꿔요. 터미널 명령(`playpets say` 등)도 같은 값을 봐요 |
| `CODEX_HOME` | Codex의 홈 폴더예요. 친구 초대의 Codex 펫 폴더가 `$CODEX_HOME/pets`로 바뀌어요 |
| `PLAYPETS_LANG` | 언어를 강제해요(`ko`, `en`, `ja`, `zh-hans`) |
| `PLAYPETS_PET` | 터미널 명령의 기본 친구. `--pet` 옵션과 같아요 |
| `PLAYPETS_BRIDGE` | 터미널 명령이 읽을 `bridge.json`의 경로. `--bridge` 옵션과 같아요 |

- 변수는 앱을 실행하는 환경에 두어야 해요. 터미널에서 앱을 열거나, 운영체제의 환경 변수 설정을 써요.

## 저장되는 것과 저장되지 않는 것 <Since v="0.1.0" />

**저장돼요**

- 친구의 이름, 성격, 관계, 나를 부르는 말, 크기, 놀이터 위치
- 친구마다의 친밀도
- 정원, 놀이터에 둔 소품, 도감
- AI 연결의 종류, 서버 주소, 모델 이름
- 언어, 바탕화면 모드와 돌아다니기, 창의 위치와 크기, 항상 위에 표시 설정, 고른 시간대, 날씨, 계절
- 가져온 펫 파일과 출처

**다르게 저장돼요**

- API 키는 `state.json`에 들어가지 않아요.
- 이 컴퓨터의 보안 저장소(macOS 키체인, Windows 자격 증명 관리자, Linux Secret Service)에만 저장되고, 연결을 지우면 함께 지워져요.

**저장되지 않아요**

- 친구와 나눈 대화. 메모리에만 있고 앱을 끄면 사라져요.
- 코딩 에이전트의 최근 활동 기억. 앱을 끄면 사라져요.
- 놀이 중의 위치. 놀이가 끝나면 원래 자리로 돌아가요.

- 앱을 지운 뒤 모든 흔적을 없애려면 데이터 폴더와 보안 저장소의 PlayPets 항목을 함께 지워 주세요.
