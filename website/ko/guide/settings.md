# 설정

**메뉴 → 설정**, <kbd>⌘</kbd>/<kbd>Ctrl</kbd> <kbd>,</kbd>, 또는 트레이의 **설정…**으로 열어요. 설정은 놀이터 위에 열리고, 바깥을 누르거나 <kbd>Esc</kbd>를 누르면 닫혀요. **일반**(언어와 로그인 시 시작), **놀이터**(계절·자동 수다·소리), **코딩 에이전트 연동**, **PlayPets 정보**(로고·버전·업데이트·프로젝트 링크)의 네 묶음으로 나뉘어요. [코딩 에이전트 연동](./agents.md)은 따로 설명해요.

제목과 메뉴는 고정되어 있고 선택한 항목의 본문만 스크롤돼요. 다른 메뉴를 누르면 본문이 바뀌고, 설정을 다시 열면 마지막으로 보던 항목이 나와요. 앱 종료는 **PlayPets 정보**에 있어요.

## 계절

**설정 → 놀이터 → 계절**에서 자동·봄·여름·가을·겨울을 골라요. 자동은 현지 달력을 따라요. 고른 계절은 저장되고 일반·미니 모드의 풍경과 친구 의상에 적용돼요. 바탕화면 친구도 같은 계절을 따르며, 반영에 최대 1분이 걸릴 수 있어요. 봄·가을은 겹쳐 입은 기본 의상을 사용해요. 축제는 실제 날짜에만 열려요.

## 언어 <Since v="0.1.0" />

한국어, English, 日本語, 简体中文 중에서 골라요. 처음에는 시스템 언어를 따르고, 바꾸면 놀이터와 바탕화면 창을 모두 새 언어로 다시 불러와요. 트레이 메뉴와 창 제목도 함께 바뀌어요. 고른 언어는 `state.json`의 `language`에 저장돼요.

친구의 혼잣말과 인사는 고른 언어로 해요. AI 답변도 기본적으로 고른 언어를 사용하며, 새 메시지에서 다른 언어로 답해 달라고 요청할 수 있어요. 언어를 바꾸면 생성 중인 답변은 취소하고, 이전 대화는 번역하지 않고 그대로 둬요. 코딩 에이전트와 터미널에는 영어로 말해요.

환경 변수 `PLAYPETS_LANG=ko|en|ja|zh-hans`를 주고 실행하면 저장된 언어보다 우선해요. 테스트용이에요.

## 컴퓨터를 켜면 PlayPets도 시작해요 <Since v="0.1.0" />

켜 두면 컴퓨터에 로그인할 때마다 PlayPets가 함께 시작해요. 기본값은 꺼짐이에요. 바탕화면 모드가 켜져 있으면 로그인할 때 놀이터 창은 열리지 않고, 친구들만 바탕화면에 나오고 창은 트레이에서 기다려요. 이 선택은 시스템이 보관해요(macOS의 로그인 항목, Windows의 시작 프로그램, Linux의 자동 시작 항목). 그래서 어느 쪽에서 꺼도 꺼져요.

## 가끔 자기들끼리 이야기해요 <Since v="0.1.0" />

놀이터 묶음의 이 스위치를 켜면 20분마다 AI를 연결한 친구들이 짧게 수다를 떨어요. 기본은 꺼져 있어요. 호출은 구독 한도를 쓰거나 제공 업체의 요금 정책을 따라요. 로컬 Ollama 모델은 서버 추론 요금이 없어요. 원할 때만 켜세요. 창이 숨겨져 있거나 누가 답하는 중이면 그 차례는 건너뛰어요.

## 놀이터 소리 <Since v="0.1.0" />

놀이터에는 놀이터만의 소리가 있어요. 산들바람, 호숫가의 잔물결, 잎사귀를 스치는 바람, 낮의 새소리(아침에 가장 많아요), 여름과 가을 밤의 귀뚜라미, 비 오는 날의 빗소리예요. 친구들도 작은 소리를 내요. 쓰다듬으면 부드러운 음 하나, 물고기가 물면 퐁당, 낚아 올리면 첨벙, 선물이나 새 친밀도 단계에는 짧은 가락이 울려요. 소리는 시간대, 날씨, 계절에 따라 달라져요.

- 처음부터 작은 소리로 켜져 있고, 창을 처음 누른 뒤부터 들려요.
- 놀이터가 보일 때만 들려요. 창이 숨겨지거나 최소화되었을 때, 바탕화면에만 친구들이 나와 있을 때는 조용해요. 작게 보기에서는 계속 들려요.
- 끄고 켜려면 **메뉴**의 스피커, 트레이의 **놀이터 소리**, 이 스위치, macOS 메뉴 막대의 **보기** → **놀이터 소리**, 또는 <kbd>⌘</kbd>/<kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>S</kbd>를 써요. 스위치 아래 **소리 크기** 막대로 크기를 정해요.

## PlayPets 정보 <Since v="0.1.0" />

설정 탭의 마지막 묶음에 버전과 **앱 업데이트**가 있고, 이 사이트와 GitHub의 프로젝트를 열 수 있어요. **사이트**, **사용 안내**, **버전 기록**, **GitHub**, **문제 알리기**(새 이슈), **라이선스**(MIT)가 있고, 브라우저에서 열려요.

### 앱 업데이트 <Since v="0.1.0" />

줄에 지금 버전이 보여요. **업데이트 확인**을 누르면 GitHub 릴리스의 `latest.json`을 읽고, 최신이면 "최신 버전이에요"라고 알려 줘요.

새 버전이 있으면, 이 확인이든 앱 시작 20초 뒤의 조용한 확인이든 메뉴에서 한 확인이든:

- **메뉴**를 열면 새 버전 버튼과 **설정**의 점을 볼 수 있어요.
- 버튼을 누르면 업데이트 창이 열려요. **새로운 점 보기**는 이 사이트의 그 버전 페이지를 열고, **나중에**는 다음 실행까지 업데이트 버튼을 치워요(줄과 점은 남아요). **설치하고 다시 시작**은 진행 막대와 함께 받아서 서명을 확인하고 새 버전으로 다시 시작해요. 친구들과 설정은 그대로예요.
- 정보 묶음의 줄에도 **새로운 점 보기**와 **설치하고 다시 시작**이 있어요.

확인하지 못했다면 네트워크를 보고, Windows 포터블 zip은 자동 업데이트 대상이 아니라는 점을 기억해 주세요. 자세한 내용은 [설치하기](./install.md#업데이트)에 있어요.

## 앱 완전히 종료 <Since v="0.1.0" />

놀이터 창의 닫기 버튼은 창만 숨기고 앱은 트레이에 남아요. 바탕화면의 친구와 에이전트 연동은 계속 돌아가요.

정말 끝내려면 **메뉴 → 설정 → PlayPets 정보**의 **앱 완전히 종료**를 눌러요. "PlayPets를 종료할까요?" 확인 창이 떠요. 나눈 대화는 저장되지 않고, 바탕화면의 친구들도 함께 사라져요. 트레이 메뉴의 **종료**도 같아요.

## 메뉴와 단축키 <Since v="0.1.0" />

- **트레이 메뉴**(메뉴 막대나 작업 표시줄의 고양이): **놀이터 열기**, 친구가 있을 때의 **친구**, **친구 초대…**, **작게 보기**, **바탕화면에 보이기**, 바탕화면 모드가 켜졌을 때의 **바탕화면에서 돌아다니기**, **놀이터 소리**, **설정…**, **업데이트 확인…**, **PlayPets 정보**, **종료**가 있어요. 친구가 없으면 보기 스위치는 빠지지만 초대와 소리는 계속 사용할 수 있어요. 소리가 켜지면 체크 표시가 붙어요. 새 버전이 있으면 업데이트 항목이 **새 버전 v… 설치…**로 바뀌어요. Windows에서는 왼쪽 클릭으로 놀이터를, 오른쪽 클릭으로 메뉴를 열어요. 에이전트가 기다리거나 문제가 생기면 파란 점이나 빨간 점이 붙고, 툴팁에 친구 이름이 보여요.
- **macOS 메뉴 막대**: **PlayPets** → **PlayPets에 관하여**, **업데이트 확인…**, **설정…**, 가리기, **PlayPets 종료**. 입력란에서 오려두기·복사·붙여넣기를 쓰는 **편집**, **보기** → **친구**, **친구 초대…**, 체크 표시로 켜고 끄는 **작게 보기**와 **바탕화면에 보이기**(친구가 오기 전에는 흐리게 꺼져 있어요), 체크 표시로 켜고 끄는 **놀이터 소리**, 그리고 **윈도우**가 있어요.
- **단축키**(macOS는 <kbd>⌘</kbd>, Windows와 Linux는 <kbd>Ctrl</kbd>):

| 키 | 하는 일 |
|---|---|
| <kbd>⌘</kbd> <kbd>1</kbd> | 친구 탭 열기 |
| <kbd>⌘</kbd> <kbd>2</kbd> | 초대 탭 열기 |
| <kbd>⌘</kbd> <kbd>,</kbd> | 설정 열기 |
| <kbd>⌘</kbd> <kbd>Shift</kbd> <kbd>M</kbd> | 작게 보기 켜고 끄기 |
| <kbd>⌘</kbd> <kbd>Shift</kbd> <kbd>D</kbd> | 바탕화면에 보이기 켜고 끄기 |
| <kbd>⌘</kbd> <kbd>Shift</kbd> <kbd>S</kbd> | 놀이터 소리 켜고 끄기 |
| <kbd>⌘</kbd> <kbd>Q</kbd> | 종료(macOS) |

## 데이터 폴더 <Since v="0.1.0" />

| 운영체제 | 위치 |
|---|---|
| macOS | `~/Library/Application Support/app.playpets/` |
| Windows | `%APPDATA%\app.playpets\` |
| Linux | `~/.local/share/app.playpets/` |

| 파일 | 내용 |
|---|---|
| `state.json` | 친구(이름, 성격과 그 출처, 관계, 나를 부르는 말, 크기, 위치, 고른 AI 연결), AI 연결 목록(키는 빼고), 언어, 바탕화면 모드와 돌아다니기, 에이전트별 담당 친구, 자동 수다, 놀이터 소리와 소리 크기, 작은 창의 자리와 크기(`miniRect`), 정원과 소품(`garden`), 도감(`album`), 친밀도(`bonds`), 직접 고른 펫 폴더, 파일 형식 번호(`schema`). 새 판이 쓴 파일을 옛 판이 열면 사본을 두고 아는 부분만 읽어요 |
| `bridge.json` | 에이전트 연동용 포트와 토큰. 앱을 켤 때마다 새로 써요 |
| `pets/` | 주소로 가져온 펫 폴더 |
| `builtin/` | 기본 펫 세 개를 켤 때마다 확인하고 풀어 둬요. 각자 독립된 기본 그림을 사용해요 |

## 환경 변수

| 변수 | 하는 일 |
|---|---|
| `PLAYPETS_DATA` | 데이터 폴더를 다른 곳으로 바꿔요. 터미널 명령(`playpets say` 등)도 같은 값을 봐요 |
| `CODEX_HOME` | Codex의 홈 폴더예요. 초대 탭의 Codex 펫 폴더가 `$CODEX_HOME/pets`로 바뀌어요 |
| `PLAYPETS_LANG` | 언어를 강제해요(`ko`, `en`, `ja`, `zh-hans`) |
| `PLAYPETS_PET` | 터미널 명령의 기본 친구. `--pet` 옵션과 같아요 |
| `PLAYPETS_BRIDGE` | 터미널 명령이 읽을 `bridge.json`의 경로. `--bridge` 옵션과 같아요 |

앱을 실행하는 환경에 변수를 두어야 해요. 터미널에서 앱을 열거나, 운영체제의 환경 변수 설정을 써요.

## 저장되는 것과 저장되지 않는 것 <Since v="0.1.0" />

**저장돼요**

- 친구의 이름, 성격, 관계, 나를 부르는 말, 크기, 놀이터 위치
- 친구마다의 친밀도
- 정원, 놀이터에 둔 소품, 도감
- AI 연결의 종류, 서버 주소, 모델 이름
- 언어, 바탕화면 모드와 돌아다니기, 작게 보기와 작은 창의 자리와 크기, 고른 시간대·날씨·계절
- 가져온 펫 파일과 출처

**다르게 저장돼요**

- API 키는 `state.json`에 들어가지 않아요. 이 컴퓨터의 보안 저장소(macOS 키체인, Windows 자격 증명 관리자, Linux Secret Service)에만 저장되고, 연결을 지우면 함께 지워져요.

**저장되지 않아요**

- 친구와 나눈 대화. 메모리에만 있고 앱을 끄면 사라져요.
- 코딩 에이전트의 최근 활동 기억. 앱을 끄면 사라져요.
- 놀이 중의 위치. 놀이가 끝나면 원래 자리로 돌아가요.

앱을 지운 뒤 모든 흔적을 없애려면 데이터 폴더와 보안 저장소의 PlayPets 항목을 함께 지워 주세요.
