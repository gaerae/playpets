# 사용 안내

PlayPets는 친구들이 함께 사는 놀이터예요. 친구들은 나와도 이야기하고, 자기들끼리도 이야기해요. 기본 캐릭터를 초대하거나 호환되는 커뮤니티 펫 파일을 가져온 뒤 이름과 성격, 관계를 정해 주면 돼요. Codex는 없어도 괜찮아요.

처음에는 맑은 봄 한낮의 놀이터가 열려요. 계절과 시간대, 날씨는 직접 고르거나 자동으로 둘 수 있어요. 친구들은 산책하고 간식을 먹고 세 가지 놀이를 하며 지내요. 꽃씨와 묘목은 땅을 파서 찾아요.

선물은 친구가 몇 명이든 놀이터 전체에 현지 날짜로 하루 하나까지 와요. 꽃을 키우고 낚시와 채집으로 도감을 채우다 보면 친구들과 조금씩 가까워져요.

창을 줄여 작업하는 화면 옆에 둬도 되고, 바탕화면 모드로 친구들을 다른 창 위로 내보내도 돼요.

대화하려면 로컬 모델이나 로그인한 CLI 같은 AI 연결이 있어야 해요. 코딩 에이전트 연동은 원할 때만 하면 돼요.

## 필요한 것

| 항목 | 내용 |
|---|---|
| 운영체제 | macOS, Windows, Linux |
| AI | 선택이에요. 연결하지 않아도 초대, 놀이, 바탕화면 모드는 모두 돼요 |
| 코딩 에이전트 | 선택이에요. Claude Code, Codex CLI, Gemini CLI, Cursor, Grok Build, MCP를 쓰는 도구와 이어져요 |
| 인터넷 | 설치 파일 다운로드, 커뮤니티 펫 가져오기, 업데이트, 원격 AI 대화에 필요해요. 놀이터 활동과 미리 내려받은 로컬 Ollama 모델은 오프라인에서도 돼요 |

Tauri로 만들어서 운영체제에 들어 있는 웹뷰를 써요. 브라우저를 통째로 앱에 넣지 않아요.

## 두 낱말

펫은 캐릭터 파일이에요. `pet.json`과 스프라이트 시트가 든 폴더 하나가 펫 하나예요. Codex 펫 폴더에 있는 펫은 알아서 보이고, 커뮤니티 사이트에서 가져오거나 내 컴퓨터의 폴더를 골라도 돼요.

친구는 놀이터에 초대한 펫이에요. 같은 펫을 여러 번 초대하면 친구가 여럿 생기고, 친구마다 이름과 성격, 크기, AI를 따로 정할 수 있어요.
