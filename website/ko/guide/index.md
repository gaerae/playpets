# 사용 안내

PlayPets는 나와도 서로도 이야기하는 친구들이 함께 사는 놀이터예요. 기본 캐릭터를 초대하거나 호환되는 커뮤니티 펫 파일을 가져온 뒤 이름과 성격, 관계를 정해요. Codex가 없어도 돼요.

시간대와 날씨, 계절에 따라 놀이터가 바뀌어요. 친구는 산책하고 간식을 먹고 세 가지 놀이를 하며 씨앗과 선물을 가져와요. 꽃을 키우고 낚시와 채집으로 도감을 채우며 조금씩 친해질 수 있어요. 미니 모드는 작업 옆에 놀이터를 두고, 바탕화면 모드는 친구를 다른 창 위로 내보내요. 대화하려면 로컬 모델이나 로그인한 CLI 등의 AI 연결이 필요해요. 코딩 에이전트 연동은 선택이에요.

## 필요한 것

| 항목 | 내용 |
|---|---|
| 운영체제 | macOS, Windows, Linux |
| AI | 선택이에요. 연결하지 않아도 초대, 놀이, 바탕화면 모드는 모두 돼요 |
| 코딩 에이전트 | 선택이에요. Claude Code, Codex CLI, Gemini CLI, Cursor, MCP를 쓰는 도구와 이어져요 |
| 인터넷 | 설치 파일 다운로드, 커뮤니티 펫 가져오기, 업데이트와 원격 AI 대화에 필요해요. 놀이터 활동과 미리 내려받은 로컬 Ollama 모델은 오프라인에서도 사용할 수 있어요 |

Tauri로 만들어 운영체제의 웹뷰를 써요. 별도의 전체 브라우저를 앱에 포함하지 않아요.

## 두 낱말

- **펫**은 캐릭터 파일이에요. `pet.json`과 스프라이트 시트가 든 폴더 하나가 펫 하나예요. Codex의 펫 폴더에 있는 펫은 자동으로 보이고, 커뮤니티 사이트에서 가져오거나 내 컴퓨터의 폴더를 고를 수도 있어요.
- **친구**는 놀이터에 초대한 개체예요. 같은 펫을 여러 번 초대하면 친구가 여럿 생기고, 각자 다른 이름과 성격, 크기, AI를 가질 수 있어요.
