# 사용 안내

PlayPets는 펫들이 서로 이야기하는 놀이터예요. Codex 펫 1만 마리를 그대로 데려와 친구마다 다른 AI로 말하고, 친구들끼리 이어서 이야기하고, 어느 코딩 에이전트가 일하든 곁에서 함께 일해요. Codex 펫 형식을 따르지만 Codex가 없어도 돼요. 펫은 그림과 소개가 든 캐릭터 파일이고, 그 펫을 놀이터에 초대하면 이름과 성격을 가진 친구가 돼요. 친구는 시간대와 날씨, 계절이 바뀌는 놀이터를 돌아다니고, 간식을 먹고, 세 가지 놀이를 하고, 원하면 바탕화면 위로 나와요. 놀이터는 날이 갈수록 자라요. 친구가 정원에 심을 씨앗과 선물을 가져오고, 낚시와 채집으로 도감을 채우고, 친구와 조금씩 친해지고, 계절 이벤트와 놀이터 소리가 함께해요. 이미 쓰고 있는 Claude Code나 Codex 구독을 연결하면 친구와 대화할 수 있고, 코딩 에이전트가 일하는 동안 친구가 곁에서 반응해요.

## 필요한 것

| 항목 | 내용 |
|---|---|
| 운영체제 | macOS, Windows, Linux |
| AI | 선택이에요. 연결하지 않아도 초대, 놀이, 바탕화면 모드는 모두 돼요 |
| 코딩 에이전트 | 선택이에요. Claude Code, Codex CLI, Gemini CLI, Cursor, MCP를 쓰는 도구와 이어져요 |
| 인터넷 | 설치 파일을 받을 때와 업데이트를 확인할 때만 필요해요. Ollama나 구독 CLI로 대화하면 그 도구의 방식에 따라요 |

Tauri로 만들어 운영체제의 기본 웹뷰를 써요. 그래서 설치 파일이 작고 메모리를 적게 써요.

## 두 낱말

- **펫**은 캐릭터 파일이에요. `pet.json`과 스프라이트 시트가 든 폴더 하나가 펫 하나예요. Codex의 펫 폴더에 있는 펫은 자동으로 보이고, 커뮤니티 사이트에서 가져오거나 내 컴퓨터의 폴더를 고를 수도 있어요.
- **친구**는 놀이터에 초대한 개체예요. 같은 펫을 여러 번 초대하면 친구가 여럿 생기고, 각자 다른 이름과 성격, 크기, AI를 가질 수 있어요.
