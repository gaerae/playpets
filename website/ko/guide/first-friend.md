# 첫 친구 초대하기

펫을 고르면 친구가 되어 놀이터에 와요. 쓰다듬고, 옮기고, 말을 걸고, 간식을 놓아 줘요.

1. 앱을 처음 열면 빈 놀이터가 **누구와 함께할까요?** 하고 물으며 움직이는 기본 펫 넷을 보여 줘요.
2. 하나를 누르면 그 친구가 놀이터로 와서 손을 흔들어요.

**다른 펫 보기**를 누르면 이 컴퓨터에 있는 펫이 모두 모인 **친구 초대**가 열려요.

::: tip 한눈에 보기
| 하고 싶은 일 | 이렇게 해요 | 더 보기 |
|---|---|---|
| 친구 더 초대하기 | **친구와 설정 → 친구 초대**에서 카드의 `+` | [친구 초대하기](#inviting-a-friend) |
| 쓰다듬기 | 친구를 한 번 눌러요 | [놀이터에서 하는 일](#things-to-do-in-the-yard) |
| 말 걸기 | 친구의 이름표를 눌러요 | [친구와 대화하기](./chat.md) |
| 간식 놓기 | **놀기 → 정원 → 소풍 간식**을 누르고 놓을 곳을 눌러요 | [놀이터에서 하는 일](#things-to-do-in-the-yard) |
| 이름, 성격, 크기 바꾸기 | 이름 옆 **⋯** → **친구 설정** | [친구 설정](#friend-settings) |
| 펫 더 들여오기 | 친구 초대의 **펫 가져오기** | [펫 가져오기](./import.md) |
:::

## 앱에 들어 있는 친구들 <Since v="0.1.0" />

처음 실행하면 친구 초대의 **PlayPets 기본 펫**에 네 친구가 먼저 보여요.

| 친구 | 소개 |
|---|---|
| Daisy | 탐험가 |
| Clover | 정원사 고양이. 앱을 대표하는 캐릭터예요 |
| Pip | 밝은 강아지 |
| Miso | 다정한 수달 |

- 카드에는 어느 언어에서나 영어 이름이 그대로 나와요.
- 네 친구도 Codex 펫 형식이라 다른 펫처럼 초대하고, 바탕화면에 내보내고, AI를 연결하면 돼요. 펫 파일은 데이터 폴더의 `builtin/` 아래에 풀려 있어요.
- 하나씩 따로 받을 수도 있어요. [홈페이지](../index.md#companions)의 친구 소개에서 계절 옷까지 담긴 `playpets-<이름>.zip`을 받아요. PlayPets에서는 [ZIP 파일](./import.md#zip-file)로 가져오고, Codex 펫 폴더(`~/.codex/pets`, Windows는 `%USERPROFILE%\.codex\pets`)에 압축을 풀면 ChatGPT와 Codex에서도 함께해요.
- 고른 계절에 맞춰 옷을 갈아입어요. 놀이터와 바탕화면 모두 그렇고, 자동이면 현지 달력을 따라요. 여름에는 가벼운 옷, 겨울에는 따뜻한 옷, 봄과 가을에는 겹쳐 입는 같은 평상복이에요. 옷이 바뀌어도 얼굴과 장신구, 동작은 그대로라 금방 알아봐요.

예전 버전의 기본 친구들은 저장된 ID와 이름, 설정, 친밀도를 그대로 지닌 채 모습만 이 친구들로 바뀌어요.

| 예전 친구 | 지금 모습 |
|---|---|
| Aria | Daisy |
| Noah | Pip |
| 기존 고양이 | Clover |

직접 가져온 펫은 바뀌지 않아요. 대화는 앱을 실행하는 동안만 남고, 다시 시작하면 되살아나지 않아요.

## 친구들의 이야기 <span id="companion-stories"></span>

네 친구를 소개하는 짧은 이야기예요. 실제 대화에 쓰는 성격은 친구 설정에서 바꾸고, AI를 연결했을 때만 적용돼요.

네 친구는 흰 꽃잎에 노란 꽃술이 달린 작은 꽃을 똑같이 달고 있어요. 한 식구라는 표시예요.

### Daisy, 길모퉁이의 작은 발견

Daisy는 다른 사람들이 그냥 지나치는 샛길이 늘 궁금해요. 새로 핀 꽃 한 송이나 고래를 닮은 구름 하나만 있어도 기억에 남는 하루가 되지요. 먼저 도착하는 것보다 함께 발견하는 걸 더 좋아하는 탐험가예요.

### Clover, 오늘도 조금 자랐어요

Clover는 정원을 조용히 돌보는 고양이이자 PlayPets의 대표 친구예요. 새 잎이 돋으면 누구보다 먼저 알아보고, 햇볕 잘 드는 자리는 친구에게 내어 줘요. 작은 변화도 시간을 두고 지켜보면 반갑다는 걸 잘 알아요.

### Pip, 한 명 더 와도 좋아요

Pip은 처음 보는 친구에게 늘 먼저 손을 흔들어요. 진청 데님 재킷에 아이보리 반바지를 입고 산책과 놀이에 활기를 불어넣다가도, 뒤처진 친구가 없는지 꼭 돌아봐요. Pip에게 좋은 오후는 누구나 함께할 수 있는 오후예요.

### Miso, 연못가에서 책 한 쪽

Miso는 책 한 권과 잠깐의 여유를 늘 곁에 두는 다정한 수달이에요. 연보라 니트 조끼를 입고 물결을 바라보며 생각이 가라앉기를 기다려요. 말을 주고받지 않아도, 나란히 앉아 있기만 해도 좋은 날이 있잖아요.

## 다음 할 일 <Since v="0.1.0" />

첫 친구가 오면 구석에 작은 **다음 할 일** 카드가 떠서 남은 일을 알려 줘요.

| 할 일 | 버튼 |
|---|---|
| 친구에게 AI 연결하기 | **연결하기**. 이 컴퓨터에 Claude Code나 Codex CLI가 있으면 **바로 연결**로 바뀌고, 누르면 키 없이 모든 친구에게 한 번에 연결돼요([친구와 대화하기](./chat.md#connect)) |
| 코딩 에이전트 소식을 전해 줄 친구 정하기 | **정하기** |

- 끝낸 일에는 체크 표시가 붙고, 다 끝내면 카드가 사라져요. 그 전에 치우려면 **그만 보기**를 눌러요.
- 놀이터에 친구가 없으면 놀이 도구는 숨어요. 그래도 **친구와 설정 → 친구 초대**는 언제든 쓸 수 있어요.

## 친구 초대 <Since v="0.1.0" />

<Shot name="invite" caption="친구 초대는 펫이 있는 곳별로 카드를 묶어 보여 줘요." />

카드는 펫 파일이 있는 곳에 따라 네 묶음으로 나뉘어요. 펫이 없는 묶음은 보이지 않아요.

| 묶음 | 어디서 온 펫인가 | **폴더 열기** |
|---|---|---|
| PlayPets 기본 펫 | 앱에 든 펫 네 개. 데이터 폴더의 `builtin/`에 풀려 있어요 | 있어요 |
| Codex 펫 폴더 | `~/.codex/pets`에 있는 Codex 펫. 자동으로 보여요 | 있어요 |
| 주소나 ZIP으로 가져온 펫 | **펫 가져오기**로 커뮤니티 페이지나 ZIP 파일에서 받은 펫. 데이터 폴더의 `pets/`에 복사돼요 | 있어요 |
| 내 컴퓨터에서 고른 펫 | 직접 고른 폴더의 펫. 복사하지 않고 그 폴더를 그대로 봐요 | 없어요. 카드마다 폴더 이름이 적혀 있어요 |

- **폴더 열기**를 누르면 그 폴더가 탐색기나 Finder에서 열려요.
- 선반 위 **종류** 칩(전체, 사람, 동물, 기타)은 펫 파일의 `kind` 값으로 추려요. 사람 모양 펫만 남길 수 있어서 연인이나 선배로 둘 친구를 고를 때 편해요.
- **펫 검색**에 이름이나 제작자를 넣으면 같은 선반에서 더 좁혀 찾아요. 종류 필터와 함께 써도 되고, **전체 보기**를 누르면 둘 다 풀려요.
- 카드가 하나도 없다면 [펫 가져오기](./import.md)부터 해 주세요.

## 친구 초대하기 <Since v="0.1.0" /> {#inviting-a-friend}

1. 카드(오른쪽의 `+`)를 눌러요. 이미 놀이터에 있는 친구의 카드에는 **한 명 더 초대**라고 적혀 있어요.
2. 친구가 놀이터에 나타나 손을 흔들고, 친구 화면이 그 친구로 열려요.
3. 같은 펫을 다시 누르면 **한 명 더 초대**가 돼요. 두 번째 친구부터는 구별하도록 이름 뒤에 번호가 붙어요.

놀이터에는 친구를 12명까지 둘 수 있어요.

## 친구 설정 <Since v="0.1.0" /> {#friend-settings}

친구 화면에서 이름 옆 **⋯** 메뉴를 열고 **친구 설정**(연필)을 골라요. 이름 옆의 관계 칩을 눌러도 돼요.

| 항목 | 내용 |
|---|---|
| **이름** | 놀이터의 이름표와 대화 창에 보여요. 24자까지 |
| **성격** | 대화할 때 이 성격으로 답해요. 400자까지. 처음에는 펫 파일의 소개를 쓰고, 고치거나 덧붙여 저장하면 그 내용으로 바뀌어요. **펫 파일의 소개 넣기**로 원래 소개를 다시 가져와요. AI를 연결하기 전에는 쓰이지 않아요 |
| **관계** | 친구, 연인, 든든한 선배, 장난꾸러기 동생 중 하나. 말투와 호칭, 안부가 달라져요([친구와 대화하기](./chat.md#relationship)) |
| **나를 부르는 말** | 친구가 나를 이렇게 불러요. 24자까지 |
| **크기** | 아주 작게, 작게, 보통, 크게, 아주 크게의 다섯 단계. 슬라이더를 밀면 놀이터에서 바로 바뀌어요 |

- 창 아래에 있는 친구 ID는 [코딩 에이전트 연동](./agents.md)에서 특정 친구를 가리킬 때 써요.
- **⋯** 메뉴나 친구 설정의 **내보내기**를 누르면 빨간 확인 창이 한 번 더 묻고 친구를 놀이터에서 내보내요. 펫은 친구 초대에 남아 언제든 다시 초대할 수 있지만, 이 친구와 나눈 대화와 쌓아 온 친밀도는 지워져요.

## 놀이터에서 하는 일 <Since v="0.1.0" /> {#things-to-do-in-the-yard}

| 하는 일 | 방법 |
|---|---|
| 쓰다듬기 | 친구를 한 번 눌러요. 친구가 뛰며 하트를 보여요 |
| 옮기기 | 친구를 끌어서 놓아요. 놀이터의 위치는 기억돼요 |
| 대화하기 | 친구의 이름표를 눌러요. 마우스를 올리면 말풍선 표시와 함께 **Clover에게 말 걸기** 같은 안내가 떠요. 친구 화면이 그 친구로 열리고, 창 크기에 맞춰 같은 창 안에서 이어져요. 처음 초대한 친구가 대화하는 방법을 한 번 알려 줘요 |
| 친구 메뉴 | 친구를 우클릭하면 말 걸기, 놀이, 땅파기 부탁하기가 담긴 짧은 메뉴가 열려요 |
| 간식 놓기 | **놀기 → 정원 → 소풍 간식**을 누르고 놓을 곳을 눌러요. 키보드로는 한 번 더 누르면 고른 친구 옆에 놓여요. 돗자리에 도시락과 과일, 간식이 차려지면 친구들이 빙 둘러 모여요. 모두 오지 않으면 15초 뒤에, 모두 먹으면 마지막 친구가 먹고 6초 뒤에 정리돼요 |

- 친구 아래에는 이름표가 있어요. 친구를 고르면 이름표가 선택된 모양으로 바뀌고, 코딩 에이전트가 일하는 동안에는 이름표 안 이름 옆에 상태 점이 보여요.
- 혼자 두면 친구들은 놀이터를 천천히 돌아다니며 혼잣말을 해요. 비가 오면 "우산 있어?" 같은 말을 하고, 밤이 되면 졸려 해요. 시간대와 날씨는 [놀이터와 놀이](./play.md#weather)에 있어요.
