# 자주 묻는 질문

## PlayPets는 어떤 앱인가요?

- PlayPets는 내 Codex 펫을 12명까지 함께 놀게 하는 무료 오픈소스 데스크톱 펫 앱이에요. macOS, Windows, Linux에서 써요.
- 펫들은 한 놀이터에서 지내고, 바탕화면으로 나올 수도 있어요. ChatGPT 데스크톱 앱은 고른 펫 하나만 보여 줘요([OpenAI 안내](https://learn.chatgpt.com/docs/pets), 2026년 10월 기준).
- 연결한 AI로 나와 이야기하고 친구끼리도 수다를 떨어요. Claude Code, Codex, Gemini CLI, Cursor가 일할 때 반응해요.

## Codex 펫도 쓸 수 있나요?

- 'Codex 펫'은 ChatGPT와 Codex용으로 만든 커스텀 펫을 부르는 이름이에요. OpenAI는 이 기능을 Pets라고 불러요.
- 네. PlayPets는 Codex 펫 파일을 그대로 읽어요. `pet.json`과 스프라이트 시트가 든 폴더 하나가 펫 하나예요. 모든 동작을 쓰고, 시트에 시선 방향이 있으면 열여섯 방향 시선도 써요.
- Codex 펫 폴더(`~/.codex/pets`)에 있는 펫은 따로 가져오지 않아도 **친구 초대**에 보여요. 커뮤니티 사이트, GitHub 폴더, 내 컴퓨터 폴더에서 [더 데려올 수 있어요](./import.md).
- Codex가 없어도 돼요. ChatGPT 데스크톱 앱을 쓴다면 거기 펫도 그대로 두세요. PlayPets는 같은 펫 파일을 읽어요.

## 돈이 드나요?

- 앱은 무료고, MIT 라이선스의 오픈소스예요.
- 구독으로 로그인한 Claude Code나 Codex CLI는 별도 API 결제 없이 플랜 한도를 써요.
  - 사용 한도가 적용돼요.
  - 선택해서 구매하는 크레딧에는 비용이 들 수 있어요.
- 로컬 Ollama 모델은 내 컴퓨터에서 돌아가고 서버 추론 요금이 없어요.
- API 키 연결, 호환 서버, Ollama 클라우드 모델은 제공 업체의 요금 정책을 따라요.
- 자세한 내용: [AI 연결 종류](./chat.md#connections)

## 인터넷 없이 되나요?

- 인터넷 없이 돼요: 초대, 놀이, 바탕화면 모드, 시간대와 날씨.
- 날씨 자동도 실제 날씨를 가져오지 않고 시계로 정해요.
- 인터넷이 필요해요: 커뮤니티 펫 가져오기, 업데이트 확인, 인터넷을 쓰는 AI와의 대화.
- 내려받은 로컬 Ollama 모델은 인터넷 없이 대화하고, 대화가 내 컴퓨터에 머물러요.
- Ollama 클라우드 모델에는 인터넷이 필요해요.

## 내 코드나 프롬프트가 펫에게 가나요?

- [코딩 에이전트 연동](./agents.md)은 사용자 프롬프트와 도구 입력을 생략해요.
- 로컬 연결은 `127.0.0.1`과 토큰 인증을 써요.
- 짧은 완료, 알림 보고에는 에이전트 답변 일부 등 작업 정보가 들어갈 수 있어요. 친구와 대화할 때 선택한 AI에 전달될 수 있어요.
- 터미널이나 MCP로 보내는 메시지를 확인해요.
- 이 내용을 컴퓨터 안에 두려면 다운로드한 로컬 모델을 써요.

## 잘 안 될 때 {#troubleshooting}

| 이런 일이 있으면 | 이유 | 이렇게 해요 |
|---|---|---|
| macOS에서 PlayPets가 열리지 않아요 | 1.2.0 이하는 서명이 없어요 | 1.3.0 이상을 설치해요. 이전 버전은 [그래도 열기](./install.md#macos)를 보세요 |
| Windows 설치 파일에 SmartScreen 경고가 떠요 | GitHub 설치 파일은 아직 코드 서명이 없어요 | Microsoft가 서명하는 [Microsoft Store나 winget](./install.md#microsoft-store)으로 설치해요. 또는 받은 곳을 확인하고 **추가 정보 → 실행**을 골라요([GitHub 설치 파일](./install.md#installer-from-github)) |
| Linux에서 AppImage가 실행되지 않아요 | FUSE 2가 없어요 | `libfuse2`(Ubuntu 24.04는 `libfuse2t64`)를 설치하거나 `--appimage-extract-and-run`으로 실행해요([Linux](./install.md#linux)) |
| 창을 닫았더니 놀이터가 사라졌어요 | 창을 닫으면 숨기기만 해요 | 트레이 아이콘에서 **놀이터 열기**를 골라요. GNOME은 AppIndicator 확장이 없으면 트레이 아이콘을 숨기는데, 앱을 다시 실행해도 놀이터가 돌아와요 |
| 친구가 "같이 놀 준비 완료!"라고만 하고 답하지 않아요 | 그 친구에게 AI가 없어요 | [AI를 연결해요](./chat.md#connect) |
| Claude Code나 Codex CLI 카드에 **설치됨**이 없어요 | 앱이 명령을 찾지 못했어요 | 터미널에서 `claude`나 `codex`가 실행되는지 확인해요. Windows에서 npm으로 설치했다면 `%APPDATA%\npm`에 있어야 해요 |
| 연결을 저장할 때 보안 저장소에 접근할 수 없다고 해요 | 키 저장소가 잠겨 있거나 없어요(Linux는 Secret Service가 없을 때) | 접근을 허용하거나, Linux에서는 GNOME Keyring이나 KWallet을 써요. Ollama와 로그인한 CLI는 키가 필요 없어요 |
| 코딩 에이전트가 일해도 친구가 반응하지 않아요 | 연결하지 않았거나, 새 세션을 시작하지 않았거나, 앱을 옮겼어요 | **설정 → 코딩 도구 연결**에서 **연결**이나 **다시 연결**을 누르거나 설정을 다시 복사해 붙여 넣고, 새 세션을 시작해요([코딩 에이전트 연동](./agents.md)). Codex CLI 친구는 작업 완료만 보여 주고 일하는 중은 보여 주지 않아요 |
| 다른 친구에게 소식이 가요 | **담당 친구**를 고르지 않아서 첫 친구가 받아요 | **설정 → 코딩 도구 연결**에서 담당 친구를 고르고 **다시 연결**을 누르거나 설정을 다시 복사해 붙여 넣어요 |
| 펫 주소를 가져올 수 없어요 | 지원하지 않는 사이트거나, 파일이 다른 사이트에 있어요 | 펫을 내려받아 폴더나 ZIP으로 가져와요([펫 가져오기](./import.md)) |
| 느리거나 배터리를 많이 써요 | 친구가 움직이는 동안 자주 그려요 | 놀이터 창을 닫아요. 숨긴 놀이터는 그리지 않아요. 친구 수를 줄이거나 **바탕화면 산책**을 꺼 보세요 |

다른 문제가 있으면 쓰는 시스템과 PlayPets 버전을 적어 [이슈](https://github.com/gaerae/playpets/issues)로 알려 주세요. Windows 빌드는 아직 실제 기기에서 충분히 확인하지 않았어요.

## 펫을 직접 만들 수 있나요?

- 네. `pet.json`과 스프라이트 시트가 든 폴더 하나가 펫이에요. 형식은 Codex 펫과 같아요.
- 만든 폴더는 **펫 가져오기**의 **내 컴퓨터의 폴더에서 가져오기**로 바로 초대해요.
- 자세한 규칙: [펫 가져오기](./import.md#make-your-own), 개발자 문서 [펫 파일 형식](/dev/standards/pet-files)

## 모니터가 여러 대인데 어떻게 되나요?

- [바탕화면 모드](./desktop.md)에서 친구는 어느 모니터에나 있을 수 있어요.
- 끌어서 다른 모니터로 데려가면 그곳에 머물러요.
- 모니터마다 배율이 달라도 돼요.

## 데이터는 어디에 있나요?

| 운영체제 | 위치 |
|---|---|
| macOS | `~/Library/Application Support/app.playpets/` |
| Windows | `%APPDATA%\app.playpets\`. Microsoft Store(winget으로 설치한 경우 포함): 패키지 전용 폴더 안 |
| Linux | `~/.local/share/app.playpets/` |

- 친구와 설정은 `state.json`, 가져온 펫은 `pets/`, 가져온 배경은 `backgrounds/`, 기본 펫은 `builtin/`에 있어요.
- API 키는 여기 없고 OS의 보안 저장소에 있어요.
- PlayPets는 대화 기록을 파일에 저장하지 않고, 앱을 켠 동안만 유지해요.
- 연결한 서비스의 대화 저장은 그 서비스의 정책을 따라요.
- 자세한 내용: [설정](./settings.md#data-folder)
