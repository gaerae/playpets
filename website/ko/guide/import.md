# 펫 가져오기

펫은 캐릭터 파일이에요. 앱에 들어 있는 기본 펫과 Codex 펫 폴더(`~/.codex/pets`)의 펫은 따로 손대지 않아도 **친구 초대**에 나와요. 그 밖의 펫은 가져와야 해요.

## 링크로 한 번에 가져오기 <Since v="0.1.0" />

1. 펫 갤러리에서 **PlayPets에서 열기** 같은 링크를 눌러요. 링크는 `playpets://import?url=<펫 페이지 주소>` 모양이에요.
2. PlayPets가 설치돼 있으면 "이 펫을 가져올까요?" 하고 묻고, 링크가 어느 사이트에서 왔는지 보여 줘요.
3. 가져오겠다고 하면 그 펫을 가져온 뒤 친구 초대를 열어요.

갤러리를 운영한다면 펫 페이지에 이 링크를 달아 주세요.

```text
playpets://import?url=https%3A%2F%2Fpetdex.dev%2Fpets%2Fboba
```

## 펫 가져오기 창 <Since v="0.1.0" />

**친구 초대** 위쪽의 **펫 가져오기**를 누르면 창이 열려요. 가져오는 방법은 세 가지예요.

| 방법 | 하는 일 |
|---|---|
| **펫 페이지 주소** | 커뮤니티 사이트의 펫 페이지 주소나 GitHub 펫 폴더 주소를 붙여 넣고 **가져오기**를 눌러요 |
| **내 컴퓨터의 폴더에서 가져오기** | 펫 폴더를 골라요 |
| **내 컴퓨터의 ZIP 파일에서 가져오기** | 제작 키트로 받은 ZIP 같은 펫 ZIP 파일을 골라요 |

가져오기가 끝나면 그 펫이 바로 친구가 되어 놀이터에 들어와요. "새 펫을 가져와 놀이터에 초대했어요" 알림도 떠요.

- 파일은 https 주소에서만, 붙여 넣은 주소의 사이트(와 그 하위 도메인)에서만 받아요.
- 펫 페이지가 다른 사이트의 파일을 가리키면 가져오지 않아요.

## 지원하는 사이트 <Since v="0.1.0" />

1. **다른 펫 찾아보기**를 펼쳐요. 주소 입력란과 가져오기 버튼이 잘 보이도록 처음에는 접혀 있어요. 펼치면 사이트 목록과 짧은 가져오기 안내가 나와요.
2. 사이트를 열어요.
3. 마음에 드는 펫 페이지의 주소를 위 입력란에 붙여 넣어요.

목록은 커뮤니티 링크예요. 목록에 있다고 해서 제휴 관계라는 뜻은 아니에요.

| 사이트 | 사이트 주소 |
|---|---|
| OpenPets Registry | openpets.sh |
| Petdex | petdex.dev |
| Codex PokéPets | github.com/dnnyngyen/codex-pokepets |
| Awesome Codex Pet | codexpet.top |
| Codex Pets | codex-pets.net |

위 사이트에는 전용 가져오기 기능이 있어요. 칩에 없는 곳이어도 괜찮아요. GitHub의 펫 폴더(`pet.json`이 든 폴더) 주소나 codex-pet-share로 만든 사이트의 펫 페이지 주소도 가져와요.

**(구경만)** 표시가 붙은 사이트는 전용 가져오기 기능이 없어요. 그래도 지원하는 일반 펫 페이지 형식이면 주소를 붙여 넣어 가져와요. 목록에 사이트를 올리는 것만으로 가져오기 기능이 생기지는 않아요.

- 주소가 틀렸거나 사이트가 응답하지 않으면 창 안에 이유가 나와요.
- 가져오는 동안에는 창을 닫을 수 없어요.

## 내 컴퓨터의 폴더 <Since v="0.1.0" />

**내 컴퓨터의 폴더에서 가져오기**로 고른 폴더는 앱 저장소로 복사하지 않고, 앱이 그 자리에서 그대로 읽어요. 그래서 친구 초대의 **내 컴퓨터에서 고른 펫** 묶음에 폴더 이름과 함께 보여요.

제작 키트로 받은 ZIP은 압축을 풀 필요 없이 아래 [ZIP 파일](#zip-파일)처럼 가져오면 돼요. 폴더로 고른 펫은 복사본이 따로 없으니, 그 폴더는 계속 보관할 위치에 두고 펫을 쓰는 동안 옮기거나 지우지 마세요.

::: warning 폴더를 옮기면 친구가 기다려요
친구는 펫 폴더의 경로로 자기 펫을 알아봐요. 고른 폴더를 옮기거나 지우면(그 폴더가 있는 드라이브를 빼도 마찬가지예요) 다음에 앱을 열 때 그 펫의 친구가 놀이터에 나오지 못해요.

그렇다고 친구가 지워지지는 않아요. 친밀도를 그대로 지닌 채 기다리고, 몇 명이 기다리는지 알림으로 알려 줘요. 폴더를 원래 자리에 되돌려 놓으면 다시 나와요.
:::

## ZIP 파일 <Since v="1.4.0" />

**내 컴퓨터의 ZIP 파일에서 가져오기**로 고른 ZIP은 앱 안으로 복사돼요. 그래서 가져온 뒤에는 ZIP을 옮기거나 지워도 괜찮아요. 친구 초대의 **주소나 ZIP으로 가져온 펫** 묶음에 보여요.

- 제작 키트의 ZIP도, 펫 폴더를 직접 압축한 ZIP도 돼요. `pet.json`이 ZIP 맨 위나 그 안의 폴더 하나에 있으면 돼요.
- 같은 ZIP을 다시 가져와도 하나만 남아요. 내용이 바뀐 ZIP은 원래 펫 옆에 새 펫으로 들어와요.

## 어디에 저장되나요 <Since v="0.1.0" />

주소나 ZIP으로 가져온 펫은 [데이터 폴더](./install.md#데이터-폴더)의 `pets/` 안에 폴더 하나로 저장돼요.

- **주소나 ZIP으로 가져온 펫**, **PlayPets 기본 펫**, **Codex 펫 폴더** 묶음에는 **폴더 열기** 버튼이 있어요. 누르면 그 폴더가 바로 열려요.
- **내 컴퓨터에서 고른 펫** 묶음에는 버튼 대신 카드마다 폴더 이름이 적혀 있어요.

가져온 펫의 `pet.json`에는 어디서 왔는지가 함께 적혀요. 친구 초대 카드에는 "Petdex, 제작자, CC BY-NC 4.0"처럼 사이트, 제작자, 라이선스가 한 줄로 나와요. 커뮤니티 펫은 만든 사람의 저작물이니 라이선스를 확인하고 써 주세요.

## 펫 지우기 <Since v="1.4.0" />

직접 들여온 펫은 친구 초대에서 카드 옆에 휴지통 버튼이 있어요.

- 주소나 ZIP으로 가져온 펫은 `pets/` 안의 그 폴더가 지워져요. 다시 쓰려면 다시 가져와요.
- 내 컴퓨터에서 고른 펫은 목록에서만 빠지고, 폴더는 그 자리에 그대로 남아요.
- 그 펫으로 만든 친구가 놀이터에 있으면 지울 수 없어요. 친구를 먼저 내보내 주세요.
- 놀이터가 가득 차서 나중에 돌아올 친구가 그 펫을 쓰고 있어도 지울 수 없어요. 어떤 친구인지 이름을 알려 줘요.

PlayPets 기본 펫과 Codex 펫 폴더의 펫에는 휴지통 버튼이 없어요.

## 직접 만들기

펫 하나는 `pet.json`과 스프라이트 시트(PNG 또는 WebP) 한 장이 든 폴더예요. 형식이 Codex 펫과 같아서 Codex용으로 만든 펫을 그대로 쓸 수 있어요.

```json
{
  "id": "white",
  "displayName": "White",
  "kind": "animal",
  "description": "A puppy.",
  "spriteVersionNumber": 2,
  "spritesheetPath": "spritesheet.webp"
}
```

| 항목 | 규칙 |
|---|---|
| 시트 크기 | 너비 1536px, 한 칸 192×208px, 한 행 8칸 |
| v1 | 9행(1872px). 차례로 쉬기, 오른쪽으로 걷기, 왼쪽으로 걷기, 손 흔들기, 점프, 오류, 기다리기, 일하기, 완료 |
| v2 | 11행(2288px). 16방향 시선 두 행이 더 있어서 바탕화면에서 마우스를 눈으로 따라가요 |
| `description` | 새 친구의 처음 성격이 돼요 |

- 행별 애니메이션과 검사 규칙은 개발자 문서 [펫 파일 형식](/dev/standards/pet-files)에 있어요.

다 만든 폴더는 **내 컴퓨터의 폴더에서 가져오기**로 바로 초대해요.
