# 놀이터와 놀이

놀이터는 시계와 날씨, 계절을 따라 바뀌고 날마다 조금씩 자라요. 친구들은 땅을 파고 낚시를 하고 선물을 가져오며 함께 놀고, 찾은 것은 도감에 차곡차곡 쌓여요.

|---|---|---|
| 장소, 계절, 시간대, 날씨 바꾸기 | 아래쪽 **배경과 분위기** | [시간대와 날씨](#weather) |
| 꽃씨, 묘목, 작은 발견 찾기 | **놀기 → 땅파기**를 고르고 빈 땅 누르기 | [땅파기](#digging) |
| 꽃과 나무 키우기 | **놀기 → 씨앗 심기**나 **나무 심기** | [정원](#the-garden) |
| 선물 받기 | 그날 친구와 무언가 함께 하기 | [선물](#gifts) |

| 친구와 더 가까워지기 | 날마다 조금씩 쓰다듬고, 간식 주고, 대화하고, 놀기 | [친밀도](#closeness) |

## 화면 구성

풍경이 창을 가득 채우고, 아래쪽 독에서 패널을 한 번에 하나씩 열어요. 패널마다 한 페이지를 몇 개의 묶음으로 나눴고, 안에 탭이나 뒤로 가기는 없어요.

| 독 | 들어 있는 것 |
|---|---|
| **배경과 분위기** | **장소**(기본 배경과 가져온 배경을 한 목록에, **배경 가져오기**, **배경 제작실**), **분위기**(계절, 시간대, 날씨, **놀이터 소리**, **소리 크기**) |
| **놀기** | 고른 친구에 맞춰 **Clover의 놀이**처럼 제목이 붙어요. **찾기**: **땅파기**, **낚시**, **도감**. **정원**: **씨앗 심기**(가진 씨앗 수와 함께), **나무 심기**, **소풍 간식**. **함께 놀기**: 네 가지 놀이(**눈사람 만들기**는 놀이터가 겨울일 때만), 벚꽃 축제 동안의 **꽃구경**, **수다 떨기** |
| **친구와 설정** | **친구와 대화**, **친구 초대**, **창과 바탕화면**, **설정**, **창 닫기**, **PlayPets 종료** |

- **수다 떨기**만 AI를 연결한 친구가 둘 있어야 하고, 나머지는 AI 없이도 다 돼요.
- 처음 여는 놀이터는 맑은 봄날이에요. 계절, 시간대, 날씨가 저절로 바뀌게 하려면 **자동**을 고르세요. 고른 값은 모두 저장돼요.

### 소리

- **놀이터 소리**와 **소리 크기**: **배경과 분위기 → 분위기**.
- 처음 한 번 조작한 뒤부터, 놀이터가 보이는 동안에만 들려요.
- 빗소리, 새소리, 물소리 같은 소리는 장소, 날씨, 계절, 시간대를 따라 달라져요.
- 친구끼리 알아서 대화하는 설정은 따로 있어요: **친구와 설정 → 설정 → 친구와 AI**.

## 시간대와 날씨 <Since v="0.1.0" /> {#weather}

하나하나 직접 고르거나 **자동**으로 둬요. 바꾸는 즉시 반영돼요.

<Shot name="yard-spring" caption="맑은 봄 한낮의 놀이터예요. 시간 자동을 고르면 시계를 따라 바뀌어요." />

1. 오른쪽 아래 **배경과 분위기**를 열어요.
2. **장소**에서 그림을 보고 배경을 골라요. 삭제 버튼은 가져온 배경을 골랐을 때만 보여요.
3. **분위기**에서 계절, 시간대, 날씨를 골라요.

| 고르기 | 선택지 | 자동일 때 |
|---|---|---|
| 장소 | 언덕 정원, 정원 공방, 자연 정원, 호숫가 집, 직접 가져온 배경 | |
| 계절 | 자동, 봄, 여름, 가을, 겨울 | 야외 장소가 날짜를 따라가요. 꽃과 흩날리는 꽃잎, 짙은 초록, 붉고 노란 단풍, 눈 덮인 땅. 컴퓨터의 시간대가 남반구면 계절이 반대로 흘러가요 |
| 시간대 | 자동, 아침, 한낮, 저녁, 밤 | 시계를 따로 보여 주지 않고 컴퓨터 시계를 따라가요. 하늘과 땅 색이 바뀌고, 해는 왼쪽에서 오른쪽으로 건너고, 밤에는 오늘 밤 모양 그대로 달이 떠요 |
| 날씨 | 자동, 맑음, 비, 눈 | 20분마다 새로 정해요. 대개 맑고 가끔 비가 오며, 눈은 겨울에만 와요. 인터넷에서 실제 날씨를 가져오지는 않아요 |

- 직접 고른 계절, 시간대, 날씨는 그대로 고정되고, 다음에 앱을 열어도 남아 있어요.
- 계절과 날씨는 따로 정해요. 여름에 눈을 고르면 여름 풍경과 옷차림 위로 눈만 내리고, 겨울에 맑음을 골라도 겨울 풍경은 그대로예요. 실내 창밖과 가져온 배경도 마찬가지예요.
- 계절을 직접 고르면 아무 날이나 [계절 이벤트](#seasonal-events)를 불러올 수도 있어요.
- 날씨가 바뀌면 친구 한두 명이 "비다!", "눈사람 만들까?"처럼 한마디씩 해요. 가만히 두면 시간대에 어울리는 혼잣말도 해요.

### 날씨가 만드는 장면

| 장면 | 언제 | 할 일 |
|---|---|---|
| 무지개 | 낮에 비가 그치면 몇 분 동안 언덕 위에 떠요 | 무지개가 끝나는 땅이 반짝여요. 사라지기 전에 그 자리를 파면 빈손으로 돌아오지 않아요 |
| 여우비 | 맑던 낮에 비가 오면 | 해가 난 채로 내리는 비를 구경해요 |
| 물안개 | 맑은 가을 아침 | 들판에 깔린 물안개를 구경해요 |
| 달빛 눈밭 | 밤에 눈이 그치면 | 달빛 아래 반짝이는 눈밭을 구경해요 |
| 별똥별 | 맑은 여름밤 | 밤새 자주 떨어지니 하늘을 올려다봐요 |
| 새 떼 | 맑은 날 가끔 | 하늘을 지나가는 새 떼를 구경해요 |

곤충도 빛과 계절을 따라 나와요. [채집](#bugs)을 보세요.

### 장소 {#places}

| 장소 | 어떤 곳 |
|---|---|
| 언덕 정원 | 탁 트인 언덕, 저만의 집이 있어요 |
| 자연 정원 | 들꽃이 가득한 자연 그대로의 정원, 맑은 연못이 있어요 |
| 호숫가 집 | 호숫가의 작은 집, 저만의 집이 있어요 |
| 정원 공방 | 유리 지붕 아래 공방. 일 년 내내 같은 모습이에요 |

- 언덕 정원, 자연 정원, 호숫가 집은 사계절 풍경과 낚시 자리가 저마다 달라요. 색감은 빛을 따라 바뀌어요.
- 배경은 풍경이나 창 크기가 바뀔 때만 다시 그려요.
- 장소는 시간대나 날씨와 따로 기억해 둬요.
- 장소를 바꿔도 자란 정도와 도감은 그대로 이어져요.

### 정원 공방 <Since v="1.7.0" /> {#garden-workshop}

유리 지붕 아래 긴 작업대 두 개, 체커판이 놓인 찻상, 앞쪽에 종이 달린 정원 벤치가 있어요. 유리 너머로 하늘과 시간대, 날씨가 보이고, 비와 눈은 유리 밖에만 내려요.

- 친구들은 산책하고, 작업대에서 씨앗을 고르고, 함께 차를 마시고, 벤치 옆에서 쉬어요.
- 코딩 에이전트와 연결된 친구는 작업대에서 일하고, 에이전트가 확인을 기다리면 종 옆에 나와 기다려요([친구들이 그곳에서 하는 일](./agents.md#where-friends-go)).

친구를 쓰다듬고, 대화하고, 꽃을 키우고, 크리스마스트리를 꾸미고, 놀이를 하는 건 어느 장소에서든 돼요. 나머지는 장소마다 달라요.

| 활동 | 언덕 정원, 자연 정원, 호숫가 집 | 정원 공방 |
|---|---|---|
| 꽃 | 땅에 심어요 | 작은 화분에 담겨요 |
| 땅파기, 낚시 | 돼요 | 안 돼요 |
| 나무 | 장소마다 여섯 그루까지 | 안 돼요 |
| 곤충 | 맑은 날 나와요 | 없어요 |
| 계절 풍경과 효과 | 계절을 따라 바뀌어요 | 없어요 |
| 눈사람 만들기, 눈 위의 발자국 | 겨울에 | 없어요 |
| 봄 새싹 | 봄에 | 없어요 |
| 크리스마스 밤 | 눈 내리는 겨울 저녁이나 밤 | 없어요. 눈이 유리 밖에만 내려요 |

## 수다 떨기 <Since v="0.1.0" />

**놀기 → 함께 놀기 → 수다 떨기**를 누르면 AI를 연결한 친구가 세 명까지 모여, 지금 시간대와 날씨를 두고 짧게 이야기해요. 말은 놀이터 말풍선으로 차례로 떠요.

- AI를 연결한 친구가 둘이 안 되면 버튼이 꺼진 것처럼 보여요. 눌러 보거나 마우스를 올리면 이유를 알려 줘요.
- 직접 대화에 끼고 싶다면 [친구 화면의 함께 대화](./chat.md)를 쓰세요.
- 알아서 떠들게 하려면 **친구와 설정 → 설정 → 친구와 AI**에서 **가끔 자기들끼리 이야기해요**를 켜세요. 20분에 한 번 수다를 떨고, 창이 숨겨져 있거나 누가 답하는 중이면 쉬어요.

## 정원 <Since v="0.1.0" /> {#the-garden}

꽃씨와 묘목은 둘 다 [땅파기](#digging)로 얻어요. 친구가 산책만 해서는 생기지 않아요.

1. **놀기 → 정원 → 씨앗 심기**를 골라요. 옆의 숫자가 가진 씨앗 수예요.
2. 들판에서 심을 자리를 눌러요. 계속 누르면 여러 개를 심고, **Esc**나 도구를 한 번 더 누르면 그만 심어요.

- 키보드로는 **씨앗 심기**를 Enter나 Space로 고른 뒤 한 번 더 누르면 고른 친구 옆에 심어요. 소풍 간식과 같은 방식이에요.
- 도구를 든 채 숫자 키 1, 2, 3을 누르면 **땅파기**, **나무 심기**, **씨앗 심기**로 바꿔 들어요. 입력란에 글을 쓰는 중에는 바뀌지 않아요.

식물은 앱을 꺼 둔 동안에도 실제 시간에 맞춰 자라요.

| 심은 뒤 | 10분 | 40분 | 2시간 | 4시간 |
|---|---|---|---|---|
| 단계 | 싹 | 잎 | 꽃봉오리 | 꽃 |

어떤 꽃이 필지는 심은 계절에 따라 정해져요.

| 심은 계절 | 꽃 |
|---|---|
| 봄 | 튤립, 수선화, 크로커스, 무스카리 |
| 여름 | 해바라기, 수국, 라벤더, 초롱꽃 |
| 가을 | 코스모스, 국화, 달리아, 아스터 |
| 겨울 | 동백, 설강화, 헬레보루스, 시클라멘 |

| 식물에 | 이렇게 돼요 |
|---|---|
| 마우스 올리기 | 무슨 꽃인지, 피기까지 얼마나 남았는지 보여요 |
| 누르기 | 가장 가까운 친구가 걸어가서 물을 줘요. 친구들이 알아서 꽃을 구경하러 가기도 해요 |
| 끌기, 방향키 | 옮겨요. 옮긴 자리에서 그대로 자라요 |
| 오른쪽 클릭 → **뽑기**, 또는 **Delete**나 **Backspace** | 묻지 않고 바로 뽑혀요. 알림의 **되돌리기**로 6초쯤 되돌릴 수 있고, 그 뒤에는 완전히 사라져요. 그 전에 앱을 닫으면 그대로 남아요. 쓴 씨앗은 돌아오지 않아요 |
| 오른쪽 클릭 → **바탕화면에 보이기** | 책상 위에서도 자라요([바탕화면 모드](./desktop.md#flowers-and-trees-on-the-desktop)) |

- 씨앗은 20개, 식물은 24포기까지예요.
- 꽃은 종류마다 처음 필 때 **도감**에 올라가요.
- `state.json`의 `garden`에 저장돼요.

### 선물 {#gifts}

선물은 시간이 아니라 함께 지낸 친구가 가져와요.

| 선물 | 언제 오나요 |
|---|---|
| 평소 선물 | 쓰다듬기, 간식 주기, 대화, 함께 낚시처럼 친구와 무언가를 한 날, 10~20분 뒤에 와요(맨 첫 선물만 5분). 놀이터 전체에 이틀에 한 번까지이고, 켜 두기만 해서는 오지 않아요 |
| 친밀도 선물 | **편한 사이**부터 단계가 오를 때마다 하나씩, 그 친구와 함께 논 날에 와요 |
| 추억의 선물 | **각별한 사이**가 되면 그 친구만의 선물을 가져와요. 작은 하트가 하루 동안 붙고, 그다음에는 마우스를 올리거나 선택했을 때만 보여요 |
| 이벤트 선물 | 계절 이벤트 날짜에만 와요([계절 이벤트](#seasonal-events)) |

- 기다리는 시간은 저장되고 앱을 꺼 둔 시간도 쳐 줘서, 계속 켜 둘 필요는 없어요. 친구는 폴짝 뛰며 알려 주고 선물을 옆에 내려놓아요.
- 처음에는 벤치, 등불, 새집, 작은 연못, 우편함, 돗자리, 바람개비, 모닥불, 그네, 화분, 그루터기 의자, 텐트, 이정표, 풍경종 순서로 와요. 그다음부터는 놀이터에 없는 것을 가져와요.

친구들은 받은 선물을 잘 써요. 벤치와 그네, 그루터기에 앉고, 돗자리에 모이고, 하늘이 비치는 연못을 들여다봐요. 등불과 모닥불은 저녁부터 빛나고, 낮에는 새집에 새가 앉고, 풍경종은 친구가 다가가면 딸랑 울려요.

| 선물에 | 이렇게 돼요 |
|---|---|
| 끌기, 또는 선택한 채 방향키 | 들판 어디로든 옮겨요 |
| 누르기 | 가장 가까운 친구가 걸어가요 |
| 오른쪽 클릭 → **치우기**, 또는 **Delete**나 **Backspace** | 바로 치워져요. 알림의 **되돌리기**로 6초쯤 되돌릴 수 있고, 그 전에 앱을 닫으면 그대로 남아요. 다른 날 친구가 다시 가져오기도 해요 |
| 오른쪽 클릭 → **바탕화면에 보이기** | 바탕화면으로 내보내요([바탕화면의 선물](./desktop.md#gifts-on-the-desktop)) |

- 장식은 놀이터에 12개까지 둬요. 가득 차면 새 선물은 도감 선물 권 맨 위의 **선물 상자**에서 기다리고, 상자에도 12개까지 들어가요. 자리가 나면 상자에서 눌러 꺼내 놓아요.
- 하나를 치워도 도감 기록은 남고, 앞으로 올 선물의 자리가 생겨요. 추억의 선물은 치우면 선물 상자로 돌아가요. 상자가 가득 찼을 때만 그냥 치워져요.
- 한 번 받은 선물은 놀이터에 자리가 있으면 도감 선물 권의 카드에서 **꺼내 놓기**로 다시 꺼내요. 눈사람만은 예외라서 다시 만들어요.
- 선물은 모두 29종이고, 그중 일곱 종류는 이벤트 날짜에만 와요. 눈사람도 29종 가운데 하나지만 직접 만들어요([눈사람 만들기](#snowman)). 추억의 선물도 29종 가운데 하나라서 새 칸이 생기지는 않아요.

## 낚시와 채집 <Since v="0.1.0" />

### 낚시

| 방법 | 이렇게 해요 |
|---|---|
| 손으로 | 보이는 물을 누르면 가장 가까운 한가한 친구가 낚싯줄을 던져요. 찌가 잠기면서 **!**가 뜨면 누르세요. 너무 이르거나 늦으면 놓쳐요 |
| **놀기 → 낚시** | 고른 친구가 가서 끝까지 알아서 낚아요 |

- 어느 쪽이든 그 배경의 낚시 자리를 써요.
- 낚싯대에는 민물새우, 가재, 우렁이, 참게, 말조개도 걸리고, 가끔은 자라도 올라와요. 물고기와 함께 **물속 생물** 도감에 기록돼요.
- 무엇이 낚일지는 계절, 시간대, 날씨에 따라 달라요. 메기와 뱀장어는 어두워지면 나오고 비 오는 날엔 더 자주 나와요. 빙어는 겨울에만, 황금잉어는 아주 드물게 나와요. 물고기는 잡을 때마다 크기가 달라요.

### 채집 {#bugs}

곤충은 맑은 날 야외에서만 나오고, 비나 눈이 오면 보이지 않아요. 곤충을 누르면 가장 가까운 친구가 잡아요.

| 언제 | 곤충 |
|---|---|
| 봄부터 가을까지 아침과 한낮 | 나비와 잠자리, 풀밭의 딱정벌레와 메뚜기 |
| 봄과 여름의 저녁과 밤 | 반딧불이 |
| 가을의 저녁과 밤 | 풀밭의 귀뚜라미 |

### 혼자 가는 낚시 {#fishing-on-its-own}

- 친밀도 3단계부터는 한가한 친구가 놀이터가 보이는 동안 12~25분 간격으로 혼자 낚시를 가기도 해요.
- 놀이 중이거나, 다른 낚시 중이거나, 배치 도구를 들고 있으면 쉬어요.
- 입질이 오면 친구가 불러요. 몇 초 안에 찌를 누르면 함께 끌어올리고, 아니면 놓쳐요. 그래서 도감에는 내가 잡은 것만 올라가요.

### 도감 {#album}

- **놀기 → 찾기 → 도감**. 꽃, 물속 생물, 곤충, 선물, 나무, 작은 발견, 발자국, 봄 새싹 여덟 권이에요.
- 모든 종류가 다 실려 있어요. 잡은 것은 몇 번 잡았는지와 가장 큰 크기가, 못 잡은 것은 실루엣과 함께 언제 어디서 찾으면 되는지가 보여요.
- 희귀한 발견을 언제 다시 만날 수 있는지 알려 주지만, 정확한 확률 수치는 보여 주지 않아요.
- **희귀**는 잘 나오지 않는 것과 계절 이벤트 때만 나오는 것에 붙어요. 이벤트 카드에는 날짜와 그 이벤트를 불러오는 장면이 함께 나와요.
- 잡으면 카드가 떠서 무엇을 잡았는지, 처음 잡은 건지 알려 줘요. 도감에 남는 것(물고기, 곤충, 핀 꽃, 선물, 작은 발견, 봄 새싹)이면 카드의 **도감에서 보기**로 그 권을 바로 열어요.
- 새로 들어온 게 있으면 도감을 열 때까지 **도감**과 아래쪽 독의 **놀기**에 작은 점이 붙어요.
- `state.json`의 `album`에 저장돼요.

## 계절 이벤트 <Since v="0.1.0" /> {#seasonal-events}

일 년에 몇 번은 놀이터가 한동안 다른 모습이 돼요. 이벤트는 날짜가 되면 저절로 오고, **배경과 분위기 → 분위기**에서 그 장면을 직접 고르면 아무 날이나 와요.

| 이벤트 | 저절로 오는 때 | 아무 날이나 직접 고르기 |
|---|---|---|
| 벚꽃 축제 | 4월 1일~20일, 놀이터가 봄일 때 | <SceneChips lang="ko" event="blossom" label="아무 날이나 직접 고르기" /> |
| 반딧불이 밤 | 7월 20일~8월 20일, 놀이터가 여름일 때 | <SceneChips lang="ko" event="fireflies" label="아무 날이나 직접 고르기" /> |
| 한가위 보름달 | 9월 8일~10월 15일, 놀이터가 가을일 때 | <SceneChips lang="ko" event="harvest" label="아무 날이나 직접 고르기" /> |
| 겨울 별빛 | 12월 1일~31일, 계절과 상관없이 | <SceneChips lang="ko" event="lights" label="아무 날이나 직접 고르기" /> |
| 새해 | 1월 1일~7일, 계절과 상관없이 | <SceneChips lang="ko" event="newyear" label="아무 날이나 직접 고르기" /> |

| 이벤트 | 놀이터에서 | 선물(그 날짜에만) |
|---|---|---|
| 벚꽃 축제 | 꽃잎이 흩날리고 나비가 더 많이 나와요. 친구들이 모여 [꽃구경](#flower-viewing)을 해요 | 벚나무 묘목 |
| 반딧불이 밤 | 밤에 반딧불이가 더 많아지고, 잡을 수 있는 금빛 반딧불이가 나와요 | 수박 |
| 한가위 보름달 | 밤 호수에 달빛 잉어가 나와요. 직접 불러오면 보름달이 떠요. 저절로 올 때는 추석이나 중추절처럼 이벤트 기간의 첫 보름 앞뒤로 이틀씩 크고 노란 보름달이 뜨고, 다른 밤에는 그날의 달 모양 그대로예요 | 호박 |
| 겨울 별빛 | 나무마다 꼬마전구가 걸려 저녁부터 반짝여요 | 작은 크리스마스트리, 아기 순록, 산타 할아버지 차례로 |
| 새해 | 친구들이 새해 인사를 해요 | 연 |

- 장면 이름 옆에 이벤트 이름이 붙고, 그해 처음 볼 때는 시작을 알리는 카드가 떠요. 친구들도 그 이야기를 해요.
- 계절이 **자동**이면 날짜로만 이벤트가 와요. 달력의 이벤트가 먼저라서, 12월에는 어떤 장면을 골라도 겨울 별빛이 그대로예요.
- 금빛 반딧불이나 달빛 잉어처럼 이벤트 때만 나오는 물고기와 곤충은, 어느 쪽으로 왔든 이벤트가 열려 있으면 나와요.
- 이벤트 선물은 그 날짜 동안 선물이 올 차례마다 하나씩, 정해진 순서로 오고, 그때만 와요. 한 번 받은 선물은 계속 남고, 언제 오는지는 도감에 나와 있어요.
- 남반구에서는 컴퓨터의 시간대를 기준으로 벚꽃 축제, 반딧불이 밤, 한가위 보름달이 여섯 달 늦게 와요. 겨울 별빛과 새해는 날짜가 그대로예요.

### 12월

12월에 놀이터가 겨울이 아니면, 1월 7일까지 겨울로 보여 줄지 한 번 물어봐요. 그러겠다고 하면 고른 계절은 1월 8일에 돌아와요.

- 크리스마스트리, 아기 순록, 산타 할아버지는 12월 1일부터 1월 7일까지, 그리고 놀이터가 겨울일 때면 언제든 놀이터와 바탕화면에 나와요.
- 그 밖에는 보이지 않게 기다리고, 장식 12개에는 그대로 들어가요. 치우면 선물 상자로 돌아가요.

### 크리스마스 밤 {#christmas-night}

언덕 정원, 자연 정원, 호숫가 집에 작은 크리스마스트리를 꺼내 두고 이 장면을 맞추면, 어느 날이든 트리에 불이 켜지면서 커다란 트리로 자라나요.

<SceneChips lang="ko" :when="['season:winter', 'period:evening|night', 'weather:snow', 'gift:xmas_tree']" label="필요한 것" />

- 눈이 오는 동안 커다란 트리로 남아서 꼬마전구가 이따금 반짝여요. 눈이 그치면 작은 트리로 돌아가고, 다시 내리면 또 자라나요.
- 아기 순록과 산타 할아버지도 나와 있으면 밤에 함께 하늘을 올려다보고, 트리가 자랄 때마다 썰매가 달 앞을 지나가요.
- 바탕화면에 꺼내 둔 트리도 놀이터의 트리와 함께 자라나요.

### 크리스마스트리 꾸미기

크리스마스트리를 누르면 꾸밀 수 있어요.

- 하루에 세 개까지, 도감에서 찾은 꽃, 나무, 선물, 작은 발견을 걸어요. 물속 생물과 곤충은 물가와 풀밭에 남아 있어요.
- 걸린 것은 종류마다 다른 빛깔의 작은 장식이 되고, 가리키면 무엇인지 알려 줘요.
- 트리를 바꾸고 싶으면 카드에서 장식을 내려요. 그날의 세 개는 쓴 것으로 남아요.
- 장식은 놀이터의 트리와 커다란 트리에 걸려 있다가, 다음 12월에 빈 트리로 새로 시작해요.

### 꽃구경 {#flower-viewing}

벚꽃 축제가 열려 있으면 친구들이 키워 둔 벚나무 아래 모여, 올려다보며 1분쯤 이야기하다가 흩어져요.

| 방법 | 내용 |
|---|---|
| 알아서 | 맑은 날 아침부터 저녁까지 하루에 한 번. **가끔 자기들끼리 이야기해요**를 켠 때만 모여요 |
| 직접 부르기 | **놀기 → 함께 놀기 → 꽃구경**, 한 시간에 한 번. 이미 꽃구경 중이거나 놀이가 한창이면 버튼이 흐려져요 |
| 어디서 | 키워 둔 벚나무 아래. 없으면 소풍 돗자리나 놀이터 한가운데 |
| 일찍 끝날 때 | 다른 장소로 옮기거나 밤이 되거나 비가 오면요. 놀이, 낚시, 땅파기는 끊지 않아요 |

- AI를 연결한 친구는 자기 말로 꽃 이야기를 해요.
- 축제 기간 맑은 날 아침부터 저녁까지, 가끔 꽃잎 한 장이 친구 머리에 내려앉아요. 그 친구가 움직이거나 밤이 되거나 비가 올 때까지 머물러요. 꽃구경 중에는 꽃잎이 더 많이 떨어지고 머리에도 더 자주 앉아요.
- 떨어지는 꽃잎을 누르면 잡아요. 반짝이며 사라지고, 하루에 처음 잡는 꽃잎에는 친구가 소원을 빌어 줘요.
- 움직임 줄이기를 켜 두면 꽃잎이 떨어지지도 잡히지도 않지만, 친구들은 그대로 모이고 머리에 앉은 꽃잎도 그대로예요.

### 연말 편지

12월 26일부터 31일 사이 PlayPets를 처음 연 날, 가장 가까운 친구가 함께한 한 해를 담아 편지를 써요. 도감에 새로 채운 것, 같이 키운 나무, 얼마나 가까워졌는지, 만난 지 얼마나 됐는지를 이야기하고, 올해는 어땠는지, 내년에는 뭘 하고 싶은지 물어봐요.

- 놀이터에 우편함이 있으면 편지가 거기서 기다리고, 없으면 친구가 알려 줘요. 1월 7일까지는 장면 이름 옆의 **편지** 칩이나 놀이터 메뉴로 열어요.
- 200자까지 답장을 쓰거나 그냥 넘어가도 돼요.
- 1월 1일부터 7일 사이 처음 연 날에는 친구가 답장을 다시 가져와 응원해 주고, 다음 12월의 편지는 그 답장을 돌아봐요.
- AI가 연결된 친구는 자기 말로 편지를 쓰고, 다음 해 편지를 쓸 때 그 AI가 답장을 읽어요.
- 편지와 답장은 이 컴퓨터에 저장되고, 편지 카드에서 지울 수 있어요.

## 친밀도 <Since v="0.1.0" /> {#closeness}

친구 이름표의 하트가 얼마나 가까운지 보여 줘요. 친구 화면에서는 지금 단계, 다음 단계까지 남은 정도, 다음 단계에서 생기는 일을 볼 수 있어요.

| 단계 | 생기는 일 |
|---|---|
| 알아가는 사이 | 모든 친구가 여기서 시작해요 |
| 편한 사이 | 앱을 열 때와 한참 뒤에 돌아왔을 때 반겨 줘요 |
| 가까운 사이 | 가끔 [혼자 낚시](#fishing-on-its-own)를 가요 |
| 각별한 사이 | 추억의 선물을 가져와요 |
| 소중한 사이 | 이름표에 꽃이 피고, 가끔 나만을 위한 말을 해요 |

- 단계는 얼마나 가까운지만 나타내요. 어떤 사이인지는 [관계](./chat.md#relationship)에서 정해요.
- 놀이터가 보이는 동안 10분마다 함께 보낸 시간이 쌓이고, 하루에 한 시간 몫까지예요.
- 쓰다듬기, 간식, 대화, 물 주기, 낚시와 채집, 선물은 더 많이 쌓이지만 하루 몫까지예요. 쓰다듬기만으로는 그중 4분의 1까지만 채워요.
- 그래서 창을 켜 두기만 하거나 몇 분 마구 누른다고 빨리 친해지지 않고, 자리를 비워도 줄지 않아요.
- `state.json`의 `bonds`에 저장돼요.

## 땅파기와 나무

### 땅파기 {#digging}

1. **놀기 → 찾기 → 땅파기**를 골라요. 친구를 오른쪽 클릭해 **Clover에게 땅파기 부탁하기**(그 친구 이름으로)를 고르면 그 친구가 먼저 가요.
2. 빈 땅을 눌러요. **Esc**를 누르면 취소돼요.
3. 친구가 걸어가서 땅을 파요. AI는 없어도 돼요.

- 지름길: 빈 땅을 오른쪽 클릭해 **여기 땅파기**를 골라요.
- 물, 가구, 나무뿌리 자리는 팔 수 없어요. 친구가 도착하기 전에 다른 일을 시키면 발견은 없어요.
- 도구는 내려놓을 때까지 손에 들려 있어요. 자리를 고를 때마다 쉬고 있는 친구가 가고, 방금 판 친구는 잠깐 쉬어요.
- 독 자리에 뜨는 띠에서 **나무 심기**나 **씨앗 심기**로 한 번에 바꿔 들어요. 띠의 닫기 버튼이나 **Esc**로 도구를 내려놓아요.
- 도구를 들고 있어도 호수와 생물은 가려지지 않아요. 물이나 생물을 누르면 도구를 내려놓으면서 낚시나 채집을 해요.

| 땅에서 나오는 것 | 규칙 |
|---|---|
| 꽃씨, 묘목, 작은 발견 25종 가운데 하나(**도감 → 작은 발견**), 또는 아무것도 없음 | 희귀한 발견이 나오면 모든 친구와 장소를 통틀어 24시간 동안 다음 희귀한 발견을 기다려요. 같은 땅은 24시간 동안 더 나오지 않아요. 친구마다 땅파기 사이에 8초를 쉬어요. 같은 것이 또 나올 수 있어서 다 모으는 데 시간이 걸려요 |

- 꽃씨는 20개, 묘목은 종류마다 20개까지 보관해요. 가득 찼다고 다른 것으로 바뀌지는 않아요.

### 나무 심기

1. 땅을 파서 묘목을 찾아요.
2. **놀기 → 정원 → 나무 심기**를 고르면 보관 수가 보여요. 벚나무, 단풍나무, 소나무, 참나무, 자작나무, 버드나무, 은행나무, 감나무, 대나무, 목련, 배롱나무, 메타세쿼이아가 있어요.
3. 가진 종류를 골라 빈 땅을 눌러요. 묘목을 하나 써요.

- 앱을 꺼 둔 시간도 쳐서 2시간이면 어린 나무, 12시간이면 다 자란 나무가 돼요. 다 자라면 **도감 → 나무**에 한 번 기록돼요.
- 장소마다 여섯 그루, 모두 합쳐 24그루까지예요. 나무는 심은 장소에 남아요.
- 끌어서 옮겨요. 오른쪽 클릭 → **정리하기**, 또는 **Delete**: 바로 정리되고 **되돌리기**로 6초쯤 되돌릴 수 있어요. 도감 기록은 남지만 묘목은 돌아오지 않아요.
- 가져온 배경은 흙을 쓸지 따로 정할 수 있어요.

### 눈 위의 발자국

겨울 놀이터에는 눈 위로 희미한 동물 발자국이 지나가요. 하루에 한 줄, 눈 내린 밤이 지난 아침에는 한 줄 더 나요(12월 26일부터 1월 7일까지는 하루 한 줄뿐).

- 발자국을 누르면(또는 Tab으로 옮겨 가 Enter) 쉬고 있던 친구가 킁킁대며 따라가요.
- 끝에서는 덤불 뒤로 꼬리가 빼꼼 나왔다가 사라져요. 그 자리에 작은 것이 묻혀 있고, 동물마다 좋아하는 발견이 달라요.
- 새 눈이 한 시간 쌓이면 발자국이 덮이고, 다음 날에는 사라져요.
- **도감 → 발자국**에는 따라가 보기 전까지 발자국만, 따라가면 꼬리와 이름이 보여요.

### 봄 새싹

놀이터가 야외의 봄일 때는 비 온 뒤에 새싹이 몇 개, 맑은 아침에는 하나가 올라와요. 한 번에 세 개까지 서 있고, 몇 시간 지나면 들어가요.

- 새싹을 누르면 선택한 친구나 가장 가까이에서 쉬는 친구가 가서 캐요.
- **도감 → 봄 새싹**에는 냉이, 쑥, 고사리, 산마늘, 죽순, 뱀밥, 아스파라거스, 곰보버섯 여덟 가지가 담겨요. 모으는 재미를 위한 것이고, 야생 식물 안내서는 아니에요.

### 동작과 옷

- Daisy, Clover, Pip, Miso는 사계절 내내 땅파기, 심기, 낚싯줄 던지기, 입질 기다리기, 낚아 올리기, 발견했을 때의 반응까지 전용 동작을 보여 줘요. 가져온 펫도 원래 동작 그대로 함께해요.
- Daisy, Pip, Miso는 봄과 가을엔 평상복을 입고 여름과 겨울엔 계절 옷으로 갈아입어요. Clover는 가을까지 청록색 멜빵바지에 밀짚모자 차림이고, 겨울엔 코트에 목도리를 두르고 니트 비니를 써요.

## 놀이 <Since v="0.1.0" /> {#games}

네 가지 놀이는 **놀기 → 함께 놀기**에 있고, 한 번에 하나씩 해요. 놀이 중에는 그 칸이 **숨바꼭질 끝내기**처럼 끝내기 버튼으로 바뀌고, 누르면 바로 끝나요. 끝날 때까지 다른 놀이와 **소풍 간식**, **씨앗 심기**, **나무 심기**는 꺼져 있고, 끝나면 친구들은 원래 자리로 걸어 돌아가요.

| 놀이 | 이렇게 놀아요 | 끝 |
|---|---|---|
| 숨바꼭질 | 친구들이 숨어요(15초 안에 자리에 못 간 친구는 그 자리에서 숨어요). 독 바로 위 안내에 **눌러서 찾기**, 찾을 친구, 아직 숨은 친구들이 차례로 떠요. 맞는 친구를 누르면 "들켰다!" 하며 뛰어나오고 안내가 다음 친구로 넘어가요. 다른 친구를 누르면 "아쉬워요, 그 친구가 아니에요" 알림만 뜨고 그 친구는 계속 숨어 있어요 | "모두 찾았어요!" |
| 산책 행렬 | 고른 친구가 맨 앞에 서고 나머지가 뒤로 줄을 서요. 줄이 다 서면 놀이터를 한 바퀴 돌아요 | "한 바퀴 끝!" |
| 술래잡기 | 친구가 둘 있어야 해요. 고른 친구가 술래가 되어(이름표에 "술래") 가장 가까운 친구를 쫓아요. 화면에서 겹치면 잡힌 친구가 새 술래가 되고, 잡은 친구는 잠깐 안전해요 | 정해진 시간이 지나면 "술래잡기가 끝났어요. 다들 잘 뛰었어요!" |
| 눈사람 만들기 | 놀이터가 겨울일 때. 친구 둘이 눈덩이를 굴리고, 세 개를 쌓아 눈사람을 만들어요([눈사람 만들기](#snowman)) | 눈사람이 서면 |

<Shot name="play-hide-and-seek" caption="숨바꼭질. 아래 바 위의 안내에 찾을 친구의 이름이 적혀 있어요." />

놀이 안내, 발견 카드, 알림처럼 놀이터가 알려 주는 건 모두 독 바로 위 그 자리에 나와요.

### 눈사람 만들기 {#snowman}

1. 놀이터가 겨울일 때 **놀기 → 함께 놀기 → 눈사람 만들기**를 눌러요. 가끔은 친구가 먼저 만들자고 하며 눈덩이를 굴리기 시작해요.
2. 친구 둘이 굴리는 눈덩이는 굴릴수록 커져요. 눈덩이를 누르면 같이 밀어 주고, 끌거나 방향키로 직접 굴려요. 지나간 자리에는 옅은 파란 자국이 남았다가 사라져요.
3. 눈덩이 세 개를 쌓으면 반짝이와 함께 눈사람이 완성돼요.
4. 모자, 목도리, 당근 코를 골라요. 나중에 바꾸려면 눈사람을 누르거나 메뉴에서 **꾸미기**를 골라요.

- 하루에 하나예요. 다시 하자고 하면 친구가 이미 만들었다고 말해요.
- 새 눈사람을 만들면 먼저 있던 눈사람은 녹아요. 친구가 곁에 있으면 작별 인사를 건네요.
- 눈사람은 놀이터가 겨울일 때만 놀이터에 있어요. 메뉴의 **바탕화면에 보이기**로 꾸민 모습 그대로 바탕화면에 내보내는데, 이때도 놀이터가 겨울일 때만 보여요. 치우면 녹아요.
- 놀이터에 장식이 12개 있고 눈사람이 없으면 친구가 놀이터가 가득 찼다고 말하고 시작하지 않아요.

## 작업 옆에 두는 창 {#a-window-beside-your-work}

창 가장자리나 모서리를 끌면 300 × 210까지 크기를 줄이고, 맨 위의 좁고 투명한 띠를 끌면 창이 움직여요. 위치와 크기는 기억해 두고, 크기가 어떻든 친구, 대화, 초대, 설정, 배경과 놀이 도구를 그대로 써요. 바탕화면 전체를 놀이터처럼 쓰려면 [바탕화면 모드](./desktop.md)를 켜세요. 창 크기와 상관없이 함께 써요.

<Shot name="mini" caption="작업 옆에 둔 작은 놀이터 창이에요." />

### 작은 창

너비가 640픽셀 이하이거나 높이가 480픽셀 이하면 작은 창이에요.

- 독이 숨어요. 포인터를 창 위에 올리거나 Tab으로 옮겨 가면 오른쪽 아래에 동그란 버튼이 보여요. 빈 배경을 오른쪽 클릭할 때와 같은 짧은 메뉴가 열려요: **배경과 분위기**, **놀기**, **친구와 설정**, **항상 위에 표시**.
- **Cmd/Ctrl + Shift + P**를 누르면 친구와 설정이 열려요.
- 패널 항목은 칸으로 보이고(이름이 길면 두 줄), 묶음 이름은 숨기고, 창 안에서 스크롤해요.
- 새 버전은 버전이 적힌 버튼 대신 점이 붙은 32픽셀 다운로드 아이콘으로 보여요. 접근성 이름에 버전이 들어 있고, 누르면 앱 업데이트가 열려요.

<Shot name="mini-chat" caption="작은 놀이터 창 안에서 대화하고 다시 작업으로 돌아가요." />

### 메뉴와 돌아가기

| 어디서 | 무엇을 하나요 |
|---|---|
| 친구 이름표 | 그 친구와 대화해요(마우스를 올리면 **Clover에게 말 걸기**처럼 알려 줘요) |
| 친구 오른쪽 클릭 | **말 걸기**, **놀이**(그 친구의 놀기 패널), **땅파기 부탁하기**(땅파기 도구를 들고 그 친구가 먼저 가요) |
| 빈 배경 오른쪽 클릭, 구석 버튼 | 마우스 옆에 짧은 실행 메뉴가 열려요. 창 안에 맞춰 뜨고 필요하면 스크롤돼요 |
| 친구, 꽃, 선물 | 오른쪽 클릭하면 저마다의 동작이 나와요 |
| 닫기, **Esc**, 바깥 클릭 | 풍경으로 돌아가요 |
| 배경과 분위기, 놀기 | 닫으면 곧바로 풍경으로 돌아와요 |
| 친구 화면, 친구 초대 | **뒤로**는 친구와 설정으로, **×**는 놀이터로 가요. 친구 초대는 상단에 가져오기를 보여 줘요 |
| 설정 | **뒤로**는 묶음에서 설정 목록으로, 목록에서 친구와 설정으로 가요 |

### 창 다루기

| 항목 | 어디에 | 무엇을 하나요 |
|---|---|---|
| **전체화면 보기** | **친구와 설정 → 창과 바탕화면** | 화면을 가득 채워요. 그동안 **이전 크기로 돌아가기**로 바뀌고 **Esc**로도 돌아와요(열린 패널이나 메뉴가 있으면 그것부터 닫아요). 크기, 위치, 항상 위에 표시가 그대로 돌아와요 |
| **항상 위에 표시** | **창과 바탕화면**, 짧은 오른쪽 클릭 메뉴, 트레이, macOS 보기 메뉴, **Cmd/Ctrl + Shift + M** | 놀이터를 다른 창 위에 둬요. 창 크기와 상관없고 기억해 둬요. Linux에서는 데스크톱에 따라 달라서 일부 Wayland 환경은 받아 주지 않으니, 창 관리 설정을 확인해 주세요 |
| **창 닫기** | **친구와 설정** | 놀이터를 트레이로 숨겨요. 바탕화면 친구와 에이전트 연동은 계속 돌아가요 |
| **PlayPets 종료** | **친구와 설정**, 트레이, macOS의 <kbd>⌘</kbd> <kbd>Q</kbd> | 바로 앱을 끝내요. 대화는 저장되지 않아요 |

### 창과 확인 창

- 친구 설정, 가져오기, AI 연결 창은 제목과 버튼을 고정해 두고 입력 영역만 스크롤해요. 도감과 확인 창은 각자 본문 안에서 스크롤해요.
- 확인 창은 차분하게 묻고 다른 버튼은 **취소**예요. 되돌릴 수 없는 것을 잃을 때만 빨갛게 묻고, 다른 버튼은 **그대로 두기**가 돼요. AI 연결 삭제, 친구 내보내기, 배경 삭제가 그래요.
- 모든 확인 창에는 **닫기** 버튼도 있어요. 꽃, 나무, 선물은 묻지 않는 대신 **되돌리기**를 보여 줘요.

## 천천히 모으는 작은 공략

도감에는 물속 생물, 곤충, 꽃, 선물, 나무, 발자국, 봄 새싹, 작은 발견을 합쳐 169종이 있어요. 꺽지와 참게, 추운 밤의 귀한 철갑상어, 풀밭의 사마귀, 가을밤의 베짱이와 귀뚜라미를 찾아보세요. 민들레, 나팔꽃, 꽃무릇, 팬지를 키우고, 은행나무나 감나무를 심고, 땅속에서 솔방울, 종이배, 가끔은 네잎클로버를 캐 보세요. 친구가 가져올 물레방아, 해먹, 장독대 자리도 비워 두세요.

### 기다림이 필요한 것

- 도감을 다 채우는 건 하루나 일주일짜리 목표가 아니고, 언제 끝날지도 정해져 있지 않아요.
- 일반 선물 21종은 저마다 다른 날에 와요.
- 이벤트 선물 일곱 종류는 달력 곳곳에 흩어진 이벤트 날짜에만 와서, 언제 시작했느냐에 따라 다 모으는 데 몇 달이 걸리기도 해요. 계절을 직접 골라 불러오는 건 이벤트의 장면이지 선물이 아니에요.
- 꽃은 심고 4시간, 나무는 12시간이면 다 자라요. 앱을 꺼 둔 시간도 쳐요.

### 요령

| 대상 | 요령 |
|---|---|
| 물고기 | 비가 오면 메기와 뱀장어를 만나기 쉬워요. 그 물고기가 나오는 계절과 시간대를 고르고, 발견 안내에서 무엇이 낚일지 살펴보세요 |
| 이벤트 물고기와 곤충 | 이벤트의 계절을 고르고 이벤트에 맞는 시간대와 날씨로 맞추면, 금빛 반딧불이나 달빛 잉어가 아무 날이나 나올 수 있어요 |
