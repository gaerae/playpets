# 친구와 대화하기

초대하고 노는 건 AI 없이도 다 돼요. 친구와 대화하려면 AI를 하나 연결하면 돼요. 연결하기 전에는 대화 창에 "같이 놀 준비 완료! 대화하고 싶을 땐 AI를 연결해 주세요."라는 말과 **AI 연결하기** 버튼이 나와요.

## AI 연결 종류 <Since v="0.1.0" />

| 종류 | 어떻게 대화하나 | 비용과 데이터 |
|---|---|---|
| Claude Code | 이 컴퓨터에 로그인된 Claude Code를 써요 | 구독 로그인은 구독 한도를 쓰고, API 키 로그인은 API 요금이 나가요 |
| Codex CLI | 이 컴퓨터에 로그인된 Codex CLI를 써요 | ChatGPT 로그인은 플랜 한도를 쓰고, API 키 로그인은 API 요금이 나가요 |
| Ollama | `http://127.0.0.1:11434`의 Ollama로 모델을 써요 | 로컬 모델은 대화가 내 컴퓨터에 머물고 서버 추론 요금이 없어요. 클라우드 모델은 그 서비스의 조건을 따라요 |
| OpenAI API | API 키로 OpenAI에 연결해요 | 대화 내용이 OpenAI로 가고, API 사용료가 생길 수 있어요 |
| Grok API | xAI API 키로 Grok에 연결해요 | 대화 내용이 xAI로 가고, API 사용료가 생길 수 있어요 |
| OpenAI 호환 서버 | 서버 주소와 API 키를 직접 넣어요 | 대화 내용이 그 서버로 가고, 사용료가 생길 수 있어요 |

연결 창에는 종류마다 무엇이 필요한지 적힌 카드가 있어요. 이 컴퓨터에서 Claude Code, Codex CLI, Ollama를 찾으면 그 카드에 **설치됨**이 붙고 미리 골라져 있어요. 하나도 못 찾으면 아무것도 골라 두지 않아요. 카드를 고르면 그때 입력칸이 나타나요.

- API 키는 이 컴퓨터의 보안 저장소(macOS 키체인, Windows 자격 증명 관리자, Linux Secret Service)에만 두고, 설정 파일에는 넣지 않아요.
- 구독으로 로그인한 CLI 대화는 API 요금이 따로 나가지 않아요.
  - 대신 다른 CLI 작업과 같은 사용 한도를 쓰고, 플랜 한도도 그대로 적용돼요.
  - 따로 사는 크레딧에는 비용이 들 수 있어요.
- 인터넷 없이 대화하려면 내려받은 로컬 Ollama 모델을 고르면 돼요. Ollama 클라우드 모델은 대화가 그 서비스로 가요.

## 연결 만들기 <Since v="0.1.0" />

1. **친구와 설정 → 친구와 대화**에서 **친구** 화면을 열고 대화할 친구를 골라요. 친구가 여럿이면 이름 자리가 목록으로 바뀌어요.
2. 대화 창의 **AI 연결하기** 버튼을 누르거나, 입력창 왼쪽 아래 AI 목록에서 **＋ 새 AI 연결…**을 골라요.
3. **AI 종류**에서 카드를 고르고, 종류에 따라 서버 주소나 API 키를 넣어요.
4. **모델 이름**을 고르거나 직접 적어요.
   - 입력칸을 누르면 그 AI가 주는 모델 목록이 떠요. 키나 주소가 필요한 종류는 먼저 넣어야 목록이 떠요.
   - Claude Code와 Codex CLI: 비워 두면 기본 모델을 써요. `sonnet`처럼 짧은 이름을 적으면 늘 최신 버전에 연결돼요.
   - Ollama와 API 연결: 모델 이름을 꼭 적어야 해요.
5. **저장하고 연결**을 눌러요. AI가 없는 다른 친구가 있으면 "아직 AI가 없는 다른 친구에게도 이 AI를 써요" 스위치가 켜져 있어서, 모두가 한꺼번에 말할 수 있어요.

꼭 먼저 연결하지 않아도 괜찮아요. AI가 없는 친구에게 말을 써서 보내면 연결 창이 열리고, 연결이 끝나면 그 말이 친구에게 가요.

처음 켰을 때 이 컴퓨터에 Claude Code나 Codex CLI가 있으면 놀이터의 시작 카드에 그 이름이 나와요. **바로 연결**을 한 번 누르면 키 없이 모든 친구에게 붙어요. 친구가 둘 이상이면 연결하자마자 서로 이야기를 시작해요.

연결은 한 친구만 쓰는 게 아니에요. 한 번 만든 연결을 다른 친구도 같이 쓰고, 친구마다 AI 목록에서 다른 연결을 고르면 저마다 다른 AI로 대화해요.

- 연결을 고치거나 지우는 곳은 두 군데예요.
  - 친구 이름 옆 **⋯** 메뉴의 **AI 연결 설정**: 여기서 연 연결은 그 친구가 써요.
  - **친구와 설정 → 설정 → 친구와 AI**에서 그 연결의 **편집**: 모든 연결이 모여 있고, **AI 연결하기**로 새 연결도 만들어요. 양식은 그 자리에서 펼쳐지고, 여기서 고쳐도 친구가 그 연결로 옮겨 가지 않아요.
- 연결을 지울 때는 한 번 물어봐요. 저장된 키도 함께 지워지고, 그 연결로 대화하던 친구는 AI 없이 놀아요.

## 대화하기 <Since v="0.1.0" />

- 아래 입력칸에 쓰고 Enter를 눌러요. 줄을 바꾸려면 Shift+Enter를 눌러요.

AI가 있는 친구와 아직 대화를 시작하지 않았다면 "오늘 뭐 했어?" 같은 첫마디가 몇 개 보여요. 하나를 누르면 바로 보내져요.

메신저처럼 친구가 말할 차례마다 그 친구의 그림이 앞에 붙어요. 답을 기다리는 동안에는 "생각하는 중이에요" 말풍선이 뜨고, ■ 버튼을 누르면 멈춰요. 답은 놀이터에 있는 친구 머리 위에도 말풍선으로 떠요.

- 이름 옆 **⋯** 메뉴의 **대화 비우기**를 누르면 이 친구와 나눈 대화가 모두 지워져요. 이름과 성격은 그대로예요.
- 대화 기록은 메모리에만 있어요. 앱을 끄면 사라지고 파일로 남지 않아요.
- 대화창에는 친구마다 최근 메시지가 500개까지 남아요. 친구가 대답할 때는 그중 최근 24개를 기억해요.

## 성격 정하기 <Since v="0.1.0" />

성격은 친구가 답할 때의 말투와 태도예요. 정하는 방법은 두 가지예요.

| 방법 | 내용 |
|---|---|
| **친구 설정**에서 직접 쓰기 | "츤데레지만 칭찬에 약해요. 반말로 짧게 대답해요."처럼 적으면 돼요. 저장하면 다음 대화부터 반영돼요 |
| 대화 중에 말하기 | "이제부터 반말로 해 줘"처럼 말하면 친구가 성격으로 저장해요. "친구의 성격을 저장했어요" 알림이 뜨고, 친구 설정에서 확인해요 |

## 관계 정하기 <Since v="0.1.0" />

친구 설정의 **관계**에서 이 친구가 나에게 어떤 사이인지 골라요. 카드마다 어떤 말투인지 적혀 있어요.

- 친구(기본)
- 연인
- 든든한 선배
- 장난꾸러기 동생

친구 화면에서 이름 옆 관계 칩을 누르면 이 카드가 바로 열려서, 한 번에 바꿀 수 있어요.

관계에 따라 친구의 말투와 나를 부르는 호칭, 안부를 묻는 방식이 달라져요. 친구들끼리 대화할 때도 서로의 관계를 알아요. 연인, 선배, 동생은 AI가 없어도 반겨 줄 때, 더 가까워졌을 때, 마음을 전할 때 자기만의 말투로 말해요.

**나를 부르는 말**에 "자기야"나 내 이름을 적으면 친구가 그렇게 불러 줘요. 입력칸의 예시는 관계에 맞춰 바뀌어요.

Codex 펫에는 사람 모양 캐릭터가 많아서 연인이나 선배로 두기 좋아요. 관계 안에서 어디까지 말하는지는 앱이 아니라 연결한 AI의 정책을 따라요.

## 함께 대화 <Since v="0.1.0" />

AI가 연결된 친구가 둘 이상이면 입력창 아래쪽에 **친구 부르기**가 나와요.

1. 펼쳐서 함께 이야기할 친구를 눌러요. 3명까지 고를 수 있어요.
2. 메시지를 보내면 지금 친구가 먼저 답하고, 고른 친구들이 차례로 이어서 답해요. 저마다 자기 AI와 성격으로 말해요.
3. 새 메시지 없이 친구들끼리 이야기를 이어 가게 하려면 **놀기 → 함께 놀기**에서 **수다 떨기**를 눌러요. AI가 있는 친구들이 지금 시간과 날씨를 두고 한 바퀴 이야기하고, 그 말이 놀이터에 말풍선으로 떠요.

친구 이름 아래 작은 칩에는 이 친구에게 보고하는 코딩 에이전트가 보여요(담당, Claude Code). 놀이터에서는 친구들끼리 나누는 이야기가 말풍선으로 보여요.

## "뭐 하고 있었어?" <Since v="0.1.0" />

[코딩 에이전트 연동](./agents.md)을 해 두면 에이전트가 최근에 한 일을 친구가 기억해요. 대화에서 "뭐 하고 있었어?"라고 물으면 그 작업 이야기를 자기 말로 들려줘요.

이 연동은 대화에 쓰는 AI 연결과 따로 움직여요.
